# 몬스터

몬스터별 실루엣, 색, 크기, 발 위치와 Unity 적용 규격을 기록합니다. 기존 제작본의 승인 상태와 게임 내 적용 상태는 각각 확인합니다.

전투 패턴 논의용 문서: [잉크 잔형 공격 패턴 HTML](attack-patterns.html). 이미지가 내장된 단일 파일이므로 다운로드한 뒤 브라우저에서 열 수 있다. 각 몬스터의 두 패턴은 제안이며 승인된 게임 규칙이 아니다.

## 동식물형 잉크 잔형 · 원화 탐색

2026-10-23 제작한 1차 **미승인 시안**이다. 첨부된 맵은 출현 환경의 감각만 참고했다. 몬스터의 해부학이나 장식에 맵의 건축 요소를 직접 옮기지 않았다. 현대적인 거리에서 마주칠 수 있는 종을 바탕으로, 종이 조각·붉은색·동양화풍의 새 형상보다 검은 잉크의 덩어리와 흐름을 우선했다. 형태와 설정을 고른 뒤 큰 픽셀·적은 색의 화풍으로 옮긴다.

| 시안 | 실루엣 탐색 | 상태 |
|---|---|---|
| [잉크 들개](concepts/ink-stray-dog-v1.png) | 낮은 어깨, 큰 앞발, 웅덩이로 풀리는 뒷몸 | 미승인 |
| [잉크 쥐](concepts/ink-rat-v1.png) | 낮은 등, 큰 귀, 고리처럼 휘는 긴 꼬리 | 미승인 |
| [잉크 나방](concepts/ink-moth-v1.png) | 넓은 날개와 커다란 빈 무늬, 작은 몸통 | 미승인 |
| [잉크 담쟁이](concepts/ink-ivy-v1.png) | 낮게 퍼진 덩굴, 위로 휘어 든 긴 줄기 | 미승인 |

종명은 작업용이다. 크기, 공격 방식, 출현 위치, 실제 게임 적용 여부는 결정하지 않았다. 생성 시안은 단색에 가까운 검은 액체 잉크, 젖은 붓자국, 지워진 빈 공간, 최소한의 회색 강조를 공통 기준으로 요청했다.

### 동물형 2차 시안 · 정체를 암시하는 얼굴

얼굴이 너무 선명하다는 피드백에 따라 눈·주둥이·촉각을 잉크 속으로 흩어지게 했다. 원형은 자세와 일부 특징으로만 짐작하도록 조정했다. 1차 시안은 위 링크에 보존한다.

| 시안 | 조정점 |
|---|---|
| [들개로 보일 듯한 잔형](concepts/ink-stray-dog-v2.png) | 얼굴 절반이 무너지고 눈은 빈 공간만 남음 |
| [쥐로 보일 듯한 잔형](concepts/ink-rat-v2.png) | 긴 꼬리는 유지하고 눈·수염·이빨을 지움 |
| [나방으로 보일 듯한 잔형](concepts/ink-moth-v2.png) | 날개는 유지하고 머리의 곤충 얼굴을 덜어냄 |

### 큰 픽셀·적은 색의 화풍 시안

사용자가 말하는 “픽셀화”와 “단순화”는 이 화풍으로 변환한다는 뜻이다. 동물형은 위 2차 원화, 담쟁이는 1차 원화를 기준으로 제작했다. 검정·회색·흰색 계열의 큰 픽셀 덩어리로 실루엣을 정리하고, 불분명한 얼굴을 유지했다.

| 쥐로 보일 듯한 잔형 | [보기](pixel-concepts/ink-rat-pixel-v1.png) |
| 나방으로 보일 듯한 잔형 | [보기](pixel-concepts/ink-moth-pixel-v1.png) |

이 파일은 화풍 비교용 이미지다. 실제 게임 스프라이트의 해상도, 투명 배경, 애니메이션 프레임, 피벗은 아직 정하지 않았다.

#### 2차 단순화 · 128px 가독성 검토
