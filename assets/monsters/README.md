## 동식물형 잉크 잔형 · 원화 탐색

2026-10-23 제작한 1차 **미승인 시안**이다. 첨부된 맵은 출현 환경의 감각만 참고했다. 몬스터의 해부학이나 장식에 맵의 건축 요소를 직접 옮기지 않았다. 현대적인 거리에서 마주칠 수 있는 종을 바탕으로, 종이 조각·붉은색·동양화풍의 새 형상보다 검은 잉크의 덩어리와 흐름을 우선했다. 형태와 설정을 고른 뒤 큰 픽셀·적은 색의 화풍으로 옮긴다.

종명은 작업용이다. 크기, 공격 방식, 출현 위치, 실제 게임 적용 여부는 결정하지 않았다. 생성 시안은 단색에 가까운 검은 액체 잉크, 젖은 붓자국, 지워진 빈 공간, 최소한의 회색 강조를 공통 기준으로 요청했다.
