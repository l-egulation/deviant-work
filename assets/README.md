# 에셋 디자인 작업 공간

이 폴더는 Deviant의 캐릭터·몬스터·배경/맵 시각 에셋을 작업하고 검토하기 위한 공간입니다. Unity 본 게임과 팀의 승인 에셋은 별도 SSAFY 저장소·공유 Drive에서 관리합니다. 이 폴더에 파일이 있다는 사실만으로 게임 적용이나 최종 승인을 뜻하지 않습니다.

| 폴더 | 범위 |
|---|---|
| `characters/` | 주인공·NPC의 외형, 실루엣, 색과 장비의 시각 기준 |
| `monsters/` | 몬스터 외형과 크기·접지 기준 |
| `environments/` | 배경, 지형 타일, 맵의 시각 구성 |

## 작업 순서

1. 대상별 폴더를 만들고 레퍼런스의 출처와 현재 상태를 기록합니다.
2. 시안과 승인본을 분리합니다. 승인한 사람·날짜·범위를 기록하기 전에는 `확정`으로 표시하지 않습니다.
3. 게임 적용용 파일에는 이미지 크기, 투명도, PPU, 피벗·발 위치, 프레임/타일 순서, 사용 씬과 원본 경로를 함께 기록합니다. 세부 수치는 대상의 현행 Unity 규격을 확인한 뒤 적습니다.
4. 실제 게임 화면에서 크기·접지·클리핑과 배경 대비를 검토합니다. 모션·이펙트 담당과는 필요한 파츠, 부착점, 피벗, 타이밍 자료만 공유합니다.

현재 제작 대상과 스타일은 [팀 저장소](https://lab.ssafy.com/s15-final/S15P31F109)의 최신 기획·아트 자료를 먼저 확인합니다. 2026-10-12 이전의 작업자·마공학 공구 디자인은 제작 과정의 참고 자료이며 현 세계관의 확정 외형이 아닙니다. 이미지가 공유 Drive에만 있는 경우 Git의 문서·해시 목록과 실제 이미지를 함께 확인합니다.

작은 참고 이미지와 검토용 미리보기는 Git에 둘 수 있습니다. 대용량 원본, 에셋 ZIP, Unity 빌드는 이 저장소에 바로 복사하지 않고 전달 방법을 먼저 정합니다. 외부 자료는 출처와 사용 범위를 기록합니다.
