# 컨셉 아트

현재 방향은 `A-C-pixel-concept.png`의 **C**를 출발점으로 한 검은 잉크 인간형 + 와인색 어깨천 + 황동색 눈입니다. 실제 픽셀 모션은 상위 `basic-motions/`에 있습니다.

![A/C](A-C-pixel-concept.png)

`exploration-*.png`는 이전 슬라임·전신 무기 변형·인간형 탐색 기록입니다. 컨셉 이미지 보존용이며 채택안이나 구현 가능한 프레임 시트로 취급하지 않습니다. 해당 시기의 실패 모션은 포함하지 않았습니다.
