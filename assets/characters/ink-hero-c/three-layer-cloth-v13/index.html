몸체 + 로브 + 목도리

원본 실루엣과 C 색감 · 세 묶음으로 관리하는 의상 변형

실시간 의상 움직임 시안
대기구매 에셋 Idle옷의 관성 켜짐

자동으로 대기 → 달리기 → 급정지 → 가라앉기를 반복합니다. 방향키를 누르면 직접 조작하고, 놓으면 멈춥니다. 왼쪽은 같은 프레임의 구매 원본입니다.

3개의 관리 레이어

몸체, 두건·소매를 포함한 로브, 목둘레·꼬리를 포함한 목도리. 끝부분을 별도 조각으로 떼어 이동시키지 않습니다.

두 종류의 움직임

구매 에셋의 자세로 몸을 움직이고, 프레임별 머리·어깨·손 위치에 옷을 맞춥니다. 그 위에 끝부분의 작은 관성 변형을 더합니다.

가벼운 변형 방식

고정부는 그대로 따라가고, 자유로운 끝으로 갈수록 스프링 영향을 늘립니다. 관성을 끄면 몸을 따라가는 기본 옷만 비교할 수 있습니다.

조사 결과와 구현 범위

Unity Sprite Skin은 뼈대와 가중치를 요구합니다. Magica Cloth 2의 공식 2D 가이드는 Unity 2D Animation과 BoneCloth 사용을 설명하므로 PNG만 넣는 무설정 방식으로 보기는 어렵습니다.

이 시안은 구매 에셋 Idle/Run의 몸 포즈를 사용하며, 원본 C 의상 이미지를 고정점과 영역별 변형으로 맞춥니다. 수작업 부착 위치 데이터가 필요합니다. 완전한 천 충돌, 전투 자세 보정, Unity 통합은 포함하지 않습니다. 원본 에셋에 전용 급정지가 없어 Run에서 Idle로 전환합니다.
