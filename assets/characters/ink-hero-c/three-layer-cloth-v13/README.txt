몸체 / 로브 / 목도리 — 세 묶음 모션 시안 v13

preview.html 하나를 브라우저에서 열면 실행됩니다. 다른 컴퓨터에 가져가도 동작합니다.
방향키 누르기: 달리기 / 놓기: 급정지 / Space: 정지 / 자동 시연 재시작.
기본 몸체·로브 전체·목도리 전체를 개별 표시하고, 관성 유무를 비교할 수 있습니다.

에셋
assets/body.png, assets/robe.png, assets/scarf.png : 128x128 같은 좌표의 세 관리 원본.
character-three-layers.aseprite : 정적 대기 자세3레이어. 합성하면 v11 디자인과 정확히 일치.
design-static.png : 세 레이어 합성 확인본.
assets/idle-* 및 run-* : 구매 에셋에서 가져온 동작 데이터. 관리 의상 레이어와 별개.
content.json : 몸 모션, 수동 부착 위치, 로브/목도리 내부 변형 영역.
cloth.js : 영역별 변형과 스프링. app.js : 입력·재생·겹침 처리.
RESEARCH.txt : 공식 자료를 확인한 적용 방법 비교.

모션 설명
구매 Idle10장/Run8장의 몸 동작과 원본 재생시간을 사용합니다.
C 디자인과 비율이 다른 몸체에 맞추므로 정적 대기 합성본과 움직이는 입힘 결과는 동일한 픽셀 외곽이 아닙니다.
원본의 큰 얼굴과 두건은 유지하고, 몸체는 구매 모션을2배 정수 확대해 사용합니다.
손의 부착 위치를 프레임별로 맞추며, 소매 아래의 팔은 가려서 처리합니다.
로브·목도리는 조각 전체를 따로 지연시키지 않고 내부 위치별로 변형량을 조절합니다.
급정지 전용 몸 클립은 없어서 기존 Run에서 Idle로 전환합니다.

검증
세 관리 레이어의 정적 합성은 기존 C 디자인과 RGBA 완전 일치.
Aseprite 레이어를 바이너리로 다시 읽어 PNG와 동일한지 검증.
브라우저 이미지 로드/자동 전환/좌우 이동/정지/관성 오버슈트/감쇠/실행오류 없음 확인.
preview-motion.gif는 실제 브라우저 시연6초를20fps로 저장한 것입니다.

범위와 한계
독립 브라우저 동작 시안입니다. Unity 실행/이식은 아직 하지 않았습니다.
단일 이미지에 옷을 입히면 모든 자세가 자동 완성되는 방식은 아닙니다.
팔과 로브가 크게 겹치는 자세는 프레임별 보정이 더 필요할 수 있습니다.
옷 충돌/몸 관통 방지/전투 동작/새 급정지 몸 모션은 이번 범위 밖입니다.
부착 위치와 영역 정보를 유지하면 의상 색 변경에는 재사용할 수 있으나 실루엣이 크게 바뀌면 다시 맞춰야 합니다.
이전 시안은 보존하고, 개인 레포의 별도 three-layer-cloth-v13 폴더에서 공유합니다.
