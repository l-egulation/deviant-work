# 모션 실험실

모션 자연스러움 실험을 쌓는 곳입니다. 이 폴더의 PNG·GIF·WebP·JPG·Aseprite·PSD·MP4는 **Git LFS**로 올라갑니다. 기기마다 `git lfs install`을 한 번 실행해야 합니다.

## 규칙

- 실험마다 폴더를 하나 만듭니다: `YYYY-MM-DD-<주제>/` (예: `2026-11-04-hood-scarf-idle/`)
- 폴더마다 `README.md`에 다음을 적습니다.
  - 목적: 무엇이 부자연스러웠고, 무엇을 확인하려 했는지
  - 방법: 쓴 도구·설정, 원본 동작
  - 결과: 비교 GIF 링크(전후, 크기 비교)
  - 판단: 채택 / 다시 시도 / 폐기, 그리고 이유
- 채택한 방법은 [결정 기록](../../docs/decisions.md)에도 남깁니다.
- 실패한 실험도 지우지 않습니다. 판단에 "폐기"라고 적어 둡니다.
