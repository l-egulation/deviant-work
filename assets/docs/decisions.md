## 2026-11-03 · 새 실험은 work/motion-lab에, 이미지는 LFS로

- 결정: 새 모션 실험은 `work/motion-lab/YYYY-MM-DD-<주제>/`에 쌓는다. 이 폴더와 `work/monsters/`·`work/environments/`의 이미지·Aseprite는 Git LFS로 올린다. 기존 이미지는 기록을 다시 쓰지 않고 일반 Git으로 둔다.
- 이유: 중간 작업물을 남기면서 레포가 무거워지는 것을 막기 위해. 기존 기록을 다시 쓰면 두 기기 로컬을 새로 받아야 한다.
- 근거: 사용자 결정, [레포 구조 설계](../../docs/specs/2026-11-03-repo-structure-design.md) 5.5
- 상태: 현행
