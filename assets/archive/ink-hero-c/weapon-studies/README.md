# 무기 모션 적용 연구

기존 구매 에셋의 자세와 C 캐릭터 의상을 재사용한 가능성 검토용입니다. Unity 적용·실제 판정·최종 VFX가 아닙니다. 기본검의 실제 전투 검토는 옆 `sword-combat/`가 최신입니다.

- `*.aseprite`: 편집용 레이어 파일.
- `이름-NN.png`: 합성 프레임.
- `-body`, `-weapon`, `-trail`: 몸·무기·궤적 분리 PNG.
- `c-weapons-v7-timings.json`: 기본검과 레이피어 타이밍.
- `c-weapons-v8-timings.json`: 추가 6종 타이밍.
- `additional-weapons-scope.json`: 무기별 미완료 항목.

구매 원본 비교용 PNG는 업로드에서 제외하여 타이밍 JSON의 `original` 필드도 제거했습니다. `source`와 `source_frame`은 원본 동작/프레임 추적용 메타데이터입니다.

망치·대검은 양손 지지와 무게 이동, 방패는 가드 자세, 수리검·폭탄은 손을 펴는 릴리스 자세를 보정해야 합니다. 발사기는 총구 효과·소리가 없습니다. 투사체 궤적은 시각 연구로 게임 유닛/충돌에 연결되지 않았습니다. 지적된 채찍·단검 시안은 이 폴더에서 제외했습니다.
