# Deviant 시네마틱 티저 · 공통 스타일 블록

T1에서 선택한 B 화풍을 적용한다. 영상 생성 프롬프트에 아래 공통 블록을 그대로 사용한다. `@hero`는 T3에서 만들고 T6에서 등록할 주인공 기준 에셋이다.

## 공통 블록 · L1

```text
Pixel-inspired 2D illustration, flat color planes with subtle pixel texture, crisp clean outlines, soft painterly light. A quiet rural village in a world made of warm paper and ink.
Character consistency: keep @hero exactly as in the reference — cream hooded cloak, teal scarf, same face, proportions and silhouette in every shot.
Light: soft late-afternoon sunlight, warm ivory highlights, lavender-grey shadows.
Motion: hair, hood, scarf, laundry and chimney smoke always move gently; nothing freezes.
Camera: simple and steady — static, slow dolly-in, slow pan, wide, close-up only.
No text, no letters, no logos, no watermark, no channel bug in any corner.
```

## L2 · 지워진 스케치

```text
Everything is drawn as an unfinished sketch: warm ivory paper, confident graphite contours, sparse diagonal hatching, no color.
```

## L3 · 잉크의 순간

```text
Near-monochrome: dense ink #221C18 bleeding through paper, almost no light.
```

## 적용 메모

- B의 부드러운 공간감과 카메라 움직임을 참고한다. 주인공의 세부 디자인은 승인된 F01 스프라이트에 맞추고, 배경의 잎과 바닥 질감은 팀의 단순한 마을 미술 방향에 맞춰 줄인다.
- L2와 L3은 해당 톤이 필요한 장면에 공통 블록과 함께 사용한다. 상충하는 조명·색상 표현을 모델이 어떻게 해석하는지는 실제 생성 때 확인한다.
