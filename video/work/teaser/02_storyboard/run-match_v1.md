# 마을→수로 달리기 접지 콘티 v1
상태: 사용자 검토 후보. 정밀 영상 키프레임 아님.

- 위 마을, 아래 수로. 오른쪽 달리기, 크림 후드·청록 스카프·먹색 얼굴 유지.
- 수로 물길을 뒤로 분리하고 앞쪽에 폭과 두께가 보이는 돌길 배치. 앞발 접지 및 접촉 그림자 확인: 접지 수정 통과.
- 두 인물의 좌우 위치·크기·달리기 위상은 유사. 합본에서 상대 발 높이는 위 약89%, 아래 약82%로 차이가 남아 정밀 매치 컷 기준은 불통과. 스카프·옷자락도 완전 동일하지 않음.
- 생성 결과 각 패널이 약3.6:1로 요청한16:9보다 가로로 길어짐. 단독16:9 키프레임 제작 시 구도와 좌표 재정렬 필요.
- 이번 콘티는 발판과 동작 선택용. 영상 연결 검증 전이며 추가 유료 생성 없음.
- 다음: 사용자 검토 후 동일16:9 프레임의 두 키프레임으로 정밀화. 도시 전투·지하 연구동·아지트는 아직 미착수.
