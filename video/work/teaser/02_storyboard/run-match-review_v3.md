## 모험 확장 제안 — 새 설정 확정 아님
마을 달리기 → 수로 달리기 → 수로에서 적 공격 회피와 짧은 반격 → 도시에서 이어지는 다른 공격 → 같은 측면 구도에서 멈춰 주변 단서 확인 → 지하 연구동 탐색 → 잠입 → 도서관 조우.
수로 적은 팀 resources 확인 후 후보 지정. 임의의 신규 적을 확정하지 않는다. 도시의 단서는 흔적/소품 관찰 정도로 두며 연구동과 연결되는 구체 설정은 미확정.
인물 중심 위치·몸 크기·발선은 동일 기준. 이동 속도·자세·배경만 변하며 여정을 압축한다. 발견 때 잠시 멈춰 전투와 리듬 차이를 만든다.
강조점: 잉크로 살아남는 순간 / 동작이 연결되는 장소별 전투 / 거대한 눈·손의 공간 공개. 전부 같은 강도로 빠르게 편집하지 않는다.
1분 이상 여부는 아직 미검증. 컷 수로 길이를 계산하지 않는다. 새 행동을 콘티로 확인한 뒤 임시 시간 배치로 길이·호흡 검토. 기존 공식 시간 목표 변경 없음.
