# 초반 연결 보완 v1
상태: 사용자 검토 후보. 2열3행 왼쪽→오른쪽 순서.
1. 마을 채움 소실 및 주인공 옷 끝 소실 시작.
2. 마을/주인공 거의 빈 윤곽. 잉크와 주인공은 분리.
3. 잉크가 손에 닿고 접점부터 먹색으로 변화. 나머지 몸은 아직 스케치.
4. 주인공만 실체 회복, 손을 가슴에 대고 숨 돌림. 마을 스케치 유지.
5. 손 펴고 몸 상태 확인.
6. 우물을 짚고 일어서며 오른쪽 출발 준비.

## 검수
인과와 회복 후 행동 전달은 콘티 기준 통과. 접촉 전 복원 없음, 배경 복원 없음. 5컷 확인 손이 크게 표현되었고 1컷 머리 옆 만화식 강조선은 최종본 제거 필요. 컷별 우물/주택 배치·인물 비율 차이 있음. 6컷은 거의 서 있는 자세로, 일어나는 연속 동작은 영상에서 검증 필요. 잉크 이동 방향은 정지 그림만으로 확정할 수 없어 영상에서 외부→몸 유입을 명확히 해야 함. 기존 공식 ID/시간 미변경.

다음: 사용자 검토 후 전체 통합본에 채택 반영. 아직 통합본 교체 안 함. 검 내려놓기/회수는 이후 별도 연결 작업.
