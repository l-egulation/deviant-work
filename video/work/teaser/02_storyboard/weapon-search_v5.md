# 연구동 v5 화풍·연결 검수
- 직접 비교: weapon-search_v4, lab-hideout_v3, side-montage_v10.
- 판단: 동일한 2D 일러스트 계열. 기존 v4는 주변보다 표면이 매끈하고 배관 광택이 강함. v5에서 넓은 붓결과 부드러운 명암으로 완화.
- 통과(콘티 수준): 기존 색조·선·짧은 팔 유지, 심한 바닥 잔얼룩 재발 없음. 위 두 컷 검의 가드·끝점 위치가 육안상 유사하게 정렬됨.
- 한계: 정확한 픽셀 정합은 미검증. 새 그림에서 옷에 미세 붓결 증가. 주변 기존 콘티 자체에는 과도한 돌 얼룩이 남아 있어 최종 전체 미술 정합은 별도 필요.
- 상태: 사용자 검토 후보. 영상 생성용 최종 키프레임 확정 아님.
