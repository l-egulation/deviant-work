# 탐색→엄폐 동작 연결 v3
상태: 사용자 검토 후보.
- 1컷 서랍 탐색 유지. 영상에서 손 멈춤→오른쪽 시선 전환→검 회수 연결 필요.
- 2컷 문 바로 옆 돌벽에 손을 짚고 웅크린 자세. 검은 몸 뒤로 둠. 고개 내밀기 시작.
- 3컷 같은 손 지지와 오른쪽 시선 유지, 어깨 너머로 시점 전환하며 고개 내밀기 계속.
- 편집: 2컷 고개 이동 도중 3컷으로 컷. 문 안 옷 스침/발소리를 앞 컷에 먼저 들려주는 것은 사운드 후보이며 아직 제작하지 않음.
- 검수: 벽·문 고리·촛불·손 지지·시선 방향의 반복으로 연결 개선. 2컷은 요청보다 가까운 중경으로 생성. 손 높이와 문 철물 각도/노출량은 정밀 일치 아님. 실제 움직임 전환 미검증.
- 세계관/등장인물 설정 추가 확정 없음. 다음 장면 미착수.
