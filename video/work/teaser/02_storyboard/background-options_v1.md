# 여정 배경·도서관 결말 비교 v1
상태: 연출 후보, 게임 맵·설정 확정 아님. 잘못 선택한 Higgsfield hero 컨텍스트는 사용하지 않음. 기존 로컬 승인 화풍 및 눈·손 이미지만 참조.
읽는 순서: 2열×3행, 왼쪽→오른쪽, 위→아래.

|위치|후보|역할·전환|
|---|---|---|
|상단 왼쪽|지워진 마을 지붕길|출발. 문틀이 화면을 가릴 때 다른 장소로 전환. 마을의 색이 복구됐다는 해석 금지|
|상단 오른쪽|돌다리·지하수로|달리기 매치 컷. 인물 크기·발선·오른쪽 진행 고정. 마을/수로 테마는 팀 문서 근거, 구체 구조는 시안|
|중단 왼쪽|무너진 회랑|공격 몽타주. 기둥 가림과 검 궤적을 전환 지점으로. 후반 미정 공간|
|중단 오른쪽|매달린 통로·서가 입구|전투에서 탐험으로 감속. 책장 반복을 마지막 장소의 시각적 예고로 사용. 후반 미정 공간|
|하단 왼쪽 A|끝없이 깊은 도서관|주인공 뒤에서 전진→시선 따라 위로 공개. 눈·손과 서가의 원근으로 압도감. 전진 여정과 연결하기 쉬움|
|하단 오른쪽 B|수직 도서관 심연|좁은 난간에서 멈춤→위쪽 눈→내려오는 팔과 거대한 손. 깊이·높이 대비 강조. 공간 방향과 팔 연결 검증이 더 어려움|

## 추천과 경계
- A를 마지막 장면 기본 후보로, B를 공간 규모 비교안으로 제안. 최종 선택은 사용자 검토 후.
- 마을→수로→회랑→서가는 여정 압축용 후보 배열. 실제 게임의 연속 지도·챕터 순서가 아니다.
- ‘운명을 쓰는 도서관’은 분위기 표현. 실제 운명 기록 시스템, 지워짐의 원인, 눈·손의 최종 보스 여부는 미확정.
- 눈은 위쪽 어둠/천장에 걸쳐 있고 동공에서 팔이 나오는 기존 방향 유지. 바닥 눈으로 바꾸지 않는다.
- 스케치화된 마을의 채움은 돌아오지 않는다. 다른 공간의 잔존 색상 비율은 별도 미술 후보.
- 이번 이미지는 배경과 카메라 구도 비교용. 캐릭터 크기·매치 컷 발선·여섯 펜촉 디테일을 최종 키프레임으로 보증하지 않는다.
- 단편/오프닝 길이, 공식 B/G/I ID, 크레딧 승인 규칙 유지. 유료 영상 생성 없음.


## 실제 시안 검수
board-backgrounds_v1.png: 여정 4종+도서관 2구도 비교 후보. 공통 종이·크림·라벤더 질감과 도서관 위쪽 눈→팔 연결 확인. A는 수평 깊이, B는 난간·수직 서가의 깊이 대비가 강함. 생성물은 배경 후보 수준으로만 통과.
미완료: 마을의 잔존 색이 요청보다 많아 완전 스케치 상태를 보완해야 함. 벽 종이에 글자처럼 보이는 미세 표시가 있어 최종본에서는 제거. 주인공의 노란 신발·비율 디테일은 기준 시트와 다름. 손가락/펜촉 개수는 작은 합본에서 최종 검증 불가, 확대 단독 시안에서 승인 v9 대조 필요. 최종 납품용 아트 아님.
