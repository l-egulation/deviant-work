# 전체 콘티 연결 검토 v1
2026-11-06 · 통합 HTML: storyboard-full-review_v1.html

## 검토 결론
현재 흐름은 생존→모험→잠입→거대한 존재 발견으로 성립한다. 최종 이미지 제작 전 보완 우선순위는 인과, 빠진 행동, 연속성 순서다. 모든 컷을 같은 구도로 맞출 필요는 없다.

## 구성
총18개 검토 카드: 기존 이미지17개 표시 구간 + 미제작 소실 과정1개. 이는 최종18컷 확정이 아니다. 원본 PNG는 변경하지 않고 HTML 표시 창으로 합본의 선택 부분만 보여준다. 카드용 화면비는 비교 목적이며 원본 합본은 페이지 하단에서 확인 가능. 이전 journey_v2의 하늘 눈/임시 몬스터 후반부는 사용하지 않는다. 수로 달리기 중복은 한 번만 사용.

## 연출 경계
- 기존 몸 확인 시안은 배경 정보가 약하다. 우물 가까이에서 회복했다는 위치를 유지한다.
- 배경 전환은 여정 압축. 실제 인접 지도나 순간이동 능력을 약속하지 않는다.
- 검의 생성/소멸 능력으로 연결 공백을 임의 해결하지 않는다.
- 연구동 소품, 로브 실루엣, 아지트 생활품은 미확정 연출 후보. 인신공양/몬스터 탄생을 직접 설명하지 않는다.
- 마지막 눈은 바닥, 긴 팔이 동공에서 솟음. 조력자와 분리. 정체·재난 원인·최종보스 여부 미정.
- 제목/로고는 나중 편집. 공식 B/G/I ID,80초/45초 목표 및 기존 I4 길이 규칙과 확장 결말의 충돌은 최종 컷표 단계에서 명시 조정 필요. 이번에는 초 단위 배분 미확정.

## 다음 제안
전체 흐름 사용자 검토 후, 가장 오래된 초반부를 먼저 보완: 평온→소실 과정→접촉/생존→손과 몸 확인→출발. 이후 개별 장면 미술/동작 기준 정렬. 현 단계에서 추가 유료 생성 필요 없음.
