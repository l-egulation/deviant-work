# 확장 티저 연결 콘티 v1
상태: 사용자 승인 방향을 시각화한 검토 초안. 초 단위 길이·최종 컷표·전투 설정 확정 아님.
핵심: 사라지던 사람이 잉크로 살아남고, 달리고 싸우고 탐험한 끝에 압도적인 존재와 마주한다.
첨부 보드: board-journey_v2.png. 왼쪽→오른쪽, 위→아래. 아래 번호는 이 보드의 설명 순번이며 공식 B/G/I 식별자를 대체하지 않는다.

## 두 매치 컷의 제작 기준
- 달리기 4→5: 같은 발이 같은 위치에 착지하는 프레임을 연결. 카메라가 주인공과 같은 속도로 이동해 화면 위치를 유지한다. 배경만 바뀌는 부분은 디졸브보다 하드 컷 우선.
- 공격 6→7: 칼끝이 같은 화면 좌표를 같은 방향으로 통과할 때 전환. 한 번의 베기가 다른 장소에서도 이어지는 듯 보이되 실제 순간이동 능력으로 묘사하지 않는다.
- 빠른 장면도 전부 동일 자세로 고정하지 않는다. 몽타주 구간만 앵커를 유지하고 탐험·조우에서는 구도와 속도를 풀어준다.
- 연속 재생 시 크기/발선 오차·역방향·무기 변경을 검사한다. 생성 보드가 정확한 매치 컷용 키프레임은 아니다.
- 첫 영상 시험 추천은 4→5 한 쌍. 달리기 위치 연결을 먼저 검증한 뒤 공격 복잡도를 늘린다. 이번 작업은 영상 생성 없음.

## 기존 문서와 관계
- 초반 사건만으로 끝나는 구성을 확장하는 방향은 사용자 승인. 기존 80초/45초 목표는 보존, 각 블록 배분은 재설계 전.
- 눈·손을 마지막 조우로 보여주는 방향은 승인. 기존 I4 1초 제한을 넘어서는 구체 길이는 이번에 정하지 않음. 최종 컷표에서 조우 컷을 별도 설계하고 관련 규칙 갱신 필요.
- 기존 B1~B5, G01~G09, I1~I5를 임의 증설/재정의하지 않았다. 신규 몽타주를 해당 생성 단위에 어떻게 배분할지는 콘티 승인 후.
- 게임 화면 없는 시네마틱이다. 게임 플레이나 완성된 적 모션을 확보했다고 표현하지 않는다.
