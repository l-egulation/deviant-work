# 연구동 검 내려놓기·회수 v1
상태: 사용자 검토 후보. 2열2행 왼쪽 위부터.
1. 서랍 옆에 앉아 검을 바닥에 놓음.
2. 검은 같은 쪽 바닥에 두고 천을 들어 탐색.
3. 오른쪽으로 고개를 돌리며 손잡이를 다시 잡음. 소리는 이후 편집 후보.
4. 검을 들고 낮은 자세로 오른쪽 이동, 바닥에 남은 검 없음.
검수: 검 내려놓기/회수 인과와 단일 검 유지 통과. 검 위치는 첫3컷 유사하나 4컷 바닥판이 오른쪽으로 이동해 엄밀한 고정 카메라 정합은 불통과. 1컷 서랍도 이미 열려 있으므로 서랍 열기를 별도 보장하지 않음. 손은 장면별 시점 변화로 좌우 검수 필요. 검 밝은 가장자리 잔여. 현재는 행동 연결 콘티이며 모든 단계를 독립 컷으로 사용할 필요 없음.
다음: 사용자 검토 후 초반 보완본과 함께 통합본 갱신. 영상 미생성.
