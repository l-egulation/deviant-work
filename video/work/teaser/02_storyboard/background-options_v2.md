## 제작 우선순위
1. 마을→수로 달리기 한 쌍을 별도 키프레임으로 만들고 위치·크기·발선 확인.
2. 도시→연구동 공격 한 쌍. 무기·적은 승인 게임 에셋 확인 후 삽입; 이번에는 배경과 자세만 비교.
3. 아지트에서 도서관으로 이어지는 탐험과 발견. 물리적으로 인접한 장소라는 설정은 확정하지 않음.
4. 개별 시험을 통과하면 전체 여정 콘티에 통합. 유료 영상은 견적·잔액 확인 후 승인 필요.

## 실제 에셋 근거
- resources/environments/village/adopted-background-20261104/asset.json: 사용자 승인 마을 배경, main-owned. sketch/market.png에서 차양·빨랫줄·낮은 주택 확인.
- resources/environments/waterway/asset.json: user-adopted-art. 메인 게임 흐름 통합은 deferred로 표기되어 있어 2스테이지 완성 상태로 단정하지 않음.
- resources/environments/maintenance-shops/preview/references/stage2-actual.png: 청록 벽돌·배관·철제 연결 발판 확인. 화면 외곽/캐릭터는 그대로 복제하지 않고 공간 요소만 참고.
- waterway/source/accepted-preview/actual-room.png는 톱니·석조 벽의 개별 리뷰 이미지여서 전체 수로 공간 근거로 단독 사용하지 않음.
- 도시·연구동·아지트는 이번 사용자 제안에서 출발한 미술 후보. 존재 이유, 사건 원인, 최종 보스 여부를 추가 확정하지 않음.

## 고정 조건
B 화풍 유지. 마을은 스케치 상태에서 복원하지 않음. 잉크 조력자와 거대 손은 분리. 마지막 눈은 바닥. 기존 공식 컷/생성 ID 및 러닝타임 미변경. 구 v1의 천장 눈 지시는 구안.

## 생성 결과 검수
배경 비교용 조건부 통과, 사용자 선택 전. 여섯 장소 구별과 달리기/공격 자세 반복 확인. 마을의 채움 소실 표현 개선. 수로는 B보다 타일 질감이 선명하며 도시와 마을 건축 구별은 추가 강화 가능. 연구동 공격 대상이 없어 현재는 동작 연결 예시. 아지트 문양은 요청한 여섯 펜촉 대신 다섯 펜촉으로 생성되어 채택 금지; 구체 문양 확정 전. 합본 도서관은 축약된 참고이며 승인 v4를 대체하지 않음. 달리기 발선과 공격 인물 위치는 정밀 불일치, 실제 매치 컷 키프레임 보정 필요.
