# 도서관 바닥 눈 단독 콘티 v1
상태: 사용자 검토 후보. 1672×941, 약16:9. 최종 영상/세계관 설정 확정 아님.
- 사용자 선택: 높은 난간에서 비스듬히 내려다보는 도서관, 왼쪽 아래 주인공, 바닥의 거대한 눈에서 올라오는 팔과 오른쪽 위 펜촉 손. B 화풍, 무광 잉크.
- 검수 통과: 바닥 눈의 동공→팔→손 연결, 여섯 개 분리된 펜촉, 작은 주인공과 깊은 서가 대비, 크림 후드·청록 스카프, 부드러운 종이 질감. 기존 하늘 눈 구성은 이번 결말 구도에서 대체.
- 검토 필요: 원본 참고보다 전체가 밝고 라벤더 안개가 강해 위협감은 약해졌다. 여섯 손가락이 비슷하게 평행 배열되어 손의 자연스러운 분리와 관절은 후속 확인. 영상화 시 손가락 수·팔 접점 유지 미검증. 일부 책 표면 장식은 최종 글자 검수 필요.
- 카메라 후보: 주인공 뒤 난간에서 느린 전진, 바닥 눈을 따라 팔과 손으로 시선 이동. 실제 이동 경로·컷 길이는 미확정.
