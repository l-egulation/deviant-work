# 측면 몽타주 v2 — 공격 연결 보완
상태: 사용자 검토 후보.
- 수로 달리기→도시에서 검을 들어 준비→내려베기와 적 반응→연구동에서 낮은 끝자세로 연결.
- 측면 카메라와 인물의 화면 영역 유지. 검의 밝은 날 테두리 제거, 먹색 유지.
- 검수: 준비 자세와 곡선 궤적으로 베기 가독성 개선. 칼끝과 적의 뿌리 접촉 확인. 마지막 낮은 자세가 이전 달리기 리셋보다 끝동작에 가까워짐. 콘티 전달 기준 조건부 통과.
- 남은 한계: 요청한 칼날 중간 접촉보다 끝부분 접촉으로 생성. 3컷 무기 손잡이에 황갈색 띠가 생김. 공격 컷의 몸 위치와 크기 미세 변화, 완전한 동작 정합은 미검증. 곡선은 콘티 동작 설명이며 실제 영상에서 그대로 고정 표시하지 않음.
- 실제 게임 공격/적 배치 확정 아님. 다음 장면으로 진행하지 않음.
