# 측면 몽타주 v5 — 2·4컷 팔 구조
상태: 사용자 검토 후보.
- 2컷 머리 뒤 준비 자세를 몸 앞 높은 양손 준비 자세로 교체. 팔이 후드/스카프 뒤로 엉키는 문제 감소.
- 4컷 팔꿈치를 몸 옆에 두고 손을 앞쪽 아래에 모으는 단순한 자세로 수정.
- 검수: 2컷의 소매 교차와 과도한 꺾임 개선. 4컷 팔꿈치 굴곡 완화, 두 손 파지 유지. 단, 낮은 손이 앞다리와 겹치고 검 끝이 바닥 가까워 실루엣 분리는 추가 개선 여지. 2컷 머리 위치/크기가 바뀌어 최종 정합은 미확정.
- 전체 재생성 편집의 배경 연화가 누적되어 최종 제작은 원본 B 참조와 별도 컷 기준으로 품질 회복 필요.
- 영상용 최종 통과 아님. 사용자 팔 자세 확인 후 다음 작업.
