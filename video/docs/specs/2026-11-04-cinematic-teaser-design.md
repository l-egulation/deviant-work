# Deviant 시네마틱 티저 설계

작성: 2026-11-04 · 상태: **승인됨 (2026-11-04)** · 팀 레포 기준: `dcccf936` (2026-11-04)

게임 화면을 쓰지 않는 시네마틱 영상을 만든다. 한 번 만든 장면들로 **단편(약 80초)**과 **발표 오프닝(약 45초)** 두 편을 편집한다. 마감은 **2026-11-14**다. Higgsfield 구독이 11/15에 끝나고 발표는 11/18이다.

> 표시 규칙: **[결정]** 사용자가 정한 것 · **[제안]** Claude가 정한 것(사용자가 바꿀 수 있음) · **[시험]** 직접 뽑아 보고 정할 것

## 1. Context — 왜 만드나

- **[결정]** 쓰는 곳은 두 군데다. 11/18 SSAFY 발표장에서 발표를 여는 영상, 그리고 게임 홍보 영상이다.
- **[결정]** 실제 게임 장면은 넣지 않는다. 보는 사람이 "이 게임 뭐지?" 하고 궁금해지게 만드는 시네마틱 티저다.
- **[결정]** 핵심 감각: 화사한 분위기가 이어지다가 "지직" 하고 끊기며 "어? 방금 뭐지?" 하게 만든다. 그 틈에 어두운 무언가나 기괴한 형체가 보였다가 사라진다. 게임 이야기가 뒤로 갈수록 어두워지는 것을 미리 암시한다(사용자가 참고용으로 준 방향).
- **성공 기준 [제안]**
  - 발표장에서 영상이 끝났을 때 "저 끊기는 건 뭐였지?"라는 질문이 남는다.
  - 픽셀풍 주인공과 잉크·종이 세계가 Deviant만의 것으로 읽힌다.

## 2. 목표 · 하지 않을 것 · 실패 조건

**목표**
- 단편 1편(16:9, 70~90초)과 오프닝 1편(16:9, 60초 이내)을 11/14까지 최종 파일로 내보낸다.
- 두 편이 같은 세계로 보이도록 기준 이미지 한 세트로 만든다.

**하지 않을 것**
- 게임 플레이 화면 캡처는 넣지 않는다.
- 대사나 성우 연기는 넣지 않는다(AI의 한국어 발음이 어색함).
- 아직 정하지 않은 어두운 비밀은 확정해서 보여 주지 않는다.
- 30초 SNS판은 11/14 이후 여유가 있을 때만 만든다(스트레치).

**실패 조건 (기술적으로 완성돼도 실패)**
- 공포 영상으로 읽힌다(점프 스케어, 비명, 고어).
- 끊기는 효과가 흔한 디지털 RGB 노이즈로 보여서 Deviant와 상관없는 효과처럼 느껴진다.
- 주인공이 컷마다 다른 사람처럼 보인다.
- 지워짐의 원인, 「저 너머」의 정체 등 팀이 정하지 않은 설정을 화면이 정해 버린다.

## 3. 제약

- **기한:** 11/4~11/14(11일). Higgsfield 생성은 11/14까지 끝내고, 모든 생성본을 같은 날까지 내려받는다.
- **크레딧:** Higgsfield Ultra 잔액 6,716(11/4 기준). 15초 720p 한 편이 약 67.5크레딧(레퍼런스 가이드 실측). 시험 생성은 싼 설정(480p·fast 계열)으로 하고, 확정 컷만 고화질로 뽑는다.
- **도구**
  - 이미지: ChatGPT(GPT Image), Gemini(Nano Banana). 사용자가 직접 생성한다.
  - 영상: Higgsfield 웹에서 사용자가 직접 생성한다. 이 Cowork의 Higgsfield 연결로는 생성이 안 된다.
  - Claude: 프롬프트, 콘티, 컷표, 정리를 맡는다.
  - **[결정] 생성부터 편집까지 사용자가 GPT와 함께 한다.** Claude는 작업 기록(`video/docs/`)을 바탕으로 결과를 검토한다. 그래서 작업이 끝날 때마다 기록을 남긴다(8장의 기록 규칙). 출처가 불분명한 리버스 엔지니어링 편집 도구는 쓰지 않는다.
  - **[결정] 음악은 Suno, 효과음은 Higgsfield 안에서 만든다.** 영상 생성 때 소리를 켜서 나오는 효과음을 쓰거나, Higgsfield의 효과음·오디오 생성을 쓴다. ElevenLabs는 목소리가 필요할 때만 쓴다(지금 계획에는 대사 없음). 홍보용으로 쓰므로 각 도구의 요금제가 상업 이용을 허용하는지 확인하고 기록한다.
- **세계관 기준 (팀 문서)**
  - 지워짐: 색과 질감이 빠지고 불완전한 스케치 선과 빈 종이가 된다.
  - 주인공: 크림 후드 + 청록 스카프. 지나가던 평범한 사람이다.
  - 장소: 우물 앞에서 쓰러지고, 조력자의 희생 뒤 잉크 몸으로 각성한다.
  - 깃털펜은 쓰지 않는다.
  - 마을 스케치 화풍은 `STAGE1_WARM_PAPER_HATCH`(따뜻한 종이색, 흑연 선, 성긴 사선 빗금)를 따른다.
  - 1챕터 외곽선 색: RGB 34·28·24.
- **영상 모델 한계:** 한 번에 최대 15초다. 픽셀 아트는 움직일 때 뭉개지거나 지글거리기 쉽다(→ 7장의 시험).

## 4. Approaches — 제작 방식

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A. 한 번 만들어 두 번 편집 (채택)** | 단편을 기준으로 설계한다. 그 장면들을 다시 편집해 오프닝을 만들고, 오프닝 전용 컷은 2~3개만 추가한다. | 기준 이미지 한 세트로 끝나 크레딧과 시간이 가장 적게 든다. 두 편이 같은 세계로 보인다. | 두 편에 같은 장면이 겹친다. |
| B. 오프닝 먼저, 단편은 나중에 | 발표용부터 만들고 반응을 본 뒤 넓힌다. | 발표 날짜를 맞추기 가장 안전하다. | 단편으로 넓힐 때 이야기를 끼워 맞추느라 장면을 다시 만들 수 있다. |
| C. 완전히 다른 두 편 | 오프닝은 분위기 몽타주, 단편은 이야기로 따로 만든다. | 맛이 가장 확실하게 다르다. | 작업량이 거의 두 배라 11일 안에는 무겁다. |

**[결정] A안.** 이유는 크레딧과 기한 안에서 두 편을 모두 만들 수 있는 유일하게 여유 있는 방식이기 때문이다. 비밀이 정해지면 단편 한 곳만 고치면 된다. 생성 순서는 오프닝에 들어가는 컷부터 해서 B안만큼 발표 날짜를 안전하게 챙긴다.

## 5. Narrative — 이야기

**로그라인 [제안]**
따뜻한 픽셀 마을을 지나가는 한 사람. 그런데 세상이 가끔, 아주 잠깐, 지워진다.

**숨은 구조 [제안]**
The Elevator처럼 화면에서는 설명하지 않는 뼈대를 둔다. 티저의 흐름은 실제 게임 초반 이야기를 그대로 따른다(지나감 → 지워짐 → 우물 앞 쓰러짐 → 잉크 각성 → 「저 너머」). 그래서 게임을 시작한 사람은 "영상에서 본 그 장면"을 다시 만나게 된다. 이 부분은 스포일러가 아니라 게임의 처음 5분이다.

**단편 구성 (약 80초, 5블록) [제안]**

| 블록 | 길이 | 내용 | 지워짐 |
|---|---|---|---|
| B1 평화 | ~20초 | 시골 길을 걷는 주인공, 햇살, 마을 어귀, 우물, 빨래와 굴뚝 연기 | 1회, 2~3프레임. 놓쳐도 되는 정도 |
| B2 균열 | ~20초 | 마을의 작은 순간들(문 앞 화분, 고양이, 종이 같은 하늘). 주인공이 뭔가를 느끼고 뒤돌아본다 | 2~3회. 점점 길어진다(0.2 → 0.5초). 틈에 잉크 형체가 보인다 |
| B3 밀려옴 | ~15초 | 지워짐이 양쪽에서 밀려온다. 달리는 주인공, 색이 빠지는 지붕들. 우물 앞에서 쓰러진다 | 지워짐이 이제 끊기지 않고 실제로 번진다 |
| B4 각성 | ~12초 | 정적. 아주 큰 잉크 손이 주인공을 감싼다(조력자, 실루엣만). 스케치가 된 마을에서 잉크 몸으로 눈을 뜬다 | 화면 전체가 스케치 |
| B5 저 너머 | ~13초 | 주인공이 지평선을 본다. 마지막 한 번의 끊김 속에 거대한 무언가의 눈이 보인다. 암전 → 제목 `DEVIANT` | 마지막 1회, 가장 길게(약 1초) |

**오프닝 구성 (약 45초) [제안]**
B1~B5에서 가장 강한 컷만 고르고, 처음부터 빠르게 자른다.

- 시작(오프닝 전용 컷): 암전 → 종이 찢기는 소리 → 잉크 한 방울
- 중간: 평화 컷과 끊김 컷이 점점 짧게 번갈아 나오며 가속
- 끝(오프닝 전용 컷): 제목이 "쾅" 하고 뜨고, 그 뒤 1초 동안 다시 끊긴다

**대사 · 자막 [제안]** 대사는 없다. 자막은 B4~B5 사이에 한 줄까지만 넣는다(예: "기록이 지워지고 있다"). 문구는 편집 단계에서 정한다.

## 6. Visuals — 보이는 방식

**규칙 하나 [제안]: 지워짐만이 세계의 규칙을 깬다**

끊기는 순간은 언제나 같은 순서로 온다.

1. 채도가 0으로 떨어진다.
2. 색칠이 사라지고 흑연 스케치 선과 빈 종이만 남는다.
3. 짙은 잉크가 번지며 무언가가 보인다.
4. 원래 화면으로 돌아온다.

소리도 같은 순간에 한꺼번에 빠지고, 종이 긁히는 소리 하나만 남는다. 디지털 RGB 노이즈나 VHS 줄무늬는 쓰지 않는다.

**세 가지 화면 톤 [제안]**

| 톤 | 쓰는 곳 | 특징 |
|---|---|---|
| L1 밝은 픽셀 | 평화 장면 | 따뜻한 오후 햇살, 높은 채도. 크림·청록·흙빛 주조. 픽셀 아트 질감 |
| L2 지워진 스케치 | 끊김의 앞부분, B4 이후 | 따뜻한 종이색 바탕, 흑연 선, 성긴 사선 빗금. 팀 마을 스케치 화풍과 같은 문법 |
| L3 잉크의 순간 | 끊김 속 형체, B5 | 거의 흑백. 짙은 잉크(RGB 34·28·24 계열)가 번진다. 빛은 거의 없다 |

**끊김 속에 보여 줄 것 [제안]**
설정을 확정하지 않는 이미지만 쓴다.

- 반쯤만 그려진 사람 형체
- 종이 뒤에서 스며 나오는 잉크
- 스케치 선 사이로 보이는 커다란 눈
- 지평선의 검은 번짐
- 너무 긴 팔다리를 가진 그림자

한 번에 0.5초 넘게 보여 주지 않는다(B5의 마지막 1회만 예외). 팀이 승인한 몬스터 디자인은 그대로 쓰지 않는다. 나중 설정과 부딪히지 않도록 새로 만든 모호한 형체를 쓴다.

**톤의 한계 [제안]:** "불길하고 기묘하지만 공포 영상은 아니다." 피, 비명, 갑자기 튀어나오는 장면은 넣지 않는다.

**스타일 블록:** 모든 영상 프롬프트 앞에 같은 문단을 붙인다(Morek 방식, 가이드의 '앵커 반복'). 문단에는 화풍, 장소, 주인공, 시간대, 조명을 토씨까지 같게 적는다. 문단 내용은 7장의 시험 뒤에 확정한다.

## 7. Production — 만드는 순서

**[시험] 화풍 결정 (11/5까지)**
같은 장면(우물 앞 주인공)을 두 화풍으로 만들어 영상 2~3초씩 시험 생성한다.

- (가) 진짜 픽셀 아트
- (나) 픽셀 느낌을 살린 2D 일러스트: 픽셀 질감의 색면, 또렷한 외곽, 부드러운 움직임

비교 기준은 움직일 때 깨지는지, 주인공이 유지되는지, L2 스케치로 바꿀 때 자연스러운지다. 결과를 보고 사용자가 고른다.

**기준 이미지 (Lullaby·Morek 방식)**

| 종류 | 만들 것 | 출발점 |
|---|---|---|
| 주인공 | 정면·측면·뒷면·걷기, 표정 3종, 잉크 몸 버전 | 팀 승인 스프라이트(`unity/Assets/Deviant/Combat/Resources/CharacterApproved13` 등). 화풍 결정 뒤 고해상도 시트로 옮긴다 |
| 장소 | 시골 길, 마을 어귀, 우물 광장, 지평선. 각각 L1·L2 두 상태 | 팀 마을 시안(`Stage1VillageReference/ArtDirection/phase2-selected`) |
| 잉크 형체 | 끊김용 3~4종, 조력자 손 실루엣, 거대한 눈 | 새로 만든다(6장의 범위 안에서) |

- 각 기준 이미지는 Higgsfield에 @캐릭터, @장소로 등록해 고정한다.
- 이미지 안에 글자는 넣지 않는다. 제목과 자막은 편집에서 올린다.

**스토리보드:** 블록별 컷표를 만든다. 열은 컷, 구간(초), 장면, 카메라, 시작 프레임, 끝 프레임, 톤(L1/L2/L3), 끊김 여부, 소리다. 그다음 멀티 패널 콘티 이미지를 블록당 1장 만든다.

**영상 프롬프트 규칙 (가이드 + Lullaby)**
- 블록 하나(15초 이내)는 `(0-2s)(2-5s)…` 타임스탬프로 한 번에 생성한다. 블록 사이는 마지막 프레임을 다음 블록의 시작 이미지로 이어 붙인다.
- 카메라는 단순한 것만 쓴다: static, slow dolly-in, slow pan, wide, close-up.
- 머리카락, 스카프, 연기처럼 멈추면 안 되는 것은 움직임을 꼭 적는다. 동서남북 같은 방향어는 쓰지 않는다.
- 결함이 있으면 다시 만들기 전에 잘라 내서 쓸 수 있는지부터 본다. 다시 만들 때는 그 컷만 한다.
- 무기, 공격 같은 표현은 우회해서 적는다(심의 대응).

**끊김 만드는 법 [제안]**
L1 컷과 L2/L3 컷을 따로 생성하고, 편집에서 몇 프레임씩 바꿔 끼운다. 영상 모델에게 "glitch"를 시키지 않는다. 그래야 끊김의 순서와 길이를 우리가 정할 수 있다.

**소리 [제안]**
- 평화 장면: 잔잔한 음악
- 끊김: 소리를 완전히 빼고, 종이 긁는 소리 하나만 남김
- B5: 낮은 울림 → 제목 순간에 정적

음악은 Suno로 평화 테마 1곡과 낮은 울림 1곡을 만든다. 종이 긁는 소리, 찢는 소리, 잉크 번지는 소리는 Higgsfield에서 만든다. 곡 길이는 편집본 길이에 맞춰 자른다.

**편집 방법 [결정·제안]** 편집은 사용자와 GPT가 한다. 도구는 그때 정하고, 어떤 도구든 아래 순서를 지킨다.
1. 컷표 순서대로 이어 붙인다.
2. 끊김은 컷표에 적힌 위치에 L2/L3 컷을 몇 프레임씩 끼워 넣는다.
3. 소리를 섞는다. 끊김 구간에서는 음악과 환경음을 빼고 효과음 하나만 남긴다.
4. 제목과 자막은 편집에서 올린다.
5. 검토본을 먼저 만들고, 고친 뒤 최종본(1080p)을 내보낸다.
