# Deviant 게임 UI 테마 기준 초안

상태: 사용자와 함께 탐색 중인 시각 기준. 확정된 내용과 제안값을 아래에서 구분한다. 2026-11-03 작업 대화 기준. 실제 실행 화면·어두운 챕터·다양한 해상도에서 검증 후 조정한다.

## 목적

전투 중 체력, 두 무기와 스킬, 지도와 상황 알림을 빠르게 파악할 수 있게 한다. 게임의 밝은 스케치 배경과 이후 어두워지는 장면 양쪽에서 읽히는 통일된 UI를 만든다. UI가 배경과 캐릭터를 가리지 않게 한다. 잉크·스케치에 연결되되 장식을 과도하게 붙이지 않는다.

## 사용자가 선호한 방향

- 차분한 중립 흑연색 패널, 밝은 선과 글자. 갈색 기운의 먹색과 금속성 금색 테두리는 선호하지 않음.
- 픽셀 게임에 맞는 정돈된 형태, 체력바와 지도에서 보이는 **계단형 모서리**, 테두리에 붙은 짧은 연필선과 제한적인 빗금.
- 작은 스킬·무기 슬롯은 장식을 줄인다. 특히 작은 박스 위에 떠 있는 짧은 선을 넣지 않는다.
- 무기·스킬 아이콘은 각자의 색과 형태를 살린다. 과장된 폭발·네온·모바일 양산형 테두리는 피한다.
- 좌측 하단 4개 아이콘은 개별 슬롯으로 구분하며 두 무기의 짝은 간격으로 표현한다. 무기 이름은 상시 크게 보여줄 필요가 없다.
- 현재 시안의 미니맵은 작게 느껴져 **조금 더 크게** 조정한다. 크기와 배치는 실제 플레이 화면에서 결정한다.
- 획득 알림은 화면 위쪽 중앙 위치를 선호한다. 상시 표시는 아니며 보스 체력·상호작용 안내와 겹치지 않는 우선순위는 후속 검토한다.
- 한국어 게임 UI를 기본으로 한다. Q/W/E/R 등 실제 입력키는 예외다. 시안에서 임의 영어 문구를 넣지 않는다.

## 색상 시작값 — 제안

| 역할 | 시작값 | 사용 |
|---|---|---|
| 패널 | #22282F | 무채색에 가까운 어두운 흑연 |
| 기본 글자·테두리 | #F5F2EA | 정보와 얇은 외곽선 |
| 보조선 | #AAB2B4 | 구분선·희미한 연필선 |
| 행동·상태 강조 | #4D9E9B | 지도 위치나 준비 피드백 등에 제한적으로 사용 |
| 체력 | #CF5A5A | 체력 게이지. 실제 배경 대비는 테스트 |
| 쿨타임 덮개 | 검정 또는 중성 회색, 반투명 | 스킬 그림을 유지한 채 회복 중인 부분을 가림 |

색상값은 작업용 출발점이다. 아이콘과 잉크의 고유색을 무조건 이 팔레트로 바꾸지 않는다. 상태는 색뿐 아니라 아이콘·형태·숫자로 구분한다. 글자/바탕 시작값의 대비는 약 13.3:1이나 실제 투명도·크기·배경이 적용된 결과는 별도 측정한다.

## 형태와 질감

1. 큰 패널(체력·미니맵): 정렬된 형태와 계단형 모서리, 얇은 밝은 외곽선. 짧은 연필선 또는 구석 빗금은 한두 곳에만 둔다.
2. 작은 슬롯: 각각 분리된 사각형에 축약한 계단형 모서리를 쓴다. 위에 떠 있는 장식 선과 복잡한 빗금은 사용하지 않는다.
3. 무기 1의 기본/스킬 사이와 무기 2의 기본/스킬 사이는 좁게, 두 무기 묶음 사이는 조금 넓게 둔다. 정확한 간격은 게임 크기에서 조정한다.
4. 배경은 매트한 흑연과 드문 연필 획으로 표현한다. 두꺼운 프레임, 금속광, 번쩍이는 효과, 화면 외곽 장식은 피한다.
5. 장식보다 아이콘·숫자·상태가 먼저 읽혀야 한다.

## 전투 HUD 정보와 상태

- 체력: 현재/최대 수치와 빨간 게이지. 낮은 체력 상태는 색 이외에 형태·피드백을 함께 검토한다.
- 좌측 하단: 무기 1의 기본 공격 Q, 스킬 E; 무기 2의 기본 공격 W, 스킬 R. 현재 입력 체계에 기반한 예시이며 키 재설정 시 실제 바인딩을 표시한다. 아이콘만으로 구분이 어려운 신규 이용자에게 조작 안내를 어떻게 제공할지는 검토한다.
- 스킬 쿨타임: **스킬 아이콘 이미지를 유지하고 그 위에 반투명 회색 부채꼴 덮개**를 표시한다. 덮개가 회복에 따라 줄고 남은 시간 숫자는 아이콘 위에서 읽힌다. 별도의 원형 선만 도는 방식은 사용자가 선호하지 않았다. 방향·숫자 자릿수·종료 효과는 검토 중이다.
- 다중 충전 스킬: 남은 사용 횟수와 다음 회복 중 상태를 구별해야 한다. 구체적인 표기 방식은 미정이다. 버튼을 길게 누르는 차지와 충전 횟수도 구분한다.
- 우측 상단: 골드, 가방, 일시정지와 미니맵. 지도는 주변 지형과 위치를 읽을 수 있도록 이전 시안보다 키운다. 아이콘의 예시 숫자·지도 모양은 실제 게임 데이터가 아니다.
- 위쪽 중앙: 획득 또는 상황 알림. 보스바가 필요한 상황의 겹침·우선순위는 팀과 확인한다. 저장소에는 획득 알림을 하단에 두는 현재 구현 설명도 있으므로 이 위치는 **사용자 선호를 반영한 디자인 제안**이다.
- 보스전에서는 기존 문서의 골드·가방·미니맵 숨김 및 보스 체력 표시 정책을 먼저 확인한다. 테마 시안으로 게임 동작을 확정하지 않는다.

## 크기와 제작

기준 게임 화면은 저장소 문서의 960×540을 우선 참고한다. 이전 이미지 생성 시안의 슬롯은 너무 작게 보였으므로 그보다 약간 키운다. 정확한 픽셀 크기나 미니맵 확대율은 합의된 값이 아니다. 실제 Unity 게임 화면에서 아이콘·키·남은 시간과 미니맵 지형이 읽히는 최소 크기를 측정해 결정한다.

아이콘, 프레임, 키 표시, 쿨타임 덮개, 숫자를 분리된 편집 가능 요소로 만든다. 생성 이미지는 분위기 참고이며 실제 무기·스킬 아이콘이나 정확한 맵·수치를 확정하는 자료가 아니다. 스킬별 충전 수와 쿨타임은 게임 데이터에 연결한다.

## 검토할 화면

1. 밝은 스케치 마을 전투: 일반 상태 / 스킬 회복 중 / 충전형 예시.
2. 어두운 챕터 배경: 동일 패널과 아이콘의 대비·가독성.
3. 보스전: 보스 체력과 기존 HUD의 공간·노출 규칙.
4. 정비·인벤토리: 같은 색과 모서리 언어를 확장하되 전투 HUD와 정보량에 맞게 조정.

## 열려 있는 결정

- 미니맵의 정확한 크기, 확대·축소와 지도 위치 표시.
- 쿨타임 덮개가 줄어드는 방향과 남은 시간의 자릿수·완료 피드백.
- 다중 충전 횟수와 차지 동작의 구체적 표현.
- 입력키 안내의 초보자 노출·숨김 정책, 패드 바인딩.
- 알림과 보스 체력의 위치·우선순위.
- 어두운 배경에서 동일 색을 쓸지 조건별 보정할지.

## 현재 근거와 역할 분담

게임 규칙·현 구현은 `S15P31F109/docs/design/ui-and-interaction.md`, `docs/design/systems/combat/rules.md`, `docs/design/systems/combat/melee.md`, `docs/development/temporary-gui.md`를 최신 커밋에서 확인한다. 문서 사이 차이와 목표/구현을 구분한다. GPT는 테마 탐색, Claude는 Figma 사용자 흐름·와이어프레임과 편집 가능한 구조를 다룬다. 게임 소스 구현을 완료했다는 뜻은 아니다.


## 보급소까지 확장한 공통 스타일 기준 — 2026-11-04

이 항목은 사용자 피드백을 반영한 작업 기준이다. 세부 수치와 접근성은 실제 크기에서 검증하며, 별도 승인 없이 이미지 시안마다 임의로 새 스타일을 도입하지 않는다.

### 공통 프레임

- 기준 실루엣: 미니맵에서 사용자가 제시한 형태. **왼쪽 위와 오른쪽 아래는 짧은 계단형, 오른쪽 위와 왼쪽 아래는 대각선**이다. 네 모서리를 전부 대각선으로 바꾸거나 계단을 생략하지 않는다.
- 어두운 외곽과 밝은 선이 서로 바짝 붙은 얇은 이중 외곽. 선이 프레임에서 떨어져 떠 보이거나 지나치게 두꺼워지지 않게 한다. 패널 내부에 장식용 흰 선을 넣지 않는다. 미니맵 내부의 흰색은 길 등 실제 정보에 쓴다.
- 큰 패널만 오른쪽 위 바깥에 짧은 수평 연필선을 제한적으로 배치한다. 작은 키캡·스킬 슬롯·행에는 이 선을 추가하지 않는다. 무늬는 정보의 가독성을 해치지 않을 정도로 약하게.
- 큰 패널은 중립 흑연색, 기본 텍스트는 밝은 아이보리. 갈색·금색 프레임, 광택 금속·화려한 장식, 불필요한 영어는 피한다. 실제 아이콘의 고유 색상은 유지한다.

### 보급소 화면

- 기준 구조는 Figma 마을 작업대 v4: 화면 오른쪽 위 부분 창, 제목·보유 안료·다음 런 요약·네 항목·선택 항목 설명·F 길게 해금. 기능과 수치는 [작업대 설계](../../docs/specs/2026-11-04-village-workbench-windows.md)를 따른다. 시안 속 수치와 잠금 조건은 임의 확정하지 않는다.
- 각 항목 행의 배경은 전체 패널보다 **약간 밝은 흑연색**으로 채워 선 없이도 구별되게 한다. 선택된 행은 밝기 차이와 포인터 등으로 구분한다. 청록색은 선택 상태의 시험안이며 정확한 색·테두리는 미확정이다. 잠금·안료 부족·완료는 색상 외에 문구와 기호를 사용한다.
- 이전 크기 비교에서 사용자는 작은 창보다 **기준 크기**를 선호했다. v4의 1440×810 기준 약 900×530을 출발점으로 하고 실제 960×540 등에서 텍스트·건물·캐릭터 가림을 검증한다. 수치는 최종 확정이 아니다.
- 실제 마을의 보급소 건물·작업대·캐릭터와 마을 HUD를 참고한다. 마을에는 확인되지 않은 체력바·전투 스킬·적·미니맵을 임의로 넣지 않는다. 실제 배경 위 합성과 이미지 생성으로 재해석한 장면은 구분해 표시한다.

### 다음 작업에서 유지할 점

1. 기준 화면에서 프레임·행·버튼·선택·잠금 상태를 개별 요소로 만들고 같은 요소를 재사용한다. 이미지 생성 결과만으로 모서리 치수나 글자를 확정하지 않는다.
2. 화면 구성을 바꿀 때 위 공통 테두리·색·선의 배치를 고정한다. 새 제안은 기존 기준과 분리하여 비교한다.
3. 마을의 보급소는 현재 구현과 v4 목표안에 차이가 있다. 현재 실행 화면을 v4가 이미 구현된 것처럼 설명하지 않는다.
