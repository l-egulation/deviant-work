# 문양 재디자인 — 대표 5종

[이전/수정/문양 단독/작은 크기 비교](comparison.png)

사용자 피드백인 지저분한 선과 추상 기호 느낌을 줄이는 검토안. 기존 54종 중 덧칠·뛰어난 발걸음·든든한 배리어·난무·사약 5개를 같은 20×20 격자로 다시 그렸다. 팔레트는 승인된 v6를 그대로 사용한다.

- 직접 편집한 픽셀 격자, 정수 4배 확대. 문양 영역 80×80, 표시용 전체 캔버스 220×155.
- runtime PNG는 문양만 있는 투명 파일. 단독 비교 줄의 회색 바탕은 미리보기용이며 파일에는 없다.
- build.py / pixel-grids.json은 제작 원본. manifest.json은 아이템 ID와 규격.
- 날카로운 단일 픽셀 돌출, 끊긴 장식 획, 여러 추상 기호의 조합을 줄였다.
- 사물 중심: 두 칼자국, 장화, 방패 속 칼, 시계, 해골 표시 독병.

## 검토 범위
110px 및 66px 슬롯 크기 비교판을 육안 확인했다. 66px에서는 장화 끈과 독병 내부 세부 표시가 약해진다. 효과의 모든 발동 조건을 문양에 표현하지 않는다. 시계는 쿨타임 계열 공통 형태를 먼저 검토하는 것이며 다른 쿨타임 파츠와의 구분은 후속 작업이다.

5종 대표 스타일 검토안이며 54종 재디자인 완료를 뜻하지 않는다. v1과 승인 팔레트 파일을 덮어쓰지 않았다. Unity 미적용.
