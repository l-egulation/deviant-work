# Deviant · 현행 UI 에셋 검토 묶음

2026-11-12 · 팀 기준 bb88516c3 · Unity 적용 없음.

[index.html](index.html)에서 분류·검색·크기 변경·배경 전환·효과 설명을 확인한다. [manifest.json](manifest.json)은 모든 콘텐츠 ID와 실제 원본 이미지 영역을 연결한다.

## 이번 제작

| 영역 | 대응 범위 | 방식 |
|---|---:|---|
| 런 잉크 | 43종 전부 | 효과 문양 10개 + 발동/조건 보조 문양의 조합. 기존 5색 병·팔레트와 합성 표시 |
| 공방 증강 | 39종 전부 | 개별 효과 모티프. 실행 목록 30종 / 제안만 존재하는 9종 표시 |
| 봉인 증강 | 12종 전부 | 별도 ID·효과·문양 |
| 실제 스킬 | 근접 28 + 원거리 12 = 40종 | 기본/범위/이동/후속타별 아이콘 |
| 이벤트·알림 | 16개 | 새 이벤트 4종, 소진·보상·기록·경고 등 |

신규 원본은 11개 투명 PNG 아틀라스이며, 목록상 142개 스프라이트 항목이다. S14는 영문 A 모티프를 폐기하고 보스 왕관·검 문양을 재사용하므로 고유 이미지 수와 항목 수는 다르다. 43개 잉크를 각각 별도 그림으로 만든 것이 아니라 효과/조건 레이어를 조합한다.

## 재사용

기존 승인 무기 13개, 팔레트 16개, 칠 5개, 지도 11개, 공통 16개, 팀 마을 잉크·기록용 이미지 15개를 연결했다. 팀 원본 15개는 바이트 변경 없이 복사했으며 `team-reuse/sources.json`에 출처와 해시가 있다. 기존 수첩 삽화 두 장은 기존 UI 폴더를 참조한다.

## 파일과 적용 계약

- `atlases/`: 이미지 생성 원본. 투명 배경 유지.
- `manifest.json`: `rect`는 왼쪽 위 원점의 x/y/width/height, `view`는 검토용 광학 크기 보정 영역, `imageSize`는 원본 크기.
- `data.js`, `gallery.js`, `style.css`: 검토 HTML. SVG는 래스터 이미지를 잘라 보여주는 창으로만 사용하며 문양을 도형으로 대체하지 않는다.
- `previews/`: 실제 브라우저 렌더링. 원본 에셋을 그대로 사용한다.
- `reference-audit.json`: 현행 갤러리 디렉터리의 정적 이미지 참조 점검.

이번 묶음은 **디자인 검토용 투명 아틀라스와 좌표 패키지**다. 개별 PNG 추출, 동일 논리 픽셀 격자로의 최종 정규화, Unity Sprite 메타데이터·아틀라스 등록은 아직 하지 않았다. 이 작업을 했다고 간주하면 안 된다. 기존 화면 전체의 아이콘을 새 목록으로 일괄 교체하지도 않았다. 이 페이지에서 먼저 전체 문양과 조합을 확인한다.

Unity에서 쓰게 될 때는 Sprite Multiple로 영역을 분리하고 Point/Clamp, mipmap off, 압축 없음으로 시작한다. 좌표의 Y는 Unity 하단 원점으로 변환한다. 실제 표시 크기에서 단순화·색상 수·픽셀 격자를 최종 검수한다. 프레임은 기존 모서리를 보존하는 9-slice 후보이며, 이 단계에서 모든 border 값이 확정됐다는 뜻은 아니다.

## 제외/미정

- 폐기된 스탬프 교체, 칸 강화·색 변경, 가방 용량 초과 화면의 신규 에셋은 만들지 않는다.
- 타이틀 전용 로고·키아트, 아직 미정인 최종 엔딩 삽화는 확정 범위가 아니다.
- 세계 배경·NPC·보스 스프라이트는 팀 게임 에셋이며 UI 문양 제작과 구분한다.
- 텍스트, 단순 구분선, 내구도/쿨타임 마스크, 버튼 확대·비활성 상태는 별도 그림을 중복 생성하지 않는다.

## 검수 한계

콘텐츠 ID 누락과 파일 참조 확인은 했지만, 이것이 모든 UI 흐름·Unity 플레이 검증을 의미하지 않는다. 생성 원본은 일부 외곽의 미세 픽셀·명암 정규화가 남은 검토본이다. 현재 갤러리에서 32/48/64/96px를 비교한 뒤 최종 래스터 정리 대상으로 삼는다.
