- 창 모드·해상도 목록과 10초 자동 복귀는 와이어 기반 제안이며 실제 Unity 지원 목록과 연동하지 않음.
- 키 변경·중복 거부·기본값 복원은 검토용 구현. 패드 재지정 화면은 포함하지 않음. 시안에서 바꾼 키는 실제 게임이나 다른 시안의 키를 변경하지 않으며 새로고침 시 초기화됨.

## 테마/에셋
- 1920×1080, 960×540 비례 축소. 외곽 160px, 분류와 내용 사이 130px 여백.
- 본문 아이보리 / 보조 회색 / 조절·실행 하늘색 / 충돌 살구색. 선택은 기존 selection-wash-v1.png와 10–15% 확대.
- 기존 마을 배경, 승인된 선택 번짐 PNG 재사용. 새 `assets/slider-thumb.png`는 투명 픽셀 질감 손잡이 생성 에셋. 슬라이더 선에도 선택 PNG를 사용.
- 폰트 파일은 포함/재배포하지 않음. 기존 review-font.js를 통해 로컬 선택한 폰트를 적용.

## 검토할 화면
- `?tab=sound`: 전체 음량·배경 음악·타이틀 효과음. 로컬 브라우저의 검토 전용 값만 즉시 저장. 실제 음원 재생 없음.
- `?tab=display&state=changed`: 창 모드·해상도 변경 → 적용.
- `?tab=display&state=confirm`: 유지/되돌리기, 10초 자동 복귀.
- `?tab=controls`: 이동·전투·탐험. 실제 기본 키 기준.
- `?tab=controls&state=rebind`: 새 키 입력 대기. 중복 키는 거부, Esc 취소.
- 화면 설정 변경 중 다른 분류/뒤로 선택 시 변경 취소 확인.
- 일시정지 → 설정 → 뒤로 연결. 설정 메뉴로 선택 복귀.

## 검증
음량 값·검토 저장, 화면 유지/되돌리기, 중복 키 거부, 키 변경, 이동 6행과 하단 간격, 960 축소 확인. 새 기술/게임 옵션이 완성됐다는 의미가 아님.

## 후속 결정
실제 지원 해상도·창 모드, 디스플레이 복귀 제한 시간, 패드 전용 설정 범위는 구현 담당자와 확정 필요. 현재는 디자인 검토를 진행할 수 있는 대표값으로 표시.
