총 54종. 수치는 direction_approved_tuning_draft 상태이며 문양은 수치보다 효과와 발동 조건을 표현한다.

## 제작 원칙
- 같은 색 안에서도 효과가 다르면 다른 문양을 쓴다.
- 핵심 효과 실루엣 하나 + 필요한 경우 작은 발동조건 표식 하나. 숫자·긴 문자·여러 작은 그림은 피한다.
- 범위(퍼짐)와 사거리(긴 획), 속박(족쇄)과 기절(충격), 독(방울/독성)과 독폭발(방울 파열)을 구분한다.
- 반복되는 보호막·회복·쿨타임 효과는 발동 조건을 구분할 보조 형태가 필요하다.
- 아래 기존 문양은 채택 확정이 아니라 대조 대상이다. 실제 에셋 제작 및 작은 크기 식별 검증은 후속 작업.
