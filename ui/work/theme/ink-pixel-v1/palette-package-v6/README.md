# 바탕 노출 소폭 조정 v6

[이전/수정 비교](comparison.png) · [효과 54종 문양 대조 목록](effect-symbol-audit.md)

v5 칠의 전체 크기·위치를 바꾸지 않고 바탕과 겹치는 가장자리 두 구간에서 최대 3px 깊이만 덜어냈다. 색상별 칠 면적 감소는 2.55~3.10%. 안쪽 색·복원 영역·문양은 변경하지 않았다. 같은 칠을 색상/무색 바탕에 같은 좌표로 재사용한다.

runtime/slots의 16종과 runtime/symbols 검토용 5종은 모두 220×155. Unity 미적용. source에는 변경 후 제작 원본을 보관한다. 복원 칠 및 검토용 문양의 한계는 v5 README와 동일하다. 바탕 노출 조정안은 사용자 검토 전이다.

refine.py 재실행 시 v5를 읽어 재생성한다. validation.json에 색별 제거 면적을 기록했다. 54종 문양은 최신 로컬 개편안을 읽고 기존 문양과 대조한 목록이며 새 에셋 54종을 제작 완료한 것이 아니다.
