# 가방·장비 시안 v5

최신 실제 PNG를 그대로 사용하는 HTML과 직접 캡처한 화면. 생성 이미지를 UI로 대체하지 않음.

- 병: ink-bottles-tag-v3 — 54문양 크기·여백 조정본
- 문양: effect-symbols-v5/runtime
- 팔레트: palette-package-v6/runtime/slots
- 무기: weapon-ink-v8/runtime — 기본 발사기 최종 수정, 레이저/샷건/유탄 포함 13종
- 선택 표시 등: screen-set-v2/assets

asset-sources.json에 원본 경로와 SHA256 기록. 화면의 검·발사기는 96×96 원본 크기로 표시. 예시 장비를 검/발사기로 구성. 두 무기의 독립 장비 데이터 및 실제 장착·파괴 로직은 미구현인 시각 시안. Unity 미적용.
