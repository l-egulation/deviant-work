# 잉크 판매대 시안
기존 배경/폰트/잉크병/선택 wash 직접 참조. 3개 고정 진열 예시. 구매 전, ?case=bought 구매 후, ?case=full 포화, ?case=poor 재화 부족.
근거: docs/design/systems/progression-and-economy.md 잉크 판매대. 시설별 런 내 진열 유지, 구매 후 판매 완료, 3등급420G/4등급600G, 포화/골드부족 시 결제 거절. 등급은 data/combat/ink_color_parts_tuning.json의 fixedGrade(집중공격3, 터지는잉크4, 전기발자국3).
기본 공용가방5칸 예시. HTML 안에서만 구매 상태(골드 차감/보관 수/판매완료) 변경. 재접속 시 초기화하며 Unity/실제 저장 데이터 미변경. F 반복 입력 방지, 위아래로 판매 완료 제외 탐색. 가격은 시험값.
가방 관리로의 실제 이동/복귀·런별 영속 저장은 구현하지 않음. 기존 가방 카테고리 시안과 현행 공용가방 규칙 차이는 후속 정리 대상.
