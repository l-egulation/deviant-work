# 붓칠 실행 버튼 파일럿

출발 준비와 잉크 판매대에만 적용. 기존 selection-wash-v1.png를 버튼 바탕으로 재사용한다.
- 모든 실행 버튼에 낮은 대비의 붓칠 바탕 유지.
- 현재 실행 대상만 밝은 바탕, 6% 확대, 왼쪽 F 키캡 표시.
- F가 숨겨져도 해당 공간을 유지하여 선택 이동 시 정렬이 바뀌지 않음.
- 출발 준비는 실제 키보드 초점과 표시가 연결됨. 마우스로 버튼에 진입하면 초점을 이동하며 방향키도 그 위치부터 이동.
- 판매대는 F가 바로 구매하는 단일 실행 동작이라 구매 가능 시 구매 버튼에 표시. 부족/가득 참이면 F 숨김.
- 항목/탭 선택 강조와 버튼 바탕은 다른 역할로 유지. 기존 다른 화면의 버튼은 이번 파일럿 대상 아님.
- Unity 변경 없음. 기존 아이템 이름·효과 예시 수치는 이번 버튼 작업에서 개정하지 않음.

확인: 9개 기존 상태 및 확정 버튼 선택 미리보기. 이미지 로딩, 화면 밖 넘침, 단일 F 표시, 방향키로 이동 후 F 실행 확인.
