## 방향
효과 작동 방식을 설명하는 기호 조합보다 각 잉크의 성격을 암시하는 문양을 지향했다. 덧칠은 겹쳐 찍힌 자국, 집중 공격은 모이는 획, 종합 병원은 모여 핀 독꽃으로 표현한다. 이런 해석은 게임 설정 추가가 아니라 디자인 제안이다.

## 파일
- sheets: 이미지 생성으로 만든 색상별 디자인 원본 5장. 각 4×3 시트의 앞 10~12칸 사용.
- pixel-source: 각 문양을 분리하고 단색 알파로 정리한 32×32 격자. 새 디자인 제안의 픽셀 정리본이며 승인 원본 그대로의 추출을 뜻하지 않는다.
- runtime: 문양만 있는 220×155 투명 PNG 54종. 32×32를 정수 3배(96×96)로 확대해 (62,29)에 배치했다. 팔레트는 포함하지 않는다.
- manifest.json: 아이템 ID, 디자인 의도, 파일/원본 위치, 검토 상태.

## 비교 HTML
이전은 직전 문양(v2 대표 5종 + v1 나머지 49종). 새 문양과 같은 크기·같은 v6 팔레트에 얹어 비교한다. 색상 필터, 효과·이름 검색, 문양 단독/팔레트 표시 전환, 220/110px 크기 전환 제공. 효과 설명은 요청한 UI 비교용이며 로컬 팀 개편안 기준이다. 원본 게임 규칙 JSON은 복사하지 않았다.

## 검증 및 상태
54 ID·54 PNG·54 카드 대응, PNG 크기/투명 알파, 중복 래스터 없음, HTML 이미지 경로 확인. 색상별 5개 시트 및 실제 Chrome HTML 화면을 육안 확인했다.

최종 확정 에셋이 아닌 전체 방향 비교 시안이다. 갈대·매듭·전류 같은 가는 부분은 작은 크기에서 추가 정리가 필요하다. 잔류 폭발·사방으로 튀는 잉크 등 복잡한 실루엣의 축소 가독성도 후속 검토 대상이다. 승인된 v6 팔레트와 이전 문양은 덮어쓰지 않았다. Unity 미적용.
