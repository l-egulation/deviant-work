# 장비 선택 표시 개정 · 2026-11-06

- 사용자 발표 장표의 “눈에 보이면” 강조를 참고: 글자 하단에 겹치는 회청색 마커 획. 선택 박스나 모서리 괄호는 사용하지 않는다.
- 장비 상태 간 배경색, 왼쪽 무기·도장·팔레트 위치와 크기를 공통으로 유지한다. 오른쪽 상세와 보유 아이템 영역만 선택에 따라 바뀐다.
- 탭·현재 무기는 약한 문맥 표시, 실제 조작 대상은 더 강한 선택 표시로 구분해야 한다. 생성 시안의 여러 강조는 추가 조정 대상이다.
- 강화 수치 +0 등은 원형 슬롯 아래에 표시한다. 슬롯 내부는 장착 효과 아이콘에 사용한다.
- 08: 잉크 교체 검토 상태. 09: 특수 도장 선택, 현재 장착 및 보유 없음 상태.
- 팔레트 모양과 내부 기호는 구조 검토용 임시 표현이며 최종 에셋이 아니다. 무기 도장도 같은 상세 영역을 사용한다.
- 두 이미지는 생성 시안이므로 픽셀 단위 공통 배치를 보장하지 않는다. 구현 시 하나의 공통 레이아웃으로 고정해야 한다.
- 현재 변경은 이미지 및 기록만이며 Figma·Unity 구현이나 원격 업로드는 수행하지 않았다.
