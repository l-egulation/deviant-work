최신 사용자피드백에 따라 가방은 획득아이템 확인/처분, 장비는 무기/도장/팔레트 구성. 기존 합쳐진 장착흐름보다 최신 분리제안 우선. 빈 값 —, 장착가능/호환칸개수 문구 제거. 팔레트형태 미정으로 재개방.
