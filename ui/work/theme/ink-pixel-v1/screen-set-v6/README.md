# 가방·장비 여백 검토 v6

기존 에셋과 바깥 여백(좌우150px), 글자 크기 유지. 좌측760px / 영역 사이72px로 정보 영역 간 간격 축소. 가방 목록 행 간격22px, 목록과 카테고리24px. 무기-도장-팔레트의 수직 간격 정리. 오른쪽 현재/교체 구분선 유지, 긴 효과는 해당 설명 영역에서 스크롤.

원본 연결은 asset-sources.json. v5와 에셋 파일 동일. 실제 게임 기능은 구현하지 않은 검토용 HTML, Unity 미적용.

[가방](previews/bag.png) · [장비](previews/equipment.png) · [긴 설명](previews/bag-long.png) · [빈 카테고리](previews/bag-empty.png) · [무색 칸](previews/equipment-neutral.png)

현재 대화의 X 짧게 버리기/3초 파괴와 일시정지 표시는 유지. 팀 구현 및 Figma와의 규칙 차이는 2026-11-09 제작 현황 보고서 참조. 5칸 팔레트는 확장 후 예시이며 초기 지급 규칙으로 해석하지 않음.

## 정비소와 선택 표현 통일
동일 selection-wash-v1.png를 복사해 탭/무기 이름/팔레트 이름/잉크병 하단/도장 이름에 사용. 탭 120%, 무기 115%, 도장 110%, 잉크병 90→105%, 팔레트 80→100%. 탭과 무기 간격 확대. 기존 팔레트 밑줄 제거, 효과명 뒤에 질감 표시. 실제 아이템 변경 및 Unity 적용 없음.

가방 잉크 목록은 아이콘 확대만 사용하며 하단 선택 질감은 제거. 장비의 교체 잉크 및 다른 선택 표현은 유지.

## 장착된 스탬프 상태
기본 예시: 무기1 레이피어 + 범위 스킬 스탬프. 무기2는 미장착. ?view=equipment&stamp=무기 / stamp=특수 로 각각 설명 표시, &stamps=empty 로 빈 상태. 현재 선택 이름과 형태 아이콘을 표시하며 별도 스탬프 전용 아이콘 제작은 포함하지 않는다. 실제 전투 수치 대신 docs/design/systems/ink-blueprint-proposal.md의 형태/변형 역할 설명 사용. 교체는 정비소 전용이므로 스탬프 열람 상태의 F 장착 안내 제거. 기존 공용 가방 카테고리 등 구형 규칙 정리는 별도 과제.
