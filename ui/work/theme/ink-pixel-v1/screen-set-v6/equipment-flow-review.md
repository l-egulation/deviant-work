# 장비 탭 단계별 조작

- 무기 선택: 좌우로 무기 탐색 → F로 팔레트 선택 진입.
- 팔레트 선택: 좌우로 칸 탐색 → F로 교체할 잉크 선택 진입.
- 잉크 선택: 좌우로 잉크 탐색, 페이지 자동 전환 → F로 장착/교체.
- Esc: 잉크 → 팔레트 → 무기 → 가방 순서로 복귀. 취소는 장착하지 않음.
- 장착 후 팔레트 선택으로 복귀. 별도 완료 화면 없이 장착된 칸과 소모된 보유 잉크로 결과 확인.
- 마우스도 현재 단계 항목만 선택 가능. F 버튼 클릭은 동일한 확인 동작.
- 동일 잉크는 교체 후보에서 제외. 적합한 잉크가 없으면 다음 단계 진입 불가.
- 이전 단계의 선택은 유지하고 현재 조작 영역은 밝기/확대로 구분. 잉크 아이콘에는 선택 밑줄 없음.
- Unity 적용 없음. 브라우저 새로고침 시 시안의 아이템 상태 초기화.

검증: 3단계 확정, 영역 내 방향키 이동, Esc 복귀, 무기별 독립 장착, 무색 칸 페이지 전환, 보유 후보 없음, 이미지 누락 없음.
