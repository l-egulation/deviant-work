# 잉크 43 → 36 대응 검토

현행 36종은 ID·설명·기본/색상 일치 수치가 이전 목록과 동일하다. 중독 부여 4종, 중독 조건 빨강 1종, 중독 조건 파랑 2종만 제외됐다.

- 재사용: 병 5색, 효과 문양 9종, 공격/스킬/스위칭/대쉬/상태 부여 배지 5종, 상태 조건 문양 3종(효과 문양과 공유).
- 신규 원화 필요: 0. 새로운 효과나 발동 조건이 추가되지 않았다.
- 보존 전용: ink-symbol-6(중독) 및 중독 관련 7개 조합. 원본 PNG를 삭제하지 않고 현행 선택 후보/패키지 활성 잉크 목록에서 제외.
- 병 중앙은 효과, 우측 하단 배지는 조건/트리거. 팔레트는 슬롯 바탕→잉크 칠→효과 문양 3레이어 유지. 서로 다른 슬롯/잉크 색 허용.
- 가방·제작·장비는 RuntimeContent.run.inks의 동일 문구와 ContentRules의 파랑 조건/초록 효과/노랑 적용값 규칙을 사용한다.
- 제작/장비 예시의 순번 참조를 ID 참조로 변경하여 목록 축소 뒤 잘못된 문양/설명 연결 방지.
- 패키지 버전3은 활성 잉크 목록만 변경. 원화 파일/좌표/라벨 위치/팔레트 형태 변경 없음.

mapping.csv/json은 기존 전체 43개 각각의 처리 상태를 제공한다. index.html은 실제 승인 병·문양 합성 비교 보드다. Unity 미적용, 팀 저장소 변경 없음.
