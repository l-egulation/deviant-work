# 확인창 공통 규격

승인 크기: 1920×1080 기준 폭 960, 안쪽 여백 세로 45 / 가로 48, 제목 42, 본문 34.5, 버튼 37.5, 버튼 간격 60. 화면 비율에 맞춰 전체 축소.

적용: 화면 유지 확인 / 미적용 설정 취소 확인 / 기본키 복원 확인 / 도전 포기·마을 복귀 / 타이틀 복귀 / 영구 진행 초기화. 일시정지의 기존 다시 시작 확인 경로도 동일 규격 적용하되 현행 갤러리에 추가하지 않음.

제작 확정은 팔레트·효과를 검토하는 상세 화면이므로 유지. 무기 이름 입력, 건물 말풍선, 회복 팝업, 보상 결과는 목적이 달라 이 규격으로 확대하지 않음.

공통 원본: confirmation.css. 설정의 네이티브 dialog는 별도 레이어이므로 settings.js에서 화면 배율을 직접 적용. F/G 고정 동작과 방향키 선택 후 F 실행 방식은 각 화면의 기존 조작 규칙을 유지.
