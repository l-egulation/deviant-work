# UI 에셋 현황 — 여기서 시작

[레이어별 실제 파일 보기](layers.png). 체크무늬는 미리보기에서만 표시하며 실제 PNG 배경은 투명하다.

| 종류 | 수량 | 폴더 | 상태 |
|---|---:|---|---|
| 빈 바탕 | 6 | [bases](../palette-package-v6/source/bases) | 승인 형태, RGBA |
| 문양 없는 칠 | 5 | [paint](../palette-package-v6/source/paint) | 가려진 문양 부분 복원 포함 |
| 표시용 슬롯 | 16 | [slots](../palette-package-v6/runtime/slots) | 빈 6 + 색상 바탕/칠 5 + 무색 바탕/칠 5, 문양 없음 |
| 별도 효과 문양 | 54 | [symbols](../effect-symbols-v1/runtime) | 재디자인 대상, 확정 아님 |

실제 사용은 슬롯 이미지 한 장 + 효과 문양 한 장을 같은 220×155 위치에 겹친다. 비교판의 합쳐진 모습은 미리보기이며 문양 파일 자체가 팔레트와 합쳐져 있는 것이 아니다. 빈 무색 칸은 bases/neutral.png 및 slots/empty-neutral.png에 있다.

## 문양 재디자인 방향
현재 54종은 목록 연결 및 초안 제작까지 된 상태다. 사용자 피드백: 직관성이 부족하고 도형처럼 보임. 최종 채택하지 않는다.

- 추상 도형보다 알아볼 수 있는 사물 실루엣: 장화·사슬·독병·방패·칼.
- 작은 기호 여러 개를 조합하기보다 큰 주제 하나 중심으로 설계.
- 유사 효과 차이는 효과 설명을 바탕으로 표현하되 숫자와 모든 조건을 아이콘에 억지로 넣지 않음.
- 픽셀 격자는 유지하되 규칙적인 기하학 도형만으로 만들지 않고 사물의 특징·비대칭을 표현.
- 먼저 대표 문양 몇 개로 스타일을 검토하고 그 기준으로 54종을 개정. 아직 개정 문양 제작 완료가 아님.

Unity 미적용. 잉크병 전체 효과별 제작도 아직 완료되지 않았다. 기존 팔레트 패키지의 reference-* 문양 5개는 과거 비교용이므로 실제 ID별 에셋과 혼용하지 않는다.
