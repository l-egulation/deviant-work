# Unity 전달용 승인 에셋 패키지

[전체 미리보기](index.html) · [기계 판독 명세](manifest.json) · [ID 대응표](id-map.csv)

원본 PNG를 그대로 복사하고 SHA-256으로 대조한 소스 패키지. Unity 프로젝트를 수정하지 않음. 모든 파일은 이 폴더 안에서 참조.

## 사용 기준
- sprites의 고유 id로 참조. contentId는 게임 데이터 ID, file은 패키지 내 실제 PNG. 잉크43종은 inks에서 병·효과·조건을 조합.
- rect는 아틀라스 원본의 자르기 영역, view는 시안의 표시 범위. 둘을 하나로 대체하면 크기와 중심이 달라짐.
- Unity 좌표는 아래가 원점: y = imageHeight - top - height. 소수 view는 UI의 논리 표시 범위로 유지하고 실제 spriteRect는 정수 경계 사용. 패딩 차이는 자식 위치/크기로 보정.
- 팔레트: 바탕6색 → 칠5색 → 효과 문양. 공통220×155 표시 좌표, 문양 중심110,78 / 크기80. 바탕·칠은 각자 전체 이미지를 같은 표시 영역에 배치. 빈 슬롯은 바탕만.
- 잉크병: 병 view 좌표에서 label 중심/172크기, badge 중심/92크기로 문양 배치. 병별 중심값은 manifest 참조.
- 말풍선: 모서리·하단 꼬리 고정. manifest frames의 경계로 행/열을 나누고 중간 띠만 늘림. 단순 통이미지 늘림 금지.
- 일반 프레임: 현재 이름변경창의260px slice 기준. 다른 크기는 모서리 보존 상태를 확인 후 사용.
- 원본 아틀라스를 유지하므로 그림 재생성/리터칭 없음. 개별 PNG 분리 대신 정확한 영역/표시좌표를 전달.
- UI 투명 PNG는 Point/무압축/mipmap 없음/FullRect 기준. 시트가2048보다 크면 가져오기 최대값도 키워야 함.
- 증강 대기9종은 아트 제공과 게임 후보 활성화를 구분. 보상 용기는 에셋만 포함, HUD 전체는 보류.
- 폰트는 기존 로컬 방식. 배경·캐릭터는 패키지에서 제외.

## 검증 경계
원본 파일 해시 일치 및 브라우저 원본/패키지 동일 렌더 대조. Unity import 후의 픽셀 표시·9분할·폰트는 이후 실제 적용 검증 대상.

잉크 ID별 병/문양 대응은 ink-id-map.csv. 미리보기 팔레트30조합은6바탕×5잉크를 검사하는 예시이며 문양은 해당 색의 대표 효과를 사용합니다. 실제 효과 ID는 선택 잉크에 따라 교체합니다.
