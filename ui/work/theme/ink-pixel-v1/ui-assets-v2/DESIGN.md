# 증강 화풍 기반 에셋 개정

사용자 요청: 공방·봉인 증강의 화풍을 무기, 마을 잉크·기록, 잠긴 상자, 팔레트, 일반 잉크병으로 확장한다. Unity에는 적용하지 않는다.

- 기준: ui-assets-v1/atlases/aug-a.png 및 seal.png. 굵은 먹선, 아이보리 면, 제한된 청록, 단순한 2~3단계 명암.
- 무기: 13종의 식별 가능한 형태를 유지하며 과도한 세부 묘사를 줄이고 작은 실루엣 수정 허용.
- 팔레트: 물리적인 그릇/3D 팔레트로 바꾸지 않음. 색별 불규칙 칠 형태, 빈칸/채움 구분, 무색 바탕, 동일 잉크의 동일 칠 모양 유지. 바탕·칠·문양을 별도 층으로 표시.
- 잉크병: 기존 외부 네모 보조 배지를 폐기. 효과는 전면 밀착 라벨 중앙, 발동 조건은 뚜껑 앞면에 각인처럼 표시하는 시안. 중앙과 광학 여백을 실제 합성에서 확인.
- 마을 잉크: 일반 잉크병과 구분되는 긴 목/무라벨 병 유지. 보석 광택·발광을 제거하고 증강 화풍 적용.
- 기록: 수첩 종이·띠·진행 방울과 기존 이야기 삽화 두 장의 내용을 유지하고 화풍만 변경.
- 상자: 닫힘/열림의 몸체·폭·밑선 일치. 새 그림자·광원·보상 이펙트는 추가하지 않음.

기존 에셋은 보존하고 v2 비교 갤러리에 이전/개정/크기별 보기를 제공한다. 이번 산출물은 디자인 검토용 투명 원본 및 스프라이트 영역 정보이며, 팀 Unity/월드 원본을 교체하지 않는다.
