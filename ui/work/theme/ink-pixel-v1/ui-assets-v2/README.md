# 에셋 화풍 재디자인 v2

기존 증강 아이콘의 굵은 먹선, 아이보리 면, 절제된 명암을 기준으로 제작한 검토용 시안입니다.

- 무기 13종, 잉크병 5색(43종 문양 조합), 상자 2상태
- 팔레트 빈 바탕 6종 + 칠 레이어 5종. 동일 칠을 색상/무색 바탕에 사용
- 마을 잉크 5색과 드롭 5종, 기록 부품 6종과 삽화 2종
- 원본은 보존. Unity와 기존 게임 UI에 아직 적용하지 않음

index.html에서 분류별 비교 및 96/128/160px 크기 확인 가능.
PNG는 투명 아틀라스이며 개별 파일로 분리한 최종 Unity 스프라이트는 아닙니다. manifest.json에 영역 좌표를 기록했습니다. 잉크 문양은 기존 v1 에셋을 별도 레이어로 조합합니다.

검증: 6개 분류 브라우저 표시, 이미지 경로 누락 없음, PNG 알파 채널 존재, 잉크병 경계 및 문양 위치 수정 후 재확인. 기록 삽화는 부드러운 주변 명암이 남아 있어 최종 런타임 적용 전 배경별 확인 필요.
