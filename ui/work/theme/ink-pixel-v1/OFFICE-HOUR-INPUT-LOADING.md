2026-11-13 사용자 확정. 기존 문서의 미정 항목보다 이 문서를 우선한다. HUD/타이틀 디자인 보류, Unity 미적용.

|---|---|

## 시안 반영 범위
- world-flows-v1 로딩 실패 확인창, 좌우 선택/선택 버튼만F. Esc로 탐험에 잘못 복귀하지 않음.
- 재시도는 예시 로딩 성공으로 연결. 타이틀로는 기존 진행 상태를 건드리지 않는 이동 경계 화면까지만 제공. 타이틀 디자인은 추가하지 않음.
- 실제 장면 로딩/세이브/오류 신호는 Unity 연결 대상. 기존1.8초는 성공 시연용 시간이며 오류 판정 시간이 아님.
- guide-progress.js는 브라우저 로컬 안내 완료 기록만 저장. 첫 안내 이어보기 경로와 검토 도구의 사망 후 재개 버튼으로 검수. 갤러리 개별 화면은 강제 미리보기라 이미 본 화면도 표시한다.
- 이동/맨손/첫 보상 수령/첫 제작 완료/내구도 안내 닫기 기준으로 단계 완료 기록. ‘나중에 보기’로 제작을 닫으면 완료되지 않음.
- 게임 초기화 시안은 브라우저 안내 기록만 삭제. Unity 영구 데이터 초기화는 실행하지 않음.
- 장비 대기 시안은 기존부터 advanceCombat으로만 감소. 자동 시계는 추가하지 않고 메뉴 유지/전투 경과 검수.

## Unity 연결 계약
안내 완료 신호를 게임 행동 성공에서 받는다. 키 누름만으로 이동·공격 성공 판정하는 HTML은 검토용. 저장소에는 완료 ID 집합을 기록하고 버전 관리한다. 런 사망/타이틀 이동으로 삭제하지 않는다.
장면 이동 요청의 목적지와 진행 스냅샷을 보존한다. 실패/재시도는 보상/정산을 재지급하지 않는다. 타이틀 복귀 후 이어하기도 같은 보존된 진행을 사용하도록 연결한다. 로딩중 중복F와 게임 입력 차단.
메뉴용 고정 입력 맵과 재지정 가능한 플레이 입력 맵을 분리하고, 메뉴가 최상위이면 플레이 입력 맵을 비활성화한다.
