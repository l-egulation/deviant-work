# UI 검토 반영 · 2026-11-12

Unity 미적용. 기존 승인 에셋·테마를 유지한 HTML 검토본.

- 설정: 분류 ↑↓ → F 진입 → 항목 ↑↓ / 값 ←→ → Esc 분류 복귀. 분류에서 Esc 닫기. 조작키 복원 G.
- 고정 F/G 확인창: 방향키로 선택 이동하지 않으며 F/G 각 기능을 직접 실행. 설정 포커스 밑줄 제거, 확인창 크기 축소.
- 하단 키 안내: 가방·제작·장비 및 공통 시안, 설정, 일시정지, 지도에 동일한 키캡·구분선 스타일 적용.
- 제작: 왼쪽 정체성 영역과 팔레트 간격을 조정하여 세로 스크롤 제거. 팔레트 가로 스크롤 유지.
- 공방: 왼쪽 항목 간격과 오른쪽 비교 영역 압축, 대시 적용 시점의 중복 설명 제거. 닫기는 왼쪽 목록 아래 및 최상위 Esc 유지.
- 상자: 승인 이미지의 비율 유지, 160×140 표시 영역으로 축소.
- 지도: 적·충전소·엘리트·보스·출구까지 보이는 전체 요소 검토 예시. 실제 런 스냅샷이 아니며 실제 제품은 방문 공간만 공개해야 함. 확대 시 마커 크기 고정. 소진된 충전소 및 사망한 적은 런타임에서 숨겨야 함.

지도 기준 문서: 팀 저장소 docs/design/run/run-structure.md, docs/getting-started/playtest.md, docs/development/presentation/ui/temporary-gui.md. 최신 포탈은 1/2 두 개. 지도는 기존 승인 도상과 최신 기능을 대조한 시안이며 Unity 기능 구현을 변경하지 않음.

검증: 브라우저 실제 키 입력으로 한글 키보드 KeyF 진입, 항목 이동/값 변경, Esc 복귀, F/G 고정 동작 확인. 제작 5칸/잉크 선택과 공방 일반/조건 미충족 화면의 content scrollHeight == clientHeight 확인. 증강 선택 카드 W/S 동작 회귀 확인.
