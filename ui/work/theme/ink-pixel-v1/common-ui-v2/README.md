# 원형 새 획득 표시

16×16 투명 PNG. 14px 원형 실루엣, 청록색 바탕과 작은 밝은 포인트. 정비소 결과 화면 팔레트 탭 옆에 실제 PNG로 표시. Unity 미적용.

내장 이미지 생성으로 제작 후 알파 경계 정리 및 nearest-neighbor 축소. 프롬프트: round teal pixel notification dot, stepped circular edge, tiny cream highlight, transparent background, no glow or text. 확대본은 runtime PNG를 그대로 정수 배율 확대.
