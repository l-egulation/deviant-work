# 봉인 도전 증강 선택 시안 v1

Unity 적용 전 검토용입니다. 타이틀과 HUD는 보류 상태를 유지합니다.

## 구성
- 어두워진 실제 전투 배경, 세 증강 가로 비교, 기존 붓칠 선택 표시와 확대.
- 이름 / 핵심 효과 / 적용 범위를 같은 위치에 표시합니다.
- 클릭 또는 좌우 키로 선택하고, 아래 증강 획득 버튼에서 확정합니다. F는 항목에서 획득 버튼으로 이동, 버튼에서 확정합니다.
- 보상 선택 중 취소·가방·지도 진입 없음. 획득 후 화면은 검토용 상태이며 게임에 영향을 주지 않습니다.

## 데이터 근거
게임 실행용 저장소 S15P31F109의 data/combat/chapter1_run_augments.json 및 docs/design/stage-gimmicks.md를 확인했습니다. 원격 최신 커밋 대조는 하지 않았습니다.
실제 규칙은 적격 증강 중 서로 다른 3개, 최대 중첩 3회입니다. 시안은 첫 획득 예시로 공격 피해 +12%, 기본 공격 속도 +18%, 최대 체력 +15 및 즉시 15 회복을 고정했습니다.

## 이미지
assets에는 위 세 증강용 투명 PNG 아이콘이 있습니다. 전체 12종의 완성 에셋 목록은 아닙니다. HTML과 미리보기는 동일 파일을 사용합니다.
배경과 선택 표시는 기존 공용 에셋을 재사용합니다. 폰트는 기존 로컬 검토 방식을 유지하며 폰트 파일은 배포하지 않습니다.

## 확인
1920×1080 미리보기 3종, 960×540 영역 간격, 단일 선택, 클릭 후 미확정, 취소 제한, F 이동/확정, 이미지 로딩을 확인했습니다.
