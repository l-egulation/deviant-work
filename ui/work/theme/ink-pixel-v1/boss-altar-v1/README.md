# 보스 잉크 제단 v1 · 테마 검토 시안

Unity에는 적용하지 않습니다. 기존 어두운 배경, 붓칠 선택 표시, 선택 확대, 태그 잉크병 에셋을 재사용합니다. F 키캡을 확정 버튼 왼쪽에 표시합니다. 팀 피드백에 따라 후속 UI의 확정 버튼에도 이 규칙을 사용하며, 과거 화면 일괄 변경은 아직 하지 않았습니다.

## 확인한 규칙
2026-11-10 로컬 게임 실행용 S15P31F109 문서와 코드 확인. 원격 최신 커밋 동기화 검증은 하지 않았습니다.
- docs/design/run-structure.md: 첫 클리어로 런이 끝나는 경우 제단 없음. 다음 챕터로 이어지는 경우 제단 보상.
- unity/Assets/ForestCombatV2/Runtime/Chapter1InkAltar.cs: 다섯 색 선택 → 확정 후 색 변경 불가 → 서로 다른 잉크 최대 3개 → 하나 획득. 닫았다 다시 열어도 후보 유지. 출구로 떠나면 미획득 후보 소멸.
- data/combat/ink_color_parts_proposal.json / ink_color_parts_tuning.json: 최신 이름·효과·고정 등급. 관련 문서 마지막 커밋 c0d20607 (2026-11-09).
- 현재 구현은 잉크 보유 개수 제한 없음. 따라서 이 시안에 가방 포화나 바닥 드롭을 추가하지 않음.

## 시안 범위
색상 선택과 빨강 3후보 비교를 대표 화면으로 제공합니다. 나머지 색도 기존 에셋이 있는 후보로 조작할 수 있으나, 전 53종/보스 확률/중복 제외를 구현한 게임 시뮬레이터는 아닙니다. 후보는 고정된 비교 예시이며 부족한 색은 2개를 보여줍니다.
빨강 후보: 추가타 1등급, 집중 공격 3등급, 표식 폭발 4등급. 수치는 +0 기준이며 팔레트 강화에 따른 실제 수치는 게임에서 결정됩니다.
닫기와 재열기는 시안 안에서 후보를 유지합니다. 출구 이동 자체는 시뮬레이션하지 않습니다. 획득 후 안내는 검토용 종료 상태입니다.

## 조작
좌우 선택 → 아래 또는 F로 확정 버튼 이동 → F 확정. 마우스는 항목 선택 후 버튼 클릭. Esc 닫기. 각 버튼에 보이는 F는 현재 포커스의 실행 키입니다.

## 검토 포인트
색상 선택은 색 이름과 역할을 함께 표시합니다. 잉크 비교는 이름·핵심 수치·발동 조건 순으로 읽습니다. 봉인 증강과 달리 가방으로 획득하며 즉시 장착하지 않습니다.
폰트는 기존 로컬 적용 방식을 유지하고 폰트 파일을 배포하지 않습니다.
