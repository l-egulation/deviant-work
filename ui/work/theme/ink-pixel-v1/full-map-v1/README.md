## 지도 아이콘 에셋 적용

assets/의 투명 PNG를 실제 지도 및 범례에 사용. 정비소는 노랑, 보스는 검붉은색, 포탈은 하늘파랑이며 내부를 짙은 파랑으로 채웠다. portal-1.png부터 portal-5.png까지 번호 포함 에셋을 준비했다. 현재 지도 예시에는 기존 규칙대로 1·2번만 배치한다. 물음표는 흰색을 유지한다. 기존 임시 마름모·모루 도형·보스 점·물음표 글자를 대체했다. 생성 원본 및 프롬프트: [assets/README.md](assets/README.md).

## 지도 근거
2026-11-09 Figma 직접 조회:
- 디자인: [② 챕터 탐험 페이지](https://www.figma.com/design/qjL5PNYHPgTDQ0huZXBzLg?node-id=120-75), 최신 지도 v2 `121:550` 확인(페이지 상위 목록에서 이후 지도 버전 없음).
- [현재 흐름도](https://www.figma.com/board/nHfGBYZsYIcHNUD9SU4cGs?node-id=100-1706): M 지도, Esc 일시정지, 포탈 C/V 설치·F 왕복·지도 번호 1/2.
- 팀 저장소 docs/design/ui-and-interaction.md, docs/design/run-structure.md.

와이어의 정보 역할을 유지하고 사용자 요청에 따라 기존 테마로 재배치했다. 회색 박스와 단일 포탈 표기를 그대로 복제하지 않았다.
- 왼쪽 지도 / 오른쪽 범례 / 하단 조작, 일시정지 및 M/Esc 닫기.
- 현재 위치, 지형·발판, 카메라 범위, 설치된 포탈 번호 1/2.
- 랜덤 스테이지의 방문 영역+인접 통로 규칙을 선택. 아직 방문하지 않은 보스 위치는 지도에 노출하지 않는다(범례만 유지).
- 방향키/드래그 이동, +/−/휠 확대, C 현재 위치, Home 전체 보기: HTML에서 동작. 지도 열린 동안 C는 지도 조작이며 포탈 설치 아님.
- 지형은 정보 배치를 확인하기 위한 예시이며 실제 런 좌표를 추출한 맵이 아니다. 배경은 기존 승인 시안의 마을을 그대로 재사용했다. 실제 전투 배경 및 Unity 지도 데이터 연결은 후속.
- 지형 선은 동적 지도 표현용 벡터이며 장식 에셋이 아니다. 정비소·포탈 표식은 별도 PNG 에셋을 사용한다.

## 통일성을 위해 남긴 검토 항목
1. 가방 용량: 팀 UI 문서의 분류별 15칸과 성장·경제의 공용 5→15칸이 다름. 이번에는 임의로 하나를 확정하지 않음.
2. 가방 정지: 사용자/와이어는 일시정지, 현재 팀 구현 문서는 비정지·피격 시 닫힘. 테마에선 기존 일시정지 표기 유지.
3. 정비소는 기본 3칸, 장비는 확장 5칸을 보여주는 서로 다른 예시 상태. 같은 세이브의 연속 화면으로 보면 안 됨.
4. 성장 증가량/상한은 시안 예시. 나머지 거래도 HTML 상태 표현이며 Unity 완료가 아님.
5. 헤더 닫기·시설 복귀와 키보드 전체 포커스 흐름, 패드 표시, 버리기/파괴의 짧게·길게 입력은 후속 인터랙션 검증 필요.
6. 지도 와이어의 적 표시는 현재 제품 지도 요구에 명시되지 않아 보류. 테스트 맵 전체공개와 랜덤 스테이지 탐험공개도 공급 데이터에 따라 달라야 함.

## 확인 범위
1920×1080 화면 렌더 및 대표 12개 비교, 지도 960×540 가독성 확인. 브라우저 시안만 확인하며 Unity/실제 게임 플레이 검증은 수행하지 않음.
