# 일반 사망 / 보스전 사망 / 클리어 결과

## 정산 확인
팀 docs/design/systems/roguelite-progression.md 28,207행: 마법안료는 처치 즉시 획득하며 사망에도 유지한다. 결과는 이번 런 획득량을 표시하며 중복 지급하지 않는다. TemporaryGameGui.Chapter.cs RefreshMenu도 마법안료 획득량을 표시한다. run-structure.md 결과 규칙에 플레이 시간·처치 수·탐험 구역 수·사망 시 보스 잔여 체력·마을 팔레트 조각 수가 명시되어 있다.

주의: 팀 문서의 자발적 귀환 유지 문구는 최신 사용자 결정(자발적 마을 귀환은 진행 및 이번 런 영구재화 포기)과 충돌한다. 이 시안은 사망 유지 / 정상 클리어 유지 / 자발적 귀환 포기를 구분한다. 팀 게임 로직과 원본 문서를 수정하지 않았다.

## 디자인
중앙 폭 820의 열린 레이아웃, 흑연 배경, 기존 Memoment 폰트와 선택 잉크 PNG. 정보는 아이보리, 보조는 회색, 안료는 재화색, 보스 잔여 체력은 연한 적색, 새 마을 잉크는 연한 녹색. 버튼 키캡은 없고 하단에 F 선택을 한 번 표시한다. 마을로는 시안 오버레이만 닫는다.

모든 수치는 가독성용 예시. 클리어는 첫 1챕터 클리어로 런이 끝나며 마을 잉크를 얻는 사례다. 다음 챕터로 계속 진행하는 중간 보스 처치와 구분한다. 마을 잉크는 팀 문서의 마을 팔레트 조각을 표시하는 흐름도 명칭이다.

배경은 기존 승인 마을 이미지의 테마 비교용이다. 실제 사망/보스 장면 캡처가 아니며 Unity 적용 때 사망·클리어 당시 월드를 유지해야 한다. 사망 후 실제 시간 2.5초 표시 대기는 HTML에 구현하지 않았다. Unity/실제 프로필 저장 미적용.
