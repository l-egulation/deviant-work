## 제작 상태
Unity 파일은 수정하지 않았다. 이 폴더는 시안·제작 원본이며 런타임 패키지가 아니다. 생성된 병 라벨·등급은 모든 실제 아이템과 아직 대응하지 않았으며, 외형 검토용이다. 원본 시트는 개별 분리·픽셀 크기 통일·알파 가장자리 검증이 필요하다. 모든 게임 에셋 제작이 끝난 상태가 아니다.

가방 시안은 생성 모델의 글꼴이며 MemomentKkukkukk를 정확히 적용한 이미지가 아니다. 실제 폰트 검토는 spec/font-preview.png에서 한다. 사용자 제공 폰트 바이너리는 라이선스 재배포 조건 확인 전이므로 커밋에 포함하지 않았다.

이전 단순 도형 PNG는 최종 이미지 에셋으로 채택하지 않았고 이 패키지에 포함하지 않았다. history는 비교용 과거 시안이다. 현재 선택 표시는 한 곳에만 강하게, 화면은 박스 없이 여백과 얇은 선으로 구성한다.

## 남은 제작 목록
1. 잉크병 기본형과 색상별 병을 개별 이미지로 고정하고 라벨 효과를 실제 ID와 연결.
2. 팔레트 6색 빈/채움 상태, 선택 획, 선, 화살표, 키캡, 등급 배지, 파괴 진행 표시를 번짐 없는 개별 이미지로 제작.
3. 실제 무기·무기 도장·특수 도장 원본과 맞춘 아이콘.
4. 첨부 폰트로 가방·장비를 조립하고 후보 가로 넘김(무색 슬롯), 긴 설명, 여러 해상도 검토.
5. 위 과정 후 Unity 적용. 현재는 적용하지 않는다.

제작 도구: 내장 이미지 생성. 최초 프롬프트는 prompts.md. 가방은 생성 후 개수를12개로 수정했고 잘못 생성된 빈칸 표시는 제거했다. 빈 공간은 보관 수치로 확인한다.
