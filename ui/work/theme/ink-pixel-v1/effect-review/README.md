# 전체 효과·문양 검토

index.html을 로컬 브라우저에서 열면 54종을 색상/검색으로 비교한다. 전체 theme 폴더와 함께 내려받아야 이미지 상대 경로가 유지된다.

게임 규칙 JSON 전체를 복사하지 않고 사용자가 요청한 UI 검토에 필요한 효과 설명·발동 조건·제약을 카드로 표시했다. 기준은 현재 로컬 S15P31F109/data/combat/ink_color_parts_proposal.json이며 원격 최신 여부는 이번에 확인하지 않았다.

문양 파일은 수정 대표 5종에 v2, 나머지 49종에 v1을 연결한다. 팔레트 합성 미리보기와 문양 단독을 나란히 표시하고, v2에는 이전 문양도 접어서 확인할 수 있다. 54개 모두 의미 전달 검토 의견을 작성했다. 디자인 확정·게임 규칙 변경은 아니다.
