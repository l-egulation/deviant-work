# 장비

[공통 명세](README.md) · [6칸/긴 이름](../sketch-v3/index.html?state=equipment-six) · [빈 상태](../sketch-v3/index.html?state=equipment-empty) · [자리 교환](../sketch-v3/index.html?state=equipment-swap)

## 배치
좌측680px: 장착할 자리 제목 → 무기1/2 → 완성 무기3열 → 행동 버튼. 우측840px: 선택 무기 이름/내구도/기본공격/스킬/적용 효과. 중앙140px.
목록 간격 세로32/가로22px, 목록 아이템 내부gap18px. 이름25px, 장착중 표시20px. 자리 버튼너비230px/간격48px, 자리 아래 이름은 한줄 말줄임. 목록은 이름·게이지%·장착중만 표기.
내구도: 목록 게이지95×7px + 숫자23px, 상세205×10px + 숫자28px, 상세 간격22px. 원시 잔량/최대값 숫자를 추가하지 않음.

## 입력
|단계|방향키/F|Esc|
|---|---|---|
|자리 선택|←→무기1/2, F 완성 무기 선택으로|메뉴 닫기 요청|
|완성 무기 선택|3열 이동, 첫줄↑자리. F 장착/교환|자리 선택|
|행동 버튼|←→장착/해제 등 활성 행동, F 실행. ↑목록 복귀|자리 선택|
|상세|W/S 스크롤, 이름변경 버튼으로 입력창|현재 단계의 뒤로|
|이름 변경|최대20자, Enter 저장, Esc 취소. ↓저장/취소, ←→버튼, ↑입력|저장 없이 닫기|

자리 선택 중 목록 opacity .42, 제목 밝은 금빛. 무기 탐색 중 자리 옵션 opacity .65, 목록 제목 밝은 금빛. 보존된 자리와 현재 후보를 혼동하지 않도록 한다.

## 장착/해제 판정
|상황|행동|
|---|---|
|현재 자리에 이미 장착|장착중 비활성, 중복 실행 없음|
|반대 자리에 장착|두 자리 교환. 대기중에도 허용, 기존 타이머 유지|
|가방 무기, 대기0|장착 후 공유10초 대기 시작|
|가방 무기, 대기중|남은 초와 비활성 버튼. 위쪽 중복 안내 없음|
|해제, 대기0|빈 자리로 변경, 공유10초 대기 시작|
|해제, 대기중|불가. 자리 교환은 별도 허용|
|완성 무기 없음|빈 자리/안내. 장착 불가, 제작 탭 이동 가능|

두 자리 모두 비어도 장비창에 맨손 무기를 생성하지 않는다. 전투에서 무기1 맨손은 HUD 구현 범위. 효과 목록은 잉크명 중복을 생략하고 실제 효과 문장 표시, 일치 효과만 은은히 강조. 긴 효과는 우측 스크롤, 무기/스킬 설명 영역 분리.

## 데이터/실행
입력: weapon.uid/customName/form/skill/durabilityPercent/slotColors/appliedInkIds/effectiveEffects, equippedUid[2], sharedSwapRemaining.
실행: Equip(target,uid), Swap, Unequip(target), Rename(uid,name). UI 버튼 비활성만으로 보안/정합성을 맡기지 않고 게임 로직에서 재검증. 잔여 대기는 메뉴/일시정지 중 정지하고 게임 진행 시간으로만 감소한다. 복귀 시 남은 시간부터 재개한다.

## 수용 기준
두 자리 이름20자 말줄임,3열 이동/첫줄↑, 반대 자리교환, 대기중 장착·해제 차단, 스왑타이머 유지, 긴6효과 스크롤,0무기, 이름 한글조합20자·Esc 취소.
