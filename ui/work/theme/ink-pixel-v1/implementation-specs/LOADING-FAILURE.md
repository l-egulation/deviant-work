제목: 장면을 불러오지 못했어요.
본문: 진행 상황은 유지됩니다. / 다시 시도하거나 타이틀로 돌아갈 수 있습니다.
행동: 다시 시도 / 타이틀로. 기본 초점 재시도. ←→선택, 선택한 버튼에만F, F실행. 고정F/G창이 아님. Esc는 화면 유지(실패한 장면으로 복귀하지 않음). 로딩중 모든 메뉴 입력 차단.
재시도→기존 목적지 재요청→성공시 다음 장면/오류시 같은 확인창. 타이틀로→진행 저장 유지 후 타이틀. 임의 타임아웃으로 오류 생성 금지.
시안 검토 도구 ‘로딩 오류 발생’은 명시적 오류 주입. 실제 게임에서는 loader error 신호로 호출. 타이틀 실제 화면은 보류라 시안은 이동 경계 안내만 표시한다.
검수: 좌우/F/한글입력의 물리F, Esc유지, 재시도중 입력차단, 수량 보존,960×540 잘림 없음. 테스트 기록은 world-flows-v1/office-input-check.json.
