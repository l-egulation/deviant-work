## 조작
M/Esc 닫기(게임으로 입력 복귀), 방향키 지도 이동, +/− 확대축소(현재 .75~2, .25단위), C 현재 위치 중심, Home 전체 보기. 마우스 드래그/휠 동일. HTML 닫기 후 M/Esc는 다시 열기 검토 상태로 연결되나 실제 닫힌 지도 입력은 게임 라우터가 소유한다. F가 필수인 버튼목록 화면이 아니며 기존 전용 키를 유지한다.
지도 확대 시 지형/좌표만 확대, 마커는 역배율로 **화면상 크기 유지**. 현재 위치76px, 상점72px, 포탈64px, 일반 마커52~56px(논리 기준). 플레이어/카메라/문/방 위치를 실제 좌표 투영으로 갱신한다. 하드코딩된 예시 지형·이동40px·범위 제한은 게임 데이터와 연결한다.

## 정보와 상태
탐험한 지형·발판/길, 미탐험 방향, 현재 위치, 카메라 범위, 상점(시안 명칭 정비소), 상자방, 봉인, 보스/엘리트, 충전소, 살아있는 적, 출구, 포탈. 상점 노랑/보스 검붉음/포탈 하늘파랑/물음표 흰색/캐릭터 눈 어두운 노랑. 방 영역은 종류별 낮은 불투명도 색(현재 .12~.16), 길로 오인될 내부 장식선 금지.
완료 방/열린 상자/사라진 적/사용 불가 표시는 게임 상태로 갱신해야 한다. 현행 지도는 정적 풀버전 예시이며 완료 전후 전환이 모두 구현된 것은 아니다. 미탐험 방의 상세 보상/목적지를 미리 노출하지 않는다.

## 에셋·미완성 경계
지도 소스에는 충전소 십자·적 점·출구 범례 기호가 도형/문자로 남아 있다. 이벤트4종 각각의 마커/완료 표현도 아직 전체 지도에 연결되지 않았다. [월드 이벤트 명세](CHALLENGES.md) 및 승인 에셋 ID로 연결해야 하며, ‘전체 요소 검토’라는 제목만으로 모든 마커가 승인 에셋 적용 완료됐다고 간주하지 않는다. 보류한 미니맵/HUD 배치를 여기서 새로 확정하지 않는다.

검수:100/200%에서 마커 크기 동일·실제 위치 일치, 방 색/길 대비, 범례와 맵 가장자리 겹침, 미탐험 숨김, 입력 재지정, 작은 화면 전체 범례, 닫기 후 게임 입력 복귀. 실제 지도 생성·포그·저장 데이터는 미연결.

## 2026-11-13 시안 보완
충전소/출구는 승인 atlas 이미지, 이벤트4종은 ui-assets-v1/world-0~3, 완료 표식은 control-6을 사용한다. 완료는 아이콘 감쇠와 체크를 함께 쓴다. 이벤트 방의 영역은 연한 색으로 표시한다. 적 위치의 점은 위치 표시용 그래픽이다.
`full-map-v1/index.html?events=complete`에서 완료 상태를 비교한다. 지도 확대 시 마커는 역배율로 크기를 유지한다. W/S는 범례 스크롤, 방향키는 지도 이동, Esc는 닫기다.
방 배치는 시각 검수용 예시다. 실제 생성된 방 좌표/탐험 여부/완료 여부는 아직 연결하지 않았다. 전체 갤러리에 완료 상태 추가.
