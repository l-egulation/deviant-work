# 사망·챕터 클리어·최종 클리어 결과

[공통](README.md) · [일반 사망](../sketch-v3/index.html?state=result) · [보스전 사망](../sketch-v3/index.html?state=result-boss) · [챕터 클리어](../sketch-v3/index.html?state=result-clear) · [최종 클리어](../world-flows-v1/index.html?state=final)

현행은 sketch-v3/resultScreen과 world-flows-v1 최종 결과. run-result-v1은 이전 시안이므로 별도 신규 화면으로 중복 구현하지 않는다.

## 정보 순서·배치
큰 중앙 결과 제목 → 결과 요약 → 기록 → 이동 버튼. 제목을 좌측으로 이동하거나 일반 화면 상단 제목을 중복 표시하지 않는다. 배경은 기존 어두운 게임 화면, 승인 글꼴·붓칠 선택 유지.

|요소|일반/보스 사망·챕터 클리어|
|---|---|
|전체|1920×1080, 최대폭1360px, 중앙|
|결과 제목|112px, 자간18px, 중앙, 아래18px|
|제목 영역|상하 padding24/42px|
|보조문구|27px 회색|
|기록|2열 간격130px, 상단 구분선+38px|
|기록 소제목|32px, 아래28px|
|기록 행|28px, 행 아래26px, 항목/값 간30px|
|이동 행동|중앙, 위36px·구분선 아래28px, 글자32px·최소폭260px|

사망 제목 옅은 적색 #e6aaa1, 클리어 #c7ddd5. 기록명 회색 #acb5c0/기록값 아이보리 #f1ede3. 과도한 여러 색 강조는 피한다. 획득 마법안료는 승인 에셋 사용.

최종 결과는 현재 별도 월드 시안: 폭1450px/top95px, 제목104px #c3dfd2/아래24px. 부제27px/아래48px. 기록 영역 상하45px, 열간120/행간34px, 최소350px. 항목28/값34px·사이16px. 버튼30px 중앙. 차이를 숨기지 않고 현행 수치로 전달하며 Unity에서 임의로 일반 결과와 다른 정렬을 추가하지 않는다.

## 표시 데이터·이동
|결과|기록/문구|이동|
|---|---|---|
|일반 사망|사망 / 이번 도전이 끝났습니다. 시간·처치·탐험 구역·보스 미도달, 획득 기록|마을로|
|보스전 사망|사망 / 보스전에서 쓰러졌습니다. 보스 남은 체력%|마을로|
|챕터 클리어|클리어 / 챕터를 돌파했습니다. 보스 처치 완료·획득 기록|다음 챕터로. 첫 클리어도 동일|
|최종 클리어|최종 클리어 / 마지막 챕터를 돌파했습니다. 도달지점·시간·사용무기·마법안료|마을로 또는 기록 확인|
|최종 기록 상세|이번 도전의 기록, 처치/완료 이벤트|결과로 돌아가기|

정산 수치는 시안의 18:42/84/18 또는 32분18초/120 등을 복사하지 않는다. 게임 정산 스냅샷을 받는다. 사망 시 런의 스케치·무기·잉크는 새 도전으로 이어지지 않음. 남은 일반 보상 기회는 챕터 이동에 유지. 지급·저장·장면 이동을 UI가 별도로 재계산하지 않는다.

## 조작·상태
단일 이동 버튼은 초점과 F를 명확히 표시, F 실행. 최종은 ←→로 마을로/기록 확인 선택, 선택한 것만 F. 기록 확인 후 결과로 복귀해 정산을 재실행하지 않는다. 전환 요청 중 버튼 비활성 및 중복 입력 차단이 필요하다.

**Esc는 현행 시안의 미연결 지점이다.** sketch-v3 결과의 Esc는 stage만 browse로 바꾸며 실제 마을로 가지 않는다. world-flows 최종은 공통 Esc 분기로 탐험 시안에 복귀할 수 있다. 이를 게임의 ‘최종 결과에서 전투 복귀’ 규칙으로 복제하지 않는다. 최종 기록에서 Esc→결과, 결과 본화면은 명시적 이동 행동으로만 목적지 이동하도록 연결 검수가 필요하다. 이 문서는 해당 동작을 이미 수정/승인했다고 주장하지 않는다.

## 구현 계약·검수
runId/resultId/resultKind/chapter/hasNextChapter, 시간·처치·방·이벤트·보스상태·사용무기·정산재화·기록조각·정산완료 여부를 전달. 정산 한 번만 실행, 결과 재표시는 저장된 값 사용. 보스 선택 보상과 결과의 호출 순서는 보상 흐름 관리자에서 연결하고 재방문으로 중복 지급하지 않는다.
현재 일반 이동 버튼은 toast 예시이고 최종 마을도 HTML 상태 전환이다. Unity 장면 로드는 미적용. 일반/보스 사망 구분, 첫/반복 클리어 다음 챕터, 최종 마을, 기록 왕복, 중복 F, 긴 수치·960×540 가독성·전환 입력 차단을 검수한다.
