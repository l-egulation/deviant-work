## 목적/구성
보유 스케치·잉크의 정보 열람 전용. 장착·잉크 적용 버튼을 가방에 추가하지 않음.
좌측: 스케치/잉크 분류와4열 아이콘, 아래 보유 개수. 우측: 선택 항목 이름·무기 기본공격/스킬 또는 잉크 설명. 좌측 이름/효과를 중복 나열하지 않음.

4열 간격 세로48/가로18px. 목록은 세로 스크롤. 우측 상세는 독립 스크롤. 중앙140px 여백 유지. 주탭과 분류 탭을 혼동하지 않도록 분류는 본문 위 별도행.

|상태/입력|동작|
|---|---|
|진입|기본 스케치 첫 항목 선택, 상세 동기화|
|목록 ←→/↑↓|4열의 이웃 항목으로 이동, 필요하면 자동 스크롤|
|첫 줄 ↑|분류 탭으로 초점 이동, 목록 명도 낮춤|
|분류 ←→|스케치/잉크 변경 및 첫 항목 미리보기|
|분류 F 또는 ↓로 목록 이동|항목 탐색 재개|
|W/S|우측 상세만 스크롤|
|Q/E|제작/장비 등 주탭 변경|
|보상에서 열람 중 Esc/복귀 버튼|기존 후보·선택 위치로 복귀. Q/E 다른 메뉴 이동 차단|
|일반 최상위 Esc|게임으로 닫기 요청. 독립 HTML은 닫기 연결 대상|

## 상태와 데이터
빈 목록은 ‘보관한 항목 없음’. 아이템 선택/실행을 허용하지 않고 분류/주탭/뒤로는 가능. 잉크는 소모성 카운트나 반복사용 설명을 붙이지 않는다. 스케치 상세의 팔레트는 정보용, 편집 불가. 보상 비교 복귀는 새 후보를 만들지 않는다.
입력 데이터: sketch.uid/form/skill/colors, ink.id/name/description/기본·일치값, 선택 ID, 분류, 목록/상세 스크롤 위치. 표시 순서는 실제 보유 목록. 데모 순서를 고정 게임 규칙으로 사용하지 않는다.

## 수용 기준
43종 끝까지 방향키 이동, 첫줄↑분류 복귀, 이름을 숨겨도 우측 상세로 식별, 긴 효과가 버튼/안내를 밀지 않음. 빈 목록에서도 Esc 가능.
