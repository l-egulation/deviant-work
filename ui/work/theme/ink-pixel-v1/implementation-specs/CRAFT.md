# 제작

[공통 명세](README.md) · [6칸](../sketch-v3/index.html?state=craft-six) · [잉크 선택](../sketch-v3/index.html?state=craft-match) · [빈 칸 확정](../sketch-v3/index.html?state=craft-empty-confirm)

## 배치
좌측860px: 스케치 선택 또는 선택 무기 정체성/팔레트/작업. 우측660px: 현재 칸 설명 또는 적용할 잉크/효과 또는 제작 검토. 중앙140px 유지.
슬롯 너비145px, 슬롯 간격24px, 아이콘122.5×86.8px(선택), 비선택98×69.44px. 아이콘-라벨 간격14px. 슬롯 아래에는 잉크명 또는 빈 칸. 별도1번/2번 칸 선택목록 없음. 6칸은 가로 스크롤하며 선택 칸을 드러냄.
잉크 선택은 가로 스크롤 아이콘. 아래 구분선 다음 이름·효과 설명, 큰 병을 중복 배치하지 않음. 효과30px/행간49.5px. 색상 일치/기본 적용값은 설명 아래 노랑 표시.

## 단계별 입력
|단계|방향키/F|Esc|
|---|---|---|
|스케치 목록|목록 이동, F 이 스케치로 제작|메뉴 닫기 요청|
|팔레트 선택|←→칸, F 잉크 선택. ↓작업 버튼|스케치 목록, 임시 배치 유지|
|칸 작업|←→잉크 선택/임시 적용 해제. ↑선택 칸, ↓제작 내용 확인|스케치 목록 복귀|
|제작 내용 확인 버튼|F 최종 검토, ↑팔레트로 복귀|스케치 목록 복귀|
|잉크 선택|←→보유 잉크, F 해당 칸에 임시 적용 후 팔레트로 복귀. ↓행동 버튼|팔레트 선택으로 복귀|
|최종 검토|F 제작 확정. ↑또는 돌아가기 선택으로 팔레트 재검토|팔레트로 복귀|
|제작 완료|장착하기/보관하기 선택 F. 보관은 제작 목록으로|보관하고 제작 목록으로|
|장착 자리|←→무기1/2, F로 행동 버튼 진입 후 F 장착|장착/보관 선택으로|

현재 시안의 공간상 버튼 위치가 다르면 방향키의 실제 이웃은 실측/직접 조작 기준으로 잡는다. ‘임시 적용 해제’는 적용된 칸에만 표시. 팔레트에서 오른쪽은 다음 칸이며 잉크 영역 진입은 F로 한다.

## 상태/불변 규칙
- 잉크 없음: 잉크 선택 실행 불가, 빈 팔레트 제작은 가능.
- 모든 칸 빈 상태: 확정 검토에서 이후 추가 불가 설명 제공.
- 임시 배치는 스케치 UID에 연결. 이전 목록으로 나갔다 돌아와도 유지. 확정 전 같은 잉크를 다시 고르거나 해제 가능.
- 잉크 적용은 보유 잉크를 소모하지 않음. 같은 잉크 여러 칸/무기 적용 가능.
- 확정 시 스케치를 완성 무기로 이동. 이후 빈 칸 포함 변경 불가, 중복 확정 불가.
- 10초 교체 대기 중 새 무기 장착은 비활성. 보관/돌아가기는 가능.
- 좌측 선택 칸은 우측 활성 중에도 유지하되 좌측 내용 명도 낮춤. 초점이 우측 잉크에 있음을 명확히 표시.

## 레이어/데이터
승인 슬롯 바탕 → 잉크 칠 → 효과 문양. 슬롯색과 잉크색 독립. 빈 칸은 바탕만. 자세한 합성 좌표는 에셋 패키지 참조.
입력: 스케치 UID, form/skill, slotColors1~6, draftInkIds, ownedInkIds, 선택 슬롯/잉크, 기본/일치 효과값, 장착 대기. 실행 요청: draft 적용/해제, 제작 확정, 장착 또는 보관. 게임 성공 결과를 받아 화면 전환.

## 수용 기준
6번째 칸 접근/F/Esc, 해제 버튼 방향키 접근, 제작 확인↑슬롯 복귀, 초안 유지, 빈 제작, 확정 후 재편집 불가, 보관→제작, 대기중 장착 차단.
