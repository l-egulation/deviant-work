# 월드 상점

[공통 명세](README.md) · [구매 가능](../sketch-v3/index.html?state=shop-world) · [골드 부족](../sketch-v3/index.html?state=shop-world-poor) · [품절](../sketch-v3/index.html?state=shop-world-sold) · [팀 합의](../OFFICE-HOUR-WORLD-SHOP.md)

현행은 월드의 무기 3자루·잉크 3개, 총 6자리와 근접 말풍선. 기존 전체 화면 shop 시안은 보관용이며 신규 구현 대상으로 혼동하지 않는다. 코드 주석의 ‘Alternative proposal’보다 위 팀 합의가 우선한다.

## 배치·스타일
상품 아이콘 아래 가격, 가까운 상품 위에 승인 꼬리 프레임으로 이름·설명·구매 행동을 표시한다. 캐릭터와 상품을 가리지 않도록 앵커를 실제 월드 위치에 연결. 전체 화면 블러를 추가하지 않는다.

|요소|현재 HTML 기준(1920×1080)|
|---|---|
|상품 행|main 내부 좌우 2%, top 640px, 6열, 간격 24px|
|상품 아이콘|132×132px, 선택 1.13배|
|가격|30px, 금빛 #f3d597, 아이콘과 22px 간격|
|말풍선|너비 580px, padding 위60/좌우40/아래60px, bottom316px|
|말풍선 위치|main 너비의 상품 중심을 따르며 양 끝은 19~81%로 보정. 게임에서는 근접 상품 앵커로 대체|
|이름/본문|32px/25px, 이름 아래24px, 본문 행간1.6·아래22px|
|구매 줄|위 여백22px·구분선 아래18px, 글자27px|
|보유 골드|우측 상단, 27px; 숫자 왼쪽24px 여백, 금빛|

꼬리 프레임은 승인 에셋 패키지의 분할 기준 사용. 모서리/꼬리를 늘리지 않는다. 화면 끝에서는 패널만 안쪽으로 옮기고 꼬리는 상품을 가리킨다. 긴 설명이 상단을 벗어나면 본문 스크롤 또는 앵커 이동이 필요하며 고정 높이로 글자를 자르지 않는다.

메뉴 비교 시안은 3열×2행, 각 자리 192×276px이며 위에 무기, 아래에 잉크를 놓는다. 방향키는 실제 행·열을 따라 이동하고 W/S는 오른쪽 설명을 스크롤한다. 월드 시안도 W/S로 긴 말풍선 본문을 스크롤하며 구매 행동은 고정한다.

## 입력·상태
시안에서는 ←→로 상품 선택 후 F 구매한다. 실제 월드는 근접 대상으로 선택을 결정하고 F 상호작용 구매. 방향키를 상품 이동에 소비하여 캐릭터 이동을 막지 않는다. 근접 해제 시 말풍선 닫기; 메뉴로 진입한 경우 Esc 한 단계 복귀. 이 월드 입력 연결은 HTML에서 실제 이동으로 구현된 것은 아니다.

|상태|표현/실행|
|---|---|
|구매 가능|선택 행동만 붓칠+F, 가격 함께 표시|
|골드 부족|구매 비활성, 버튼 자리에서 골드 부족 안내. 중복 긴 안내 금지|
|구매 완료|해당 자리 품절 유지, 재구매 불가. 다른 상품 재추첨 없음|
|전종 잉크 보유|잉크 자리 3개는 비워 둠. 무기로 대체하지 않음|
|가격 미정|실제 구현에서는 구매 불가, 0G/무료로 해석 금지|

잉크 설명은 가방과 같은 문장/조건 파랑·효과 초록을 사용. 일반 조사/대상 문구는 흰색. 스케치는 이름·스킬·설명·팔레트, 필요 없는 내구도/중복 큰 이미지는 추가하지 않는다.

## 진열·가격 데이터
같은 런의 같은 상점은 무기 3자루와 미획득 잉크 3자리를 유지한다. 새 도전에서만 재구성한다. 동일 무기 구성과 동일 잉크는 중복 진열하지 않는다. 무기 칸 수는 스테이지 범위에서 같은 확률로 추첨한다. 미획득 잉크가 1~2종이면 나머지 잉크 자리는 비워 둔다. 전종 보유 시 잉크 세 자리가 모두 빈 상태다. 외부에서 획득한 진열 잉크는 해당 미구매 자리만 다른 미획득 잉크로 교체하며, 남은 종류가 없으면 비운다. 구매한 자리는 품절로 유지되고 다른 상품은 재추첨하지 않는다.

|챕터|스케치 가격|잉크|
|---|---|---|
|1|200 + 칸 수×100 + 유색 칸 수×50|220G|
|2|350 + 칸 수×175 + 유색 칸 수×90|400G|
|3|현행 데이터 pricesKnown=false|미정|

위 값은 runtime-content.js 스냅샷이며 하드코딩 UI 문구가 아니다. 게임의 가격 결과를 전달받는다. 월드와 전체 화면 모두 미정 가격 구매를 차단하며 0G로 표시하지 않는다. `shop-world-ch3`으로 월드의 미정 가격 상태도 확인할 수 있다.

## 데이터 계약·검수
runId/shopId/상품 슬롯별 itemId·type·price·sold, ownedInkIds, gold, 근접 대상. 구매 시 잔액/품절/가격을 재검증하고 차감·지급·품절을 함께 반영한다. 재입장, 외부 잉크 획득, 1종/전종 보유, 반복 F, 화면 양 끝·긴 설명을 검수. 기존 전체 화면 상점이 다시 열리지 않아야 한다.
