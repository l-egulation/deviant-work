# 마을 통합 공방 · 영구 성장

[공통](README.md) · [공방](../sketch-v3/index.html?state=permanent) · [대시](../sketch-v3/index.html?state=permanent-dash-ready)

## 진입·구성
장인의 공방 근접 말풍선 F → 영구 성장. 좌측 공격력/최대 체력/이동 속도/출발 지원금/대시 추가, 우측 현재→해금 후·설명·해금 조건·구매. 보유 마법안료는 상단 금빛 수치와 승인 아이콘. 런 중 증강과 다른 영구 시설이다.

1920×1080, 공통 좌우130px·680/140/840 열. 공방 본문 높이675px. 좌측 항목30px, padding20px 22px, 아래20px, 단계24px. 조건 행30px/아래24px, 충족 표시27px. 선택 항목 붓칠·확대, 다른 항목 낮은 명도. 조건 충족은 밝게/체크, 미충족은 opacity .7·잠김 문구. 제목 옆 장식 세로선 없음. 우측 행동 비용은 버튼 옆 노랑, 불가 이유는 같은 줄의 보조 글자.

## 입력
↑↓ 좌측 항목 탐색으로 우측 미리보기, F 해금 실행 또는 해당 행동 진입(현행 공통 focus 처리). 우측 행동에서 Esc는 선택된 좌측 항목으로, 좌측에서 Esc는 마을 상호작용으로 복귀. 마지막 대시 항목↓는 좌측 닫기, 닫기↑는 대시. 현행 시안에는 좌측 닫기가 남아 있고 우측에는 없다. 닫기를 또 추가하지 않는다. W/S 우측 설명 스크롤; 기본 5항목은 스크롤 없이 보이도록 검수한다.

## 규칙·상태
공격력/체력 최대8단계, 이동속도/지원금4단계, 대시1단계. 상세 가격과 선행 챕터는 [progression-data.js](../sketch-v3/progression-data.js)에서 읽는다. 첫 런 정산, 해당 단계 보스 처치 조건, 대시의 이동속도4단계를 각각 표시한다. 조건 미충족/안료 부족/최대 단계/가격 미정이면 실행 불가·F 없음. 최대 단계에는 다음 값을 만들지 않는다.
지원금은 새 도전 시작 때 한 번, 챕터 이동 재지급 없음. 이동속도는 대시/점프 속도에 영향 없음. 대시2회는 하나의 쿨타임을 공유하고 함께 회복. 현행 purchase toast는 대시 마을 즉시 적용/나머지 다음 도전으로 표시하며 게임 능력 적용 시점은 데이터와 함께 연결한다.

## 데이터·검수
영구 단계/선행 플래그/안료/다음 비용/현재·다음 값/적용 시점/호출자. 구매는 조건 재검증→차감→해금→저장 한 번만. UI 숫자 step은 예시 렌더링이므로 게임 계산 결과가 우선. 첫 정산 전, 지원금3단계 잠금, 1·2챕터 조건, 대시 가능/완료, 안료 부족, 최대 단계, 960×540 조건 글자와 행동 접근 검수. 실제 저장은 미연결.
