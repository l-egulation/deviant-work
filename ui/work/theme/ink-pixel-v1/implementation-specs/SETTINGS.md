# 설정·조작 설정

[공통](README.md) · [소리](../settings-v1/index.html?tab=sound) · [화면](../settings-v1/index.html?tab=display) · [조작](../settings-v1/index.html?tab=controls) · [화면 유지](../settings-v1/index.html?state=confirm) · [키 복원](../settings-v1/index.html?state=reset-confirm)

기준: settings-v1/settings.js, style.css의 최종 선언과 공통 confirmation.css/key-help.js. Unity 연결 전 문서이며 실제 해상도·오디오·입력 변경을 완료했다는 의미가 아니다.

## 배치·상태
1920×1080, main 위90/좌우160px. 제목46px. 제목 아래100px에 좌측 분류260px + 중앙130px + 우측1210px. 좌측 항목 간55px, 글자34px. 분류 선택 확대1.15배와 승인 붓칠. **열려 있는 분류와 현재 키보드 초점은 구분**하며 좌측 탐색 중 붓칠은 실제 초점에 따라 내려간다.

우측 일반 행 최소116px, 항목30px, 선택1.1배, 값32px. 슬라이더 전체580px·값 간격32px·숫자33px. 조작은 이동→전투→탐험의 한 목록이며 하위 탭 없음. 목록높이500px, 행64px, 항목28px, 섹션 제목34px, 섹션 간35px+상단패딩28px. 선택행이 자동으로 보이게 스크롤한다.
하단 키 안내 좌우160px/바닥65px, 얇은 구분선과 키캡. Esc 안내도 여기 표시하며 우측 상단 닫기 버튼은 숨김. 추가 밑줄 선택 장식은 없음. 좌측 탐색 중 우측 opacity .72, 본문 조작 중 좌측 .7.

## 조작 단계
|단계|입력|결과|
|---|---|---|
|좌측 분류|↑↓|화면/소리/조작 초점 순환, 내용 변경은 아직 확정하지 않음|
|좌측 분류|F|분류 확정 후 우측 첫 항목 진입|
|좌측 분류|←→|동작 없음|
|우측 항목|↑↓|항목 이동, 끝에서 정지|
|우측 값|←→|선택한 음량/창 모드/해상도/효과음 값 변경|
|우측 적용/키 변경|F|적용 확인창 또는 새 키 입력 대기|
|우측 조작 설정|G|기본 키 복원 확인창|
|우측|Esc|좌측 현재 분류로 복귀|
|좌측|Esc|호출 화면으로 닫기. 미적용 화면 설정이 있으면 확인창|
|새 키 대기|Esc|변경 취소, 같은 행 복귀|

음량은 0~100%, 10단위. HTML range 좌우 입력은 브라우저 기본 동작을 사용한다. 소리 변경 즉시 저장. 화면 설정은 draft와 saved 분리, 바뀐 값이 없으면 적용 비활성. 현재 해상도 목록(1920×1080/1600×900/1280×720)은 시안 목록이며 실제 지원 모드로 연결한다.

## 확인창 공통 규격
승인 폭960px, padding45px 48px, 제목42px/행간1.45/아래33px, 본문34.5px/행간1.65. 버튼37.5px·최소높이60px, 간격60px, 위36px/구분선 아래33px. 키캡57×60px. 뷰포트 배율을 따로 적용하여 960×540에서는 절반. 원래 화면 입력과 키캡이 비치지 않도록 차단한다.

|확인창|F|G|Esc/타임아웃|
|---|---|---|---|
|이 화면 설정을 유지할까요?|되돌리기|유지|Esc 되돌리기, **10초** 만료도 되돌리기|
|변경한 설정을 적용하지 않았어요|계속 설정|변경 취소 후 이동/닫기|계속 설정|
|기본 키로 복원할까요?|취소|복원|취소|

여기는 두 고정 단축키를 모두 표시한다. 방향키는 버튼 초점을 바꾸지 않는다. 일반 ‘선택한 버튼에만 F’ 규칙의 명시적 예외. 표시된 키와 실행 동작은 항상 일치해야 한다. 확인창 종료 시 원래 행/분류로 초점을 복원한다.

## 키 연결·예외
기본 탐험: F 상호작용, G 보상 열기, I 가방·장비, M 지도, C/V 포탈. 전투 Q/E/W/R. 이동 방향키·Space·Shift. 조작 안내 화면도 같은 설정 데이터를 읽어야 한다.
현행 시안은 중복 키, Tab/Enter/Control/Alt/Meta 등록 차단. Esc는 취소. HTML 키 변경은 메모리만, 소리는 localStorage, 화면은 메모리만 저장하므로 이것을 실제 세이브 규칙으로 복제하지 않는다. 캡처는 e.key 기반이고 메뉴 단축키는 물리 code 기반이므로 한글 입력 상태·키 재지정 후 메뉴 충돌 정책은 Unity 입력 시스템에서 검수한다.

## 검수·전달 데이터
saved/draft 화면 값, 음량, 바인딩, 진입 출처·마을/전투 맥락, depth·초점·스크롤·카운트다운. 설정에서 돌아오면 일시정지 ‘설정’ 항목에 초점 복원. 확인창 중 배경 입력 금지, F/G 역전 없음, 10초 복구, 미적용 이동, 중복키, G 복원, 작은 화면과 마지막 탐험 행 접근 검수. 하드웨어 설정 실패 시 기존 값 복구는 게임 연결 책임.
