# 입력 모드·복귀 계약

현행 시안과 확정된 조작을 전달한다. 게임 적용 전 계약이며 Unity 구현 완료를 뜻하지 않는다. 세부 탐색 이웃은 각 화면 명세 우선. 타이틀/HUD 전체 제외.

## 입력 우선순위
이름 입력/키 재지정 → 확인 모달 → 현재 화면의 활성 영역 → 월드. 최상위 하나만 처리하며 같은 F/Enter/Esc가 아래 화면으로 전달되지 않도록 소비한다. 대화 종료 F가 바로 월드 상호작용까지 실행되지 않도록 동일 입력 처리 차단. 길게 누르기 외 확인 입력은 키다운 1회이며 화면 전환 시 눌린 키를 해제할 때까지 새 실행 차단.

|모드|방향키|확정|뒤로|표시|
|---|---|---|---|---|
|일반 목록/행동|활성 영역의 항목 이동|F 선택 항목|Esc 한 단계 복귀|활성 선택 버튼만 F·붓칠|
|설정 고정 두 키 확인|선택 이동 없음|F/G 각각 적힌 행동|아래 표 기준|양쪽 F/G 고정, 선택 포커스로 의미 바꾸지 않음|
|이름 텍스트 입력|입력 커서; ↓버튼 진입|Enter 저장|Esc 취소|Enter 저장/Esc 취소. F를 저장키로 가로채지 않음|
|설정 키 재지정|새 키 후보|허용된 새 키|Esc 취소|게임/메뉴 단축키 실행 금지|
|전체 지도|지도 이동|별도 F 실행 없음|M/Esc 닫기|+/− 확대, C 현재위치, Home 초기화|
|월드|캐릭터 이동|근접 대상 F|일시정지 요청|가장 가까운 유효 대상 하나의 F|
|로딩|차단|차단|차단|실제 완료/실패 신호로만 종료; 실패 정책 미정|

메뉴의 Q/E는 가방·제작·장비 주탭에서만 사용. W/S는 현재 선택 후보/상세 설명 스크롤이며 전투 스킬 입력으로 전달하지 않는다. 텍스트 입력 및 새 키 입력 중 Q/E/W/S/F/G는 메뉴 전환·스크롤로 해석하지 않는다. 메뉴 키는 고정이고 전투·탐험 재지정과 독립한다. 메뉴에서 플레이 입력을 차단한다.

## 화면별 단계와 복귀
|화면|진입/이동/확정|Esc 또는 닫기 복귀|
|---|---|---|
|가방|Q/E 주탭. 첫 줄 ↑ 하위 스케치/잉크 분류; ←→분류, ↓목록. 4열 탐색|최상위는 호출 게임/메뉴로 닫기. 이름 입력은 취소 후 원래 UID|
|제작|스케치 F→팔레트 F→잉크 F 임시 적용→팔레트. 제작 확인→확정|잉크→선택 칸, 팔레트→스케치. 임시 배치 유지. 완성 후 보관/장착 절차 종료는 제작 탭|
|제작 후 장착|장착/보관 먼저 선택 F. 장착일 때 자리1/2 F|현재 하위 선택의 이전 단계. 확정 제작을 Esc로 취소/복제하지 않음|
|장비|자리 F→완성 무기 F. 첫줄 ↑ 자리; W/S 상세|목록→자리→호출자. 장착/교환 후 후보와 대상 자리 유지|
|일반 보상|G로 진입. ←→3후보, W/S 현재 후보, F 획득|후보 닫기 시 미사용 기회 유지. 획득 후 계속 뽑기/닫기; 닫기는 탐험|
|보스 보상|스케치1→잉크1→잉크2 각 선택|독립 시안 닫기와 월드 연속 흐름 차이 있음. 보상 미수령 처리/후속 결과는 REWARDS.md 계약 우선, 임의 보상 소멸 금지|
|이벤트 보상|성공 후 혼합3중1택|완료 roomId/수령 상태 유지. 일반 기회 차감 없음|
|증강|구매→후보, ←→선택 W/S 설명 F획득|닫았다 재진입 시 결제/후보 보존, 재결제 없음. 봉인은 보상 상자 호출자로 복귀|
|월드 상점|근접 팝업 F구매, 불가 상태 F없음|팝업 닫기/범위 이탈, 상품/품절 유지|
|마을 공방|좌측 ↑↓ F→우측 행동 F|우측→원래 좌측항목, 좌측→마을. 현행 닫기 항목은 해당 화면 명세 기준|
|설정|좌측 ↑↓ F→우측, ↑↓행 ←→값, F적용/키변경|우측→좌측, 좌측→호출자. 미적용이면 확인창|
|일시정지|↑↓ F 실행|계속하기. 설정/도움말 닫기 후 해당 원래 메뉴 항목|
|기록 농가|이전/다음/닫기 방향선택 F|삽화→기록→마을. 페이지와 스크롤 보존은 같은 세션 범위|
|우물·충전소·상자|유효 행동 F, 충전소는 길게|원래 상호작용 대상. 누르는 도중 닫으면 충전 진행 취소|
|결과|이동 또는 기록 버튼 F|기록 상세→결과. 결과 본문 Esc로 전투 복귀 금지; 명시적 이동 버튼 사용|
|오프닝·첫 안내|표시된 진행키/실제 행동|스킵·사망 후 재개는 미정, 일반 Esc탐험 예시를 정책으로 복제 금지|
|보스 소개|시간 후 종료/F건너뛰기|전투 유지. 메뉴처럼 초점 이동하지 않음|

## 설정의 고정 F/G
|모달|F|G|Esc|
|---|---|---|---|
|화면 유지|되돌리기|유지|되돌리기. 10초도 되돌리기|
|미적용 이동|계속 설정|변경 취소 후 요청 목적지|계속 설정|
|기본키 복원|취소|복원|취소|

일시정지의 포기/타이틀/초기화 확인은 이 표와 다르다. 취소 기본 초점, 방향키 선택+F, Esc취소. 이름 저장은 Enter/Esc로 별도 구분한다.

## 복귀 정보
화면을 열 때 caller, context(마을/전투), depth, selected UID, tab, scroll offset을 보존한다. 닫을 때 원래 존재하는 항목으로 복귀. 소모/삭제되어 없으면 같은 위치의 다음 항목→이전 항목→빈 상태 행동 순서로 유효 초점 선택하는 구현 권장안을 사용한다. 이 fallback은 현재 시안의 자동 보장으로 주장하지 않는다.
모달이 여러 번 열려도 pause/입력 잠금을 중복 해제하지 않는다. 보상 수령/구매/제작/정산은 UID와 완료 상태로 1회만 실행한다. 브라우저 history/back이나 HTML 예시 scene 전환은 게임 복귀 계약이 아니다.

## 확정된 후속 규칙
[Office hour 결정](../OFFICE-HOUR-INPUT-LOADING.md): 장비 대기는 메뉴에서 정지, 안내는 못 본 단계부터 재개/종료 후 유지/초기화 때만 삭제, 이야기 건너뛰기 허용, 로딩 실패 재시도·타이틀로, 메뉴키 고정.
화면 적용 확인의10초는 메뉴에서도 진행한다. 장비 대기10초와 같은 시계를 사용하지 않는다.

## 적용 전 검사
각 화면 첫 초점→방향→F→Esc→재진입, 한글 입력중 F/WS/QE, 키 재지정 Esc, 모달 배경입력 차단, 방향 이동 없는 F/G, 장문 WS는 선택중 항목만, 삭제된 선택 UID, 길게 입력 취소를 검사한다. 이 문서는 실제 조작 검수 결과가 아니라 구현·검수 계약이다.
