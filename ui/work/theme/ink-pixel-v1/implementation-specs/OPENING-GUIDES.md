## 안내 표시와 입력
이동 안내는 상단 음영 전체폭, 개별 네모 배경 없음. padding43px 160px 25px/gap70px, 항목 최소230px, 제목29px·아래22px, 키캡23px. 수행한 항목은 옅은 초록. 실제 입력/행동 성공 이벤트로 완료해야 하며 시안처럼 단순 키누름 횟수를 게임 성공으로 판정하지 않는다.
추격은 상단 ‘지워짐이 밀려옵니다’와 이동키. 대화는 화자 위 꼬리 프레임, 배경 블러 없음. F 계속, 마지막에 다음 사건. 오프닝 전체 스킵/사망 후 재개/세이브 복원 UI는 현재 미정 연결 지점이며 Esc를 임의로 스킵으로 만들지 않는다.
맨손 안내는 현재 **A**키 예시로3번 누르면 보상으로 이동한다. 기존 전투 Q/E/W/R과 충돌 가능성이 있으므로 실제 맨손 바인딩 확인 후 표시할 항목이다. 확정 조작이라고 간주하지 않는다. 첫 보상은 **G**, F로 잘못 실행하지 않음.

## 제작·내구도와 복귀
첫 제작: 스케치 선택/모든 색 잉크 가능/색 일치 강화/확정 후 수정 불가. 제작 열기 또는 나중에 보기, 방향키·F. 제작 최상위 Esc는 원래 안내로. 실제 완성 무기 발생 때 내구도 안내로 이동.
