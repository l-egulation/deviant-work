## 공통 근접 표현
승인된 계단 모서리·아래 꼬리 프레임을 사용. 대상을 기준으로 위에 띄우고 캐릭터를 가리지 않으며 가장자리를 clamp한다. 실제 거리 판정/피격/이동은 게임 상태가 담당. 현재 HTML 좌표는 배치 검토값. 근접 팝업을 전체화면 창으로 확대하지 않는다. 행동이 여러 개면 방향키 이동/F 선택, 최상위 Esc 닫기. 비활성 행동 F 없음.

## 잠긴 상자
팝업570px, padding40/40/50px, 제목34px·아래26px, 본문25px/행간1.65·아래32px, 행동28px·gap28px. 승인 locked-chest-closed/open과 열쇠 아이콘 사용.
열쇠 있음: 열쇠 보유/상자 열기/닫기. 없음: **열쇠 필요 비활성**/닫기. 열기 성공 시 열쇠1개 사용, 열린 그림과 사용완료·닫기. 재실행 금지. 보상은 상자 위치에서 지급한다는 시안 설명만 존재하며 정확한 보상 출처/종류는 게임 상자 시스템 연결 대상으로 남긴다. 이벤트 위험상자와 규칙을 섞지 않는다.

## 잉크 충전소
폭620px, top190px 중앙, padding42/42/56px. 제목34px·본문27px, 행동26px·gap20px. 승인 꼬리 프레임. 체력 현재/최대, 비용·남은 사용횟수, 회복량, 길게 눌러 회복/닫기.
F 누르고 유지: **버튼 붓칠 안쪽이 차오름**, 별도 아래 진행바 금지. 놓기/포인터 이탈/방향 이동/뒤로/피격 시 취소. 시안 hold1초, 회복25%, 사용2회·100/150G는 연결 데이터 확인 대상. 완료 때만 차감/회복/횟수 감소; 부분 진행은 초기화. 체력 가득/골드 부족/충전 소진은 같은 버튼에 이유, 비활성. 피격 취소는 문구만 있고 실제 Unity 이벤트 연결 필요. HP 예시 최대100을 고정하지 않는다.

## 포탈
검은 문과 위 번호를 표시, 상시 건너가기 팝업/설치불가 알림 없음. 번호54×54px, 현행 문 기준 top−8px, 수평중앙 주변 배치. 승인 포탈1/2 에셋. 지도 번호1~5 에셋 보유가 실제 설치5개를 뜻하지 않는다.
C/V 각 문 설치·같은 키로 재배치. 2초 설치와 Shift 취소, 두 문 근접 F 왕복(시안1.44초 잠금). 기존 문은 설치 완료 전 유지, 취소 시 유지. 공중/두 문 너무 가까움은 설치 차단; 현재140px 기준은 검토값이다. 설치 동작/거리/전환은 게임에서 판정한다. 시안은 취소 안내 문자열을 보유해도 일반 월드에는 렌더하지 않는다.
첫 설치 안내만 꼬리 팝업으로 C/V/F 설명, F 확인. 좌우 여백 대칭·긴 빈 오른쪽 공간 금지. 일반 포탈 화면에 하단 키 설명 띠를 추가하지 않는다. 미설치/한쪽/양쪽/설치중/취소/이동중 입력 차단을 검수한다.
