## 보스 소개
상단 전체폭 자연스러운 음영, 보스명·맞서는 자·건너뛰기. 1챕터 시계탑 집행자, 2챕터 베르소·렉토는 시안 데이터. 약4초 후 소개 제거, F 건너뛰기도 같은 종료. 보스전 내내 배너 유지하지 않는다. 이름/장별 콘텐츠를 게임 데이터로 전달한다.
현재 CSS 마지막 선언이 timedIntro 애니메이션을 끄고 타이머로 화면을 제거한다. 따라서 자연스러운 페이드가 완료됐다고 전달하지 않는다. Unity에서는 기존 요구대로 등장/사라짐을 연결하며 정확한 페이드 곡선은 추후 모션 검수 대상.

## 장착 무기 소진
중앙하단 bottom72px, 내용폭 자동, padding15px 30px, 아이콘/본문gap18px, 제목29px·아래14px, 본문24px. 무기 자리·이름·0% 표시, 약3.5초 후 제거. 입력 없음/pointer-events none. 장비 확인 버튼·보관 무기 소진 알림 없음. 긴 이름은 화면 안전영역 안에서 줄바꿈/말줄임하며 HUD와 겹침은 추후 HUD 작업에서 확인.
알림은 파괴 결과를 표시할 뿐 무기를 삭제하는 주체가 아니다. 실제 장착UID 파괴→슬롯 비움→알림, 보유 잉크 유지. 동시 파괴/연속 알림 우선순위와 큐는 게임 연결 검수 항목.

## 보상 충전 표시(부분 검토, HUD 전체 보류)
[검토 시안](../world-flows-v1/index.html?state=reward-alert): 우측하단 승인 reward-reservoir-v2.png 틀, 안쪽 수직 충전·수면 강조, G와 보유 기회 수. 채워진 양은 다음 기회 진행, 숫자는 이미 보유한 기회. 0회 열기 비활성이나 충전량은 보인다. +1 별도 팝업 없음. 처치15%/35%는 검토 도구값이며 몬스터별 실제 충전량 연결. 진행100%마다 기회 증가와 나머지 이월. 이 문서는 HUD 전체 디자인 확정이 아니다.

## 로딩
전체 화면 어두운 영역, 중앙 세로정렬 gap38px. 승인 다음챕터 아이콘120px, 제목48px, 보조27px. 이동 중 게임·메뉴 입력 차단. HTML은 1.8초 뒤 자동 탐험으로 넘어가는 예시이며 실제 로딩 완료/실패와 무관하다. 게임 준비 완료 신호 후 화면·입력 해제, 실패 시 재시도/복귀 상태 UI는 아직 별도 시안이 없음을 남긴다. 임의 가짜 퍼센트를 표시하지 않는다.

데이터: 보스 소개ID/이름/종료, 소진 이벤트ID/자리/무기명, charge/threshold/bank, transitionId/destination/status. 타이머는 상태 종료시 취소, 재진입한 화면에 이전 타이머가 작동하지 않게 한다. 작은 화면, 중복 이벤트, 건너뛰기 직후 타이머, 로딩 중 F/Esc 연타, 실제 장면 전환을 이후 Unity에서 검수한다.
