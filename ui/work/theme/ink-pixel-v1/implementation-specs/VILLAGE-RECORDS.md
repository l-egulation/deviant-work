## 근접 말풍선과 대화
기록 농가/우물/통합 공방/출발 이정표의 대상 위에 승인 꼬리 프레임. 새 기록/미사용 마을 잉크만 작은 새 소식 에셋. 근접 대상 F로 시설 진입, 멀어지면 표시 해제. HTML의 ←→ 건물 이동은 검토용이며 Unity 캐릭터 이동을 대체하지 않는다.
말풍선 최소폭330px, padding28/34/40px(위/좌우/아래). 대화는 폭1000px, padding38/48/44px, 화자 머리 위에 배치. 세계 배경 블러 없음. NPC와 캐릭터를 가리지 않는다. 꼬리·모서리 크기 고정, 중앙과 변만 확장. [에셋 분할 기준](../unity-handoff-v1/README.md)을 따른다.
대화 F 다음/마지막 마치기, 방향키로 다음·닫기 선택, Esc 마을 복귀. 고정된 검토 앵커 좌표는 실제 월드 바운드의 위쪽으로 교체한다. 팝업 아래 불필요한 방향키 안내 띠는 만들지 않는다.

## 기록 농가
기록0페이지 → 발견한 수첩 삽화1페이지. 미발견 시 다음 비활성/1페이지뿐. F 이전·다음·닫기, ←→ 행동 탐색. Esc 삽화→조사 기록, 조사 기록→마을. W/S는 현재 코드에서 우측/마지막 scroll을 선택하므로 **좌측 장문 독립 스크롤 접근은 Unity 선택 영역 연결로 보완**한다.
조사 기록2열 gap120px/높이660px, 본문28px·행간1.9·문단아래40px. 삽화2열 gap100px/높이665px, 제목35px·아래20px, 그림높이395px, 본문28px·행간1.85·위36px. 하단 이전/쪽수/다음/닫기 중앙, 간격42px, 쪽수27px. 삽화는 record-eroders/record-well 승인 파일. 소스의 radial mask·낮은 채도는 현행 표현이며 그림을 새로 생성하지 않는다.
스토리는 해당 사건 이후에만 추가: 첫 조사→첫 회귀→첫 마을 잉크. 발견/읽음/진행 플래그를 영구 데이터로 관리, 단순 화면 열기로 아직 겪지 않은 내용을 해금하지 않는다. 시안은 열 때 새 기록 표시를 지우지만 실제 읽음 처리 시점은 게임 연결에서 명시해야 한다.

## 우물·색 복원
폭600px, padding42/36/50px, 중앙 정렬. 마을 잉크 그림과 이름 gap24px. 잉크 있음: 설명→잉크 붓기/닫기. 없음: 안내→닫기만. 선택 행동만 F. 잉크 붓기 성공 시 해당 잉크 소모와 복원 플래그 기록 후 결과 메시지, F 확인/Esc 마을 복귀. 배경 블러 없음. 슬롯에 적용하는 런 잉크와 마을 잉크를 혼동하지 않는다.
색 복원 결과는 승인 마을 잉크+‘마을에 붉은색이 돌아왔습니다’. 현재 붉은색 예시이며 실제 색상별 명칭/복원 대상과 애니메이션은 데이터·월드에 연결한다. 현재 HTML은 복원 메시지만이고 마을 전체 재채색 구현이 아니다.

## 출발·하늘길
이정표 F 출발은 1챕터 이동 연결점. 구형 도면2개 선택/팔레트 다시 뽑기를 재도입하지 않는다. 비색인 start 상태의 ‘새로운 도전’ 안내도 현재 스케치 획득 후 제작 설명용이며 별도 필수 확인창으로 확정하지 않는다.
하늘길: 최고 기록 상단(48px 값, 항목28px, gap50px), 최근10회 표 높이540px·본문28px·셀24/28px padding. 날짜/시간/추락/화살/기록, 연습은 최고에서 제외. W/S 표 스크롤, F 닫기/Esc 호출자 복귀. 예시 기록값을 저장 데이터로 사용하지 않는다.
