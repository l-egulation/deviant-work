## 적용 전에 마무리할 것
1. 지도 시안의 충전소·출구·이벤트4종 및 완료 체크 연결 완료. 실제 방 좌표와 탐험 상태 연결은 Unity 단계에 남음.
2. 최종 전달 기준 커밋과 에셋 패키지 v2/화면별 ID표를 고정. Unity 프레임워크·Canvas 기준·메뉴 입력 라우터·실제 바인딩·UI 데이터 공급자를 팀 구현 담당과 확인. 새 게임 규칙 결정이 아니라 실제 코드 연결 작업.
3. 팀에서 사용할 폰트 확보/글리프 범위·말풍선 분할·팔레트3레이어·상태별 아이콘을 작은 테스트 화면에서 확인할 준비. 폰트 파일은 기존 방침대로 배포 패키지 제외.

## Unity 적용 승인 후
1. 공통 UI 기반: 폰트,1920×1080 배율, 픽셀 샘플링, 승인 프레임/붓칠, 고정 메뉴 입력/초점 복귀, 모달 차단.
2. 가방→제작→장비 한 흐름 먼저:43잉크/6칸/내구도%/제작 확정/교체 대기/맨손 데이터 연결. 실게임에서960×540 검수.
3. 보상·월드 상점·증강: 후보와 가격, 구매/보상 한 번만 처리, 재진입 보존.
4. 설정·일시정지·결과·로딩: 실제 설정/정산/저장·오류 재시도 연결.
5. 마을·지도·월드·이벤트·오프닝: 실제 좌표/팝업 경계/방ID/안내 완료 기록 연결.
