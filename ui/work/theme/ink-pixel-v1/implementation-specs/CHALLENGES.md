## 공통 시각·조작
목표/완료는 화면 상단 전체폭의 아래로 사라지는 음영. 사각 플로팅 블러·원형 음영 금지. 목표 padding38px 80px 20px, 아이콘80px/텍스트gap30px, 제목30px·아래14px/본문28px·수치36px. 완료 padding38/120/15px, 제목43px·아래16px/본문27px/아이콘54px. 완료 음영은 내용높이+160px까지 자연스럽게 확장.
근접 행동은 대상 위 꼬리 프레임(최소폭235px, padding20/28/38px, 글자26px), 가까운 대상 하나만 F. 위험상자 오답 피드백도 같은 프레임. 목표는 입력을 빼앗지 않고 전투 중 표시. 실제 방향키는 캐릭터 이동이며 HTML의 상자 선택/검토 도구는 게임에 노출하지 않는다.

## 봉인
석판 근접 F 시작 → 3페이지 진행 → 완료 안내 → 보상 상자 근접 F → 봉인 증강 → 완료 열린 상자. 진행은 승인 seal-progress-v2.png의 대기/현재/완료 종이3장, 크기66px·gap24px, 현재1.12배/opacity1, 대기.6, 완료1. 도형 원형 점으로 대체하지 않는다.
현재 처치4/5/6은 시안값, 게임 웨이브 완료 이벤트로 페이지를 갱신한다. 완료만으로 증강 자동 지급하지 않고 상자 열기 필요. 봉인 증강은 [AUGMENTS.md](AUGMENTS.md), 완료ID로 중복 지급 방지. 봉인 중 이탈·재입장 세부는 이벤트 초기화 규칙을 자동 전용하지 말고 게임 시스템 정책에 연결한다.

## 이벤트별 상태
|방|시작·목표|완료 전 이탈|완료|
|---|---|---|---|
|정령 구출|진입 후 장치 해제 수만 표시. 정령 무적|장치·진행·적 전부 초기화|모든 장치 해제, 남은 적 제거→혼합 보상|
|묘목 생존|묘목 F 시작, 플레이어 생존. 남은 시간만|초기화, 재입장 후 다시 시작|시간 종료, 남은 적 제거→혼합 보상|
|위험 상자|가까운 상자 F, 정답 찾기|정답 위치·열린 상자·오답 적 처치/잔존 유지|정답 열기, 남은 적 제거·나머지 상자 비활성→혼합 보상|
|함정 수집|장치 F 가동, 수집 수만. 시간 제한 없음|수집 진행 유지|목표 달성, 함정 종료→혼합 보상|

완료 연출 약1.3초 후 [보상 선택](REWARDS.md) 자동 연결. 일반 보상 기회/보장 집계와 별개, 완료당1회. 완료 상태 재진입 보상 없음. 시안3장치/45초/3상자/5수집은 수량 확정값이 아니다. 위험상자 완료의 ‘체력 회복’ 문구는 현행 시안에 있으나 회복 계산이 없으므로 별도 게임 보상 규칙 확인이 필요하다.

## 데이터·검수
roomId/type/phase/target/progress/remainingTime/answerSeed/openedChestIds/enemyStates/trapsActive/rewardClaimed. UI가 적 제거를 대신하지 않는다. 게임 완료 신호→적/함정 처리→보상 요청, 재진입에서도 일관되게 저장. 현재 HTML rewarded는 scene 문자열 기반으로 여러 같은 종류 방을 구분하지 못하므로 실게임은 고유 roomId 필요.
시작/진행/성공/수령/이탈/복귀, 각각 초기화·유지, 중복보상 금지, 위험상자 두 번 열기 방지, 긴목표·작은화면, 근접 프레임 꼬리 검수. 시안의 Esc 공통 탐험복귀는 완료 방을 리셋하는 게임 규칙이 아니다. 안내 팝업 Esc는 닫기, 전투중 Esc는 일시정지 라우터에 전달한다.
