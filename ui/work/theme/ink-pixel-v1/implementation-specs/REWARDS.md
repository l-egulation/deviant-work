기준: 2026-11-13 현행 시안. 일반/보스는 app.js와 reward-rules.js, 이벤트 연결은 world-bridge.js. 수치·확률의 데모 구현과 팀 합의를 구분한다.

## 배치·정보
1920×1080 논리 캔버스, 좌우 130px, 폭 1660px. 상단 제목 다음 기회 수/보스 진행 상태, 그 아래 3열 후보, 하단 행동 순서. 상단 분류 탭 없음.

|요소|현재 스타일 기준|
|---|---|
|후보 영역|높이 620px, 열 간격 64px, 3등분|
|상태 제목↔숫자|36px, 숫자 35px, 보조 집계 24px|
|후보 이미지|무기 120×150px, 병 102×150px, 위/아래 여백 18/28px|
|이름|34px, 아래 28px|
|설명|26px, 그룹 본문 행간 1.65; 잉크 문장은 공통 색상 규칙 적용|
|팔레트|58×42px, 간격 10px, 제목 아래 24px; 내구도 표기 없음|
|행동 줄|위 여백 24px, 항목 간격 44px|
|획득 상세|최대 폭 1000px, 상단 여백 60px; 이름 38px, 아래 16px|

각 후보 내부가 독립 스크롤된다. 제목·이미지·설명의 정렬을 유지하고 긴 글을 축소하지 않는다. 선택하지 않은 후보는 텍스트 opacity .74, 이미지 .6/채도 .55; 선택 후보는 원색, 현재 초점 밝기 1.15. 이름의 승인 붓칠 강조를 유지한다.

## 조작
|현재 위치|입력|결과|
|---|---|---|
|탐험|G|기회가 있으면 바로 후보 선택. 별도 기회 보관 화면 없음|
|후보|←→|후보와 상세 스크롤 대상을 변경, 아직 획득하지 않음|
|후보|W/S|선택 중인 후보의 설명만 스크롤, 260 논리px 단위|
|후보|F|선택 후보 획득|
|후보|↓|획득/가방 확인 행동 줄로 이동|
|행동 줄|←→ / ↑|버튼 선택 / 기존 후보로 복귀|
|가방 확인|F, 이후 Esc|열람 후 같은 후보·선택 위치로 복귀, 재추첨 없음|
|획득 결과|←→, F|무기: 가방에 넣고 계속 / 지금 구성하기. 잉크: 계속 / 지금 부여하기|
|후보 선택 중|Esc|현행은 닫지 않고 하나 선택하도록 안내. 월드 이벤트/보스도 선택 완료 전 닫기 차단|
|일반 획득 결과|Esc|탐험 복귀|

F는 현재 실행 가능한 행동에만 표시한다. 0회면 보상 열기를 비활성화한다. 획득 결과의 계속 행동은 남은 횟수와 무관하게 탐험으로 복귀한다. HTML의 ‘탐험으로 복귀’ 검토 화면과 기회 +1 버튼은 게임에 만들지 않는다.

## 보상 종류와 상태
|종류|후보·집계|완료 이후|
|---|---|---|
|일반|스케치/미보유 잉크 혼합 3중1택. 6회 이후도 계속 획득. 첫 6회 스케치 최소 3개 및 잉크 선택 기회 보장|기회 1 차감, 선택 종류 집계, 계속 또는 지금 구성·부여|
|보스|스테이지 최대 칸 수의 무기 3자루 중 1자루 선택|일반 기회 차감 없음. 한 번 획득하면 완료|
|이벤트 4종|혼합 3중1택, 완료당 1회|일반 기회·회차·보장 집계 불변. 결과에서 계속 또는 지금 구성·부여|
|봉인|증강 선택|[증강 명세](AUGMENTS.md) 참조|

받아 둔 일반 보상은 스테이지 출구를 쓰기 전에 남은 횟수를 모두 선택한다. 다음 챕터로 이월하지 않는다. 후보가 이미 열렸으면 반드시 선택한다. 일반 잉크 전종 보유 시 무기 후보로 채운다. 보스는 잉크 보상을 별도로 열지 않으며 잉크 도감 보유 상태와 무관하게 무기 3자루를 표시한다.

획득 결과의 이미지·이름·설명·팔레트는 선택한 실제 후보를 그대로 사용한다. ‘지금 구성하기’는 이미 획득한 미확정 무기의 팔레트를 연다. 닫으면 획득 무기와 임시 배치를 보존한 채 탐험으로 돌아가며 후보를 다시 고르지 않는다. 구성 확정 후 장착하거나 보관할 수 있다.

‘지금 부여하기’는 미확정 스케치 목록을 열어 획득한 잉크를 임시 배치한다. 구성 확정 시 고정된다. **확정한 무기는 빈 칸에도 잉크를 추가할 수 없으며 부여 대상에 표시하지 않는다.** 부여하지 않고 닫아도 잉크는 런 도감에 남는다.

## 구현 경계·연결 주의
- reward-rules.js의 랜덤 가중치와 슬롯 생성은 시안용이다. ‘첫 6회 보장’의 실제 후보 결정은 게임 시스템에서 받아야 한다. UI가 후보를 재생성하지 않는다.
- 실제 획득은 하나의 처리로 실행: 선택 검증 → 인벤토리 반영 → 기회/회차 갱신 → 결과 표시. F 반복 입력으로 중복 지급 금지.
- 보상 ID, 출처, 후보 ID 목록, 선택 위치, 남은 기회, 보스 완료 여부, 챕터 집계를 보존. 이벤트 완료 ID로 중복 보상 차단.

혼합/전부 스케치/긴 잉크/6칸 후보, 선택 중 W/S, 가방 왕복, 기회 0/7회 이상/챕터 출구 전 소진, 보스 1회, 잉크 전종 보유, 이벤트 전후 일반 집계 동일. 960×540에서 설명 잘림은 스크롤로 해결하고 행동 줄은 항상 접근 가능해야 한다.
