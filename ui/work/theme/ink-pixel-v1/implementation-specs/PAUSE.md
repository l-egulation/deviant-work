## 메뉴 구성
|런 중|마을|
|---|---|
|계속하기|계속하기|
|설정|설정|

|마을로 돌아가기|게임 초기화|
|—|타이틀로|

게임 초기화는 마을에만 표시. 현행 메뉴에 ‘다시 시작’은 없지만 restart 확인/출발 링크 코드가 남아 있다. 이전 도면·팔레트 재생성 문구를 현행 스케치 제작 규칙으로 오인해 구현하지 않는다. 이번 명세에서는 메뉴 추가 없이 비노출 상태로 기록한다.

## 배치·선택
1920×1080, main 위100/좌우180px. 제목46px. 메뉴 폭700px 중앙 배치, header 이후 위175px. 세로항목 간46px, 항목37px/padding8px 0. 선택1.12배, 왼쪽 기준 확대, 승인 붓칠 opacity .53. 비선택 회색 #b3bbc4, 선택 아이보리. **선택 버튼에만 F**, 다른 버튼 키캡 공간은 유지해 정렬 흔들림 방지.
배경 게임을 어둡게 하고 현재 시안 blur2px. footer 좌우180/바닥90px, 공통 키캡·구분선 스타일. 조작 안내는 3열(이동/전투/탐험), 간격80px, 섹션 제목33px/아래45px, 행27px/세로32px. 게임에서는 현재 바인딩으로 표시하며 G 보상 열기 유지.

## 입력·복귀
↑↓ 메뉴 이동, F 실행, Esc 계속하기. 설정을 닫으면 일시정지의 설정 항목으로 복귀. 조작 안내 Esc는 일시정지. 마우스 선택도 동일 동작. 현재 HTML은 좌우도 전후 항목 이동으로 처리하고 메뉴 끝에서 순환한다. Unity에서 주 안내는 ↑↓이며 숨은 동작이 필수 탐색 경로가 되어서는 안 된다.

포기/타이틀 확인은 ←→로 취소/이동 선택, F 선택 실행, Esc 취소. 초기 선택은 취소. 고정 F/G 창이 아니므로 양쪽 모두 F를 표시하지 않는다. 확인창 크기는 [설정의 공통 규격](SETTINGS.md)과 confirmation.css 사용.

|행동|실행 계약|
|---|---|
|계속하기|메뉴 닫기, 게임 입력/시간 복원|
|런 중 마을로|확인 후 현재 진행·이번 런 획득 영구 재화 포기, 마을 이동|
|마을 타이틀로|확인 후 타이틀 이동. 초기화와 구분|
|마을 게임 초기화|영구 진행 삭제 확인창 진입. 취소 기본 초점|

초기화는 영구 해금/진행 기록 삭제, 음량·조작 설정 유지. 시안의 ‘초기화 확정’은 실제 파일을 삭제하지 않고 같은 확인 상태를 표시한다. 게임 연결은 삭제 범위와 저장 성공 여부를 검증한 후 전환해야 한다. 연타 중복 실행을 막는다.

## 구현 경계·검수
pause-menu HTML의 resume/leave는 검토용 문구로 끝나며 Unity 이동은 없다. 실제 시간 정지/오디오/입력 차단은 메뉴 관리자가 담당. 이전 게임 상태·호출자·초점을 저장하고 닫기에 복원한다. 런 포기와 일반 사망 정산을 같은 처리로 묶지 않는다.
마을5항목/전투4항목, 설정 왕복, 조작 안내 G, 취소→이전 메뉴, 초기화 취소, 선택 F 단일 표시, 960×540 전체 항목/하단 안내 간격을 검수. 타이틀 디자인/HUD는 보류 범위.
