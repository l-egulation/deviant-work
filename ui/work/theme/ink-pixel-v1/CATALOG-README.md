# UI 모음 사용법
저장소 전체를 내려받은 뒤 catalog.html을 브라우저로 연다. GitHub 파일 화면에서는 HTML이 실행되지 않는다.

- 38개 화면 상태 + 채택 재화 에셋 1묶음. catalog-manifest.json은 화면 목록, catalog-data.js는 갤러리 표시 자료.
- 분류와 검색 → 이미지 확대 → 같은 상태 직접 조작. 조작 창은 상단 닫기 또는 Shift+Esc로 닫는다.
- 원래 화면의 방향키/F/Esc 동작은 변경하지 않았다.
- 폰트는 공식 https://www.memoment.kr/font 에서 받는다. 공식 안내의 파일 재배포 제한 때문에 Git에 넣지 않았다.
- OS에 꾹꾹체를 설치하거나 assembly-v1/fonts/MemomentKkukkukk.ttf에 둔다. 또는 ‘내 폰트 불러오기’로 TTF/OTF를 선택한다. 파일은 현재 페이지 메모리에만 보관하며 업로드하지 않는다. 갤러리 안 직접 조작 창에도 전달한다. 새 창은 별도로 불러와야 할 수 있다.
- 선택 파일은 페이지를 새로고침하면 다시 선택해야 한다. 정지 이미지는 폰트 설치 없이도 동일하게 보인다.
- Unity 미적용. 다음 작업은 전투 HUD. 시안의 수치·게임 동작은 실제 저장/정산 구현이 아니다.
