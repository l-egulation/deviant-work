# 현행 UI 모음

[현행 UI 명세](CURRENT-UI-SPEC.md) · [화면/상태 색인](CURRENT-SCREEN-INDEX.md) · [갤러리](catalog.html)

- Office hour는 팀 합의. UI 에셋은 제작·승인한 원본으로 교체.
- catalog-data.js가 갤러리 등록 목록의 기준. 현재 149개 항목(에셋 검토 포함). 구형 catalog-manifest.json을 현행 전체 목록으로 사용하지 않음.
- 검색 → 이미지 확인 → 직접 조작. 로컬 서버에서 저장소 전체를 열어 사용. GitHub 파일 화면은 HTML 실행을 지원하지 않음.
- 방향키/F/Esc, 설명 W/S. 고정 F/G 확인창은 방향키 선택 없음.
- 폰트는 내 폰트 불러오기를 사용. 업로드/재배포하지 않음. 정지 이미지는 폰트 없이 열람 가능.
- Unity 미적용, 타이틀/HUD 전체 보류.
