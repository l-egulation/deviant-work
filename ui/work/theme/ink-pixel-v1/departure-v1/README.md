# 출발 준비 개정 (사용자 결정)

도면마다 미리 정해진 팔레트를 목록에 표시한다. 서로 다른 도면 두 개 선택 후 바로 준비 저장 상태로 간다. 다시 뽑기 미해금이면 도면 다시 선택만 제공한다. 해금되어 잔여 횟수가 있으면 팔레트 변경이 가능하다. 변경은 선택한 도면 하나의 팔레트 전체 색을 다시 생성하며 무색은 유지한다. 도면 재선택만으로 색이나 잔여 횟수를 초기화하지 않는다.

새 단계형 공통 키보드 조작은 사용자 요청으로 철회. 기존 5개 화면은 이전 입력으로 복구했다. 이 화면은 방향키/Tab으로 버튼을 고르고 F/Enter로 바로 선택한다. 실제 게임/프로필 저장에는 연결되지 않는 HTML 시안이다.

마을 다시 시작은 사용자 확정: 영구 해금·보유 재화 유지, 모든 도면 시작 팔레트 재생성, 도면 선택 해제, 리롤 횟수 새 출발 기준 복구. 출발 구성을 새로 만드는 동작이며 영구 진행 초기화가 아니다. HTML은 실제 프로필을 수정하지 않고 URL의 해금 예시를 유지한다. 기존 departure.mjs의 단계형 입력 테스트는 폐기된 동작이다.

기본 3칸/해금 5칸, 무색과 리롤 횟수는 예시 상태. 기존 승인 PNG 재사용. Unity 미적용.

## 준비 저장 화면 정리
출발 이정표 안내 두 줄과 하단의 중복 출발 안내를 삭제했다. 미해금/해금 모두 도면 다시 선택과 확정 제공. 해금 시에만 팔레트 변경 추가. 확정은 구성 저장 후 준비 UI를 닫고 마을 배경으로 복귀하며 런을 시작하지 않는다. HTML은 실제 Unity 마을과 연결되지 않는다.
