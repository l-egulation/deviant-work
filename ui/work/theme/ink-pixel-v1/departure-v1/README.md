F/Enter로 좌측 선택에서 우측 확인 버튼에 진입하고 다시 F로 확정한다. 우측 방향키도 영역 진입, Esc는 이전 영역/단계. 리롤 버튼에서 F를 누르면 1회만 소비한다. 같은 도면은 두 번째 선택에서 제외한다.

## 검토용 제안 및 한계
저장 후 안내는 테마 검토용 상태이며 새로운 출발 확인 절차가 아니다. 실제 게임은 저장 후 준비대를 닫고 이정표로 이동한다. 마을 배경은 기존 승인된 비교 배경이며 준비대 실제 위치 캡처가 아니다.

팔레트는 시안용 고정 초기색/균등 랜덤이다. 실제 생성 확률·구성 보정 구현이 아니다. 문서는 실제 런을 이정표에서 생성하면서 준비대에서 색 미리보기·리롤을 요구하므로, 구현에서는 준비 구성 스냅샷을 보존해 재진입·도면 변경으로 무료 재추첨이 발생하지 않도록 계약 확인이 필요하다. 시안은 도면을 변경해도 팔레트와 리롤 잔여 횟수를 다시 만들지 않는다. 새로고침 시 초기화되는 로컬 데모이며 실제 저장/지급은 없다.

5칸과 리롤 2회는 해금 완료 예시. 둔기의 정확한 특수 스킬명은 별도 확인 전이므로 일반 명칭으로 표시. 출발 골드 기본값/프로필은 연결하지 않아 임의의 금액을 표시하지 않았다. 키보드 검증 완료, 실물 게임패드 미검증.
