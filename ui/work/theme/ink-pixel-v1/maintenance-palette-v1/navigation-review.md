# 정비소 팔레트 조작 개정
무기 선택 → F → 칸 선택 → F → 작업 선택 → F → 실행 영역.
무기·칸·잉크·결제 방법은 좌우, 작업은 위아래. 실행 영역에서 F로 실행. Esc는 한 단계 복귀. 상단 단계 표시 없음.
현재 영역만 활성화하고 이전 선택은 어둡게 유지. 좌우 구분선과 밝은 버튼 글자, 기존 붓칠 에셋 적용.
기존 색 변경/잉크 장착 결과는 미리보기이며 Unity에 반영되지 않음. 강화는 브라우저 시안의 수치만 변경.
검증: 최종 F 전 비용 미차감, 강화 후 차감, Esc 복귀, 결제/잉크 선택 시 팔레트 고정, 이미지 누락 없음.
