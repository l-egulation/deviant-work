# 정비소 팔레트 관리 v1

[칸 선택](index.html) · [잉크 선택](index.html?state=ink)

Figma 128:128,128:224의 정보 역할을 승인된 어두운 픽셀 테마로 재구성. 기존 PNG는 screen-set-v6/assets를 직접 참조하며 별도 재생성하지 않았다. 3칸 기본 상태, +0 효과 예시. 강화50G/변경권1은 와이어 예시. 강화·색 변경·판매·파괴 거래는 다음 범위이며 이번에는 미구현. 버튼 F는 미리보기 안내만 변경하고 실제 아이템/재화는 바꾸지 않는다. 무기별 독립 장착 상태, 칸/후보 클릭, 방향키, Tab 무기 전환, Esc 칸 선택 복귀. Unity 미적용.

참고 와이어는 회색 오른쪽 창이지만 사용자 테마 지시에 따라 전체화면 열린 배치로 변경했다. 가방 용량은 표시하지 않아 충돌하는 규칙을 확정하지 않는다. 스탬프는 라벨만이며 기능 연결 전. 실제 에셋 원본 해시는 asset-sources.json 참조.

## 2026-11-09 레이아웃 검토 반영
- 좌우 구성 유지. 탭·무기 선택선은 약하게, 현재 조작 단계의 선택선을 선명하게 표시.
- 현재 효과 영역 높이를 고정하고 오른쪽 하단에 안내와 실행 버튼을 분리 배치.
- 병 아이콘 84×96 → 96×110, 효과 설명 27 → 28px. 빈 상태 중복 문구 제거.
- 강화/색 변경은 클릭하여 비용 예시를 확인 가능. 거래는 미구현이며 상세 준비 안내만 표시.
- Esc: 잉크/거래 안내에서는 슬롯 선택으로, 슬롯 선택에서는 시안 닫기.
- ?state=ink&slots=5 로 5칸 확장 확인. 실제 아이템·재화 변경 없음.
- 원본/960×540/5칸 렌더 확인. 키보드 전 과정 자동화 검증은 수행하지 않음.

## 강화·색 변경 시인성 수정
- 제목 28px, 강화 수치 34px, 비용 31px. 비용을 별도 행으로 분리.
- 핵심 수치/비용 #F3EEE4, 강화 후 수치 #BDDBC7, 보조 비용 라벨 #C3CBD3. 푸른 강조색은 선택/조작에 유지.
- 참고 배경 #36383D 대비 계산: 핵심 10.15:1, 강화 후 7.89:1, 비용 라벨 7.15:1. 실제 장면 전체의 최저 대비를 측정한 값은 아님.
- 1920×1080 및 960×540 렌더 시각 확인. 거래 규칙/Unity 변경 없음.
