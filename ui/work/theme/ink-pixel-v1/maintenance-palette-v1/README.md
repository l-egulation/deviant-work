# 정비소 팔레트 관리 v1

[칸 선택](index.html) · [잉크 선택](index.html?state=ink)

Figma 128:128,128:224의 정보 역할을 승인된 어두운 픽셀 테마로 재구성. 기존 PNG는 screen-set-v6/assets를 직접 참조하며 별도 재생성하지 않았다. 3칸 기본 상태, +0 효과 예시. 강화50G/변경권1은 와이어 예시. 강화·색 변경·판매·파괴 거래는 다음 범위이며 이번에는 미구현. 버튼 F는 미리보기 안내만 변경하고 실제 아이템/재화는 바꾸지 않는다. 무기별 독립 장착 상태, 칸/후보 클릭, 방향키, Tab 무기 전환, Esc 칸 선택 복귀. Unity 미적용.

참고 와이어는 회색 오른쪽 창이지만 사용자 테마 지시에 따라 전체화면 열린 배치로 변경했다. 가방 용량은 표시하지 않아 충돌하는 규칙을 확정하지 않는다. 스탬프는 라벨만이며 기능 연결 전. 실제 에셋 원본 해시는 asset-sources.json 참조.
