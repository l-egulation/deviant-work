# 일시정지 공통 화면 시안

현재 승인된 어두운 흑연색, 꾸꾹꾸꾹 폰트, 실제 선택 잉크 PNG, 선택 확대를 재사용. 큰 박스 없이 메뉴 중심으로 구성. Unity 미적용.

- 전투 일시정지: 계속하기 / 조작 안내 / 마을로 돌아가기
- 마을 일시정지: 계속하기 / 조작 안내 / 타이틀로
- 조작 안내: 키보드 기본값 검토용. 실제 적용 시 입력 바인딩·사용 장치에서 표시값을 받아야 함.
- 마을 복귀 확인: 취소 기본 선택. 도전 종료 경고. 현재 진행 상황과 이번 런에서 획득한 영구 재화를 포기함(사용자 확정).
- 추가 동작: 타이틀 이동 확인, 메뉴 왕복, 방향키/F/Enter/Esc, 마우스.

배경은 기존 승인된 마을 그림을 네 화면에 동일하게 사용한 비교용 배경이며, 전투 실제 캡처로 주장하지 않는다. 실제 적용에서는 일시정지 직전 화면을 유지한다.

근거: 현행 FigJam 100:1706, 팀 docs/design/ui-and-interaction.md, docs/development/input-devices.md, TemporaryGameGui.Chapter.cs MenuSecondary. 코드에는 직접 귀환이지만 확인 단계는 오조작 방지를 위한 제안. 마을의 조작 안내도 공통 접근성을 위한 추가 제안.

## 마을 다시 시작 — 사용자 확정
마을 메뉴에서 타이틀로 위에 다시 시작을 제공. 취소 기본값의 확인 후 새 출발 구성을 생성한다. 모든 도면 팔레트 색·도면 선택·해금 기준 리롤 횟수 초기화, 영구 해금/보유 재화 유지. 전투 메뉴에는 추가하지 않는다. HTML은 출발 시안으로 연결하며 실제 프로필/재화를 수정하지 않는다. 브라우저 키 입력으로 확인 진입·취소·새 출발 연결·5칸/무색 유지·리롤 2회 복구를 검증했다.

## 런 중 자발적 마을 복귀 — 사용자 확정
현재 도전 진행 상황과 이번 런에서 획득한 영구 재화를 포기한다. 기존 보유분 전체 삭제로 표현하지 않는다. 마을의 다시 시작, 사망·정상 클리어 정산과 별도 규칙이다. 확인창은 취소 기본 선택과 「포기하고 마을로」를 사용한다. 실제 게임의 즉시 지급/정산 처리 변경은 Unity 담당 구현 작업이며 이 HTML은 재화를 변경하지 않는다.
