# 가방·장비 시안 v2 — 글자와 이미지 에셋 정리

Unity 미적용. [가방](previews/bag.png) · [장비](previews/equipment.png) · [무색 슬롯](previews/equipment-neutral.png) · [라벨 문양 전후 비교](previews/label-comparison.png)

index.html을 브라우저에서 열면 화면을 전환할 수 있습니다. 실제 아이템 변경은 구현하지 않은 시안입니다.

## 변경
- 팔레트 번호 목록 제거. 각 칸 바로 아래 강화 수치 25px, 효과명 27px. 빈 칸은 문양이나 기호 없이 원래 바탕을 유지하고 아래에 빈 칸 명칭만 표시.
- 보조 글자 22→24px, 안내 글자 20→23px. 제목 40px와 본문 25~27px는 유지. 1920×1080 기준.
- 선택 획, 아래 방향 삼각형, 좌우 화살표를 투명 PNG로 교체.
- 기본검·기본망치의 기존 화면 크롭을 새로운 개별 PNG로 교체. 게임 전체 무기 에셋 완성을 의미하지 않음.
- 병 라벨 12종의 내부 선과 작은 구멍을 줄인 전용 18px 문양 제작. 팔레트용 v4와 팔레트 v6 원본은 변경하지 않음.
- 독병은 의료 십자가로 읽힐 우려가 있어 새 시트의 십자가 대신 기존 독병 형태를 간소화. 구속 문양도 기존 뜻을 유지.

## 에셋 점검
|요소|상태|
|팔레트 바탕·칠·팔레트 문양|승인 원본 PNG 유지|
|잉크병|밀착형 파생 색상과 간소화 라벨 사용|
|선택 표시|selection-swash.png, 생성 이미지 분리|
|교체 방향|transition-down.png, 생성 이미지 분리|
|목록 화살표|chevron-left/right.png, 생성 이미지 분리|
|화면의 기본검·기본망치|sword/hammer.png, 새 생성 이미지 분리|
|키 안내 테두리·얇은 구분선|일반적인 선/텍스트로 유지, 장식 에셋으로 위장하지 않음|
|도장|미장착 상태. 도장 그림은 아직 제작하지 않음|
|게임 배경|기존 실제 마을 캡처|

폰트는 사용자 제공 MemomentKkukkukk를 로컬 참조하며 PNG에 적용했습니다. 폰트 바이너리는 재배포 조건 미확인으로 제외합니다. HTML은 미설치 환경에서 대체 폰트를 사용합니다.

## 제작
내장 이미지 생성 도구로 sources/ui-sheet.png 및 label-symbol-sheet.png를 제작하고, 알파 임계값으로 번짐을 제거한 뒤 개별 PNG로 분리했습니다. 생성 결과는 UI 크기에 맞춰 픽셀 격자로 정리했습니다. 상세 문양 전체를 덮어쓰지 않은 12종 라벨 전용 검토안입니다.

생성 지시: 청회색의 자연스러운 연필 선택 획, 무광 철제 기본검·망치, 아이보리 방향 기호를 일관된 제한 색상 픽셀 스타일로 제작. 라벨 문양은 검은 실루엣, 굵은 획, 장식 점과 잔선 없이 12종의 효과 모티프를 표현. 병 몸체는 기존 이미지 재사용.

## 검증
1920×1080 가방·장비·무색 슬롯 화면을 렌더링하여 글자 위치와 겹침을 확인했습니다. 원본 에셋은 보존했습니다. 실제 Unity 화면과 사용자 가독성 테스트는 아직 수행하지 않았습니다.
