# 큰 중앙 태그형 잉크병

[라벨/태그 비교](previews/comparison.png)

기존 병을 이미지 편집 입력으로 사용해 몸체·뚜껑·비율을 유지하는 방향으로 제작했습니다. 목에 걸린 끈에서 정면 중앙으로 내려오는 큰 태그이며, 옆쪽 잉크색이 남도록 했습니다. 생성 편집이므로 원본 전체 픽셀 동일을 주장하지 않습니다.

54종 runtime PNG,111×128 RGBA. sources/tag-red-blank.png에 빈 태그 원본. 문양은 effect-symbols-v5의 동일 마스크를32→40px로 확대해 얹었습니다. 문양은 재디자인하지 않았습니다. 5색은 같은 병 원본에서 잉크 부분만 색상 변형했습니다. Unity 미적용.

도구: 내장 imagegen 편집 + 개별 PNG 합성. 프롬프트 핵심: 기존 병 실루엣/빨간 유리/검은 뚜껑 유지, 감긴 라벨 제거, 목의 끈으로 연결된 큰 중앙 태그, 태그는 빈 크림 종이, 문양·글자·얼룩 없이 투명 배경.
