# 검은 잉크 무기 UI 에셋 v1

[전체 13종 이미지](previews/all-13.png) · [단독 HTML](catalog-standalone.html)

기본검·채찍·레이피어·한손 단검·기본망치·방패·대검·발사기·수리검·폭탄 10형태와 발사기 레이저/샷건/유탄 변형 3종입니다. 미정 무기는 임의로 추가하지 않았습니다.

기준: 팀 저장소 docs/design/systems/weapons-and-ink.md의 10형태, unity/Assets/Deviant/Combat/Resources/ApprovedTraversal/Catalog.json의 13 form ID를 대조했습니다. 문서의 10형태와 애니메이션의 13표현은 발사기 변형 때문에 다릅니다.

- runtime: 검은 잉크 원본, 96×96 RGBA 13장.
- dark-ui: 같은 그림에 1px 중성 회색 윤곽을 뒤에 더한 13장. 어두운 메뉴 대비 검토용이며 검은 몸체는 동일합니다.
- sources: 내장 이미지 생성 원본 2장.
- manifest.json: 이름과 ID 및 파일 대응.

UI용 정지 아이콘 후보입니다. 전투 스프라이트·모션 제작이나 Unity 적용은 하지 않았습니다. 실제 게임의 모든 무기 원화와 세부 외형 일치를 승인받은 최종본은 아닙니다.

## 제작 프롬프트 요약
4열2행 근접 7종, 3열2행 원거리6종을 투명 배경에 분리해 생성. 검은 잉크 몸체, 절제된 흑연색 내부 묘사, 64px 논리 격자에 어울리는 픽셀 군집, 색 있는 손잡이·은색 칼날·광택·장식 번짐 금지. 발사기 변형은 같은 몸통과 손잡이를 유지하고 총열로 구분. 내장 imagegen 사용 후 번짐 알파 제거·회색4톤 정리·96px 캔버스 정렬.
