# 전투 HUD v2 · 승인 프레임 표현 복원

사용자 피드백으로 v1의 CSS 도형 프레임을 폐기한 재시안. 피그마는 배치 참고만 사용.

기준: ui/work/theme/hud-theme-guide.md 및 사용자가 제공한 미니맵 프레임 참조. 좌상단/우하단 계단, 우상단/좌하단 사선, 흑연 질감, 밀착한 밝은 외곽선. 큰 프레임만 짧은 연필선. 내부 흰 장식선 없음.

assets/frame-large.png 및 frame-slot.png는 기준 이미지를 참조해 이미지 생성으로 제작한 새 후보. 기존 승인 원본을 그대로 분리한 에셋이라고 주장하지 않음. 큰 프레임은 border-image 9분할로 조립하며, 작은 슬롯은 별도 PNG. 확정 재화 및 weapon-ink-v8 무기 PNG는 변경 없이 사용.

배경은 v1과 같은 팀 저장소 실제 캡처. 신규 게임 실행 아님. 스킬 그림은 강베기/모아쏘기 전용 PNG로 교체. 기본검 base_sword_default(5초), 발사기 launcher_basic_special(6초)를 샘플 장착 상태로 지정. 팀 melee_weapon_design.json 및 launcher_skills.json 기준. 기존 유형 아이콘 샘플을 기본 스킬 조합으로 정정했다. 하트·체력 채움·지도 지형·쿨타임 덮개는 동적 표시. 지도는 배치용 예시이며 실제 지형 미연동. 수치와 스킬 쿨타임 시연은 기본값 5/6초이며 실제 게임 상태와 연동하지 않는다.

Unity 미적용. v1은 비교 기록으로 보존하고 갤러리의 전투 HUD는 v2로 교체.

작은 프레임은 사각 PNG 전체 비율 변형 대신 210px 코너 슬라이스를 10px로 고정한 9분할 표시. 스킬 칸은 64×64 정사각형. 긴 재화 칸도 동일 코너 유지. 원본 손그림 질감은 유지하며 픽셀 단위 완전 대칭 프레임을 새로 제작한 것은 아니다.
