## 이번 HUD 수정
- 체력 영역 252×44 → 286×50 (960 기준).
- 재화·가방·일시정지 외곽 박스 제거, 지도 프레임 유지.
- Q/E/W/R을 각 칸 좌측 상단에 표시. 이름과 팔레트 제거.
- E/R 입력과 클릭으로 회색 덮개·남은 초 시연. Q/W 선택 표시는 키 색으로 구분.
- 시연 수치와 스테이지 배경은 검토용이며 현재 Unity 상태와 실시간 연동하지 않음.
