# 보상 UI 개정 계획

기준: 2026-11-12 office hour 사용자 확정. 기존 테마·에셋 재사용, Unity 변경 없음.

- 결정 기록을 저장하고 이전 대조표보다 우선함을 명시한다.
- 일반 보상은 무제한 기회, 첫 6회 최소 스케치 3개 및 잉크 선택 기회 3회. 후보를 열 때 생성하고 가방 왕복 시 보존한다.
- 보스는 스케치 → 잉크 → 잉크, 각 3중 1택. 획득 후 계속 뽑기/닫기만 제공한다. 닫아도 남은 보상 유지.
- 출구에서는 남은 일반·보스 보상을 처리한 뒤 출구를 다시 사용할 수 있다. 선택 전 Esc는 가방 왕복 외 포기가 되지 않는다.
- 보상 확인용 탐험 상태에 G 보상 열기와 출구 상호작용을 연결한다. 전투 HUD 정식 디자인은 하지 않는다.
- 규칙 테스트 → 브라우저 방향키/F/Esc/가방 복귀 검증 → 미리보기 생성 → 갤러리 연결 → 업로드.

미보유 잉크가 부족하면 일반 보상은 스케치로 채운다. 보스 잉크 전종 보유 시 대체 보상은 미정이므로 임의 재화 지급을 만들지 않고 별도 검토 상태로 둔다.
