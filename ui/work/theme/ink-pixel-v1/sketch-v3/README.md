2026-11-12 / 사용자 여백 확대 피드백 반영. Unity 미적용.

직접 조작: 방향키 선택 → F 확정 → Esc 이전. Tab은 조작 대상 이동, PgUp/PgDn은 우측 설명 스크롤.
제작에서는 팔레트를 직접 선택하고 F로 잉크 선택 영역에 진입한다. 방향키로 ‘제작 내용 확인’ 버튼에 이동한 다음 F로 검토한다. 방향키만으로 다음 화면을 열지 않는다.
장비에서는 자리를 선택하고 F, 완성 무기를 선택하고 F로 장착한다. 목록 첫 줄에서 ↑를 누르면 자리 선택으로 돌아간다. 이미 다른 자리에 장착한 무기를 고르면 서로 교환한다.

보유 잉크는 소모하지 않는다. 확정 전 초안은 변경 가능하며 완성 후에는 빈 칸을 포함해 모든 팔레트 구성을 변경할 수 없다.

로컬 폰트가 없으면 갤러리의 '내 폰트 불러오기'를 사용한다. 폰트 파일은 저장소에 포함하지 않는다.
기존 승인 에셋은 상위 폴더에서 참조하므로 이 폴더만 단독으로 이동하지 않는다.

## 탭·비율 개정
가방/제작/장비는 좌측 상단 Q/E 탭으로 전환. 가방 목록 첫 줄에서 ↑로 스케치/잉크 분류에 진입하고 ← →로 변경한다.
제작 팔레트 아이콘은 이전 크기의 70%, 좌측 영역 확대. 장비 효과 목록은 잉크명 생략.
보상은 HUD 호출에서 곧바로 후보 선택으로 진입. 획득 후 좌우로 행동 선택, F 확정.
잉크 충전소는 현장 팝업이며 Esc로 닫는다.

## 마을 UI 추가
갤러리의 ‘대화’와 ‘마을’ 분류에서 새 시안을 확인한다. 대화는 다음/닫기, 기록은 조사 기록 원문 열람, 우물은 마을 잉크 사용 여부를 확인한다. 상호작용 미리보기에서는 좌우로 네 시설 표시를 바꾸고 F로 연다. 이것은 실제 월드 이동이 아닌 표시/라우팅 검토 도구다.
