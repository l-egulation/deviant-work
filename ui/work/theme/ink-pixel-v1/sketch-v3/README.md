[이미지 + 직접 조작 갤러리](gallery.html) · [현행/폐기/보류 UI](UI-MATRIX.md) · [검토 기록](REVIEW.md)

2026-11-12 / 사용자 여백 확대 피드백 반영. Unity 미적용.

직접 조작: 방향키 선택 → F 확정 → Esc 이전. Tab은 버튼 이동, PgUp/PgDn은 우측 설명 스크롤.
제작에서는 팔레트를 직접 선택하고 F로 잉크 선택 영역에 진입한다. 아래 방향키로 제작 확정 검토에 진입한다.
장비에서는 자리를 선택하고 F, 완성 무기를 선택하고 F로 장착한다. 팔레트 확인 버튼을 선택하면 빈 칸에만 잉크를 추가할 수 있다.

보유 잉크는 소모하지 않는다. 확정 전 초안은 변경 가능하며 완성 후 채워진 칸은 변경 불가.

로컬 폰트가 없으면 갤러리의 '내 폰트 불러오기'를 사용한다. 폰트 파일은 저장소에 포함하지 않는다.
기존 승인 에셋은 상위 폴더에서 참조하므로 이 폴더만 단독으로 이동하지 않는다.
