# 실제 게임 데이터 연결 — 2026-11-12

Unity 적용 전 HTML 프로토타입. 전체 갤러리: `../catalog.html`.

## 반영
- 잉크 43종: RunInks.json 설명·수치·색을 한 데이터로 사용. 가방/제작/장비/보상/상점에서 공통 설명 함수를 사용한다.
- 기본 수치와 색상 일치 수치를 구분하며 제작 미리보기와 장비의 실제 적용 효과에 일치 수치를 반영한다. 트리거는 청회색, 실제 효과·지속시간은 녹색, 보조 문구와 잉크 쿨타임은 아이보리다. 제작에서 기본/색상 일치 중 적용 수치만 노랑으로 표시한다.
- 1~6칸, 팔레트 가로 스크롤, 잉크 43종 목록, 긴 효과 설명 스크롤.
- 잉크 미보유, 전부 빈 칸 제작, 화면을 나갔다 재진입해 임시 배치 유지. 확정된 무기는 제작 목록에서 빠져 추가 적용할 수 없다. 잉크는 소비하지 않는다.
- 장비 교체/해제 10초 공통 대기. 최초 빈 자리 장착은 대기가 없으며, 대기 중 두 장착 무기 자리 교환만 허용한다. 메뉴에서는 대기가 멈춘다. 시간 경과 검증은 테스트에서 수행하며 게임 UI에 검토 버튼을 노출하지 않는다.
- 장비에서는 두 장착 자리를 빈 자리로 표시한다. 둘 다 비었을 때 무기 1의 맨손 표시는 전투 HUD에서만 다룬다.
- 상점: 1·2챕터 실제 가격식, 구매 후 품절, 미획득 잉크 없음, 다른 경로로 얻은 잉크만 진열 교체. 3챕터는 팀 가격 미정이므로 구매 비활성.
- 정비소 증강: 구현된 30종만 제안(대기 9종 제외), 안정형 1+서로 다른 그룹의 도박형 2, 보유 제외. 60G부터 구매마다 30G 증가, 최대10회.
- 결제 후 선택을 미루면 동일 후보 유지, 재결제 없음. 골드 부족/최대 횟수/후보 부족 상태 구분.
- 봉인 증강: 별도12종 후보, 각 최대3중첩. 보유 증강 화면에서 효과/대가/중첩 확인.
- 실제 무기 형태의 승인 아이콘·명칭을 목록에 확장. 무기 설명은 설계 문서를 요약한 표시 문구이며 전투 시뮬레이션은 하지 않는다.

## 적용 우선순위와 한계
사용자 결정 우선: 제작 후 빈 칸 추가 불가, 대기 중 자리 교환 허용, 보상 기회 챕터 이월.
각 갤러리 화면은 독립적인 테스트 상태다. 탭 이동/닫았다 재진입은 현재 페이지에서 유지하며 브라우저 새로고침 시 초기화한다. Unity 세이브 연동은 하지 않았다. 잉크 설명은 최신 런타임 원문을 사용하지만 실제 전투 효과 실행은 검증 범위 밖이다.
3챕터 가격은 확정 후 연결해야 한다. 최대 내구도 내부 정수값 대신 모든 UI에 게이지와 퍼센트를 표시한다.

## 2026-11-13 수정
- 43종 설명의 트리거/효과 구절을 공통으로 강조. `이 무기로`, `적에게` 같은 수식어는 기본색 유지.
- 제작의 잉크 제목 아래 색상 일치 배지 삭제. 설명 아래 적용 수치에만 노랑과 `적용` 표시.
- 장비 대기 중 상단 중복 안내·시간 경과 버튼 삭제. 실제 실행 버튼의 대기 표시 유지.
- 기존 전체 화면 상점은 갤러리의 **보관 · 전체 화면 상점**으로 이동.
- **검토안 · 월드 상점**: 상품3개와 가격 → 근접 상품 위 기존 꼬리 프레임 → F 구매. 키보드/클릭으로 상품을 선택해 접근 상태를 미리 본다. 실제 캐릭터 이동·근접 판정은 Unity 미적용이며, 배경은 기존 마을 시안 재사용이다.
- 정비소→상점 명칭 변경과 실제 진열 방식은 미확정으로 기록하며 다른 기능을 일괄 변경하지 않음.
