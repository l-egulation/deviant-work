# 시안 제작·수정·검토 기록

## 이번 기준

- 화면 기준 1920×1080. 본문 26~27px, 섹션 제목 28px, 화면 제목 45px.
- 제목 아래 28~32px, 내용 묶음 사이 48px, 중앙 열 사이 140px.
- 이전 시안에서 10~18px까지 줄었던 제목/본문 간격을 크게 되돌렸다. 사용자 요청대로 1.5~2배를 기준으로 잡되, 특히 좁았던 적용 효과는 그 이상 확보했다.
- 내용이 길어지면 영역 안에서 스크롤. 글자 축소로 맞추지 않는다.
- 팔레트 5칸은 큰 아이콘을 유지하고 가로 스크롤. 선택 이동 시 해당 칸이 자동으로 보인다.
- 잉크 아이콘에는 밑줄을 넣지 않는다. 팔레트는 이름 아래 승인한 붓칠 에셋 + 선택 크기 + 대비 차이를 함께 사용한다.

## 색 역할

| 역할 | 색 |
|---|---|
| 제목·주요 정보 | 아이보리 |
| 보조 정보 | 밝은 회색 |
| 잉크의 조건/행동 | 밝은 청회색 |
| 잉크 효과/강화 의미 | 연녹색 |
| 재화 | 누런 금색 계열 텍스트 및 승인 재화 에셋 |
| 패널티/손실 | 연한 적색 |

비선택 후보는 아이콘의 채도·명도를 줄이지만 설명은 비교할 수 있도록 더 밝게 남긴다. 선택 상태를 색 하나에만 의존하지 않고 크기, 붓칠, 활성 영역 표시로 구분한다.

## 실제 검토에서 발견해 고친 점

1. **이전 공통 스타일이 목록 높이를 강제함**: 새 화면에서 공통 스타일 의존을 제거했다. 이전 UI에는 영향을 주지 않는다.
2. **큰 내용이 화면 아래로 넘침**: 열의 최소 높이/스크롤을 수정하여 설명이 스크롤 안에 남고 버튼은 고정되도록 했다.
3. **잉크 격자가 설명을 밀어냄**: 제작의 보유 잉크를 가로 선택 목록으로 변경했다. 가방은 격자를 유지한다.
4. **설명 짧은 후보가 세로 중앙에 배치됨**: 모든 보상 후보를 위에서부터 동일하게 정렬했다.
5. **비선택 후보가 너무 어두워 비교 어려움**: 아이콘보다 설명의 대비를 높였다.
6. **장비에서 효과 확인까지 너무 많이 내려가야 함**: 팔레트와 적용 효과를 기본 공격/스킬의 자세한 설명보다 먼저 배치했다. 기본 공격/스킬도 스크롤로 확인 가능하다.
7. **F 표시가 여러 버튼에 동시에 나옴**: 기본 확정 행동 하나에만 표시하고, Tab으로 다른 버튼을 선택하면 F 표시도 이동한다.
8. **유한한 잉크 예시를 전부 보유한 경우 오류**: 예시 목록 소진 안내로 막았다. 실제 43종의 후보 고갈 정책을 새로 정한 것은 아니다.

## 브라우저 조작 검증

실제 키 입력으로 확인:
- 팔레트 다섯 번째 칸 이동 및 자동 가로 스크롤.
- 다른 색상 잉크 적용. 바탕·칠·문양의 승인 에셋을 별도로 표시.
- 같은 잉크를 두 칸에 적용하고 보유 잉크 수 유지.
- 제작 화면을 나갔다 돌아와도 임시 구성 유지.
- 제작 확정 → 무기2 장착.
- 완성 무기의 빈 칸 추가. 채운 뒤 다시 변경하려 해도 차단.
- 보상창 닫았다 재개해도 후보 유지.
- 보상 중 가방 확인 후 동일 후보 복귀.
- 일반 보상 6회 이후 스케치3/잉크3 및 기회0.
- 보스 보상 스케치1/잉크2, 각 선택의 후보 중복 없음.
- 골드 부족 시 구매 차단, 구매 완료 항목 재구매 차단.
- 장비의 긴 효과 목록을 PageDown으로 스크롤.
- 충전소 길게 누르기 중 취소 시 차감 없음, 완료 시 1회 차감.
- 갤러리의 모든 상태에서 이미지 에셋 로드 확인.

## 플레이어 관점에서 남기는 한계

- 이번 결과물은 **브라우저 조작 시안**이다. 컨트롤러 연결, Unity의 입력 우선순위·일시정지·저장과 연동 검증한 것이 아니다.
- 방향키/F가 주 흐름이며 Tab은 버튼과 메뉴 간 이동용이다. 설명 스크롤은 휠 또는 PgUp/PgDn. 게임패드에서는 같은 영역 이동을 어느 버튼에 둘지 입력 구현 때 확정해야 한다.
- 긴 효과의 맨 아래까지 읽기 위해 스크롤이 필요하다. 모든 효과를 작은 글자로 한 화면에 압축하지 않는 의도적인 선택이다.
- 새 잉크 목록과 기존 문양의 의미 대응은 아직 43종 전체가 완료되지 않았다. 기존 승인 이미지 12종을 재사용한 시안이다.
- 각 화면을 새로 열면 검토용 초기 데이터로 시작한다. 화면 내부 가방/제작/장비 탭 이동에는 상태가 유지된다. 실제 저장 파일은 만들지 않는다.
- 상점/증강/스킬 문장·수치, 내구도 소모 타이밍은 예시이며 실제 전투 시뮬레이션이 아니다.
- 초기화·귀환 결과는 화면 동작만 확인한다. 실제 영구 진행 데이터는 건드리지 않는다.

전체 범위와 문서 충돌은 [UI-MATRIX.md](UI-MATRIX.md)를 참조한다.

### 축소·갤러리 확인

960×540에서도 버튼이 화면 안에 유지되는 것을 확인했다. 화면 바깥에 불필요하게 생긴 스크롤바는 제거했다. 갤러리의 38개 상태와 직접 조작 화면 연결을 확인했으며, 이미지 미리보기는 지정 폰트가 적용된 상태로 저장했다.

## 후속 사용자 피드백 반영
- 좌측 상단 주 탭과 Q/E 전환, 중복 화면 제목 제거.
- 가방 양쪽 분류 모두 4열, 스케치 목록 이름·스킬 설명 제거. 방향키 세로 이동도 4개씩.
- 제작 아이콘 70%, 열 너비 860/660 및 중앙 여백 140 유지. 효과 본문 30px.
- 같은 색일 때만 황금빛 효과 증가 표시. 장비 효과에는 잉크명 없이 문장과 일치 강조만 사용.
- 공방의 활성 세로선 제거 및 비교 화살표 52px 확대.
- 회복 충전소 현장 팝업, 보상 기회 대기 화면 제거.
- 실제 Q/E·방향키·F 조작으로 탭 전환/4열 이동/보상 영수증 좌우 행동 선택을 검증.
