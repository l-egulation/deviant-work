# 입력·신규 화면·문양 검토 · 2026-11-12

## 확정 입력 기준
- 방향키: 현재 영역의 선택 변경. F/Enter: 현재 선택 실행.
- 일반 실행 버튼: 선택된 버튼에만 붓칠 강조와 F. 비선택은 문구만 유지하며 키 자리 폭은 보존한다.
- 불가능한 실행: 비활성화, 이유를 버튼 문구로 표시. 열쇠 없음은 `열쇠 필요`, F 없음. 닫기는 선택 가능.
- 설정 조작 항목: F로 키 입력 대기. G로 기본키 복원 확인.
- 설정 확인창: F는 왼쪽 취소/되돌리기, G는 오른쪽 복원/유지. 키 표시와 동작을 일치시킨다.
- 마을 일시정지: 게임 초기화 → 영구 진행 초기화 확인. 실제 저장은 수정하지 않는다.

## 실제 이미지 에셋
- `assets/effect-atlas-v1.png`: 투명 배경 4×4. 잉크 문양 12개, 증강 3개, 마을 잉크 1개.
- `assets/blank-ink-bottles-v1.png`: 빨강·노랑·초록·파랑·보라의 빈 중앙 태그 병. 문양을 별도로 얹는다.
- 기존 팔레트 바탕과 칠, 무기, 붓칠 선택, 말풍선 프레임 유지.
- 이미지 자체를 코드 도형으로 대체하지 않았다. HTML에서는 아틀라스 영역을 참조한다. Unity 적용 전에는 실제 스프라이트 영역/픽셀 밀도·필터를 검토해야 한다.

## 문양 대응
기절=별과 어지러운 얼굴, 추격=기절 대상과 검, 집중=별과 번개, 보호=대시 흔적과 방패, 질주=전환 화살표와 신발, 속박=묶인 발, 맹공=묶인 대상과 검, 순환=회전 화살표와 번개, 회복=하트와 십자, 가속=달리는 신발, 둔화=무게추와 발, 독기=검과 독 방울.
증강: 단단한 기초=기반에 꽂힌 검, 유리 칼날=깨진 검, 마지막 불꽃=금 간 심장과 불꽃.
복합 조건의 세부 수치까지 아이콘 하나로 설명하려 하지 않으며 오른쪽 설명을 함께 유지한다.

## 확인
- F 선택→키 변경 대기, G 복원 확인, F 되돌리기/G 유지 실제 입력 검사.
- 열쇠 없음의 열기 버튼 비활성화와 닫기 동작 검사.
- 마을 초기화 메뉴 이동 검사.
- 현행 68상태의 이미지 누락 및 실행 F가 최대 한 개 노출되는지 검사.
- 설정·일시정지 미리보기 재생성. 전체 갤러리는 현행 81항목, 이전 출발 다시 뽑기 화면 제외.
