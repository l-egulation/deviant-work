# 공통 조작 규칙 — 2026-11-12

적용 범위: 현행 sketch-v3 HTML 시안. Unity 및 보류/이전 UI에는 아직 적용하지 않음.

- 방향키는 화면상 해당 방향의 선택 대상으로 이동한다. 이동만으로 구매·제작·해제·장착을 실행하지 않는다.
- F / Enter는 현재 선택한 항목을 확정하거나 현재 버튼을 실행한다. 행동 버튼의 F 표시는 현재 버튼 하나에만 표시한다.
- Q / E는 가방·제작·장비 주 탭 전환. 가방의 분류는 첫 줄에서 위로 이동하고 좌우로 선택한다.
- Esc는 이전 단계. 제작의 하위 화면에는 같은 역할의 돌아가기 버튼도 제공한다.
- Tab도 모든 조작 대상으로 이동 가능. 방향키만으로도 행동 버튼에 접근할 수 있어야 한다.
- PgUp / PgDn은 우측 상세 설명 스크롤. 목록과 팔레트는 초점 이동을 따라 스크롤한다.
- 유지된 선택과 현재 조작 초점을 구분한다. 장비는 선택 중인 구역의 제목을 밝은 금빛으로 강조하고 다른 구역은 낮춘다. 장착 자리 영역은 목록 위에 고정한다.

## 제작
스케치 → 팔레트 → 잉크 → 팔레트로 복귀.
팔레트에서 아래로 이동하면 버튼을 선택한다. ‘제작 내용 확인’을 F로 실행해야 최종 검토로 넘어간다.
임시 적용 해제도 버튼으로 접근·실행한다. 제작 확정 뒤에는 이미 완성한 무기를 수정할 수 없다.

제작 확정 → **장착하기 / 보관하기**.
장착하기 → 무기 1 / 2 → 선택한 자리에 장착.
보관하기 → 장비 탭. 기존 장착 상태는 유지한다.
자리 선택에서 돌아가기 → 장착 / 보관 결정으로 복귀한다.

## 장비
자리 선택 → F → 완성된 무기 선택 → F 장착/교환.
목록 첫 줄에서 위로 이동하면 자리 선택으로 돌아간다.
선택한 자리의 무기는 중복 장착하지 않는다. 반대 자리에 있는 무기는 서로 교환한다.

## 충전소 / 초기화
충전소는 흰 테두리를 사용하며 회복 버튼 내부의 붓칠이 왼쪽부터 채워진다.
완료 전에 놓거나 다른 버튼으로 이동하면 취소한다. 닫기 버튼에 F를 누르면 회복하지 않는다.
초기화 확인은 취소를 기본 초점으로 하고 좌우로 확정/취소를 선택한다. 시안에서는 실제 저장 데이터를 초기화하지 않는다.

## 검증
실제 브라우저 키 입력으로 임시 적용 해제 → 제작 검토 → 확정 → 보관, 장착 무기 교환과 자리 복귀, 가방 분류 이동, 초기화 취소, 회복 중단/완료/닫기를 검증했다.
이 규칙은 컨트롤러의 방향 입력/확인/뒤로에 대응하도록 설계했으나 실제 패드 입력 및 Unity 구현은 별도 검증 대상이다.
