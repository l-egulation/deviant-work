# 현재 UI 상태와 남은 작업

기준: 2026-11-13 사용자 수정 지시, 팀 로컬 `bb88516c3`. Unity 적용 전 HTML 시안 상태다. 전체 갤러리는 `../catalog.html`, 월드 묶음은 `../world-flows-v1/index.html`.

## 시안이 있는 영역 — 다시 신규 제작으로 세지 않음
- 가방/제작/장비: 잉크 43종, 1~6칸, 기본·일치 효과, 예외 상태, 장비 공유 10초 대기 및 자리 교환.
- 보상/증강: 일반·보스·봉인 선택, 기회 이월, 후보 보존, 보유 증강, 구매 불가 상태.
- 마을: 공방/기록/우물/출발 상호작용, 기록 수첩/색 복원/하늘길, 대화.
- 시스템: 설정·일시정지·확인창·이름 변경·전체 지도·잠긴 상자·충전소.
- 월드: 봉인, 신규 이벤트 4종, 보스 소개, 무기 소진, 포탈, 전환, 최종 결과, 오프닝/첫 진행.
- 에셋: 잉크43/증강51/스킬40 목록과 승인된 무기·병·문양·팔레트. 추가 기능으로 생기는 에셋은 별도.

## 삭제한 불필요한 화면/알림
- 보관 무기 소진: 사용하지 않은 보관 무기는 소진하지 않음.
- 보상 기회 +1 팝업: HUD 용기/수량에서 보여줄 예정.
- 포탈 일반 설치/불가/왕복 안내 팝업과 상시 키 설명: 제거. 첫 설치 튜토리얼만 유지.
- 구형 알림 구조·포탈 설명용 화면·잉크12종 샘플: 전체 갤러리에서 제외. 새 월드 시안/전체43종을 참고.
