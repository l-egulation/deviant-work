# UI 개편 검토 기준

2026-11-12. 기준: 사용자 최신 결정 > 팀 문서 > 예전 시안.
팀 문서 확인 커밋: ca3ee27a6394ccf2b54ccb9a5c906d78b1a294a0.

## 순서
1. 설명 간격을 이전 대비 1.5~2배 확보. 본문을 축소하지 않고 스크롤한다.
2. 보상·가방·제작·장비를 같은 선택/활성 영역 규칙으로 개정한다.
3. 보스 보상, 상점, 증강, 파손 및 보상 기회 알림을 추가한다.
4. 5칸·긴 효과 목록·빈 목록·부족 상태를 실제 조작하고 화면을 검토한다.
5. 이미지 갤러리와 조작 화면, 검토 기록을 저장한다.

## 팀 문서와 다른 결정
- 일반 보상은 강제 팝업이 아닌 쌓아두는 기회. 6회 선택 결과 정확히 스케치3/잉크3.
- 보스 보상은 스케치1+잉크2를 각각 3중1택한다.
- 내구도는 정수 대신 백분율.
- 가방은 조회, 제작은 잉크 구성, 장비는 완성 무기 장착.
- 잉크는 반복 사용하며 같은 잉크를 여러 칸에 적용 가능.

## 문서에서 추가로 확인한 상태
- 제작 전 임시 구성을 보존하고, 확정 전에는 수정 가능.
- 팀 문서는 완성 후 빈 칸 추가를 허용했지만, 최신 사용자 결정으로 폐기. 제작 확정 후 모든 구성을 고정한다.
- 제작 후 즉시 장착하거나 보관 가능.
- 보유 잉크는 보상 후보에서 제외.
- 상점 구매 완료, 골드 부족, 보관 무기 파손 안내가 필요.

## 보류
타이틀 및 전체 전투 HUD는 기존 보류 유지. 수치·스킬 문장·증강은 레이아웃 검토 예시이며 밸런스 확정안이 아니다.
