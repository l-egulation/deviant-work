## 이번 보상 시안 적용
- 후보 선택 전에 Esc로 보상을 포기하지 않는다. 가방 확인 후 후보·순서·선택 위치가 보존된다.
- 닫기는 수령 후 가능. 남은 일반 및 보스 보상은 보존하고 G로 다시 연다.
- 후속 사용자 수정: 남은 보상 기회는 다음 챕터로 이월한다. 출구에서 강제 소진하지 않고 보상 UI 안에 출구 버튼을 두지 않는다.
- 첫 3회 미보유 잉크 후보를 포함해 선택 기회 보장을 검토할 수 있도록 구성했다. 팀 코드의 정확한 확률을 복제한 밸런스 시뮬레이터가 아니다.
- 일반 보상에 미보유 잉크가 없으면 스케치 후보로 채운다.
- 보스 잉크 전종 보유는 수집 축하 이스터에그로 표시하고 닫는다. 임의의 재화 보상은 추가하지 않는다. 3개 미만이면 남은 미보유 잉크만 표시하는 시안 처리다.
- 콘텐츠는 기존 승인 에셋/12종 예시. 전체 잉크·증강은 merge 후 대응한다.

## 이번에 아직 적용하지 않은 결정
제작/장비의 교체 대기 및 상세 개정, 설정·결과·초기화 동작의 통합 검증은 다음 작업이다. 결정 기록과 실제 구현 범위를 혼동하지 않는다.
