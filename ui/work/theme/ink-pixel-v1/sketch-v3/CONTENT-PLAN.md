# 실제 게임 데이터 UI 연결 계획

1. RunInks.json 43종을 단일 데이터로 가져오고 승인 문양/병 에셋 ID 연결. 설명과 색 일치 수치 공용 렌더러.
2. 1~6칸, 미보유, 빈 제작, 임시 배치 유지, 확정 후 편집 금지 검증.
3. 장비 공유 10초 전투시간 대기·해제·맨손·장착 자리 교환 예외. 일시정지 중 시간 고정, 검토 도구로 전투시간 진행.
4. 챕터별 상점 가격/미획득 진열/품절과 고갈, 정비소 증강 30종과 봉인 12종의 별도 후보 및 구매 상태.
5. 의미 있는 상태 전이 테스트, 실제 브라우저 화면/키 입력 검수, 갤러리와 규칙 문서 갱신 후 push.

파일: runtime-content.js(출처 스냅샷), content-rules.js(공유 규칙), content-flows.js(화면/상태), 기존 app.js/approved-art.js 최소 연결. Unity 수정 없음.
