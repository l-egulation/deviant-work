# 전체 UI 검토 · 2026-11-12

## 이번 반영
- 우물: 패널 660→600px, 내용과 실행 버튼 중앙 정렬. 분할 테두리와 꼬리는 유지.
- 기록 농가: 이전 / 페이지 수 / 다음 / 닫기. 미발견 수첩은 이동 불가. 최초 기록과 추가 기록을 구분.
- 공방: 조건 본문 30px, 충족/미충족 27px. 충족은 밝게, 미충족은 회색과 잠김 문구로 함께 구분. 미충족 조건에서는 해금 불가.
- 실행 버튼: 목록에 초점이 있어도 F 표시 유지. 선택된 버튼의 강조는 별도 유지. F는 현재 초점의 버튼을 실행한다.
- 충전소: 승인한 분할 말풍선 프레임과 꼬리 적용. 버튼 내부 채우기 방식 유지.
- 전체 갤러리: 현재 사용할 화면만 수록. 이전 기획 시안과 재화 단독 에셋은 제외하고 재사용하는 설정·일시정지·지도만 포함. 현행 갤러리의 모든 미리보기를 재생성.

## 기록 농가의 실제 구조
팀 `unity/Assets/Deviant/Game/Runtime/TemporaryGameGui.InkRecord.cs`와 `data/story/record_note.json` 기준.
- 첫 펼침면: 조사 기록. 첫 도전 및 첫 마을 잉크 반환에 따라 내용이 추가된다.
- 두 번째 펼침면: 발견한 수첩의 삽화. 수첩 발견 전에는 다음으로 이동할 수 없다.
- 각 이야기마다 별도 페이지를 무한히 넘기는 구조는 아니다. 긴 기록은 본문 스크롤이다.

## 현행으로 준비된 화면
보상 선택/계속 뽑기/닫기, 가방 스케치·잉크, 제작과 제작 후 장착·보관, 장비와 내구도, 상점/품절/재화 부족, 증강, 충전소와 불가 상태, 결과, 초기화, 영구 공방과 해금 조건, 마을 상호작용·대화·우물·기록.
별도 기존 화면: 설정, 일시정지, 전체 지도. 전체 갤러리에서 함께 확인 가능하다. 이전 강화·교체·출발 준비는 현행 화면이 아니다.

## 최신 흐름도와 팀 문서가 다른 항목
확인: FigJam `현행 · 사용자 흐름 v3` 0~⑤ 섹션, 팀 `docs/overview/player-flow.md`, `docs/design/ui/screens.md`, `docs/design/run/rewards.md`, `docs/design/world/village/starting-village.md`.
아래는 사용자 결정이 기준이며, 시안에서 임의 변경하지 않았다.

|항목|현재 사용자 결정 / 시안|팀 문서 또는 흐름도|
|---|---|---|
|일반 보상 열기|기회를 쌓고 직접 열기|팀 문서는 조건 달성 즉시 열기; 흐름도는 G로 열기|
|일반 보상 구성|총 스케치 3 + 잉크 3|팀 문서는 무기 최소 3, 잉크 선택 기회 최소 3|
|보스 보상|스케치 1 + 잉크 2|팀 문서는 무기 선택만|
|보상 획득 후|계속 뽑기 또는 닫기|팀 문서 일부는 지금 구성하기 포함|
|제작 확정 후 빈 칸|추가 적용 불가|흐름도 일부는 추가 채우기 가능|
|클리어 이동|다음 챕터|팀 문서는 첫 클리어 마을, 반복 클리어 다음 챕터|

위 6개를 팀과 대조한 뒤 해당 화면을 최종 확정하는 것이 좋다. 로컬 팀 저장소 내용과 연결된 흐름도를 읽었으며 이번 작업에서 팀 저장소를 변경하거나 원격 최신 커밋을 새로 가져오지는 않았다.

## Unity 전달 전
분할 프레임의 모서리·꼬리 고정, 키보드 초점/취소/복귀, 960×540 가독성, 스크롤 끝 상태, 폰트 사용 방식, 수치의 데이터 연결을 확인한다. 현재는 HTML 검토용이며 Unity에 적용하지 않았다.

상자 시안은 팀 원본 key-item / locked-chest 그림을 사용한다. 배경은 UI 위치 검토용 기존 마을 이미지이며 실제 상자방 배치가 아니다. 팀 규칙 출처: docs/design/world/stage-gimmicks.md. 실제 보상 지급은 Unity 연결 전이며 시안에서는 상자 열림과 열쇠 소모 상태만 검증한다.
