## 기존 화면 유지 또는 후속 연결

- 설정: 이전 설정 시안 유지. 제작/장비/보상 호출 키는 새 입력 체계 확정 후 조작 목록에 추가해야 한다.
- 전체 지도: 승인한 테마 유지. 문서의 포탈1/2 및 충전소 소진 표시를 실제 지도 데이터와 연결할 때 검증한다.
- 일시정지: 기본 복귀·설정·타이틀 메뉴 유지. 런 포기 확인은 사용자 결정에 따라 **진행과 이번 런 획득 영구 재화 포기**로 유지한다. 문서의 일반 귀환 보존과 혼용하지 않는다.
- 대화·NPC: 화자·내용·다음 진행이라는 역할은 확인했지만 실제 대사와 초상은 미정. 포탈 안내는 제품 내용이 확인된 부분만 시안으로 만들었다.
- 마을 채색/영구 해금 신규 트리: 대체 가격·선행 관계가 미정. 기존 팔레트/가방 확장 트리를 현행으로 재사용하지 않는다.
- 타이틀, 전체 전투 HUD: 사용자 보류 유지. 이번 알림 시안은 HUD 레이아웃 확정안이 아니다.

## 폐기 또는 역사 기록으로 이동

- 정비소 공격 강화 → 새 증강 구조로 대체. 영구 캐릭터 강화와 혼동하지 않는다.
- 팔레트 칸 강화 / 칸 색 변경 / 기존 잉크 교체 → 삭제.
- 무기 스탬프·스킬 스탬프 독립 교체 → 스케치에 묶였으므로 삭제.
- 제한된 잉크 가방 및 가득 참 교체창 → 현행 무제한 보관 기준에서 삭제.
- 시작 무기 2개 선택 / 시작 팔레트 다시 뽑기 → 최신 문서의 맨손 출발에 따라 이전 기록으로 분리.
- 보스 제단의 색상 선택 → 사용자 최신 보스3회 보상으로 대체.
- 예전 효과 +/− 합산 요약 → 조건과 효과의 문장 목록으로 대체.

## 충돌 시 적용한 우선순위

1. 사용자: 보상 기회 적립, 일반 정확히3+3, 보스1+2, 내구도%, 조회/제작/장비 분리.
2. 최신 문서: 임시 구성 보존, 확정 전 편집, 완성 후 빈 칸 추가는 사용자 결정으로 폐기, 보유 잉크 후보 제외, 맨손 출발, 포탈2개.
3. 예시 데이터: 무기 스킬 설명, 잉크 이름·수치, 증강 이름·패널티. 상품 가격 및 회복량도 시험값이며 최종 밸런스 아님.

## 아직 확정할 수 없는 제품 항목

- 같은 잉크를 한 무기에 중복 적용했을 때 수치·쿨타임 계산: 시안은 개별 적용 사실만 보여주며 합산하지 않는다.
- 색상 일치의 정확한 증가율: “색상 일치 · 효과 증가”까지만 표시한다.
- 43개 잉크 전체의 최신 효과와 기존 문양의 일대일 대응: 이번에는 기존 승인 에셋 12종을 사용한 조작 예시. 신규 전체 잉크용 문양 제작 완료라고 간주하면 안 된다.
- 마을 신규 해금 트리 및 출발 지원금 가격: 미정은 구매 불가로 표시하며 무료로 가정하지 않는다.

최신 사용자 규칙: 장비는 완성 무기의 장착·교환과 이름 변경만 허용. 팔레트 추가/잉크 추가 불가.

## 다음 UI 작업 순서 (현행 목록 기준)
1. NPC 대화·선택지: 대화 본문/화자, 다음·닫기, 선택지와 방향키 초점. 실제 스토리 대신 검토용 대사로 구조 확인.
2. 현장 상호작용 안내: NPC·상점·충전소·출구에 접근했을 때 대상명과 F 안내. 전체 HUD 확정과 분리.
3. 챕터 전환: 클리어 결과 → 다음 챕터 진입/로딩의 최소 화면. 클리어를 마을 귀환으로 연결하지 않음.
4. 기존 일시정지·런 포기 확인·설정·지도에 현행 키 입력 및 공통 버튼 표현 연결 검토.
타이틀과 전체 전투 HUD는 보류 유지. 마을 채색/해금 트리는 기획 확정 뒤 작업.

보상 획득 후 행동은 종류와 관계없이 계속 뽑기 / 닫기로 통일. 남은 기회가 없으면 계속 뽑기 비활성화. 제작/가방으로 이동하는 보상 버튼 제거. 닫기는 남은 기회를 소비하지 않는다.
