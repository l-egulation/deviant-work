# Deviant 장비 UI 테마 v1

현재 합의 방향을 제작 기준으로 정리한 초안. Unity에 적용한 결과가 아니라 기본 에셋과 검토 자료다.

## 테마 정체성
- 어두운 중립 흑연색 위에 색을 담은 픽셀 잉크병. 배경 마을은 어둡게 눌러 남긴다. 어두운 표현만으로 게임 일시정지 여부를 의미하지 않는다.
- 큰 외곽 박스 없이 제목, 간격, 얇은 선으로 영역을 구분한다. 오른쪽은 현재 장착 / 교체 후보의 두 영역이다.
- 픽셀은 아이콘과 작은 조각에 적용하고 글자는 부드러운 한글 형태를 유지한다. 동양풍 서예, 금속 장식, 금색 외곽선, 과한 잉크 번짐은 사용하지 않는다.
- 선택은 낮고 납작한 회청색 획으로 표현한다. 현재 조작 항목만 획을 사용하고 탭·무기의 지속 선택은 밝기와 글자 굵기로 구분한다.

## 글자와 여백
첨부 MemomentKkukkukk.ttf를 실제 적용한 기준판: theme-type-and-slots.png. 이미지 생성 모델에 폰트를 흉내 내도록 한 것이 아니다.

1920×1080 제작 기준 권장 시작값(실기 검증 전): 탭 40px, 잉크명 36px, 영역 제목 28px, 본문 28px, 보조 24px. 960×540 축소에서 다시 검토한다. 글자의 실제 획 두께에 따라 본문 크기를 조정한다. 폰트에 별도 bold 파일이 없으므로 합성 굵기를 과도하게 주지 않는다.

- 배경 #25272B
- 주요 본문 #E5E4DF, 보조 #BFC3C7, 영역 제목 #ADB7C1
- 빨강 잉크명 #E4B2B4. 다른 잉크도 원색 대신 밝게 조정한 해당 계열 색. 무색/도장 이름은 밝은 중립색.
- 선택 획 #739CAD, 구분선 #62666D
- 이름→설명 16–20px, 설명 행간 약 1.4배.
- 교체할 잉크 제목→아이콘 실제 상단 32px 이상, 등급 배지 포함 아이콘 영역 112px 확보.
- 아이콘→선택한 잉크명 24px. 아래 설명 영역은 후보 수와 관계없이 고정.
- 색뿐 아니라 제목 크기·간격·위치로 위계를 유지한다.

## 팔레트
- 슬롯 테두리는 허용 색상의 어두운 색, 장착 효과 바탕은 더 밝은 잉크 색.
- 빈 슬롯은 낮은 채도의 해당 색 바탕과 —. 빈 상태에서도 허용 색상을 알 수 있다.
- 무색 슬롯은 중립 회청색 테두리와 바탕. 장착 후에도 중립 테두리를 유지하고 내부만 장착 잉크 색으로 바꿔 무색 속성을 보존한다.
- 강화 +0… 수치는 원 아래. 등급과 강화 수치를 같은 의미로 쓰지 않는다.
- 테두리/빈 바탕/장착 바탕/효과 아이콘/강화 텍스트를 개별 레이어로 조립한다.

## 가로 후보 탐색
- 컬러 슬롯: 허용 후보만. 무색 슬롯: 모든 허용 색상의 보유 잉크. 다른 호환 조건까지 무시한다는 의미는 아니다.
- 고정 폭 안에 아이콘 목록을 가로 배치. 넘칠 때만 좌우 이동 화살표와 범위 표기(예: 1–5 / 12)를 표시한다. 처음과 마지막 화살표는 비활성화, 기본은 끝에서 순환하지 않는다.
- 키보드 좌우는 후보 초점을 이동하고 가려진 후보를 자동으로 보이게 한다. 마우스 화살표는 보이는 묶음을 이동한다. 포커스가 화면 밖으로 사라지지 않게 새 범위의 가까운 후보로 옮긴다.
- 리스트 영역에서만 가로 스크롤/드래그를 처리한다. 드래그 종료를 장착 확정으로 취급하지 않는다.
- 페이지 이동은 후보 탐색일 뿐 장착하지 않는다. F로 확정하기 전에는 현재 장착 정보가 바뀌지 않는다.
- 0개: 보유 잉크 없음. 1개·정확히 맞는 수: 화살표 숨김. 넘치는 수·마지막 묶음·긴 이름 검증 필요.
- 5개 노출은 출발안이며 실제 해상도에서 결정한다. 아이콘을 작게 줄여 전부 밀어 넣지 않는다.

## Unity 적용 계획
확인한 기존 파일: unity/Assets/Deviant/Inventory/Unity/TemporaryInventoryView.Pixel.cs의 Canvas 기반 uGUI, PixelInventoryTheme.cs의 Sprite/Font 참조 구조. 현재 Ready 조건은 여러 프레임을 요구하므로 박스 없는 테마에 단순 이미지 교체만으로 맞지 않을 수 있다. 구현 단계에서 테마 참조 계약을 검토해야 한다.

- CanvasScaler 기준 1920×1080, 화면비 대응 및 960×540 가독성 점검. 실제 배율은 코드와 게임에서 검증한다.
- 후보 목록: 수평 ScrollRect + Viewport/RectMask2D + Content/HorizontalLayoutGroup. 상세 영역은 Content 밖에 고정. 자동 초점 스크롤은 별도 연결.
- Sprite: 2D and UI, Point 필터, 압축 없음, Mipmap 끔, Wrap Clamp. 원형 슬롯·잉크병은 종횡비 유지하고 정수 배율 우선. PNG에 글자를 굽지 않는다.
- 팔레트 기본 소스 40×40, 권장 미리보기 80×80 또는120×120. 선택 획64×8, 화살표16×16. 실제 배치에 맞춰 정수 배율로 확정한다. 얇은 선은 Unity Image로 구현 가능.
- 텍스트는 실제 TTF 사용. 현재 Font 참조가 있으므로 TMP 전환을 전제로 하지 않는다. TMP를 쓰는 화면에 적용할 경우 한글 글리프/동적 atlas/대체폰트 및 메모리 검증 후 적용한다.
- Sprite Atlas에는 픽셀 UI를 모으고 글꼴 atlas는 별도 관리한다. 아직 atlas·prefab·Unity import 설정을 생성하거나 실기 검증하지 않았다.

## 준비된 파일 / 남은 에셋
준비: 6색(빨강·파랑·노랑·초록·보라·무색) × 테두리/채운 바탕/빈 바탕 =18 PNG, 선택 획1, 화살표2, manifest, 실제 폰트 기준판.

다음 제작: 승인된 잉크병 형태의 투명 개별 에셋, 효과별 라벨 아이콘, 등급 표시, 실제 무기·무기 도장·특수 도장 아이콘, 키 안내/키다운 진행 표시. 게임의 기존 에셋·ID와 먼저 대응하고 부족한 것만 제작한다. 모든 잉크를 임의 아이콘으로 대체하지 않는다.

제작 순서: 이 기준판으로 글꼴/크기 승인 → 대표 잉크병·효과 3개를 실물 에셋으로 고정 → 한 화면에 조립 → 0/1/5/6/15개와 긴 설명 검증 → 확정 에셋 확장 → Unity 연결.

폰트 ZIP에는 라이선스 파일이 없었다. 로컬 검토에 첨부 폰트를 사용했으며 게임 포함·저장소 재배포 조건은 확인 전이다. 현재 파일은 로컬 output에만 있으며 원격 업로드는 하지 않았다. main 게임 저장소는 수정하지 않았다.

### 폰트 검토 결과
기준판에서 가운데점(·)과 긴 대시(—)가 보이지 않는다. 해당 문자는 대체 글꼴을 연결하거나 구분점을 UI 이미지로 분리해야 한다. 빈 슬롯 표시는 글꼴에 의존하지 않는 짧은 수평선 이미지로 처리하는 편이 안정적이다. 첨부 폰트의 불규칙한 획은 이름에 잘 드러나지만 긴 본문의 작은 크기 가독성은 게임 화면에서 확인해야 한다.
