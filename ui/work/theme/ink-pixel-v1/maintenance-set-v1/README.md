# 정비소 성장·뽑기 결과 테마 v1

[성장](previews/growth.png) · [공격 강화](previews/attack.png) · [뽑기 결과](previews/result.png)

Figma 128:75, 128:321을 읽고 작성. 팀 temporary-gui.md의 슬롯 강화 및 스탬프 탭 추가를 반영. 기존 가방/장비의 어두운 흑연 배경, 폰트, 선택 획, 실물 PNG를 재사용. 배경은 기존 마을 캡처를 임시 재사용하며 실제 정비소 배경은 아님.

- 120G → 뽑기40G → 80G, 다음60G 등은 와이어의 예시 수치.
- 결과 아이템은 현재 실제 에셋 덧칠(1등급)의 예시. 옛 와이어의 공격력+4%/2등급을 옮기지 않음.
- 가방 포화 시 결제 불가는 현재 와이어 가정. 이전 대화/팀 구현 차이가 있어 최종 거래 정책으로 확정하지 않음.
- 뽑기는 항목 선택 후 F 한 번으로 실행. HTML은 위/아래 항목 선택, F 뽑기·결과 확인을 예시 전환으로 지원. 실제 결제·강화·가방 처리는 없음. 공격 강화의 길게 누르기는 기존 검토안 유지. 확인 후 성장 상태는 초기 예시로 재설정됨.
- 결과의 팔레트 탭에는 새 잉크 알림을 작은 청록색 점으로 표시. 실제 탭 확인 시 점 해제는 후속 연결 사항.
- 팔레트/스탬프 탭은 위치 표시만, 미구현. 슬롯 강화는 임의 가격 없이 대상 선택으로 표시.
- 원본 PNG의 SHA256과 경로는 asset-sources.json. Unity 미적용.
- 폰트는 기존 로컬 참조. 배포 파일에는 폰트 바이너리 없음.


## 결과 화면 정보 정리
선택 밑줄은 assets/selection-swash.png를 재사용한다. 버튼은 내용 너비로 제한하여 긴 가로 늘어짐을 방지했다. 결과는 획득한 잉크, 등급/종류, 효과/재발동 간격, 보관 상태와 비용, 확인 순서로 배치한다. 반복된 획득 문구와 하단 확인 키, 상시 장착 안내는 제거했다.

## 정보 역할별 구분 기준
아이템 이름·효과·재발동 간격은 아이템 정보로 묶는다. 보관 완료·사용 금액·확인은 처리 결과로 묶고, 64px 여백 및 얇은 구분선으로 분리한다. 색만으로 역할을 구분하지 않는다. 내부 간격 12px보다 영역 간 간격을 크게 유지한다. ui-ux-pro-max의 Success Feedback 및 Section spacing hierarchy를 게임의 열린 레이아웃에 적용했다. 신규 UI 검토 시 설명/상태/행동의 묶음, 중복 안내, 에셋 늘어짐, 960×540 가독성을 점검한다.
