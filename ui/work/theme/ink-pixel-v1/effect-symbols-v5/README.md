# 문양 v5 — 형태 보존·내부 묘사 정리

[54종 전체 이미지](previews/all-54.png) · [54종 기존/정리/병 라벨 비교 HTML](compare-standalone.html)

직전 screen-set-v2의 12개 재디자인 모양을 확대 적용하지 않았습니다. 승인된 effect-symbols-v4 픽셀 원본에서 시작해 **외곽·각도·주요 구성요소는 유지**, 28종의 내부 음영·옷솔기·작은 홈만 정리하고 이미 단순한 26종은 그대로 유지했습니다. 눈·시계·사슬·균열 등 의미를 만드는 구멍은 보존했습니다.

전체를 억지로 바꾸지 않았습니다. 변경 여부와 수정한32px격자 픽셀 수는 manifest.json에 기록했습니다. 외부 투명 영역·바운딩박스 동일, 기존 검은 픽셀 삭제 없음으로 외곽 보존을 검사했습니다.

- runtime: 220×155 투명 문양 54장. 기존 좌표/크기 유지.
- pixel-source: 32×32 마스크54장.
- bottles: 같은 문양을 원래32px로 얹은 밀착 라벨 병54장. 별개 모양을 사용하지 않음.
- previews: 5색별 전후 비교, 전체54종.
- compare-standalone.html: 이미지 내장. 내려받아 브라우저에서 전체 보기/이름·효과검색/문양 단독 비교.

이 버전은 생성기로 다시 그리지 않았습니다. 기존 원본의 선택한 내부 묘사만 픽셀 단위로 수정했습니다. 팔레트 바탕/칠은 변경하지 않았으며 Unity에 적용하지 않았습니다.
