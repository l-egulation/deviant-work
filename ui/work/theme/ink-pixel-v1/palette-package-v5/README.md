# 팔레트 분리 원본 / 표시용 패키지 v5

[전체 비교](comparison.png) · [문양 교체 데모](index.html)

## 구성
- runtime/slots: 문양 없는 합성 슬롯 16종(빈 색상 5, 빈 무색 1, 색상 바탕+칠 5, 무색 바탕+칠 5).
- runtime/symbols: 승인 시안에서 가져온 검토용 문양 5종. 실제 전체 효과 ID에 대응한 최종 문양 목록은 아니다.
- source/bases, source/paint: 분리된 제작 원본.
- source/restoration-masks: 원본 문양에 가려져 주변색으로 복원한 영역.

## 위치 규약
표시용 슬롯과 문양은 모두 220×155 RGBA, 중앙 pivot (0.5,0.5). 동일한 크기·좌표로 겹치고 내부 여백을 자동 잘라내지 않는다. 문양별 별도 위치 보정이 필요하지 않도록 캔버스에 위치를 포함했다. 추후 Unity 적용 시 같은 RectTransform과 Preserve Aspect를 사용하고, 스프라이트별 Tight trimming을 피한다. 현재 Unity는 수정하지 않았다.

## 복원 및 검증
칠 외곽은 v4에서 유지했다. 문양과 주변 혼합 경계 6px 영역은 주변색을 고정 경계로 삼아 보간했다. 숨겨졌던 칠은 추정 복원이며 승인 원본 픽셀 그대로가 아니다. 마스크 밖 RGBA가 변하지 않음을 검사했다. 분리 문양은 색상 잔여물 없이 어두운 단색으로 정리했으므로 원본의 미세한 문양 질감과 경계는 달라진다.

16+5개 표시용 PNG의 규격을 검사했다. validation.json의 reassembledPaintMismatchPixels는 재결합과 원본 차이를 숨기지 않고 기록한 값이다. 0이어야 하는 검사가 아니다. 보존 보장은 복원 마스크 바깥 영역에 해당한다.

무색 바탕 크기는 v4 비교용 규격(195×145 가시 영역)을 유지했다. 바탕 노출량은 최종 확정 전이다. 작은 UI 크기에서의 가독성과 전체 효과 문양 ID 연결, 동일 색의 서로 다른 문양 제작은 후속 작업이다.

build.py: Pillow/NumPy 필요. 사용자 폰트는 재배포하지 않으며 없으면 시스템 폰트로 비교판을 만든다.
