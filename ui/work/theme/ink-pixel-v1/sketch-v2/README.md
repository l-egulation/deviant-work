# 스케치 개편 2차 — 2026-11-11

## 확정된 방향
- 가방은 스케치/잉크 열람 전용. 제작에서 스케치+잉크로 무기 완성. 장비에서 완성 무기를 무기1/2에 장착.
- 효과 가감 계산 삭제. 조건 → 효과를 각각 표시. 조건부 DPS 효과와 상태 이상 조합으로 읽는다.
- 일반 처치 보상 기회 6개를 적립, 원하는 때 사용. 6회 선택 결과 스케치3/잉크3 보장. 한 종류 3개 선택하면 그 종류 후보 제외.
- 보스는 별도 스케치1/잉크2, 각 3중1택. 총 챕터 스케치4/잉크5(상점 제외).

## 이번 시안 동작
일반 보상 기회 6개가 준비된 상태부터 시작. 창을 닫아도 후보 유지, 획득 때만 차감. 가방 열람, 제작 빈 칸 선택/잉크 적용/확정, 장비 수동 장착 가능. 보스 보상과 처치 게이지는 이번 구현 범위 밖.
제작: 목록에서 F → 좌우 칸 선택 → F → 좌우 잉크 → F 적용. 칸 선택에서 아래로 이동 후 F 제작 확정. Esc 한 단계 뒤로.
화면 간 이동은 상단 검토용 링크. Tab으로 링크 이동 후 F/Enter 가능.

## 확인이 필요한 시안 가정
- 제작 확정 시 스케치를 목록에서 완성 무기 목록으로 이동. 빈 칸을 남긴 제작도 허용. 완성 후 추가 적용/수정 정책은 구현하지 않음.
- 중복 잉크 획득은 보상 횟수에는 반영하지만 목록 중복은 합침. 실제 중복 획득 정책 미정.
- 후보 중복, 확률, 기회 이월/챕터 전환은 미정. 현재 후보는 예시 무작위 구성.
- 기존 잉크 아이콘은 화풍 확인용 재사용. 새 효과 문양으로 확정된 에셋이 아님.
- 조건/효과 이름과 스킬 예시는 UI용이며 최신 데이터 자동 연동 아님.

색상: 제목 아이보리, 설명 중립 밝은 회색, 조건 옅은 청회색, 효과 옅은 초록. 구분선과 세로 여백을 확대.
검증: 6회 선택 시3+3, 원본 잉크 유지, 제작 후 장비에서 수동 장착, 이미지 누락 없음. Unity 변경 없음.

## 가독성과 제작 흐름 개정
잉크는 한 문장, 조건/행동 청회색·효과 초록. 가방은 4열 격자 열람, 방향키 항목 선택·Q/E 카테고리. 보상 상단 검토용 탭 제거. 기회 숫자와 팔레트 행 간격 확대. 제작 확정 전 효과 확인 화면, 현재 실행 버튼에만 F. 키보드로 제작 후 무기2 장착 확인.

## 팔레트 복원
아이콘 직접 선택, 하단 잉크 이름, 별도 번호 버튼 제거. empty 색상 바탕 + paint-v4 paint-mark 잉크 칠 + screen-set-v6 문양 3레이어 사용. 새 효과에는 기존 문양을 임시 매핑함. 3효과 제작·장착 상태 검증.
