## 문서의 권한과 범위
Office hour에서 확정한 내용은 **팀 합의**다. 팀 문서·기존 구현과 충돌하면 이 합의 및 이후 사용자의 수정 결정을 UI 기준으로 우선한다. 합의 내용을 다시 미정으로 취급하지 않는다. 팀 저장소 자체를 수정한 것은 아니다.

본 문서는 현행 HTML 시안의 구현 전달 기준이다. Unity 적용 완료를 의미하지 않는다. 타이틀과 전투 HUD 전체는 보류한다. 갤러리의 숫자·시간·배경 배치는 검토용 예시일 수 있으며 실제 밸런스 확정값과 구분한다.

## 조작 계약
- 방향키: 선택 이동. 이동만으로 실행하지 않는다. F: 선택 확정/현재 행동 실행. Esc: 한 단계 복귀, 최상위에서는 닫기.
- 행동 버튼은 **현재 선택한 버튼에만** 붓칠 강조와 F 표시. 비활성은 실행 불가 사유를 표시하며 F를 붙이지 않는다.
- F/G로 각 행동이 고정된 확인창은 예외: 두 키를 각각 표시하고 방향키로 선택을 바꾸지 않는다. 화면 유지 확인은 F 되돌리기/G 유지, 기본키 복원 확인은 F 취소/G 복원.
- Q/E: 가방·제작·장비 주 탭. 가방 첫 줄에서 ↑로 분류에 진입하고 ←→로 스케치/잉크 선택.
- W/S: 현재 선택 중인 보상/증강 카드 또는 현재 상세 설명 스크롤. F 확정 전에도 작동. 목록과 팔레트는 선택 이동을 따라 스크롤.
- G: 일반 보상 열기. 0회일 때 열기 불가. 별도 보상 보관 화면 없음.
- 설정: 좌측 분류 ↑↓ → F 진입 → 항목 ↑↓/값 ←→ → Esc 분류 복귀 → Esc 닫기. 기본키 복원 G.
- 이름 입력: 최대20자. Enter 저장/Esc 취소. 문자 입력 중 메뉴 단축키로 이동하지 않아야 한다.
- 키 도움말은 하단 공통 스타일 사용. 변경 가능한 게임 키와 고정 메뉴 키의 재설정 후 표시 정책은 별도 연결 항목.

## 시각 규칙
- 어두운 중립 흑연색, 밝은 본문, 승인된 붓칠 선택 에셋과 픽셀 그림을 유지. 임시 도형으로 에셋을 대체하지 않는다.
- 선택은 확대+강조, 비선택은 낮은 명도로 구별. 잉크 아이콘 단독 선택에는 선택 밑줄을 넣지 않는다.
- 설명은 제목과 충분히 분리하고 긴 내용은 스크롤. 수치를 억지로 작은 글씨로 압축하지 않는다.
- 잉크 조건 핵심 구절은 파랑, 시간·효과 핵심은 초록. 조사/대상 문구 전체를 색칠하지 않는다. 기본/색상 일치 적용값은 노랑. 예: ‘상태이상 부여 시’ 파랑, ‘3초’, ‘이동속도가10% 증가’ 초록.
- 비용은 행동 버튼 옆에 표시. 버튼 안내는 오른쪽에 여백을 두며 중복 설명을 줄인다.
- 월드 상단 안내는 위에서 아래로 자연스럽게 사라지는 음영. 사각 플로팅 블러·원형 블러 사용 안 함.
- 근접 팝업은 승인된 계단 모서리+아래 꼬리 프레임. 캐릭터/대상 가림과 가장자리 잘림 방지 필요.
- 보스 소개 약4초, 무기 소진 중앙 하단 약3.5초는 현재 시안의 연출 기준. 보상+1 팝업·장비 바로가기 없음.

## 에셋 적용 기준
**게임 UI는 우리가 제작·승인한 에셋으로 교체한다.** 기존 팀 UI 그림을 최종으로 혼용하지 않는다. 배경·캐릭터 캡처는 월드 참고 자료이며 UI 교체 대상과 구분한다.

폴더 이름이 최신이라는 이유로 비교 시안을 채택하지 않는다. 실제 렌더러 참조와 승인 기록을 함께 따른다. 투명 PNG·아틀라스 영역을 그대로 사용하고, 프레임은 모서리/꼬리를 보존하여 늘린다. Unity용 분할·피벗·수입 설정은 적용 단계에서 정의한다. 폰트는 기존 로컬 불러오기 방식 유지, 저장소에 재배포하지 않는다.

## 완료와 남은 범위
시안 있음: 위 화면/상태 및 에셋. 최근 검수: 960×540 조작 화면147개 기본 입력·잘림, 핵심37흐름, 잉크43/공방증강39/봉인증강12 설명 스크롤. 가능한 모든 입력 조합이나 Unity 실행 검증을 뜻하지 않는다.

밸런스 데이터 연결: 3챕터 가격, 신규 이벤트 목표 수량·생존 시간. 상점 방식·이탈·보상·최종 목적지는 후속 팀 합의로 확정. **Office hour 합의 항목은 미정에 포함하지 않는다.**

구현 연결: 저장/재접속 시 초안·후보 보존, 재설정 키/패드 안내, 월드 좌표·화면 가장자리·안내 동시 표시, 오프닝 스킵·재개, 실제 로딩 완료/실패, 챕터 이월 후 보장 회차. UI 시안에서 실제 세이브나 전투까지 구현된 것으로 해석하지 않는다.

보류: 타이틀·전투 HUD 전체. 폐기: 칸 강화·색 변경·스탬프 교체·가방 용량 초과·시작 팔레트 다시 뽑기 등 구형 스케치 이전 화면. 기존 전체화면 상점은 비교용으로 보관.
