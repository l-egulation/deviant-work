# 가방·장비 합성 v4

[가방](previews/bag.png) · [장비](previews/equipment.png) · [무색 슬롯](previews/equipment-neutral.png)

이전 피드백을 유지하면서 최신 에셋을 합쳤습니다. index.html에서 가방/장비 전환, 슬롯 선택, 후보 선택과 무색 칸 후보 좌우 넘김을 확인할 수 있습니다. 실제 장착·파괴 처리는 없는 시안입니다. Unity 미적용.

## 사용한 원본
- 팔레트: palette-package-v6 (원본 유지)
- 문양·병: effect-symbols-v5 + ink-bottles-tag-v1 (동일 문양, 큰 중앙 태그)
- 무기: weapon-ink-v3/runtime (검은 몸체, 굵은 픽셀/넓은 명암 면, 별도 가는 테두리 없음)
- 선택 획·방향 삼각형·좌우 화살표: screen-set-v2의 투명 PNG
- 배경: 기존 실제 마을 캡처

## 유지한 피드백
- 각 팔레트 아래 이름 27px. 별도 번호 목록 없음. 강화 수치25px.
- 큰 외곽 박스 없이 여백과 얇은 선으로 영역 구분.
- 현재 장착/교체 후보 사이 삼각형 포함 구분선.
- 이름은 잉크 계열 색, 설명은 중립색.
- 후보 제목과 병 사이 여백, 무색 칸 좌우 넘김.
- 가방과 장비의 배경·위치·폰트·선택 획 통일.
- 작은 보조 글자24px, 본문25~27px, 큰 제목40px 유지.

MemomentKkukkukk는 로컬 참조이며 PNG에 실제 적용했습니다. 폰트 재배포 조건 미확인으로 바이너리는 포함하지 않습니다. HTML은 없으면 대체 글꼴입니다.

가방12개, 미장착 도장, 무기별 팔레트 상태와 등급은 배치 검토용 예시입니다. 무기 탭 선택은 시각 상태만 바뀌며 서로 다른 저장 구성을 구현하지 않습니다. 게임 로직 구현과 구분합니다.
