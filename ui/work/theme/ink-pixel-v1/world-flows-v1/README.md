# 탐험·이벤트·첫 진행 UI

이 폴더는 **HTML 조작 시안**이다. Unity 씬·전투·프로필을 수정하거나 저장하지 않는다. 기존 갤러리의 어두운 먹색, 꾹꾹체 로컬 로딩, 붓칠 선택 표시, 계단 모서리 말풍선, 승인한 픽셀 에셋을 재사용한다.

## 열기

- 전체 모음: `../catalog.html` — 이미지와 직접 조작 모두 제공.
- 이 묶음: `index.html` — 아래 시안 목록에서 상태를 선택한다.
- 방향키로 실행 버튼 선택, F/Enter로 실행. 선택한 버튼에만 F 표시. 보상 열기는 G 전용. 포탈 F는 별도 버튼 없이 근처에서 이동.
- 회색 검토 도구는 게임 UI가 아니다. 처치·장치 해제·시간 경과·방 이탈을 대신 입력한다.
- 브라우저 이동/전투 시뮬레이터가 아니라 UI 흐름 시안이다. 월드 배경은 기존 실제 게임 캡처를 재사용했다. NPC·보스·이벤트 방의 최종 배치와 애니메이션은 포함하지 않는다.
- 폰트 파일은 추가 배포하지 않는다. 이전과 동일하게 로컬 폰트/직접 불러오기를 사용한다.

## 제작 범위

| 영역 | 시안과 연결 |
|---|---|
| 봉인 도전 | 시작 → 4/5/6마리 3페이지(상단 점 3개) → 완료 → 상자 상호작용 → 기존 봉인 증강 3중 1택 → 월드 복귀 |
| 정령 구출 | 장치 해제 수 → 완료 연출 → 기존 혼합 보상 즉시 선택 → 완료. 예시 장치 수 3개 |
| 묘목 생존 | 시작 → 남은 시간 → 종료·남은 적 퇴장 안내 → 즉시 보상. 예시 시간 45초 |
| 위험 상자 | 정답을 알 수 없는 동일 상자, 오답의 적/폭발 피드백, 다른 상자 계속 열기, 정답 회복·보상, 남은 상자 비활성. 검토에서는 3번째를 정답으로 고정 |
| 함정 수집 | 장치 가동 → 수집 0~5 → 이탈·복귀 시 수집 유지 → 완료·함정 해제 → 보상. 시간 제한 없음 |
| 보스 소개 | 시계탑 집행자 / 베르소·렉토 이름과 F 건너뛰기. 상단 음영에서 4초 후 자연스럽게 사라짐. 검토 도구의 처치 후 기존 스케치1·잉크2 선택에 연결 |
| 전투 알림 | 보상 기회+1, 장착 무기 소진만 중앙 하단 3.5초 알림. 장비 바로가기 없음. 보관 무기는 소진하지 않음. 보상 획득 알림은 없애고 우측 하단 G/기회 수만 배치 검토 |
| 포탈 | C/V 2초 설치, Shift 취소, 하나일 때 왕복 불가, 2개 설치·왕복·위치 유지. 일반 포탈 알림/키 안내 없음. 첫 설치 안내만 별도 말풍선. 검토 위치 이동은 방향키 좌우 |
| 장면 전환 | 기존 보스 보상 뒤 다음 챕터 로딩. 모든 게임 입력 차단 후 탐험 복귀. 검토용 1.8초이며 실제 로딩 퍼센트를 꾸며 표시하지 않음 |
| 최종 챕터 | 클리어 → 기록 열람. 이동 목적지가 미정이라 이동 버튼은 보류. 시간·처치 수·재화는 검토 예시 |
| 오프닝·첫 진행 | 조사 수첩3쪽 → 동작 안내 → 지워짐 → 조력자 → 각성 → 기존 기록 농가 → 맨손3타 안내 → 보상 → 제작 안내 → 기존 제작 → 내구도·장비 안내. 첫 회귀도 별도 시안 |

독립적인 시안 진입점 35개를 갤러리에 등록했다. 개별 시안은 서로 다른 검토 상태이며, 하나의 실제 게임 세이브로 초기화하는 기능은 아니다. iframe의 가방·제작·장비·보상 데이터는 **같은 페이지 세션에서 유지**하며 새로고침하면 초기 예시로 돌아간다.

## 연결 경계

- `app.js`는 월드 시안 상태와 검토 도구를 소유한다.
- `../sketch-v3/world-bridge.js`는 `worldBridge=1` iframe에만 작동한다. 기존 독립 시안은 동작이 바뀌지 않는다.
- 같은 부모/iframe의 메시지만 처리하고 임의 코드 실행 메시지는 없다. 보상 완료 후 선택 결과는 기존 가방에 남는다.
- 이벤트가 지급돼도 일반 보상 기회·회차·보장 횟수는 소모하지 않는다. 같은 완료의 중복 수령과 선택 중 Esc 포기를 막는다.
- 봉인 보상에는 ‘나중에 선택’이 없으며, 일반 이벤트의 가방 비교는 동일 후보로 돌아온다.
- 실제 대화 연출의 모든 타이밍, 유령 시범, 오프닝 컷씬 건너뛰기/일시정지, 패드·재설정 키의 동적 표시, NPC를 추적하는 월드 좌표는 Unity 연결 단계의 범위다. 이번 시안은 그 기능을 구현했다고 주장하지 않는다.

## 검수

`interaction-check.json`은 브라우저 입력/흐름 검증 결과, `preview-check.json`은 상태별 이미지 확인 결과다. 캡처 중 발견한 atlas 전체 노출을 잘라내고 대화창과 수첩 여백을 수정했다. 봉인·보상·이벤트·포탈·오프닝은 실제 브라우저에서 조작했다. 새 전투 HUD 전체와 타이틀은 보류 상태를 유지한다.

## 현재 월드 표현 규칙
- 상단 목표/완료/보스/조작 안내: 화면 상단 전체 폭의 수직 음영 감쇠. 원형/직사각형 플로팅 음영은 사용하지 않음.
- 상자: 가까운 하나에만 기존 꼬리 프레임과 F 버튼. 위험 상자 ←→는 근접 대상을 시뮬레이션하며 봉인 상자는 하단 검토 도구로 접근/이탈 확인. 실제 캐릭터는 배경 캡처로 고정되어 있음.
- 포탈: 팀 승인 portal_draw/F020 원본 문 + 36px 번호. 시안은 설치 시간을 처리하되 실제 그리기 캐릭터 애니메이션은 Unity 연결 대상.
- 조사 수첩: 팀 승인 opening-prologue-notebook-20261105의 notebook 및 삽화 3장을 사용. assets/source.json 참고.
- 첫 이동: ←→, Space 두 번, Shift 입력을 각각 확인한 뒤 다음 구간. 물리/점프 타이밍 검증이 아니라 UI 입력 안내 시안.
- 보상 용기의 충전 애니메이션·형태는 전투 HUD에서 제작할 항목. 현재 병은 기존 에셋으로 위치/키/수량만 검토.
