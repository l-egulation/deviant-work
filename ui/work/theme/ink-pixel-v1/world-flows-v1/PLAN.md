# 탐험·이벤트·첫 진행 UI Implementation Plan

**Goal:** 승인한 8개 영역을 기존 테마와 보상 화면으로 연결한 HTML 조작 시안으로 제작한다.
**Architecture:** world-flows-v1은 월드 위 표시와 흐름 상태를 소유한다. 기존 sketch-v3는 iframe 안에서 보상·증강·가방·제작·장비 상태를 유지한다. 선택 완료 메시지만 연결하며 Unity는 수정하지 않는다.
**Tech Stack:** HTML/CSS/JavaScript, 기존 PNG 에셋과 atlas, Chrome 조작 검증.
**Spec:** 사용자 요청 및 팀 bb88516c3의 docs/design/world/event-rooms.md, stage-gimmicks.md, run/run-structure.md, story/opening/opening-playable.md. 사용자 확정 규칙 우선.

## Constraints / 판단
- 봉인: 4/5/6마리 3페이지·상단 점 3개·시간 제한 없음·완료 후 상자 상호작용으로 증강. 공통 이벤트 문서와 다른 부분은 구체적인 봉인 규칙 유지.
- 이벤트4: 완료 후 자동 보상, 포기 불가·한 번 지급. 미정 수치(3장치/45초/3상자/5조각)는 검토 도구에만 예시라고 명시.
- 위험 상자 보상 등급·회복 수치는 미정이라 UI에서 임의 수치 확정하지 않음.
- 보상 기회는 보관, 이벤트 보상과 별개. 포탈2초 설치·취소·두 개 필요·왕복.
- 최종 챕터 목적지 미정: 결과/기록까지만 조작 가능. 임의 마을/타이틀 버튼 없음.
- 오프닝 최신 연출 문서가 초반 개요보다 상세하므로 조사원·수첩 흐름 사용. 이야기 배경/VFX 재제작이 아니라 UI와 대사 흐름 검토.
- 기존 병/문양/무기/말풍선/붓칠/폰트 방식 유지. 반복 클릭/키 유지로 보상 중복 금지.
