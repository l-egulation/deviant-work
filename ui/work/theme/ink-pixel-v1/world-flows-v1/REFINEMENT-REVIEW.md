# 월드 UI 가독성 재검토 · 2026-11-13

## 반영
- 갤러리 상단 요약과 링크를 서로 다른 행으로 분리. 링크는 줄바꿈하며 요약 문장을 한 글자 폭으로 압축하지 않음.
- 완료 안내의 상단 음영을 본문 아래까지 확장. 이벤트 목표 아이콘 60 → 80px, 포탈 번호 36 → 54px.
- 봉인 진행: 봉인 종이 3장으로 대기/현재/완료를 구분. 생성 원본을 SVG 영역으로 참조하므로 미리보기와 원본이 동일함.
- 보상 충전 용기: 프레임 에셋 내부에 실제 충전량을 표시. G 옆 숫자는 저장된 기회. 0회일 때 열기는 비활성이나 충전량은 계속 보임.
- 최신 rewards.md 기준 몬스터별 충전량이 다르므로 고정 처치 수를 표시하지 않음. 검토 도구의 +15/+35%는 테스트 값이며 게임 밸런스 수치가 아님. 실제 누적 요구량은 게임 데이터 연결 필요.
- 설정과 일시정지 조작 안내에 보상 열기 G 추가.
- 조사 수첩: 페이지 내부가 비어 보이는 생성 실패본을 사용하지 않고, 종이가 완전히 채워진 새 원본 적용. 외곽은 HTML에서 잘라 표시. Unity용 투명 외곽 정리는 별도 내보내기 단계에서 필요.

## 검증 범위
- 960×540: 현행 갤러리 149개 URL의 이미지 로딩/가로 넘침 확인. 이는 모든 문장의 시각적 가독성이나 전체 입력 조합을 보증하는 검사는 아님.
- 월드에서 기존 화면으로 연결되는 조작 47개 검사: 봉인/이벤트 보상, 가방 비교 후 복귀, 포탈, 오프닝, 물리 F/G 키, 보스 보상, 로딩 입력 차단.
- 충전량 이월·0회 비활성·G 안내 별도 검사.
- 수첩, 봉인 진행, 보상 충전, 갤러리 이미지를 직접 확인.

## 남은 범위
- 전투 HUD 전체 및 타이틀은 보류.
- 최종 클리어 후 목적지는 미정.
- UI 시안의 목표 개수·시간과 충전 수치는 예시. Unity 실제 월드 좌표/충전 데이터/장면 전환 연결은 미적용.
- 작은 화면의 모든 긴 설명과 모든 키 조합에 대한 수동 플레이 검수는 추가 필요.
