# 무기 v4 — 어두운 UI용 명도

승인 v3의 13종 96×96 투명 영역과 실루엣 동일. 기존 4색 픽셀 면의 명도를 교체. 몸체 #94989C, 밝은 면 #BABCB9, 포인트 #DEDACF. 외곽 #23262A. 검은 내부의 넓은 면은 #5C6166으로 분리. 발광과 추가 윤곽선 없음. UI 전용, Unity 미적용.

생성 참고안 sources/color-direction-reference.png는 색 방향 확인용이며 런타임 에셋과 다름. 실제 에셋은 승인 v3의 픽셀 면을 유지한 팔레트 수정본. 내장 이미지 생성 프롬프트: preserve 13 chunky pixel silhouettes, dark graphite background, lighter graphite main planes, small warm paper highlights, no glow or added outlines.
