# 승인 시안 교차검증 v2

승인 기준은 `../mockups/palette-options/all-colors-v8-paint-variation.png`.

[index.html](index.html)을 로컬 브라우저에서 열면 각 상태·색마다 원본/수정본을 같은 좌표와 동일 배율로 비교한다. 수정본은 승인 원본의 배경과 글자를 이미지 편집 도구로 제거한 후보이며, 정확한 원본 픽셀 추출이 아니다.

## 확인 결과
- 문양: 이전 약 17% 너비의 작은 문양 대신 승인 원본의 큰 문양 구성을 복원했다.
- 칠 형태: 초록·파랑의 납작해짐은 완화됐으나 원본과 정확히 일치하지 않는다.
- 테두리: 추출 이미지 주변에 색 잡티·얇은 외곽 흔적이 남았다.
- 칠 마스크: 이번 파일은 상태별 합성 시트이므로 같은 색 마스크의 재사용을 보장하지 않는다.

**최종 에셋 검증 미통과.** 이 결과로 기존 assembly-v1 에셋을 교체하지 않는다. Unity 미적용. 원본 실루엣을 고정한 정밀 마스크 제작 및 문양 레이어 분리가 필요하다. 이미지 재생성만으로 정확한 형태 보존을 보장할 수 없다.
