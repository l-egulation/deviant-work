# 칠 형태 직접 분리 v4

[비교판](comparison.png): 위부터 승인 원본 / 분리한 칠+문양 / 색상 바탕 합성 / 무색 바탕 합성.

밝은 칠 영역 5종을 extraction-v3의 장착된 색상 칸에서 분리했다. 색상별 밝기 임계값으로 외곽을 추정하고 내부 문양 영역은 보존했다. 원본 RGB는 유지하며 재생성하지 않았다. 남긴 픽셀 RGB 불일치 0을 스크립트에서 확인한다.

**paint-mark-*.png는 칠과 검정 문양이 합쳐진 투명 이미지다.** 문양 뒤의 보이지 않는 색을 임의로 복원하지 않았다. 다른 효과 문양으로 교체하려면 별도의 문양 없는 칠 원본 제작이 필요하다.

두 합성 행에는 동일 칠 PNG를 같은 좌표 (0,0), 배율 1로 얹었다. 따라서 일반/무색 칸의 칠 형태가 동일하다. manifest.json에 파일 해시와 배치 정보를 기록했다.

색상 바탕은 빈 색상 칸 원본을 사용한다. 무색 바탕은 빈 무색 원본의 가시 영역을 195×145로 nearest 확대해 (10,5)에 놓은 비교용이다. 승인 원본의 상태별 바탕 배치와 동일하지 않으며, 이번 비교의 목적은 칠 이미지 재사용 확인이다. 바탕 노출량의 최종 조정은 별도다.

알파 경계는 추정이며 원본의 배경 혼합 경계가 일부 포함되거나 제외될 수 있다. Unity 미적용. 원본 직접 분리 자료와 이전 시안은 덮어쓰지 않았다.
