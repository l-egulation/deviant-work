# 재화 아이콘 · 첫 시안

골드: 런 내 소비 재화, 금화 실루엣과 노란색.
마법안료: 영구 해금 재화, 안료 덩어리 실루엣과 청록색. 장착용 잉크병과 구분한다.

검토용 생성 PNG. 최종 승인 전이며 Unity에는 적용하지 않는다. 비교 페이지는 동일 표시 크기와 실제 HUD에 가까운 축소 표시를 함께 제공한다. 실제 네이티브 픽셀 크기·알파 경계·atlas 패킹 최적화는 디자인 승인 후 정리한다. 생성 원본을 임의로 다시 그리거나 다른 에셋으로 대체하지 않는다.

## 마법안료 v2
보석 같은 각진 실루엣을 낮고 넓은 물감 형태와 말린 물감 결로 수정. 생성 도구로 주변 잔상을 제거한 투명 PNG. 기존 v1은 비교 기록으로 보존하며 index.html은 v2를 사용한다. 골드는 변경하지 않았다.
