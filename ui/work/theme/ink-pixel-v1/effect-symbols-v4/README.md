# 효과 문양 v4 — 직관성 검토안

[비교 페이지(단독 파일)](compare-standalone.html) · [검토 기록](agent-review.md)

HTML 파일을 내려받아 브라우저로 열면 효과 설명과 이전 v3 / 수정 v4를 비교할 수 있습니다. 이미지가 포함되어 다른 파일 없이 열립니다. 색상·검색 필터, 문양 단독/팔레트 합성, 크기 전환을 제공합니다.

## 변경 내용

- 3명의 에이전트가 54종을 검토: 유지 3종 / 보완 20종 / 교체 31종.
- 효과의 주요 성격을 알아볼 수 있도록 공격·보호·시간·독 등의 구체적인 형상을 사용했습니다.
- 수정본 재검토에서 지적된 9종은 추가 수정했습니다. 마지막 9종은 제작자의 시각 검수이며 추가 에이전트 승인이나 사용자 테스트를 의미하지 않습니다.
- 유지: ink3_red_08, ink3_green_04, ink3_green_07.

## 파일 구성

- runtime: 별도 투명 문양 PNG 54종, 각 220×155. 팔레트 바탕과 칠은 포함하지 않습니다.
- pixel-source: 32×32 문양 원본.
- sheets: 생성된 원본 시트와 추가 수정 시트.
- previews: 색상별 검토 이미지 및 비교 페이지 화면.
- manifest.json: 식별자, 파일 경로, 표현 의도와 검토 상태.

승인된 palette-package-v6는 변경하지 않았으며 Unity에는 적용하지 않았습니다. 이 버전은 검토안으로, 실제 게임 크기에서 효과를 얼마나 정확히 알아보는지는 플레이어 테스트가 필요합니다.
