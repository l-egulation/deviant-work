# 정비소 스탬프 장착·교체 시안

기존 graphite 테마, Memoment 폰트, 실제 무기 에셋, selection-wash-v1을 참조한다. 상단 120%, 무기 115%, 종류/후보명 110% 선택 확대. 중앙 간격 144px. 스탬프 전용 그림은 제작하지 않았으며 이름으로 후보를 구분한다.

- index.html: 레이피어→채찍 교체, 범위 유지에 따른 장침→가시 그물 비교
- ?kind=skill: 범위→이동 / 장침→흘려찌르기
- ?case=empty: 기본검의 첫 무기 스탬프 장착, 무료
- ?case=poor: 10G 보유, 20G 교체 불가
- 후보 레이피어/범위: 같은 효과 거절, 방패: 도면 호환 불가

아이템/재화는 변경하지 않는 시안. F는 안내만 표시한다. 전체 키보드 탐색은 미구현. 발사기 비교 상태는 준비 중임을 명시한다. Unity 미적용.

근거: 팀 docs/design/systems/ink-blueprint-proposal.md 1차 스탬프 규칙(무료 첫 장착, 교체20G, 기존소멸, 도면 호환, 변형유지), combat/melee.md 채찍 가시그물/레이피어 흘려찌르기. 빈 상태·교체 상태를 분리한다. 문구는 기본 동작 요약이며 최종 밸런스 표시가 아니다.
