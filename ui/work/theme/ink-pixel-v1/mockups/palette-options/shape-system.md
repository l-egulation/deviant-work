# 팔레트 형태 시스템

색상별 빈 바탕 5종, 공통 무색 바탕 1종, 색상별 장착 잉크 흔적 5종을 분리한다. 효과 문양과 강화 수치는 별도다.

- 색상 칸 장착 = 해당 색상 바탕 + 해당 잉크 흔적 + 효과 문양.
- 무색 칸 장착 = 공통 회색 바탕 + 위와 동일한 잉크 흔적 + 동일한 효과 문양.
- 같은 색의 흔적은 같은 원본 Sprite를 재사용한다. 위치·크기·회전도 같게 하며 화면별로 재생성하지 않는다.
- 빨강: 짧은 사선 흔적. 노랑: 위쪽 붓끝이 조금 갈라진 흔적. 초록: 부드러운 덩어리. 파랑: 옆으로 살짝 퍼진 덩어리. 보라: 한쪽에 짧은 돌기가 있는 흔적.
- 모든 흔적은 두툼하고 평평한 픽셀 형태, 입체 테두리 없음. 빈칸은 기호 없음.
- 바탕이 일부 남게 설계하며 무색 바탕은 밝은 회색. 효과 문양은 색상 고정 문양이 아니라 아이템 효과 예시다.

all-colors-v6-shape-families.png는 형태 방향을 검토하는 생성 시안이다. 두 행의 칠 모양이 픽셀 단위로 일치하는 완성 조립본은 아니다. 개별 투명 원본 제작 후 동일 이미지 중첩으로 일치시켜야 한다. Unity 적용 없음.
