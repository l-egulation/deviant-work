# 무기 v5

레이저: 길게 갈라진 레일 발사부. 샷건: 개머리판과 짧은 이중 총열. 유탄: 원형 장전부와 위로 향한 포신. 세 종류만 재디자인, 나머지 10종 v4 그대로. 모두 96×96 RGBA, 48픽셀 기반 2배 nearest 확대. 비교판은 실제 런타임 PNG 사용.

내장 이미지 생성으로 세 실루엣 제작 후 투명 분리 및 기존 5색 팔레트 적용. 프롬프트 요약: chunky graphite pixel art, three distinct silhouettes, forked laser, double-barrel shotgun, round breech mortar, no fine mechanical detail. Unity 미적용.
