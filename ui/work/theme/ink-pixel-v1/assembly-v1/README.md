## 이미지 구성
- 빈 바탕 6종: 빨강·노랑·초록·파랑·보라·무색.
- 칠 흔적 5종: 색마다 조금씩 다른 실루엣. 같은 색의 일반 칸과 무색 칸은 **동일 파일·배율·위치**를 재사용한다.
- 효과 문양 6종: 팀 저장소 `resources/ui/ink-part-symbols/source/pixels.json`의 문양 레이어를 분리해 검정으로 렌더링. 상세 출처는 effect-manifest.json.
- 밀착 라벨 잉크병 1종: 승인된 빨강 병 원본 재사용.
- 빈 칸에 기호를 넣지 않으며 강화 수치는 아래에 표시한다.

## 검토 화면의 범위
가방·장비·팔레트 비교 탭, 후보 좌우 넘김, 일반/무색 칸 전환을 제공한다. 가방은 동일한 덧칠 잉크 3개를 둔 표본으로, 전체 아이템·카테고리 구성이나 최종 레이아웃을 대체하지 않는다. 무기·도장 그림과 게임 배경은 이번 조립본에서 생략했다. 장착·버리기·파괴 문구는 표시만 하며 게임 상태를 바꾸지 않는다.

첨부 MemomentKkukkukk 폰트를 로컬에서 실제 적용해 스크린샷을 만들었다. 폰트 파일은 재배포 조건 미확인으로 Git에 포함하지 않는다. 사용자가 제공한 TTF를 fonts/MemomentKkukkukk.ttf에 두면 같은 글꼴로 열리고, 없으면 시스템 글꼴로 표시된다.

## 제작 및 검증 한계
개별 PNG는 승인된 시안에서 이미지 생성으로 재제작했으므로 v8의 정확한 잘라내기 결과는 아니다. canvas 여백과 해상도가 달라 asset-manifest.json의 가시 영역으로 표시를 정규화했다. 저투명도 가장자리는 검토 화면의 SVG 알파 필터로 줄였다. 최종 Unity용 고정 픽셀 격자·pivot·알파 가장자리 정리는 남아 있다. 원본 PNG를 그대로 런타임 완성 에셋으로 취급하지 않는다.

Chrome에서 세 화면을 렌더링해 겹침·문구·팔레트 레이어를 육안 확인했다. 1600×1050 검토 화면이며 실제 16:9 게임 화면과 여러 해상도 검증은 후속 작업이다.
