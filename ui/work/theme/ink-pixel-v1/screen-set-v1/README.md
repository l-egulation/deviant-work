# 가방·장비 에셋 조립 시안 v1

Unity 미적용. index.html을 열어 가방/장비 탭, 아이템, 슬롯, 도장 설명 자리와 무색 슬롯 후보 넘김을 확인합니다. 장착/버리기/파괴는 시안 안내이며 실제 변경 기능은 없습니다.

- 승인된 palette-package-v6와 effect-symbols-v4 PNG를 그대로 같은 좌표로 겹칩니다.
- 밀착 라벨 병 원본의 색상 변형과 문양 교체 파생본을 사용했습니다. 병 자체의 최종 전 색상 에셋 승인을 의미하지 않습니다.
- 배경은 기존 실제 마을 캡처입니다. 무기 그림은 이전 시안의 그림을 재사용한 임시 표시입니다.
- 실제 제공 폰트는 로컬 assembly-v1/fonts의 MemomentKkukkukk.ttf를 참조합니다. 재배포 조건 미확인으로 폰트 파일은 커밋하지 않습니다. PNG 시안은 해당 폰트 적용 결과입니다.
- 보유 수량/등급/장착 상태는 화면 검토용 표본이며 저장 데이터와 무관합니다. 설명은 팀 색상 잉크 개편안의 해당 효과를 사용했습니다.
- 장비 탭의 무기 선택은 시각 상태만 전환하며 서로 다른 저장 구성을 구현하지 않았습니다.
- 1920×1080 기준 두 화면의 배경/탭/바깥 여백/글자 크기를 공유합니다.
