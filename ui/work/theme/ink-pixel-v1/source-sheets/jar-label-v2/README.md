# 잉크병 라벨 개정 v2

- glued-clean.png: 병 곡면에 밀착된 종이, 얼룩 제거, 가장자리 곡면 음영만 유지.
- tag-centered.png: 목에 연결된 고리에서 정면 중앙으로 내려오는 큰 태그, 크게 그린 픽셀 공격 문양.
- 짧은 잉크병 비율을 유지하며 종전의 가로로 넓은 병보다 날씬하게 조정.
- 모두 내장 이미지 생성 도구로 제작한 개별 RGBA 원본. 64px 정수 픽셀 그리드 정제 완료를 의미하지 않는다. Unity에는 적용하지 않음.
- 나머지 색상과 효과 확장은 라벨 방식 결정 후 진행. UI 조각 시트의 번짐 제거 재생성은 만족스럽지 않아 기존 초안을 대체하지 않았다. 개별 분리와 가장자리 정리는 아직 남아 있다.

## 편집 지시
밀착형: 종이 얼룩/반점 제거, 곡면에 붙은 가장자리 음영과 계단형 공격 문양 유지.
태그형: 정면 중앙으로 이동, 몸통 너비 약55%로 확대, 문양 확대, 목 고리 연결 유지.
