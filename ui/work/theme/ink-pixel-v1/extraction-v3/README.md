# 승인 원본 픽셀 직접 분리 v3

이미지 재생성 없이 승인 v8 PNG에서 16개 상태 이미지를 직접 분리했다. Unity 미적용.

- 빈 색상 칸 5종
- 장착된 색상 칸 5종
- 장착된 무색 칸 5종
- 빈 무색 칸 1종

[원본 / 분리본 동일 배율 비교](comparison.png) · [투명 PNG 폴더](assets/)

각 쌍 왼쪽은 원본 영역, 오른쪽은 투명 배경 분리본. 원본 배율 1:1이며 리사이즈하지 않았다. UI에서 보이는 축소 미리보기와 달리 PNG 원본은 2450×850이다.

## 방법 및 확인
extract.py가 승인 PNG의 명시적 영역에서 색상·밝기 마스크를 만들고 가장 큰 연결 성분과 내부 영역을 보존한다. 검정 문양은 내부 영역으로 남긴다. 원본 RGB를 재색칠·보간하지 않고 알파만 부여한다.

16개 PNG의 불투명 픽셀 RGB는 해당 원본 영역과 모두 일치한다(불일치 0). 비교판에서 문양 크기·칠 실루엣을 육안 대조했다. 좌표와 가시 경계는 manifest.json 참조.

알파가 없는 합성 원본에서 추출했으므로 경계의 원래 알파값을 복원한 것은 아니다. 경계는 색상 임계값으로 추정했고 원본의 안티앨리어싱/배경 혼합 픽셀이 일부 남거나 제외될 수 있다. RGB 일치가 알파 마스크 완전 일치를 뜻하지 않는다.

## 용도와 제한
이번 결과는 승인 외형을 보존한 **상태별 합성 스프라이트**다. 바탕·칠·문양의 독립 레이어가 아니다. 원본 각 행에 존재하는 미세한 차이도 유지한다. 따라서 동일 칠 마스크를 색상 칸·무색 칸에 재사용하는 최종 레이어 시스템은 별도 작업이며, 가려진 원본 정보를 임의로 복원하지 않았다.

기존 assembly-v1의 재생성 에셋은 그대로 두고, 본 결과를 외형 기준으로 삼는다. 효과별 아이템 ID 대응 및 Unity 픽셀 격자·pivot·import 설정은 미적용.

재현: Pillow와 NumPy가 있는 환경에서 `python3 extract.py`.
