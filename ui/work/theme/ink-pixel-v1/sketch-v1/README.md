# 스케치 개편 시안
보상: 좌우 선택 → F 획득 → F 가방 보기.
가방: 위아래 선택/스크롤 → F 장착 자리 → 좌우 → F 장착. Esc 취소. 기존 장비는 가방에 유지.
보상 내구도 숨김, 가방 내구도 퍼센트. 기존 픽셀 무기/팔레트/붓칠/배경 재사용.
종합 효과는 사용자 예시 결과(자신 기절 0.5초 + 3초 기본 공격 피해 증가)를 고정 표시. 1.5초/−2초의 계산 및 대상 규칙은 미확정이므로 자동 합산하지 않음. 적용 칸의 문양은 새 효과 에셋 확정 전 생략.
새 시안은 메모리 상태이며 새로고침으로 초기화. Unity 변경 없음. 잉크 적용 인터랙션은 이번 범위에 없음.
