잉크는 더 좋은 개체를 획득해 교체.
팔레트·개별 칸·잉크의 직접 강화는 없음.

시연 수치 · 확정 규칙 · 미정 사항

확정 규칙: 도면과 팔레트 분리, 흰색 형태 변환·검정 특수공격 변경, 정해진 팔레트 구성, 일부 칸 활성화, 정비소 빈칸 추가, 고비용 부분 교체와 기존 파츠 소멸, 소액 흰색·검정 교체와 기존 잉크 소멸, 최종 제작 시 기존 팔레트·파츠 전부 파괴, 무색 칸, 동일 효과 독립 발동, 현재 무기 팔레트만 적용, 도면만 직접 강화.

시연용 가정: 시작 재화 2,000G, 굽기 100G, 부분 교체 300G, 빈칸 추가 80G, 흰색·검정 교체 각각 30G, 도면 강화 100G. 도면은 +0~+5, 기본 공격력 10에서 단계당 1 증가만 표시한다. 실제 강화 범위·가격·상한은 미정이다. 한 개 이상 파츠가 있어야 굽기 버튼이 활성화되는 것도 이 시연의 가정이다.

콘텐츠 예시: 팔레트 세 구성, 재고 수량, 효과 문양·수치·강한 개체는 UI 비교용이다. 빨강 외 색상의 개별 효과도 확정 콘텐츠가 아니다. 같은 효과의 발동 단위는 칸마다 나누되 발동 확률·전투 피해·내부 대기시간은 재현하지 않는다. ‘독립 발동 보기’는 각 장착 파츠를 한 번씩 강조하는 도식이다.

범위: 무색 칸의 최초 투입은 시연한다. 다른 색으로 덧칠하는 정책은 미정이므로 활성화 후에는 기존 파츠와 같은 색만 교체하도록 시연을 제한했다. 대체 도면은 비교용 독립 상태이며 실제 무기 획득·이전·해금 규칙을 정하지 않는다. 최대 체력·광폭화·상태이상의 무기 교체 처리, 본 게임 전투·드롭·저장은 포함하지 않는다. 새로고침 시 시연이 초기화된다.
