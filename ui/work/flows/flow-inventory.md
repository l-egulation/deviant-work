FigJam에 옮기기 전의 원본 표입니다. 이 표의 각 행이 흐름도의 상자 하나입니다.

- **구분**
  - `본` = 본 흐름
  - `본(사용자 안)` = 사용자가 정한 방향이 본 흐름인 곳
  - `메모` = 팀 현재 구현 메모
  - `목표` = 팀 목표 규칙인데 아직 미구현 (점선)
- **WF 상태:** `맞음` / `수정` / `수정 (팀 현재 구현엔 맞음)` / `없음` / `이전안만 있음`
