# FigJam 대조: 테마 제작 현황과 남은 UI

확인일: 2026-11-09. 현재 정비소 결과 시안은 사용자 요청으로 잠정 유지한다. 이 목록은 테마 제작 계획이며 Unity 구현 완료 목록이 아니다.

## 근거와 범위
- [FigJam 현행 사용자 흐름 v2](https://www.figma.com/board/nHfGBYZsYIcHNUD9SU4cGs/?node-id=100-1706)의 전체 및 상세 ①~⑤를 직접 조회했다.
- [Figma 와이어프레임](https://www.figma.com/design/qjL5PNYHPgTDQ0huZXBzLg)의 Page1, 마을 작업대, 탐험960, 정비소960 페이지 구조를 직접 조회했다. 이번에는 개별 화면의 시각적 재검토를 하지 않았다.
- UI 저장소의 screen-set-v6, maintenance-set-v1 및 이전 제작 현황을 대조했다. 팀 게임 코드/원격 최신화/Unity 실행은 이번 확인 범위 밖이다.
- FigJam의 맞음/수정/없음은 **와이어 상태**다. 테마 완성이나 기능 구현 상태로 읽으면 안 된다. 흐름 상자 하나가 반드시 독립 화면 하나인 것도 아니다.

## 제작 전에 정리할 충돌
1. ⑤ 색상 잉크 흐름은 아직 무제한/보관함0~5칸을 본문에 두고 있으나, 같은 보드 134:863 쪽지에 공용 가방5→15칸으로 폐기됐다고 적혀 있다. 다른 UI 기록에는 분류별15칸도 있어 현행 담당 기준을 대조해야 한다. 구 규칙대로 포화 UI를 만들지 않는다.
2. 스탬프는 FigJam/와이어에서 준비 중이지만 이전 팀 문서 검토에는 적용 구현 기록이 있었다. 기능 준비도와 와이어 준비도를 분리해 확인한다.
3. 보스 첫 클리어는 마을 잉크, 재클리어는 제단이라는 보드 분기를 반영한다. 이전 일반 보스 보상 흐름으로 되돌리지 않는다.
4. 이전 flow-inventory.md와 STATUS.md의 없음을 그대로 믿지 않는다. 마을/탐험/정비소 와이어가 추가되어 현재 보드와 차이가 있다.
5. 가방 정지·버리기/파괴 입력·저장/이어하기의 팀 구현 차이는 기존 2026-11-09 제작 현황 보고서에 남아 있으며 이번에 해소한 것으로 처리하지 않는다.

## 추천 순서
1. 정비소 팔레트 관리 대표 화면: 칸 선택 → 보유 잉크 선택 → 적용 결과. 기존 장비 테마와 기능 차이를 먼저 대조한다.
2. 정비소 거래 상태: 색 변경/강화/판매/파괴, 부족/최대/취소. 스탬프는 범위 확인 뒤 합류.
3. 플레이 필수 공통 화면: HUD/지도/일시정지와 획득·상호작용 안내.
4. 마을 영구 성장·출발 준비.
5. 보스 제단·사망/클리어·마을 잉크 해금.
6. 타이틀/설정/제작진 및 이야기 연출 UI. 일정상 플레이 가능한 한 바퀴가 우선이면 결과/출발 준비를 앞당길 수 있다.

한 번에 모두 만들지 않는다. 다음에는 **정비소 팔레트 관리 2상태**만 제작해 장비 탭과 구분되는지 확인한다. 현재 작업은 UI 목록 정리까지이며 새 시안이나 Unity 변경은 하지 않았다.
