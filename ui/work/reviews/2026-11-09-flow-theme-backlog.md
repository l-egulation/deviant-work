## 현재 버전 유지
가방(스크롤·빈칸·빈 분류), 장비(무기/스킬 설명·잉크 교체·무색 칸), 정비소 성장/팔레트 강화/무작위 색 변경/잉크 교체/무기·스킬 스탬프, 판매대(구매/부족/포화), 전체 지도(확대·방 표시).
25개는 독립 메뉴 25종이 아니라 동일 화면의 여러 상태를 포함한다. 사용자 요청으로 이번에는 추가 디자인 수정 없이 유지한다.

## 남은 UI
| 묶음 | 필요한 테마 화면/요소 | 상태 |
|---|---|---|
| 공통 메뉴 | 일시정지, 조작 안내, 마을/타이틀 복귀 확인, 설정 복귀 | 기존 와이어·설계 있음, 현행 테마 없음 |
| 전투 | 일반/보스 HUD, 미니맵, 스킬 준비/쿨타임, 획득 알림, 상호작용 키 | 과거 테마 및 팀 채택 HUD 있음. 현재 테마와 대조 필요, 신규 전체 재설계로 간주하지 않음 |
| 출발 | 마을 도면 2개 선택, 출발 팔레트/리롤, 출발 조건 안내 | 와이어·기획 있음, 현행 테마 없음 |
| 마을 시설 | 보급소, 염색공방, 회수공방, 기록 농가·초기화 | 과거 시안/와이어 있음, 현행 테마 미적용. 정비소 런 성장과 별개 |
| 탐험 기믹 | 봉인 도전 진행·증강 선택, 잠긴 상자·열쇠 부족, 충전소 회복, 포탈 설치·왕복 | 지도 아이콘만 제작됨. 게임 내 안내·보상 UI는 미제작 |
| 보스·결과 | 제단 색 선택/잉크 3후보, 사망 작은 결과창, 클리어/마을 잉크/신규 해금 | 과거 결과 초안 있음, 현행 테마 없음 |
| 시작·설정 | 타이틀, 소리/화면/조작, 화면 적용 확인, 제작진·종료 | 과거 와이어 및 팀 임시 타이틀 존재. 현재 작업 테마와 역할 조율 필요 |
| 이야기·튜토리얼 | 대사, 오프닝/건너뛰기, 첫 잉크 안내, 포탈 수첩, 장인 방문·색 복원 안내 | 장면별 별도 창보다 공통 대사·안내 요소로 제작 |
| 기존 화면 추가 상태 | 최대 강화, 변경권 없음/유료 횟수 소진, 파괴 유지 입력, 긴 설명/패드 포커스 | 대표 화면과 구분해 후속 상태 검토. 현재 유지 요청 우선 |

## 그대로 따라 만들면 안 되는 부분
- 흐름도의 정비소 뽑기와 보관함 0~5칸/무제한 구안은 현행 판매대·가방 시안과 충돌. 과거 뽑기 결과는 보관만 하고 다음 작업으로 복원하지 않음.
- 타이틀 새 게임/이어하기와 팀 문서 시작하기/중간 저장 없음이 다름. 타이틀 작업 전 기준 확인.
- 흐름도·승인 시안의 가방 일시정지와 팀 문서 비정지·피격 시 닫힘이 다름. UI 테마에서 임의 변경하지 않음.
- 팀 문서에는 채택 전투 HUD와 타이틀 아트가 별도로 있으므로 기존 작업을 확인한 뒤 테마 적용 범위를 정한다.
- 지도 표식 제작 완료는 봉인 도전/상자/포탈 UI 전체 완료가 아니다.

## 추천 다음 작업
1. 일시정지 메뉴 + 공통 복귀 확인창: 전투/마을 변형, 계속하기/조작 안내/복귀 연결을 보여준다. 기존 무기·팔레트 에셋을 건드리지 않고 공통 메뉴의 테마를 확정할 수 있다.
2. 출발 준비 + 출발 팔레트/리롤: 런 진입 흐름을 연결.
3. 사망/클리어 작은 결과창 + 마을 귀환: 한 바퀴를 완성.
4. 마을 영구 성장 시설, 보스 제단, 탐험 기믹 보상.
5. 팀 채택 HUD/타이틀과 조율한 테마 정리, 세부 설정, 이야기 안내, 기존 화면 예외 상태.

첫 묶음 산출물 제안: 전투 일시정지, 마을 일시정지, 조작 안내, 마을 복귀 확인. 복귀 시 런 종료와 손실 문구는 제작 전에 팀 규칙을 확인한다. 이번 작업은 검토·우선순위 기록이며 새 화면 제작이나 Unity 변경은 하지 않았다.
