## 적용 전 합의해야 하는 차이

| 항목 | 현재 테마 시안/사용자 대화 | 다른 근거 | 처리 |
|---|---|---|---|
| 가방의 시간 정지 | 일시정지 | Figma도 정지. 팀 InventoryPresenter.Open은 입력만 차단, PauseSimulation 호출 없음. 팀 UI 문서도 비정지·피격 시 닫힘 설명 | 사용자 의도를 시안에 유지. Unity 연결 전에 팀과 정지 정책 합의 |
| 버리기·파괴 | X 짧게 버리기 / X 3초 파괴 | Figma 11/05 기록은 Z 버리기/X 길게 파괴. 팀 BagModel.DestroyBagColor는 두 번 확인 | 세 가지를 혼합하지 말고 하나를 채택. 이번 여백 작업에서 임의 변경하지 않음 |
| 가방 분류/용량 | 종류별 필터, 12/15 예시 | 팀 최신 UI 문서 끝부분 분류별15/전체45, 앞부분 및 inventory-and-loot에 공유5칸 설명 남음 | 현행 코드·실행 기준을 담당자와 재검증. 예시 수량을 확정 규칙으로 표시하지 않음 |
| 장비 변경 장소 | 색상 잉크 교체를 장비 탭에 표시 | 팀 UI 문서는 색상 잉크 어디서나, 스탬프/판매/강화/색 변경은 정비소 | 도장 변경 버튼을 일반 장비창에 확정 추가하지 않음 |
| 팔레트 시작 칸 | 5칸 확장 상태의 시안 | 최신 인수인계 및 HUD는 3칸 시작, 해금으로4/5 | 기본3칸/잠긴칸/확장5칸을 별도 상태로 제작 |
| 테마 | 어두운 그래파이트·픽셀 잉크병·가방/장비 분리 | 팀 현재 구현은 수첩, Figma 회색 기능 와이어 | 테마와 기능 기준을 구분. 팀 구현 아트를 삭제하거나 Unity에 덮어쓰지 않음 |

## 에셋 준비 우선순위
1. 공통 선택/포커스/비활성/잠김/완료 상태, 키보드·패드 키캡, 길게 누르기 진행, 스크롤 표시. 기존 선택 획과 화살표 재사용부터.
2. 무기·스킬 스탬프 전용 아이콘과 장착/미장착 표시. 현재 무기13종·색상잉크54종과 구분해 목록 작성.
3. 골드·마법안료·팔레트 조각·열쇠 및 시설 아이콘. 팀 원본을 먼저 대조하고 없는 것만 제작.
4. 지도 마커, 보스 제단 색 선택, 결과 해금/클리어/사망 그림. 이미 구현된 자료의 재사용 여부 결정 후 제작.
5. Unity 전달 규격: 원본 PNG·피벗·표시 크기·정수배율·상태별 참조, 폰트 사용/배포 조건, 입력/취소/포커스 복귀. 이 단계에서는 Unity 적용하지 않음.
