# 글자색 역할과 UI 에셋 점검

## 글자색
- 기본 정보·제목·수치·거래 안내: 아이보리 #EEE9DF. 잉크 이름도 아이콘의 색을 다시 반복하지 않음.
- 보조 설명·등급·비활성 정보: 회색 #B3BBC4. 크기와 간격으로 위계를 구분.
- 실행 버튼: 하늘색 #B5D8E4. 선택 상태는 기존 텍스처와 확대를 우선 사용.
- 보유 골드: 노랑 #E0CC83. 일반 비용은 아이보리.
- 실행 불가 안내: 연한 경고색 #E3B59F. 경고 이유 문구를 함께 표시.
- 일반 안내에 녹색/주황색을 사용하지 않음. 강화 후 수치도 색보다 전후 배치·크기로 구분.
- 잉크·팔레트 에셋의 고유색, 지도 포탈 1/2의 표식 색은 정보 구분을 위해 유지. 글자색 규칙과 별개.

장비: F 교체·무료 오른쪽에 42px 간격을 두고 기존 잉크 반환 안내를 아이보리로 배치. 가방/장비 잉크 아이콘 단독 선택은 확대만 사용하고 하단 선/선택 텍스처는 제거.

## 에셋 점검 결과
현행 6개 HTML 화면의 정적 src/url 참조에서 누락 파일 없음. 동적으로 조립하는 모든 게임 데이터 조합을 검증한 것은 아님.

| 요소 | 상태 | 후속 |
|---|---|---|
| 잉크병·팔레트·효과 문양·무기 | PNG 사용 중 | 기존 승인본 유지 |
| 선택 텍스처·교체 삼각형·좌우 화살표 | PNG 사용 중 | 아이콘 단독 선택선은 제거 |
| 지도 현재 위치·정비소·보스·포탈·미탐험 | 이번에 투명 PNG 제작 | 작은 실제 표시 크기에서 확인, Unity 적용 전 정수 픽셀 그리드 최종 정리 |
| 스킬 스탬프 이동·범위·후속타 | 투명 PNG 존재, 1254px 생성 원본 | 최종 저해상도 스프라이트로 정리 필요 |
| 성장 공격 강화 | 기본검 PNG를 재사용한 임시 표현 | 전용 캐릭터 성장 심벌 후보 필요 |
| 키캡 | CSS 테두리·텍스트 | 필요하면 공용 9-slice 바탕 에셋 제작, 키 문자는 동적 유지 |
| 얇은 구분선 | CSS 선 | 기능적 분리선이므로 이미지가 필수는 아님 |
| 지도 지형·발판·탐험 공개·카메라 범위 | 동적 벡터 | 맵 데이터로 생성해야 하므로 고정 그림으로 바꾸지 않음 |
| 패드 버튼 | 전용 에셋 미준비 | 키보드 시안 승인 뒤 별도 입력 장치 세트 필요 |

Unity에는 적용하지 않음. 지도 새 PNG는 생성 원본을 보존해 UI에 사용하며, 네이티브 32×32 스프라이트로 완성됐다고 간주하지 않음.


## 전체 현행 시안 재검토 · 글자 색과 실행 영역
검토 범위는 catalog-manifest.json의 현행 21개 상태(가방·장비, 정비소 성장/팔레트/스탬프, 판매대, 지도). 과거 시안 폴더는 수정하지 않는다. Unity 미적용.

| 역할 | 색 | 적용 |
|---|---|---|
| 주 정보 | #EEE9DF | 이름·본문·비용·강화 수치·버튼 옆 안내 |
| 보조 정보 | #B3BBC4 | 등급·부가 설명·보조 조작 |
| 실행 | #B5D8E4 | 사용 가능한 주 실행 버튼 |
| 보유 재화 | #E0CC83 | 보유 골드 |
| 실행 불가 | #E3B59F | 골드 부족·가방 부족 등의 버튼 문구 |

잉크·팔레트·지도 PNG의 색상과 선택 배경은 글자 색 규칙의 대상이 아니다. 비활성 항목은 명시적 문구와 투명도로 구분한다.

버튼 영역은 상단 얇은 구분선 → 왼쪽 실행 버튼 / 36px 이상 간격 / 오른쪽 아이보리 안내로 통일했다. 팔레트의 버튼 위 안내와 스탬프의 소멸 안내를 오른쪽으로 이동. 성장/판매대에도 같은 구조를 적용했다. 하단 조작 안내에도 구분선을 넣었다. 구매 후 상태처럼 실행 버튼이 없는 화면은 상태 설명을 유지한다.

가방 분류는 전체 / 잉크·팔레트 / 무기 스탬프 / 스킬 스탬프. 현재 예시 데이터에는 잉크 12개만 있으며 팔레트나 스탬프 보유 데이터를 새로 추가한 것은 아니다. 카테고리별 용량 수치는 기존 예시값이다.

확인: 현행 21개 화면 렌더, 대표 6종 육안 비교, JS 구문 검사 및 기존 잉크 교체 상태 검사 통과. 실제 게임 연결이나 모든 입력 상태 검증은 별도다.
