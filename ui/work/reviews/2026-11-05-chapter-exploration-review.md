# ② 챕터 탐험 화면 검토 (2026-11-05)

대상: 피그마 [② 챕터 탐험 (960)](https://www.figma.com/design/qjL5PNYHPgTDQ0huZXBzLg/?node-id=120-75) 첫 판(HUD 3장, 출발 팔레트, 가방, 지도, 일시정지). 같은 검토자 3명(게임 UI 디자이너, 플랫포머 로그라이트 게이머, 조작·접근성)에게 따로 보였다. 결과는 「② v2」에 반영했다. 설계: [② 챕터 탐험 화면 설계](../../docs/specs/2026-11-05-chapter-exploration-screens.md)

| 지적 | 누가 | v2 |
|---|---|---|
| 가방에서 E가 탭 전환과 장착 두 가지(전투에서는 스킬) | 3명 모두 | 장착 F, 버리기 Z, 파괴 X 길게 (처음엔 C 길게였으나 포탈 키와 겹쳐 바꿈) |
| 출발 팔레트에서 색만 보고는 다시 뽑을지 판단 못 함, R 한 번에 실행·스킬 연타로 날아감 | 3명 모두 | 색 역할 한 단어, R 길게, 키 떼기 전 입력 무시 |
| 지도 이동이 드래그뿐 | 디자이너, 접근성 | 방향키 이동 |
| 상호작용 안내가 획득 알림과 같은 자리, 캐릭터에서 멀다 | 디자이너 | 대상 위로 |
| 무기 팔레트 색을 HUD에서 못 본다 | 게이머 | 무기 카드에 색 점 3개 |
| 가방 탭 숫자와 색 잉크 위치가 헷갈림, 어느 칸에 끼우는지·다른 무기는 왜 안 되는지·찬 칸이면? | 디자이너, 게이머 | 「색·능력치 9/15」 탭, 설명에 칸·이유·교체 결과 |
| 정비소 전용 잉크의 장착 버튼 상태 없음 | 디자이너 | 「정비소에서만」 |
| 런 포기 F 길게가 포커스와 무관한지 | 접근성 | 고른 상태에서만 |
| 11px 이하 글자, 미니맵 대비, 지도 점 4px, 단계 구분선 1px | 접근성 | 12px 이상, 어두운 미니맵, 점 9px+, 구분선 2.5px |

보류: 지도에 안 주운 아이템, 일시정지에 빌드 요약(게이머), 패드 표시·스틱 반복(접근성).
