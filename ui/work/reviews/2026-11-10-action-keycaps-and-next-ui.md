# F 실행 표시 통일과 후속 UI

## 반영
현재 갤러리의 실행 버튼에 F 키캡을 왼쪽에 통일했다. 장비 장착/교체, 정비소 강화/색 변경/스탬프, 판매대 구매, 출발 선택/재선택/리롤/확정, 결과 귀환, 일시정지 메뉴/확인, 설정 적용/복원/확인, 봉인 보상, 제단 확정에 적용한다.
탭·잉크 아이콘·팔레트 칸 등 항목 탐색에는 추가하지 않는다. X 버리기/길게 파괴와 Esc 닫기를 유지한다. 비활성 실행 버튼에는 흐린 F 표시. 버튼이 여러 개면 포커스된 버튼을 F로 실행하는 기존 방식 유지. 설정 확인창에서는 뒤쪽 화면이 비치며 실행 표시가 겹치지 않게 가렸다.
공통 action-keycaps.js/css가 동적 렌더 뒤에도 중복 없이 표시한다. 정비소 성장의 기존 F 안내에 실제 실행 핸들러가 빠져 있어 함께 연결했다. Unity 적용 없음.

## 검토 근거와 범위
현재 catalog-manifest.json과 저장소의 flow-inventory.md, 2026-11-09-flow-theme-backlog.md를 비교했다. Figma 실시간 재조회는 하지 않았다.
게임 실행용 로컬 저장소의 docs/design/starting-village.md 및 systems/roguelite-progression.md를 확인했다. 원격 최신 동기화는 확인하지 않았다.
기존 미리보기 전체 중 지도/HUD를 제외한 11개 화면 묶음의 상태를 다시 렌더링하고 이미지 로딩과 키캡 중복을 확인했다. 기존 모든 기능의 게임 로직 테스트를 의미하지 않는다.

## 다음 순서
1. 보스 제단 보완: 영구 해금 시 같은 색 후보 리롤 런당 1회. 미해금/사용 가능/소진 상태를 추가할 필요가 있다. 직전 후보 재등장 허용 여부는 문서상 미정이며 시안에서 임의 확정하지 않는다. 현재 제단은 기본 선택/획득까지만 제작됨.
2. 새 화면: 마을 보급소 영구 해금. 마법안료 잔액, 목록, 현재→해금 후 효과, 가격, F 해금, 잠김/선행 부족/잔액 부족/완료 상태. 런 정비소 성장과 별개다. 출발 지원금은 현재 명세상 4단계, 공격력/체력 8단계, 이동속도 4단계, 가방 5→15칸, 대시 추가. 시작 마을 개요의 지원금 3단계 표기는 세부 명세와 달라 제작 시 세부 데이터로 재확인한다.
3. 염색공방: 팔레트 칸 수/첫 칸 무색, 시작 리롤, 변경권, 제단 리롤, 잉크 해금. 보급소의 공통 목록/상세/잠김 표현을 재사용한다.
4. 회수공방: 잉크 파괴 보상 영구 해금.
5. 기록 농가와 공통 대사/수첩, 장인 방문·채색 안내. 최신 기록 농가는 이야기책이며 과거 흐름도의 통계/초기화 UI를 그대로 만들지 않는다.
6. 잠긴 상자·열쇠 부족·충전소·포탈 등 소형 안내와 기존 화면 예외 상태.

타이틀과 전투 HUD는 사용자 요청대로 보류한다. 후속 신규 UI는 이번 작업에서 제작하지 않았다.
