# 타이틀·설정 와이어프레임 검토

갱신: 2026-10-21

- [Figma 와이어프레임](https://www.figma.com/design/qjL5PNYHPgTDQ0huZXBzLg) — 9개 편집 가능한 화면
- [FigJam 흐름도](https://www.figma.com/board/nHfGBYZsYIcHNUD9SU4cGs)

## 이번 검토에서 확인한 문제

1. 게임 배경이 없는 회색 화면만으로는 Deviant 타이틀의 실제 가독성과 인상을 판단하기 어려웠습니다.
2. 타이틀의 포커스와 설정의 현재 항목이 같은 검은 채움으로 표현되어 상태를 구분하기 어려웠습니다.
3. 화면 안에 설계 메모와 임시 설명이 섞여 플레이어가 실제로 볼 문구를 판단하기 어려웠습니다.

## 와이어프레임에 반영한 것

- 현재 프로토타입 캡처의 숲·캐릭터 부분만 Figma 안에서 잘라 임시 배경으로 사용했습니다. 캡처에 포함된 전투 HUD는 보이지 않게 했습니다. 배경 아트 확정으로 해석하지 않습니다.
- 메뉴 포커스는 진한 채움, 설정의 열린 항목은 밝은 탭, 실제 조작 대상은 진한 테두리로 나눴습니다.
- 설계 메모를 화면 밖으로 옮기고, 소리 값과 조작 키는 평가용 예시로 채웠습니다.
- 설정에서 타이틀로 돌아올 때 ‘설정’ 메뉴가 다시 포커스되는 화면을 추가했습니다.
- 제작진은 이름 목록과 라이선스가 들어갈 영역으로 정리했습니다.

## 아직 결정하지 않은 것

- 새 게임·이어하기 선택 이후의 게임 흐름과 저장 규칙
- 실제 조작키 및 패드 지원 범위
- 화면 설정의 지원 옵션과 확인 제한 시간(와이어프레임의 10초는 예시)
- 소리의 즉시 저장 및 조작키 재지정 지원 여부
- 최종 타이틀 아트, 로고, 글꼴, 색과 크레딧 내용

## 다음 검토 방법

기능을 확정하기보다 다음 네 가지를 화면을 보며 확인합니다.

1. 타이틀에서 3초 안에 시작·이어하기·설정을 구분할 수 있는가?
2. 키보드 또는 패드로 현재 포커스와 열린 설정 항목을 혼동하지 않는가?
3. 화면 설정을 바꾼 뒤 적용·되돌리기·뒤로의 결과를 예상할 수 있는가?
4. 타이틀로 복귀했을 때 이전에 선택했던 메뉴로 초점이 돌아온다는 규칙이 자연스러운가?
