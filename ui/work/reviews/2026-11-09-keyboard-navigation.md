# 현재 상태: 적용 철회

사용자 요청으로 공통 단계형 키보드 탐색을 5개 화면에서 제거하고 각 화면의 이전 조작으로 복원했다. 아래 기록과 스크립트는 폐기된 실험의 이력이며 현행 동작이 아니다.

# UI 시안 키보드 탐색 개정

## 원인
화면마다 방향키 처리와 F 단축 실행이 따로 있어, 선택 중인 항목과 입력을 받는 영역이 구분되지 않았다. 장비 좌우키는 팔레트만 순환했고 스탬프에는 방향키 탐색이 없었다.

## 공통 흐름
- 방향키: 현재 영역의 항목 탐색. 항목 선택은 정보 미리보기만 변경.
- F/Enter: 다음 영역으로 진입. 실행 버튼에 도착한 뒤 다시 누를 때만 적용.
- 가로 목록 끝의 오른쪽 / 세로 목록의 오른쪽: 다음 영역 진입.
- Esc: 이전 영역 및 이전 항목으로 복귀. 최상단에서는 머무름. HTML은 실제 게임 종료를 수행하지 않음.
- Tab/Shift+Tab: 영역 순회. 상단 탭도 포함.
- 마우스 선택 후 키보드 이어서 조작 가능.
- 첫 방향키 입력은 탐색 시작. 비활성 항목은 건너뜀.

범위: 가방·장비, 정비소 성장·팔레트·스탬프, 잉크 판매대. 일시정지와 지도는 기존 전용 조작 유지.

## 검증
실제 Chrome에서 키 이벤트를 전송해 팔레트 작업→결제→실행, 장비 무기→칸→잉크→실행, 판매대 마지막 상품→우측 버튼, Esc 복귀와 진입 시 미실행을 확인했다. 재현 스크립트: theme/ink-pixel-v1/tests/keyboard-navigation.mjs (Chrome 디버깅 포트 9337 필요).

Unity/실물 게임패드 미적용. 다음 시안인 출발·시작 팔레트는 최신 흐름도 및 게임 규칙을 다시 확인하고 이 단계형 탐색을 적용한다.
