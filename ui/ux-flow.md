# 사용자 흐름 초안

갱신: 2026-10-26 · 첫 플레이 흐름은 Office Hour에서 정한 방향과 미정 사항을 구분합니다.

## 타이틀·설정 UI 검토 범위

- [타이틀·설정 FigJam](https://www.figma.com/board/nHfGBYZsYIcHNUD9SU4cGs)과 [저해상도 Figma 와이어프레임](https://www.figma.com/design/qjL5PNYHPgTDQ0huZXBzLg)을 함께 검토합니다.
- 타이틀 메뉴 초안: 새 게임, 이어하기, 설정, 제작진, 게임 종료. 저장 데이터가 없으면 이어하기를 비활성화하는 안을 시각화했습니다.
- 설정 초안: 한 화면에서 화면·소리·조작 항목을 전환합니다. 소리는 즉시 반영, 화면은 적용 후 유지·되돌리기 확인, 조작은 초기 버전에서 키 안내만 표시하는 안입니다.
- 종료 확인은 취소를 기본 선택으로 제안합니다. 입력 매핑, 저장 정책, 타이머 길이, 해상도 지원 범위, 크레딧 표기 내용은 미정입니다.
- 새 게임 이후의 첫 플레이 흐름은 아래 Office Hour 초안으로 구체화했습니다. 이어하기·저장 정책은 아직 미정입니다.

## 확인한 게임 구조

팀 합의안인 최신 개편 설계는 도면에 흰색·검정 잉크를 적용하고, 색상 효과는 별도 팔레트에 담습니다. 팔레트 없이도 도면 무기를 사용합니다. 팔레트는 일부 칸만 채워 활성화할 수 있습니다. 도면만 직접 강화합니다. 부분 교체 시 기존 파츠 하나가 소멸하고, 다른 칸 구성으로 재제작하면 기존 팔레트와 장착된 색상 파츠가 모두 소멸합니다. 전투 중에는 현재 손에 든 무기의 팔레트 효과만 적용합니다. 출처: [도면·팔레트 제안](sources/ink-blueprint-proposal.md).

후속 UI 설계 결정(2026-10-26): **팔레트 하나의 기본 잉크 칸은 5칸**이며 이후 칸이 추가될 수 있습니다. 앞선 제안서에서 5칸을 모든 팔레트의 고정 상한으로 보지 않은 점과 양립합니다. 현재 와이어프레임은 두 무기 팔레트에 각각 기본 5칸을 표시하고, 6번째부터 다음 줄로 확장하는 배치안을 검토합니다. 팔레트 획득 시점, 각 칸의 실제 색 구성과 추가 조건은 여전히 미정입니다.

기존 로컬 SSAFY 레포(2026-10-14)의 Unity 공유본은 조작·전투·HUD 프로토타입입니다. 새 제작 체계의 코드 통합을 확인한 자료가 아닙니다.

## 첫 플레이 한 바퀴 · Office Hour 결정 (2026-10-26)

[FigJam 첫 플레이 흐름도](https://www.figma.com/board/nHfGBYZsYIcHNUD9SU4cGs)에 현재 합의한 순서를 시각화했습니다. 이번 도전에서 얻거나 만든 자원의 사망 시 처리와 아직 정하지 않은 세부 수치를 구분해 기록합니다.

1. 새 게임으로 처음 진입하면 별도 튜토리얼 스테이지 없이 1스테이지가 시작됩니다. 첫 도전의 상세 NPC 조작 안내와 이동·조작 학습은 1스테이지 안에서 이루어집니다.
2. 1스테이지의 첫 전투 전에 기본 무기 두 개를 무작위로 지급받습니다. 맵의 적과 싸우는 중에도 사망할 수 있습니다. 구체적인 지급 풀과 전투 중 전환 입력은 미정입니다.
3. 몬스터가 가칭 '골드' 재화를 떨어뜨립니다. 전투 직후 별도의 보상 카드 선택 화면은 현재 흐름에 넣지 않습니다.
4. 첫 전투 뒤 안전한 정비 구역에 도착합니다. 잉크 뽑기는 플레이어의 개인 정비 UI에 상시 표시되지 않습니다. 정비 구역에 놓인 룰렛기에 접근해 상호작용하면 골드를 사용해 무작위 잉크를 뽑을 수 있습니다.
5. 뽑기는 완전 무작위입니다. 현재 무기에 바로 쓸 수 없는 잉크도 가방에 보관할 수 있습니다. 첫 뽑기의 사용 가능 잉크 보장은 두지 않습니다. 팔레트에 적용한 잉크는 소모되어 팔레트에 흡수되며, 다시 꺼내 가방에 보관할 수 없습니다. 장착된 팔레트는 가방 칸을 차지하지 않습니다.
6. 정비 뒤 다음 전투로 출발합니다. 사망하면 전투 중 정비 구역과는 다른 장소인 거점으로 돌아와 재정비하고 새로 도전합니다. 두 장소는 현재 정해진 정비 기능의 화면을 공통으로 사용합니다. 거점 전용 기능은 추후 추가할 수 있으나 내용은 미정입니다.
7. 거점에서 새 도전을 시작하면 1스테이지 처음부터 다시 시작합니다. 출발 무기 두 개도 다시 무작위로 지급합니다. 재도전에서는 첫 도전의 상세 NPC 조작 안내를 반복하지 않습니다. NPC의 간단한 대사·연출 여부는 미정입니다.
8. 사망하면 전투 중 얻은 골드(가명)는 기본적으로 전부 잃습니다. 별도의 로그라이트 재화를 얻어 일부 골드를 보존할 수 있게 할 예정입니다. 그 재화의 획득·사용 방식과 골드 보존 비율은 미정입니다. 이번 도전에서 획득한 잉크는 가방에 남아 있든 팔레트에 흡수됐든 사망 시 전부 잃습니다. 이번 도전에서 얻거나 만든 도면·팔레트도 사망 시 전부 잃습니다.

### 정비 구역의 룰렛·인벤토리·작업대 흐름 (Office Hour 결정, 2026-10-27)

- 새 도전에 무작위로 지급되는 두 무기에는 팔레트가 기본으로 붙어 있지 않습니다. 팔레트는 몬스터 드롭 보상 또는 정비 구역의 팔레트 룰렛 등으로 별도 획득합니다. 첫 정비에서 획득이 보장되는지, 룰렛이 한 기계의 카테고리인지 별도 기계인지는 미정입니다.
- 팔레트가 없어도 잉크 룰렛을 이용할 수 있습니다. 획득한 잉크는 인벤토리에 보관합니다. 인벤토리는 색상 잉크·검은 잉크·흰색 잉크·팔레트의 카테고리를 구분하고, 각 카테고리에 별도 칸 제한을 둘 예정입니다. 정확한 칸 수와 초과 처리는 미정입니다.
- 룰렛 결과 화면의 역할은 획득 결과 확인과 보관입니다. 팔레트 연결과 잉크 적용은 정비 구역의 별도 작업대에서 합니다. 기존 룰렛 와이어프레임의 ‘뽑은 직후 바로 적용’과 그에 연결된 확인 화면은 **이전 가정**으로, 작업대 흐름에 맞게 수정해야 합니다.
- 작업대에서 색상 잉크가 하나도 없는 빈 팔레트도 무기에 연결할 수 있습니다. 잉크는 나중에 채울 수 있습니다. 이는 앞선 제안서의 ‘최소 파츠 수 미정’보다 나중에 정한 규칙입니다.
- 팔레트는 연결한 무기에 귀속되며 다른 무기로 옮길 수 없습니다. 같은 무기에 새 팔레트를 연결해 교체하면 기존 팔레트와 그 안의 잉크는 모두 소멸합니다. 작업대의 교체 확정 전 소멸 대상을 보여줘야 합니다.
- 해당 카테고리의 인벤토리 칸이 가득 차도 룰렛을 돌릴 수 있습니다. 결과를 본 뒤 같은 카테고리의 기존 아이템 하나와 교체하거나 새 결과를 포기합니다. 이 규칙은 색상 잉크·흰색 잉크·검은 잉크·팔레트 모두에 동일하게 적용합니다. **검토 중인 안:** 보관 칸이 가득 찬 결과창을 닫으면 새 아이템이 룰렛기 옆 바닥에 떨어지고, 나중에 상호작용해 다시 교체·포기를 결정할 수 있습니다. 사용자가 적합성을 추후 검토하길 원하므로 확정 규칙으로 보지 않습니다. 바닥에 놓인 결과가 여러 개일 때의 관리, 유지 시간, 재뽑기 가능 여부는 미정입니다.
- 몬스터가 떨어뜨린 팔레트·잉크는 플레이어가 상호작용 버튼을 눌러 획득합니다. 해당 카테고리의 인벤토리 칸이 가득 찬 상태에서 상호작용하면 기존 아이템을 선택해 교체하는 창이 열리고, 그동안 전투는 일시정지됩니다. 교체창에서 취소하면 새 아이템은 바닥에 남아 다시 상호작용해 주울 수 있습니다. 드롭이 바닥에 남는 시간은 미정입니다.
- 팔레트에 적용한 잉크는 소모되어 회수할 수 없습니다. 장착된 팔레트는 인벤토리 칸을 차지하지 않습니다. 향후 정비 구역에서 재화를 써서 팔레트 잉크를 수정하는 기능을 계획 중이며 비용·시기는 미정입니다.

### 정비 구역·룰렛기 저해상도 와이어프레임

**와이어프레임 상태:** 아래 화면들은 새 Office Hour 결정 이전에 그린 안입니다. 단일 가방 6칸 표시, 룰렛기에서 즉시 팔레트 적용, 결과를 임시 보류해 현장에서 교체·포기하는 동작은 현재 규칙과 맞지 않거나 재검토가 필요합니다. 디자인 참고로만 사용하고, 룰렛 획득→카테고리별 인벤토리→별도 작업대 흐름으로 다시 설계합니다.

추가한 사용 전 화면은 룰렛기의 비용, 보유 골드, 가방 여유와 완전 무작위 규칙을 한곳에서 보여줍니다. 가방이 가득 찬 상태에서는 뽑기 전에 결과를 바로 처리해야 한다는 경고를 보여줍니다. 세 최종 확인 화면은 팔레트 적용 시 잉크 소모, 기존 가방 잉크 교체 시 기존 잉크 소멸, 새 잉크 포기 시 결과 소멸을 각각 명시합니다. 가방이 가득 차도 뽑을 수 있게 하는 경로와 취소·닫기 제한은 현재 와이어프레임의 제안이며 팀 합의 전입니다. 비용, 골드, 가방 칸 수와 잉크 색은 예시입니다.

첫 화면은 정비 구역에 놓인 룰렛기에 접근하는 게임 장면이고, 다음 두 화면은 기계와 상호작용한 뒤에만 열리는 UI입니다. 룰렛기 결과 안에서 무기의 팔레트 기본 5칸을 표시하며, 추가 칸은 다음 줄로 확장하는 안을 보여줍니다. 빈 가방 칸에는 자동 보관하고, 가방이 가득 찼다면 새 잉크를 임시 보류해 적용·가방 잉크 교체·포기 중 선택하는 제안을 표현합니다. 팔레트 적용 버튼은 소모 확인 단계로 이어지는 안입니다. 화면의 가방 6칸, 골드 120, 잉크 색·팔레트 구성·뽑기 비용은 배치 확인용 예시이며 확정 수치가 아닙니다. 가방 초과 처리와 어떤 빈칸에 적용 가능한지의 세부 조건은 팀 결정 전입니다.

### 다음 Office Hour에서 정할 것

- 전투 중 두 무기의 전환 방식과 첫 전투에서 두 무기 차이를 어떻게 알려줄지
- 1스테이지 재도전에서 NPC의 짧은 대사·연출을 둘지
- 가방이 가득 찬 상태의 새 잉크 처리, 팔레트 적용 가능 조건과 소모 확인, 출발 순서
- 거점에 추가할 전용 기능과 공통 정비 화면에서의 진입·복귀 방식
- 로그라이트 재화의 획득·사용 방식과 골드 보존 비율
- 전투 구간 길이, 정비 구역 접근 주기, 뽑기 가격과 추가 획득 방식
- 재화 이름과 획득 시 HUD 표시 방식

| 화면 | 플레이어가 해야 할 일 | 처음 필요한 정보 | 보류할 정보 |
|---|---|---|---|
| 타이틀 | 시작·이어하기·설정 선택 | 저장/런 재개 규칙 확정 후 문구 | 스토리 상세 설명 |
| 첫 전투 | 이동·공격·회피 경험 | 체력, 기본 공격·특수 공격 조작 | 모든 제작 규칙 |
| 정비 구역·거점 | 서로 다른 장소에서 현재 구성 파악, 정비 시설과 다음 작업 선택 | 현재 무기, 상호작용 가능한 시설, 출발 가능 여부 | 거점 전용 기능과 모든 파츠의 상세 목록 |
| 룰렛기 조작 | 정비 구역의 룰렛기에 접근해 잉크 뽑기, 결과 확인과 처리 | 비용, 골드, 가방 여유, 새 잉크, 적용 가능한 팔레트 칸 | 개인 UI에 상시 뽑기 버튼 |
| 도면 작업대 | 무기·형태·특수 공격 선택, 도면 강화 | 변경 전/후 공격, 비용, 교체 시 소멸 | 미보유 콘텐츠의 상세 수치 |

## 첫 UI 비교안

- **작업대형:** 도면과 팔레트를 나란히 보이고, 현재 무기와 변경 결과를 중앙에서 비교.
- **단계형:** 도면 설정 → 팔레트 제작·정비 → 최종 결과 순서로 진행.

두 안 모두 팔레트 없이 출발, 일부 칸만 채운 활성화, 빈칸 나중에 채우기, 부분 교체와 전면 재제작의 손실 차이를 표현해야 합니다.

## 팀에서 먼저 결정할 것

1. 이전의 네 무기 계열과 최신 제안의 검·둔기·원거리 도면 관계.
2. 지급된 두 무기의 전투 중 전환 규칙과 초기 무기 풀.
3. 첫 전투 뒤 정비 구역에서 제공할 뽑기·보관·장착 상세 흐름.
4. 도면·팔레트의 획득 시점과 재화 사용처.
5. 사망·런 종료 때 잃는 것과 다음 런에 남는 것.
6. 정비소 접근 위치, 제작 비용, 무색 칸의 다른 색 교체 처리.

이 답이 정해지기 전에는 타이틀의 ‘이어하기’, 보상 화면, 저장 안내, 런 결과를 최종안으로 그리지 않습니다.
