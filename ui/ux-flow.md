# 사용자 흐름 초안

갱신: 2026-10-21 · **제안**이며 확정 게임 흐름은 아닙니다.

## 확인한 게임 구조

최신 첨부 제안은 도면에 흰색·검정 잉크를 적용하고, 색상 효과는 별도 팔레트에 담습니다. 팔레트 없이도 도면 무기를 사용합니다. 팔레트는 일부 칸만 채워 활성화할 수 있습니다. 도면만 직접 강화합니다. 부분 교체 시 기존 파츠 하나가 소멸하고, 다른 칸 구성으로 재제작하면 기존 팔레트와 장착된 색상 파츠가 모두 소멸합니다. 전투 중에는 현재 손에 든 무기의 팔레트 효과만 적용합니다. 출처: [도면·팔레트 제안](sources/ink-blueprint-proposal.md).

기존 로컬 SSAFY 레포(2026-10-14)의 Unity 공유본은 조작·전투·HUD 프로토타입입니다. 새 제작 체계의 코드 통합을 확인한 자료가 아닙니다.

## 제안하는 첫 플레이 한 바퀴

```text
타이틀
  → 짧은 첫 전투 (기본 조작과 공격을 직접 경험)
  → 첫 정비 (도면·형태·특수 공격을 이해)
  → 구간 출발
  → 전투
  → 보상 확인
  → 정비 (팔레트 제작·부분 수정·도면 강화)
  → 다음 구간 / 런 결과
```

첫 전투를 앞에 두는 것은 선택 전에 기본 무기 감각을 주기 위한 UI/온보딩 가설입니다. 팔레트를 첫 정비부터 공개할지 첫 보상 뒤에 공개할지는 플레이어 테스트로 비교합니다. 정비는 안전한 정비 구역에서 하고, 전투 중 파츠를 편집하지 않는 이전 합의를 우선 가정합니다.

## 화면별 책임

| 화면 | 플레이어가 해야 할 일 | 처음 필요한 정보 | 보류할 정보 |
|---|---|---|---|
| 타이틀 | 시작·이어하기·설정 선택 | 저장/런 재개 규칙 확정 후 문구 | 스토리 상세 설명 |
| 첫 전투 | 이동·공격·회피 경험 | 체력, 기본 공격·특수 공격 조작 | 모든 제작 규칙 |
| 정비 허브 | 현재 구성 파악, 다음 작업 선택 | 도면/팔레트 상태, 출발 가능 여부 | 모든 파츠의 상세 목록 |
| 도면 작업대 | 무기·형태·특수 공격 선택, 도면 강화 | 변경 전/후 공격, 비용, 교체 시 소멸 | 미보유 콘텐츠의 상세 수치 |
| 팔레트 작업대 | 팔레트 선택·채우기·수정·재제작 | 칸 색, 무색 칸, 파츠 효과, 빈칸 | 확정 전 콘텐츠 개수 |
| 확정 창 | 제작·교체의 결과 승인 | 남는 것, 소멸하는 것, 소모 비용 | 장식적 세계관 설명 |
| 출발 확인 | 구성 확인 후 전투 진입 | 현재 무기와 적용 효과 | 정비 도중의 전체 이력 |
| 전투 HUD | 즉시 판단·전환 | 체력, 현재 무기, 특수 공격 상태 | 팔레트 편집 |
| 보상/런 결과 | 획득·다음 행동 이해 | 새로 얻은 도면·팔레트·잉크의 용도 | 미정인 영구 성장 규칙 |

## 첫 UI 비교안

- **작업대형:** 도면과 팔레트를 나란히 보이고, 현재 무기와 변경 결과를 중앙에서 비교.
- **단계형:** 도면 설정 → 팔레트 제작·정비 → 최종 결과 순서로 진행.

두 안 모두 팔레트 없이 출발, 일부 칸만 채운 활성화, 빈칸 나중에 채우기, 부분 교체와 전면 재제작의 손실 차이를 표현해야 합니다.

## 팀에서 먼저 결정할 것

1. 이전의 네 무기 계열과 최신 제안의 검·둔기·원거리 도면 관계.
2. 두 무기 장착을 유지할지, 현재 무기 전환 규칙은 무엇인지.
3. 첫 구간을 기본 무기로 시작할지, 출발 전에 도면을 고르게 할지.
4. 도면·팔레트·잉크의 획득 시점과 보상 방식.
5. 사망·런 종료 때 잃는 것과 다음 런에 남는 것.
6. 정비소 접근 위치, 제작 비용, 무색 칸의 다른 색 교체 처리.

이 답이 정해지기 전에는 타이틀의 ‘이어하기’, 보상 화면, 저장 안내, 런 결과를 최종안으로 그리지 않습니다.
