# 도면·팔레트·잉크 시스템 개편 설계

사용자가 결정한 도면·팔레트의 구성, 제작·정비·강화·효과 적용 규칙을 정리한다. 색상별 콘텐츠 후보와 수치 미정 사항은 확정 규칙과 구분한다.

현행 [무기·잉크 명세](weapons-and-ink.md)의 고정 능력치 5슬롯·일반 능력치 잉크 규칙과 다른 개편 설계다. 현행 전투 체계와의 이행 범위는 별도로 정해야 한다. 이 문서 작성이 코드·씬·데이터 반영이나 본 게임 검증 완료를 의미하지 않는다.

## 1. 기본 구조

도면과 팔레트를 분리한다. 도면에는 흰색·검정 잉크를 적용하고, 색상 잉크 파츠는 별도 팔레트에 넣는다. 색상 잉크 칸은 도면에 직접 부여하지 않는다.

| 구성 | 확정된 역할 |
|---|---|
| 도면 | 검·둔기·원거리의 기본 무기 종류를 결정한다. 도면에는 등급이 존재한다. |
| 흰색 잉크 | 무기의 형태 변환을 설정한다. |
| 검정 잉크 | 돌진·검기·잔상처럼 특수공격의 종류를 설정한다. 단순 특수공격 피해 증가용으로 정의하지 않는다. |
| 팔레트 | 색상 잉크 파츠를 넣는 별도 구성품이다. 칸 수와 각 칸의 색상이 정해진 구성 중 하나를 획득한다. |
| 색상 칸 | 빨강·노랑·초록·파랑·보라 중 지정된 색의 파츠를 넣는다. 같은 색 칸이 여러 개 있을 수 있다. |
| 무색 칸 | 빨강·노랑·초록·파랑·보라 중 원하는 색의 파츠를 넣는 자유 칸이다. 형태 변환용 흰색 잉크와 구분한다. |

팔레트가 없어도 도면에 흰색·검정 잉크를 적용한 구성으로 무기를 사용할 수 있다. 각 잉크가 미장착된 경우의 기본 형태·기본 특수는 현행 전투 체계와의 연결을 확인해 정한다.

## 2. 팔레트 획득과 구성

- 팔레트는 **칸 수·색상 구성이 사전에 정해진 구성 목록 중 하나**를 획득한다. 칸마다 독립적으로 색을 추첨하거나 칸 수를 별도로 무작위 생성하는 방식으로 정의하지 않는다.
- 팔레트 구성 목록, 각 구성의 칸 수, 획득 방식·확률·등급 관계는 미정이다.
- 모든 팔레트를 5칸으로 고정하지 않는다. 다섯 칸은 아래 예시의 구성이다.
- 무색 칸이 포함된 팔레트도 사용한다. 명칭은 '무색 칸'으로 통일한다.

| 팔레트 구성 예시 | 넣을 수 있는 파츠 |
|---|---|
| 빨강 / 빨강 / 빨강 / 노랑 / 초록 | 빨강 파츠 3개, 노랑 파츠 1개, 초록 파츠 1개 |
| 보라 / 보라 / 보라 / 빨강 / 초록 | 보라 파츠 3개, 빨강 파츠 1개, 초록 파츠 1개 |
| 빨강 / 노랑 / 무색 | 빨강 파츠 1개, 노랑 파츠 1개, 원하는 색 파츠 1개 |

이 표는 구조 설명용 예시다. 최종 팔레트 콘텐츠 목록·등급·등장 확률을 확정하지 않는다.

## 3. 제작·활성화·부분 수정

### 최초 제작과 활성화

1. 사용할 도면과 흰색·검정 잉크를 준비한다. 이 구성만으로도 무기로 사용할 수 있다.
2. 원하는 색상 구성의 팔레트를 획득하고 각 칸에 맞는 색상 잉크 파츠를 준비한다.
3. 팔레트의 일부 칸만 채워도 도면과 결합해 굽는 제작 과정으로 활성화·등록할 수 있다.
4. 등록된 팔레트의 색상 칸 구성은 고정된다. 빈칸은 정비소에서 나중에 채울 수 있다.

제작 비용, 정비소 접근 조건, 최초 활성화에 필요한 최소 파츠 수는 미정이다. '일부 칸으로 활성화 가능'을 파츠가 전혀 없는 상태에서도 활성화 가능하다는 뜻으로 확장하지 않는다.

### 같은 팔레트 구성 안에서의 부분 수정

- 정비소에서 해당 칸에 맞는 새 잉크 파츠를 넣어 기존 파츠를 교체할 수 있다.
- **부분 교체 비용은 높게 설정하며, 교체한 기존 파츠는 소멸하고 반환되지 않는다.** 다른 칸의 파츠는 유지된다.
- 더 좋은 성능의 파츠를 획득해 교체하는 방식이다. 개별 파츠를 직접 강화하는 시스템은 사용하지 않는다.
- 무색 칸에는 원하는 색 파츠를 넣을 수 있다. 등록된 무색 칸에서 다른 색 파츠로 교체하는 세부 처리는 미정이다.
- 빈칸에 파츠를 추가하는 비용과 부분 교체 비용의 관계는 미정이다.

### 팔레트 구성 변경

`빨빨빨노초 → 보보보빨초`처럼 칸 구성을 바꾸려면 새 팔레트와 새 잉크 파츠를 준비해 재제작한다.

1. 기존 팔레트를 유지한 상태에서 새 팔레트와 투입할 파츠를 준비한다. 새 팔레트도 일부 칸만 채워 활성화할 수 있다.
2. 최종 제작을 확정할 때 기존에 등록된 팔레트를 파괴한다.
3. **기존 팔레트에 들어 있던 색상 잉크는 모두 소멸하며 반환·이전되지 않는다.** 새 구성과 색이 겹치는 칸의 파츠도 소멸한다.
4. 새 팔레트를 도면과 결합해 굽고 활성화하여 등록한다. 기존 칸 구성의 파괴가 도면 자체의 파괴를 뜻하지는 않는다.

최종 제작 확정 시의 구체 비용과 실패·취소 처리는 별도 설계다. 제작 성공 확률이나 실패 시 재료 소멸 규칙을 임의로 추가하지 않는다.

### 흰색·검정 잉크 교체

- 소정의 비용을 내고 흰색·검정 잉크를 바꿀 수 있다.
- **교체한 기존 흰색·검정 잉크는 소멸하고 반환되지 않는다.** 새 잉크가 필요하다.
- 색상 파츠의 고비용 부분 수정과 구분한다. 정확한 비용과 교체 가능한 형태·특수공격의 호환 관계는 미정이다.

## 4. 성장과 효과 적용

### 도면 강화

- 직접 강화하는 대상은 **도면만**이다. 팔레트·개별 칸·개별 잉크의 별도 강화 시스템은 사용하지 않는다.
- 도면 자체를 강화하면 무기의 전반적인 수치가 상승한다.
- 색상 잉크는 더 좋은 성능의 개체를 획득해 교체한다. 성능 차이·등급·획득 규칙은 미정이다.
- 도면 강화가 기본 피해·특수 피해·잉크 효과 중 어디까지 영향을 주는지, 증가량·비용·상한은 미정이다.
- 무기·도면을 새로 바꿀 때 기존 도면 강화와 팔레트를 이전할 수 있는지는 미정이다.

### 동일 효과의 중복

- 같은 효과의 잉크 파츠를 여러 칸에 넣을 수 있으며, **각 파츠의 효과는 독립적으로 발동**한다.
- 예를 들어 충격파 파츠 3개를 넣으면 하나의 충격파 수치로 합치는 방식이 아니라 각 파츠가 독립적인 발동 단위가 된다.
- 개별 효과의 발동 확률·내부 대기시간, 다단 공격의 발동 횟수 보정, 추가타가 다른 추가타를 유발하는지, 상태이상·지속형·상시 수치 효과의 중첩 계산은 미정이다. 독립 발동을 무제한 연쇄 발동 허용으로 해석하지 않는다.

### 현재 무기의 팔레트만 적용

- 전투 중 **현재 손에 든 무기의 팔레트 효과만 적용**한다. 비활성 무기의 팔레트를 동시에 상시 적용하지 않는다.
- 무기 교체 시 최대 체력·광폭화·이동 속도 등 상시 효과의 전환 처리, 이미 발동한 투사체·장판·상태이상의 유지와 원본 수치 저장은 후속 설계다.
- 재교체로 체력 회복·보호막 생성·발동 횟수 초기화 등이 반복되는 문제를 검토해야 한다. 이 문서에서 구체적인 보정 규칙을 자동 확정하지 않는다.

## 5. 색상별 컨셉

| 색상 | 컨셉과 상태 |
|---|---|
| 빨강 | 공격에 추가 피해·공격 효과를 부여하는 방향. 아래 다섯 효과를 구체화 대상으로 제시했다. |
| 노랑 | 속도 관련 효과를 넓게 탐색 중이다. 가속·기동·행동 연결·재사용 순환 등에서 범위를 선택해야 한다. |
| 초록 | 생명력·회복·보호는 검토 후보이며, 최종 컨셉과 효과는 미정이다. |
| 파랑 | 냉기·제어·방어는 검토 후보이며, 최종 컨셉과 효과는 미정이다. |
| 보라 | 저주·공명·응축·전파는 검토 후보이며, 최종 컨셉과 효과는 미정이다. |
| 흰색 잉크 | 기본 무기의 형태 변환을 설정한다. |
| 검정 잉크 | 특수공격을 설정한다. |
| 무색 칸 | 팔레트에서 색상 파츠의 색 제한을 완화한다. 흰색 잉크 아이템과 구분한다. |

색상별 옵션 수와 전체 콘텐츠 수는 미정이다. 색상별 4종·총 20종으로 고정하지 않는다.

### 빨강: 공격 피해와 추가 공격 효과

| 효과 방향 | 내용 | 추가로 정할 내용 |
|---|---|---|
| 화상 | 적에게 화상을 부여해 지속 피해를 준다. | 발동 조건, 지속시간, 피해, 중첩·갱신 |
| 흡혈 추가타 | 추가타로 피해를 주고 확률적으로 체력을 흡수한다. | 추가타 발동 조건, 피해, 흡수 확률·회복량 |
| 충격파 | 공격 시 충격파를 발생시켜 추가 피해를 준다. | 발동 빈도, 범위, 피해, 대상 수 |
| 광폭화 | 장착 시 체력을 줄이는 대가로 피해를 증가시킨다. | 현재·최대 체력 중 감소 대상, 장착·해제 처리, 증가량 |
| 공격력 증가 | 공격 피해를 직접 높인다. | 기본·특수공격 적용 범위, 합산 방식, 증가량 |

광폭화의 체력 감소 50%는 제시된 수치안이다. 감소 기준과 최종 밸런스는 확정하지 않았다. 효과 간 연쇄 발동, 무기별 발동 빈도 보정, 보스 적용도 후속 설계다.

### 노랑: 속도 관련 후보군

아래는 컨셉 선택을 위한 후보군이다. 표의 예시를 모두 개별 파츠로 제작하거나 노랑 효과로 확정한 것은 아니다.

| 후보군 | 효과 예시 |
|---|---|
| 공격 동작 | 기본 공격 속도, 특수공격 준비 단축, 차지 속도, 공격 후 회수 시간 단축 |
| 이동·회피 | 이동 속도, 대시 속도·거리·최대 횟수·재충전 속도 |
| 투사체 움직임 | 탄속, 비행 중 가속, 귀환 속도, 유도 선회 속도, 연속 발사 간격 |
| 가속 누적·유지 | 연속 적중·이동으로 가속 축적, 중단 후 서서히 감소, 가속 유지 보상 |
| 행동 연결 | 대시 후 빠른 공격, 공격 후 빠른 이탈, 기본·특수 교차 연계, 무기 교체 연계 |
| 재사용 순환 | 특수공격 재사용 시간 단축, 적중·처치·회피 시 남은 시간 감소 |
| 조건부 가속 | 처치·피격·정확한 회피·전투 진입 후 일시적인 속도 증가 |
| 저장·리듬 | 가속 저장 후 소모, 일정한 박자로 공격, 주기적 가속, 자원 소모를 대가로 가속 |

재사용 시간 관련 효과의 색상 배정, 무기별 호환, 발동 조건·수치·중첩은 미정이다. 현행 기본 공속 규칙을 투사체·특수공격·대시까지 자동 확대하지 않는다.

## 6. 시각 표현 방향

- 도면·흰색 형태 변환 잉크·검정 특수공격 잉크와 색상 파츠용 팔레트를 구분해 표현한다.
- 팔레트의 색상 구성과 장착된 파츠로 무기의 색과 효과 구성을 보여주는 방향이다.
- 낡고 구겨진 도면이 깨끗하고 빳빳해지고, 희미한 검정 윤곽이 또렷해지는 표현을 검토한다.
- 정해진 팔레트 구성과 무기 그림의 채색 영역을 어떻게 대응시킬지는 미정이다.
- 도면 강화·잉크 장착·등급 중 무엇이 종이·채색·윤곽의 선명도를 바꾸는지는 추가로 정한다.
- 칸의 허용 색과 잉크의 개별 효과는 색상뿐 아니라 문양·이름·설명으로 구분한다.

## 7. 남은 결정 사항

| 항목 | 정해야 할 범위 |
|---|---|
| 기본 콘텐츠 | 도면 등급의 종류·효과, 팔레트 등급의 유무·관계, 정해진 팔레트 구성 목록, 잉크 성능 차이·획득 규칙 |
| 무색 칸 | 포함된 팔레트 구성, 등록 후 다른 색으로 부분 교체하는 처리 |
| 제작·정비 | 정확한 제작·교체 비용, 일부 활성화의 최소 파츠 수, 빈칸 추가 비용, 안전 정비 조건 |
| 도면 강화 | 대상 수치, 증가량, 비용·상한, 새 도면으로 바꿀 때 이전 여부 |
| 무기·팔레트 이전 | 같은 팔레트를 다른 무기로 옮길 수 있는지, 기존 무기·잉크 처리 |
| 효과 콘텐츠 | 색상별 최종 컨셉·종류 수·수치·무기 호환, 독립 발동 조건·상시 효과 중첩·연쇄 발동 |
| 무기 교체 | 체력·상시 효과의 전환, 비활성 무기가 이미 생성한 효과 처리, 교체를 이용한 반복 이득 방지 |
| 흰색·검정 잉크 | 각 전용 칸 수·배치, 개별 콘텐츠·미장착 동작·형태별 호환, 기존 발사기 예외와의 연결 |
| 획득과 경제 | 도면·팔레트·잉크 드롭, 재고·보관, 보상, 런 초기화·영구 해금 |
| 구현 이행 | 현행 직접 장착·반환·이전·중첩 규칙과 달라지는 범위, 데이터·UI·저장 반영 및 검증 절차 |

## 8. 관련 자료와 적용 범위

- [현행 무기·잉크 명세](weapons-and-ink.md): 현재 적용 기준. 이 개편안과 조정이 필요한 규칙을 확인한다.
- [미정 사항과 명세 충돌](../open-questions.md): 프로젝트 공통 미정·충돌 관리 기준.
- [도면·팔레트 제작소 시연](../../game-design/ink-palette-forge.html): 도면과 팔레트 분리, 일부 칸 활성화, 빈칸 추가·고비용 부분 수정, 최종 제작 시 기존 팔레트·파츠 소멸, 흰색·검정 교체, 무색 칸, 현재 무기의 독립 효과 표시를 확인하는 HTML이다. 도면 강화는 시연 수치만 표시하고 실제 전투·발동 확률·드롭·저장은 재현하지 않는다. 비용·강화 수치·재고·팔레트 구성은 시연용 예시이며, 미정인 무색 칸의 다른 색 교체는 시연을 제한한다.
- [도면 채색·강화 시각화](../../game-design/ink-blueprint-sectors.html): 도면에 고정된 다섯 색 영역과 개별 칸 강화를 시연하는 참고 HTML이다. 이 개편 설계의 별도 팔레트·굽기·부분 수정·파괴 후 재제작·무색 칸·도면 단독 강화는 시연하지 않는다.

이 문서는 개편 설계를 정리한 자료다. 도면·잉크의 획득·생성·강화·저장과 본 게임 통합의 구현·실행 검증은 별도 작업이다.
