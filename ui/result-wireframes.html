Deviant · 런 결과 화면

정보 구조 검토용 와이어프레임. 두 화면은 같은 틀을 쓰고, 결과의 의미만 제목·색·문구로 구분합니다. 숫자는 배치 예시입니다.

1챕터 출구는 결과 화면 없이 2챕터로 이어집니다. 아래 화면은 사망하거나 현재 마지막 챕터를 완료해 런이 끝났을 때만 표시합니다.

플레이 시간49:32
처치 수173

새 영구 해금이 열렸습니다 · 시작 마을에서 확인

표시 시점 현재 구현된 마지막 챕터인 2챕터를 완료하고 런을 정산한 뒤.

팀 검토용 메모

  • 마법안료는 적 처치 시 이미 획득합니다. 결과 화면의 +N은 재지급이 아니라 이번 런 획득량입니다.
  • 누적 마법안료, 사망 원인, 신규 해금의 구체적 목록은 데이터와 표시 정책을 확인한 뒤 추가합니다.
  • 3챕터가 구현되면 ‘이번 도전 완료’의 표시 시점을 최종 챕터 기준으로 다시 정합니다.
  • 이 버튼은 화면 비교용입니다. 실제 게임 이동은 Unity에서 연결해야 합니다.
