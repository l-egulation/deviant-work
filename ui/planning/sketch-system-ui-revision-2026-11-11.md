# Deviant — 스케치 개편 규칙과 UI 변경 범위

기준: 2026-11-11 사용자 설명 및 추가 확인. 이번 문서는 대화에서 합의한 개편 기준이며, 게임 저장소/Unity 구현과 대조한 명세가 아니다. 이전 UI는 비교 자료로 보존하고 새 규칙 구현 완료로 취급하지 않는다.

## 핵심 구조

스케치는 내구도가 있는 장비다. 무기 형태·스킬·팔레트 구성이 하나로 묶여 생성된다. 플레이어는 스케치의 빈 칸에 보유 잉크를 적용하고, 소진되기 전 가방에 보관하거나 다른 스케치를 장착할 수 있다.

잉크는 소모품이 아니다. 가방에 보유한 잉크를 반복 적용할 수 있다. 적용 후에도 원본 잉크는 가방에 남는다. 이미 적용한 칸의 잉크는 교체할 수 없다.

내구도가 0이면 스케치와 그 안에 적용된 효과가 모두 소멸한다. 잔해나 반환물은 없다. 가방에 보유한 원본 잉크는 이 소멸에 포함되지 않는다. 장착 자리는 비며, 플레이어가 가방에서 다른 스케치를 직접 장착한다. 자동 장착하지 않는다.

## 확정된 개편 규칙

| 항목 | 규칙 | UI에 반영할 내용 |
|---|---|---|
| 스케치 구성 | 형태·스킬·팔레트 색상이 묶여 있음 | 하나의 장비로 비교, 별도 스탬프 장착 흐름 제거 |
| 스케치 보관 | 내구도 소진 전 가방에 보관 가능, 여러 개 소지 | 현재 내구도와 장착 여부, 다른 스케치와 비교 |
| 파괴 | 내구도 0에서 전체 소멸, 장착 자리 비움 | 빈 장착 자리와 소멸 피드백, 가방에서 수동 장착 |
| 잉크 보유 | 적용해도 원본은 가방에 남음 | 소모/사용 개수 감소/반환 표현 삭제 |
| 잉크 적용 | 빈 칸에 적용, 적용된 칸은 교체 불가 | 채워진 칸은 읽기 전용, 적용 직전에 되돌릴 수 없음 표시 |
| 중복 적용 | 같은 잉크를 여러 스케치 및 한 스케치의 여러 빈 칸에 적용 가능 | 이미 사용 중이라는 이유로 후보 제외/비활성화하지 않음 |
| 전투 중 정비 | 가방에서 스케치 교체와 잉크 적용 모두 가능 | 별도 정비 시설 방문 조건 제거. 기존 가방·장비창 일시정지 방침 유지 |
| 색상 조건 | 모든 칸에 모든 색 잉크 적용 가능 | 색상 불일치 비활성화 제거 |
| 색상 일치 | 칸의 색과 잉크 색이 같으면 효과 증가 | 기본 효과와 일치 보너스를 분리, 색 외 문자/기호 보조 |
| 무기 강화 | 무기 공격력·팔레트 칸 강화 없음 | 강화 수치 +0 및 칸 강화·색 변경 UI 제거 |
| 획득 | 처치 누적으로 보상 기회, 무작위 3개 중 1개 선택 | 진행 상태 → 보상 준비 → 비교 → 선택 흐름 |
| 증강 | 3개 중 1개, 안정적 선택 1개와 위험 동반 선택 2개 | 이득/패널티를 명확히 구분, 기존 공격 성장 기능 이관 |

이전 '주입한 잉크도 소멸' 표현은 적용 효과의 소멸을 뜻한다. 원본 잉크 소모·반환과 혼동하지 않는다. 같은 잉크를 여러 스케치 및 한 스케치의 여러 빈 칸에 중복 적용할 수 있다. 런 간 영구 보존은 별도 미정이다.

## 잠정 사항 — 수치나 구현을 확정하지 않음

- 한 챕터에서 무기 약 2개 소진, 스케치 약 4개 획득, 상점에서 추가 구매.
- 스케치·잉크 가방 용량 무제한 예상. 확정 전까지 용량 초과 UI는 제작 중단.
- 팔레트 기본 3칸, 후반 최대 약 5칸 예상.
- 색상 일치 효과 배율은 미정. 200%는 예시.
- 잉크 효과는 조건/대가 → 효과로 간소화, 조합에 따라 3단계 레어도 예정.
- 노랑은 이동, 초록은 체력/보호막, 보라는 CC 중심. 빨강은 기본 공격 피해/공속, 파랑은 스킬 피해/쿨타임 중심이며 자신에게 적용되는 대가를 동반.
- 잉크통을 채우는 연출과 보상 시설의 구체 형태는 미정.

## 기존 UI 변경표

| 현재 화면/에셋 | 판단 | 변경 내용 |
|---|---|---|
| 가방 | 크게 개정 | 스케치·잉크 중심 분류, 스케치 내구도/형태/스킬/팔레트 표시. 무제한 확정 시 수용량·빈 칸 수·가방 가득 참 제거 |
| 장비 | 개정 | 장착한 스케치와 빈 장착 자리 지원. 스케치 교체/보관 및 빈 칸에 잉크 적용. 채워진 칸은 효과 열람만 가능 |
| 정비소 성장 | 기존 기능 폐기 | 공격 강화 구매 제거. 관련 성장은 증강 화면으로 이관 |
| 정비소 팔레트 | 기존 기능 폐기/재배치 검토 | 칸 강화·색 변경·결제수단 제거. 잉크 적용은 전투 중에도 가방/장비에서 가능하므로 별도 시설 필수 진입 제거 |
| 정비소 스탬프 | 기존 독립 장착 흐름 폐기 | 형태·스킬이 스케치에 포함. 설명과 아이콘은 스케치 상세에서 재사용 |
| 잉크 판매대 | 재검토 | 반복 사용 잉크 기준 구매/중복 보유 정책 필요. 스케치 구매 UI 추가. 가방 용량 경고는 보류 |
| 스케치 보상 | 신규 | 3개 스케치의 형태·스킬·팔레트·내구도 비교 및 하나 선택 |
| 잉크 보상 | 신규/재사용 | 3개 조건/대가·효과·등급 비교. 기존 보상 선택 프레임 재사용 |
| 봉인 도전/증강 | 개정 | 안정 1개 + 위험 2개 구성. 기존 고정 효과/수치 교체 |
| 보스 잉크 제단 | 재검토 | 기존 색상 선확정 구조가 새 획득 방식에도 남는지 확인 |
| 출발 준비 | 재검토 | 초기 스케치 지급/선택과 다시 뽑기 존속 확인. 기존 도면·팔레트 별도 조합 구조를 그대로 유지하지 않음 |
| 전투 HUD | 개정 | 장착 스케치별 내구도, 소멸/빈 자리, 처치 누적 보상 상태 필요 |
| 전체 지도 | 일부 개정 | 삭제/변경 시설과 보상 오브젝트 아이콘/범례 갱신 |
| 일시정지·설정 | 대체로 유지 | 시스템 관련 문구/도움말 및 조작 연결만 재검토 |
| 사망·클리어 결과 | 재검토 | 이번 개편이 런 종료 보존 규칙까지 바꾸는지는 미정. 잉크 재사용을 영구 보존으로 해석하지 않음 |

## 그대로 살릴 디자인 자산

어두운 배경, 픽셀 잉크병·무기 아이콘, 붓칠 선택 표시, F 실행 표시, 좌우 구분선, 현재 조작 영역 강조, F 진입/Esc 복귀 원칙.
팔레트 기본색은 더 옅게 조정하고 적용 잉크색과 일치 보너스를 구분한다. +0 강화 숫자는 제거한다. 모든 색상 조합이 가능하므로 칸 배경과 잉크 칠을 분리한 기존 레이어 에셋의 활용을 검토한다.

## UI 문구 방향

- '잉크 소모', '기존 잉크 반환', '교체 무료' 대신 '잉크 적용'.
- 빈 칸은 '빈 칸', 채워진 칸은 효과명. 기본 목록에 긴 경고 반복 금지.
- 적용 실행 근처: '적용 후 변경 불가 · 보유 잉크는 유지'.
- 같은 색이면 '색상 일치'와 실제 증가 효과. 미정 배율 표기 금지.
- 무기 소멸 후: 빈 장착 자리와 '가방에서 스케치 장착' 안내. 자동 장착처럼 보이지 않게 함.

## 아직 결정해야 할 규칙

1. 내구도 소모 조건(공격/명중/시간 등), 소진 전 경고 기준, 두 무기 모두 없을 때 가능한 행동.
2. 처치 보상이 준비됐을 때 자동 선택창인지 상호작용 오브젝트인지, 선택 중 일시정지 여부.
3. 같은 잉크 재획득 처리, 보상 포기/나중에 선택 가능 여부, 스케치 획득 후 보관/즉시 장착 흐름.
4. 초기 스케치 지급과 사망 시 잉크 보존 정책. 재사용 가능과 영구 보존은 별개.
5. 빨강/파랑 잉크의 대가 발생 시점·주기·지속 시간. UI에 구체적으로 표시할 수 있어야 함.

## 다음 작업 순서

규칙의 미정 항목 결정 → 새 획득/장착/소멸 흐름도 → 스케치 3중 1택 → 가방/장비 및 잉크 적용 → 증강 → HUD/상점/출발/결과 갱신.
이번 단계에서는 문서만 작성한다. 기존 시안과 에셋은 삭제하지 않으며, 현재 갤러리를 새 기획 반영 완료본으로 취급하지 않는다.

## 추가 확정 — 중복 적용 및 전투 중 사용

- 같은 원본 잉크를 여러 스케치, 한 스케치의 여러 빈 칸에 반복 적용할 수 있다.
- 적용 후 후보 목록에서 잉크를 제거하지 않는다. 사용 중 표시로 선택을 막지 않는다.
- 채워진 칸을 수정할 수 없다는 규칙은 유지한다. 중복 적용은 다른 빈 칸에 대한 허용이다.
- 전투 중 가방에서 스케치 교체와 잉크 적용 모두 가능하다. 이전에 합의한 가방·장비창 일시정지를 유지한다.
- 스케치 선택 → 빈 칸 선택 → 잉크 선택 → F 적용 흐름을 재사용한다. 적용 후 빈 칸 선택으로 돌아가 반복 적용할 수 있다.
- 같은 효과의 중첩 계산(합산/곱연산/발동 횟수 등)은 중복 적용 허용만으로 확정되지 않는다. 수치 규칙 확인 전 총효과를 임의 계산하지 않는다.
