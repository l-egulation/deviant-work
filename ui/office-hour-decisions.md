# Deviant UI Office Hour 결정 기록

갱신: 2026-10-27  
상태: 팀 검토용. **확정**은 사용자와 Office Hour에서 합의한 방향, **검토 중**은 아직 채택하지 않은 화면 제안입니다. 수치·색상·보관 칸 수는 별도 표기가 없다면 와이어프레임 예시입니다.

## 1. 첫 플레이와 런

| 주제 | 현재 결정 |
|---|---|
| 첫 진입 | 별도의 튜토리얼 스테이지 없이 1스테이지에서 시작. 첫 도전에만 NPC가 조작을 자세히 안내. |
| 시작 무기 | 매 도전마다 기본 무기 2개를 무작위 지급. 두 무기에는 팔레트가 기본 장착되지 않음. |
| 첫 정비 | 1스테이지 중 안전한 정비 구역에 도착. 정비는 선택 사항이며 아무것도 얻지 못해도 기본 무기 2개로 다음 전투에 출발 가능. |
| 사망과 재도전 | 다른 장소인 거점으로 돌아와 1스테이지 처음부터 재도전. 상세 NPC 안내는 반복하지 않음. 새 도전의 무기 2개도 다시 무작위 지급. |
| 런 자원 | 사망 시 이번 도전에서 획득·제작한 잉크, 도면, 팔레트는 모두 잃음. 골드(가명)도 기본적으로 모두 잃지만 향후 로그라이트 재화로 일부 보존 가능하게 할 예정. |

## 2. 획득 시설과 인벤토리

| 주제 | 현재 결정 |
|---|---|
| 룰렛 진입 | 정비 구역에 있는 물리적 룰렛 시설과 상호작용. 상시 개인 정비 UI에 뽑기 버튼을 두지 않음. |
| 뽑기 카테고리 | 잉크와 팔레트 등 종류별 룰렛을 구상 중. 한 기계에서 카테고리를 고를지 별도 기계를 둘지는 **미정**. |
| 잉크 룰렛 | 완전 무작위. 팔레트가 없어도 잉크를 뽑아 보관 가능. 첫 뽑기의 사용 가능 결과 보장 없음. |
| 팔레트 획득 | 몬스터 드롭 또는 정비 구역의 팔레트 룰렛 등으로 별도 획득. 첫 정비에서 획득 보장 여부는 **미정**. |
| 인벤토리 | 색상 잉크, 흰색 잉크, 검은 잉크, 팔레트로 카테고리를 나누고 **카테고리마다 별도의 칸 제한**을 둘 방향. 구체 용량은 **미정**. 장착된 팔레트는 인벤토리 칸을 차지하지 않음. |
| 룰렛 보관함이 가득 찼을 때 | 해당 카테고리가 가득 차도 뽑기 가능. 결과를 보고 같은 카테고리의 기존 아이템 하나와 교체하거나 새 결과를 포기. 네 카테고리에 공통 적용. |
| 룰렛 결과 화면 | 획득 결과 확인·보관·초과 처리만 담당. 무기에 연결하거나 잉크를 적용하는 기능은 두지 않음. |

## 3. 정비 작업대

| 주제 | 현재 결정 |
|---|---|
| 작업 위치 | 룰렛 시설과 별도인 정비 작업대에서 팔레트를 무기에 연결하고 잉크를 적용. |
| 빈 팔레트 | 색상 잉크가 하나도 없어도 무기에 연결 가능. 나중에 칸을 채움. |
| 기본 칸 수 | 팔레트의 기본 잉크 칸은 5칸. 이후 확장 여지가 있음. 실제 칸별 허용 색 구성은 **미정**. |
| 귀속 | 연결한 팔레트는 그 무기에 귀속되며 다른 무기로 옮길 수 없음. |
| 팔레트 교체 | 같은 무기에 새 팔레트를 연결하면 기존 팔레트와 그 안의 잉크는 모두 소멸. 확정 전에 소멸 대상을 보여줘야 함. |
| 잉크 적용 | 팔레트에 적용한 잉크는 소모되어 회수할 수 없음. 향후 정비 지역에서 재화를 써서 수정하는 기능을 계획 중이나 세부 비용·시기는 **미정**. |

## 4. 전투 중 몬스터 드롭

- 팔레트와 잉크 드롭은 상호작용 버튼을 눌러 획득.
- 해당 카테고리가 가득 찬 상태에서 상호작용하면 기존 아이템과 교체하는 선택창이 열림.
- 선택창이 열린 동안 전투는 일시정지.
- 취소하면 새 아이템은 바닥에 남아 다시 상호작용할 수 있음.
- 드롭의 바닥 유지 시간과 사라지는 조건은 **미정**.

## 5. 검토 중인 안과 남은 결정

- **검토 중:** 룰렛 결과를 보관할 공간이 없을 때 결과창을 닫으면 아이템이 룰렛 옆 바닥에 떨어지고, 나중에 상호작용해 다시 처리하는 안. 바닥 결과가 여러 개 쌓일 때와 재뽑기 가능 여부를 검토해야 함. 확정된 규칙으로 취급하지 않음.
- 팔레트·흰색·검은색·색상 잉크 룰렛이 한 기계인지 별도 기계인지.
- 카테고리별 실제 인벤토리 용량, 룰렛 가격, 골드 획득량, 첫 정비에서 팔레트 획득 보장 여부.
- 팔레트 칸별 잉크 적용 가능 조건, 도면·흰색/검은색 잉크 적용의 세부 절차.
- 런 저장·이어하기, 전투 중 무기 전환 입력, 정비 구역과 거점의 추가 기능.

### 카테고리별 인벤토리와 전투 획득 화면

- [인벤토리 기본 화면](https://www.figma.com/design/qjL5PNYHPgTDQ0huZXBzLg?node-id=37-75): 색상 잉크·흰색 잉크·검은 잉크·팔레트의 독립 용량과 아이템 상세를 확인합니다. 이 화면에서는 잉크를 바로 적용하지 않습니다.
- [룰렛 결과와 기존 아이템 비교](https://www.figma.com/design/qjL5PNYHPgTDQ0huZXBzLg?node-id=37-122): 해당 카테고리가 가득 찼을 때 새 결과를 포기하거나 기존 아이템을 선택해 교체합니다. 결과창 닫기 후 바닥에 두는 동작은 검토 중인 안입니다.
- [전투 중 드롭 교체](https://www.figma.com/design/qjL5PNYHPgTDQ0huZXBzLg?node-id=37-152): 상호작용 획득 시 용량이 가득 차면 전투를 일시정지하고 기존 아이템을 선택합니다. 취소 시 새 아이템은 바닥에 남습니다.

인벤토리의 진입 위치와 보관 칸 수, 아이템의 실제 이름·효과는 확정하지 않았습니다. 세 화면은 결정된 동작을 검토하기 위한 저해상도 예시입니다.
