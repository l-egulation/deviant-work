# ② 챕터 탐험 화면 설계 (전투 HUD · 출발 팔레트 · 가방 · 지도 · 일시정지)

작성: 2026-11-05 · 팀 레포 기준: `76f94a3b` (2026-11-05) · 피그마: [② 챕터 탐험 (960)](https://www.figma.com/design/qjL5PNYHPgTDQ0huZXBzLg/?node-id=120-75) 「② v2」 줄

테마 없는 회색 와이어, 실제 크기 960×540, 글자 12px 이상. 포커스는 청록 테두리(사용자 결정).

## 전투 HUD

| 자리 | 내용 |
|---|---|
| 왼쪽 위 | 체력(하트·현재/최대·막대), 지역 이름, `H 키 안내`(기본 접힘, 펼치면 두 줄: `Space 점프 · Shift 대시 · ↑ 벽타기 · M 지도` / `Q/W 기본 · E/R 스킬 · F 상호작용 · I 가방`) |
| 가운데 위 | 획득 알림 전용(3초) |
| 오른쪽 위 | 골드 → 안료 → 가방(I) → 일시정지 한 줄, 그 아래 미니맵(어두운 바탕·밝은 선, M) |
| 왼쪽 아래 | 무기 카드 둘: 번호, 기본·스킬 칸, 키(무기 1 Q·E / 무기 2 W·R). 스킬 쿨타임은 덮개+남은 초. 팔레트 색 점은 넣지 않는다(사용자 2026-11-05: 불필요) |
| 대상 위 | 상호작용 안내 `F 들어가기`를 정비소·제단·출구 위에 띄우고 대상에 포커스 색 테두리(마을과 같은 규칙) |
| 위쪽 띠 | 조작 안내는 팀 규격 「상단 띠」(960 기준 y 32~92, 가운데가 가장 진한 검은 그라데이션, 상자 없음): 첫 벽 길목 `↑ 기어오르기 · ↑+Space 벽차기 · ↓+Space 내려가기`. 첫 런 멈춤 안내(예: `[Q] 공격`)도 같은 띠(팀 `first-run-guide.md`) |

보스방: 가운데 위 보스 이름과 단계 칸이 있는 체력바(구분선 2.5px). 오른쪽 위는 일시정지만 남긴다(팀 규칙).

## 런 시작 · 출발 팔레트

팀이 넣은 「런 시작 때 출발 팔레트를 화면 가운데에 보여 주기」 창을 쓴다.

- 무기마다 칸 색 3개와 색 역할 한 단어(팀 `ink-color-parts.md`: 빨 직접 피해 · 노 이동 · 초 체력 · 파 범위·쿨 · 보 CC). 무색 칸은 「무」.
- 출발 리롤을 해금했으면 `R 길게` 다시 뽑기(고른 무기 하나의 칸 색 전체, 남은 횟수 표시). 해금 전엔 이 줄이 없다.
- `F` 출발. 창을 연 뒤 키를 한 번 떼야 입력을 받는다(스킬 연타가 다시 뽑기·출발로 새지 않게).

## 가방 (I)

- **열면 일시정지**(사용자 결정, 팀 현재 구현은 멈추지 않음).
- 왼쪽: 두 무기 카드(팔레트 칸·형태 1·특수 1·능력치 5). 오른쪽: 탭 `Q` 전체 / 색·능력치 / 형태 / 특수 `E`(각 15칸, 색 잉크는 팀 구조대로 능력치와 칸을 함께 쓴다), 15칸 격자.
- 아래: 고른 잉크 이름·등급, 색 역할·효과, **어느 칸에 들어가는지**(팔레트의 같은 색 칸 또는 무색 칸), 다른 무기에 왜 안 되는지, 찬 칸이면 기존 잉크는 가방으로.
- 키: `F` 장착(마을 창과 같은 실행 키) · `X` 버리기(바닥에 놓음, 다시 주울 수 있음) · `C 길게` 파괴(되돌릴 수 없음, 회수공방 해금 시 「+20G」 표시). 방향키 칸 이동, 격자 왼쪽 끝에서 ← = 무기 칸으로.
- 형태·능력치·특수 잉크는 정비소 밖이면 장착 버튼이 「정비소에서만」(팀 규칙). 색 잉크는 어디서나.
- 끼울 칸이 여러 개면 F 뒤 포커스가 첫 칸으로 가고 방향키로 고른 뒤 F.

## 지도 (M)

열면 일시정지(팀). 열 때는 이번 런에 발견한 곳에 맞춰 보인다(팀). 왼쪽 지도, 오른쪽 범례(모양+색: 현재 위치·정비소·보스·적·못 가 본 곳 점선·포탈)와 조작(`방향키` 이동 · `+/−` 확대 · `C` 현재 위치 · `Home` 전체). 드래그는 마우스 보조로만.

## 일시정지 (Esc)

계속하기(첫 포커스) · 조작 안내 · 설정 · 저장하고 타이틀로(런 중간 자동 저장, 사용자 결정) · 런 포기 · 마을로(그 버튼을 고른 상태에서만 `F 길게`), 아래에 음량 두 줄 「전체」·「음악」(− 값 +, 10% 단위, 팀 2026-11-04). 팀 현재 구현은 계속하기 · 조작 안내 · 마을로 + 음량.

## 팀 현재 구현과 다른 점

| 항목 | 이 설계 | 팀 |
|---|---|---|
| 안료 HUD | 골드 오른쪽 | 전투에는 없음 |
| 가방 | 열면 일시정지 | 멈추지 않음(피격 시 닫힘) |
| 가방 키 | F 장착 · X 버리기 · C 길게 파괴 | E 장착 · 두 번 눌러 파괴 |
| 상호작용 안내 | `F 들어가기`는 대상 위(조작 안내·첫 안내는 팀 상단 띠) | 상단 띠로 옮기는 중(`first-run-guide.md`) |
| 일시정지 | 설정 · 저장하고 타이틀로 · 런 포기(F 길게) | 계속하기 · 조작 안내 · 마을로 |

## 확인할 것

- 가방 파괴 키 `C 길게`: 팀이 포탈(C 설치·V 귀환)을 정식 기능으로 바꿨다(2026-11-05). 가방은 일시정지 모달이라 실제 충돌은 없지만 같은 키가 다른 뜻이다. 바꿀지 사용자 확인.

## 남은 의견 (보류)

- 지도에 안 주운 잉크·아이템 위치(게이머 제안).
- 일시정지에 지금 빌드 요약(게이머 제안).
- 패드 표시(LB/RB, A/B)와 스틱 4방향 고정·반복 간격 — 조작 단계에서.
