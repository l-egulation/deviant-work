# ③ 정비소 화면 설계

작성: 2026-11-05 · 팀 레포 기준: `76f94a3b` (2026-11-05) · 피그마: [③ 정비소 (960)](https://www.figma.com/design/qjL5PNYHPgTDQ0huZXBzLg/?node-id=127-75) 「③ v2」 줄

회색 와이어 960×540, 글자 12px 이상. 창은 마을 창과 같은 오른쪽 위 고정(폭 470), 주인공과 상인이 보인다. 열면 일시정지(팀).

## 들어가기

- 정비소 방 안에서 상인 위에 `F 들어가기`(② 상호작용 규칙).
- **첫 방문 연출**(팀 `maintenance-introductions.md`): 위아래 검은 띠 32px, HUD·상호작용 표시 숨김, 주인공 자동 접근, 상인만 말한다. `F`로 다음 줄, 마지막 줄 뒤 띠를 걷고 창을 연다. 들어올 때 누른 F가 첫 줄을 넘기지 않게 키를 뗀 뒤부터 받는다. 재방문은 F로 바로 창.

## 창 공통

머리: `1챕터 정비소` · 보유 골드 · `Esc 닫기`. 탭 `Q` **성장 · 팔레트** `E`. 스탬프 탭은 기능이 연결될 때까지 숨긴다(팀 현재 「준비 중」).

## 성장 탭 (처음 열리는 탭)

- 잉크 뽑기(40G → 60 → 80, 성공마다 +20) · 공격 강화(60G → 90, +30). 줄마다 지금 가격과 「다음 가격」(팀 `content-costs.md` 시험값).
- 아래 줄: 고른 항목 설명. 뽑기는 「가방 빈 칸 N · 가득 차면 뽑을 수 없어요(결제 안 함)」.
- 골드를 쓰는 건 `F 길게`(마을 해금과 같은 규칙).
- 뽑기 결과: 창 안의 작은 카드(잉크·이름·효과·「가방에 넣었어요 −40G」), `F` 확인. 새 잉크는 팔레트 탭 격자에 「새로」 표시. F 길게를 뗀 뒤에야 결과 카드가 F를 받는다.

## 팔레트 탭 (관리 화면을 따로 열지 않는다)

- `Tab` 무기 1 / 무기 2. 맨 위 「지금 효과」 한 줄.
- 칸 3~5개(색·끼운 잉크·칸 강화 단계 +N). 빈 칸은 점선 원 + 「빈 칸」.
- 오른쪽 색 잉크 격자(가방 공유).
- 포커스 구역: 칸 ↔ 잉크(방향키, 격자 왼쪽 끝에서 ← = 마지막 칸), 칸에서 `↓` = 행동 목록.
- **칸을 골랐을 때** 행동 목록: 칸 강화(+N → +N+1, 50G → 75 …, 최대 +5) · 칸 색 변경(무작위 색, 끼운 잉크는 가방으로; 변경권 먼저, 없으면 정비소 런당 2회·100G). 행동 목록에서 `F 길게`.
- **잉크를 골랐을 때**: 끼울 칸은 칸 아래 ▲ 표시(포커스와 다른 모양). `F` 교체(무료) · `Z 길게` 판매(가격 표시) · `X 길게` 파괴. 가방(`F` 끼우기 · `Z` 버리기 · `X 길게` 파괴)과 같은 자리 키이고, 정비소에서만 Z가 판매다.
- 등급은 효과 세기와 무관(팀). 교체 설명은 효과 이름으로 비교한다.

## 팀 현재 구현과 다른 점

| 항목 | 이 설계 | 팀 |
|---|---|---|
| 첫 탭 | 성장 | 팔레트 |
| 탭 | 성장 · 팔레트 (스탬프 숨김) | 팔레트 · 성장 · 스탬프(준비 중) |
| 팔레트 관리 | 팔레트 탭 안에서 | 팔레트 탭 → 별도 관리 화면 |
| 슬롯 강화 | 팔레트 탭의 칸 행동에만 | 성장 탭 버튼 → 팔레트 관리 |
| 구매 | F 길게 | 버튼 |
| 판매·파괴 | Z 길게 · X 길게 | 버튼 · 두 번 눌러 파괴 |

## 확인할 것

- 공격 강화 단계별 실제 수치 문구(와이어는 「두 무기 공격력 +5%」 예시).
- 색 잉크 판매 가격(와이어는 15G 자리 예시).
