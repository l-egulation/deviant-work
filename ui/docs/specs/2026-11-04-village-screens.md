# 마을 나머지 화면 설계 (회수공방 · 출발 준비대 · 기록 농가 · 귀환 우물 · 마을 HUD)

작성: 2026-11-04 · 팀 레포 기준: `5f117f89` (2026-11-04) · 피그마: [탐색 · 마을 작업대 창](https://www.figma.com/design/qjL5PNYHPgTDQ0huZXBzLg/?node-id=80-75) 「마을 v2」 줄

창 틀은 [마을 작업대 창 설계](2026-11-04-village-workbench-windows.md)를 그대로 쓴다: 오른쪽 위 900 폭, 머리(이름·한 줄·Esc), 고른 것 하나(황토 테두리), 아래 정보 줄과 버튼 하나, 1440 프레임 18px 이상.

## 회수공방

- 항목이 하나(안료 회수: 잉크 파괴마다 +20G, 40 안료)라 탭·트리 없이 보급소 한 줄과 같은 모양, 창 높이만 짧다.
- 앞 조건이 다른 건물(보급소 보관함 2칸)이라 줄 안에 「먼저: 보관함 2칸 (지금 1칸)」, 버튼은 「보급소에서 보관함 2칸 먼저」. 자물쇠는 쓰지 않는다(자물쇠는 챕터 조건 전용).

## 출발 준비대

- 무기 카드 3장(검·둔기·원거리). F로 고르기/빼기, 고른 순서대로 「무기 1 · Q E」「무기 2 · W R」 띠(전투 HUD 키와 같다).
- **두 무기를 고른 뒤 「선택하기」로 확정한다.** 확정하지 않고 Esc로 닫으면 저장하지 않는다(팀 규칙, 사용자 결정 2026-11-04). 확정 뒤 다시 열면 버튼이 「변경하기」.
- 확정 전에는 상태 줄에 「아직 확정 전 · Esc로 닫으면 저장 안 돼요」를 빨강으로 보인다.
- 두 번째 카드를 골라도 포커스가 버튼으로 자동 이동하지 않는다(F 연타가 확정으로 새지 않게). 카드에서 ↓로 버튼에 간다.
- 이미 두 개일 때 다른 카드에서 F = 무기 2와 바꾸기. Tab = 무기 1·2 순서 바꾸기.
- 확정한 조합은 다음 런에도 남는다. 바꿀 것이 없으면 이정표 F 한 번으로 출발.
- 아래: 두 무기의 출발 팔레트(칸 수, 칸 색은 출발할 때 정해짐), 상태 줄, 키 안내, 「이번 런: 체력 · 공격력 · 골드 · 변경권 · 리롤」 한 줄.
- 카드: 「종류 · 형태」 이름과 공격 한 줄(팀 `weapons-and-ink.md`·`melee.md`, Unity `BlueprintArt` sword/hammer/launcher · `5f117f89`).
  - 검 · 기본검 — 2타 베기 · 특수 강베기
  - 둔기 · 기본망치 — 묵직한 2타 · 특수 횡강타
  - 원거리 · 발사기 — 볼 탄환 · 특수는 잉크로(별도 특수 없이 잉크가 레이저·샷건·유탄으로 바꿈)
- 출발 버튼은 없다(팀 규칙). 출발은 이정표에서.

## 기록 농가

- 왼쪽 여정 횟수(출발·사망·챕터 클리어·보스 첫 클리어), 오른쪽 건물별 해금 진행 막대(산 수 / 전체)와 본 이야기.
- 기록 초기화: 아래 오른쪽, 빨간 테두리, **F 3초** 길게(해금보다 강한 확인), 누르는 동안 차오름. 창을 열 때 포커스는 초기화가 아닌 첫 줄.

## 귀환 우물

- 창 대신 우물 위 말풍선: 「다음 여정을 준비할까요?」 → 「무기 고르기 (출발 준비대)」 / 「닫기」. 앞 항목은 출발 준비대 창을 그대로 연다.
- 말풍선 안에 키 안내(↑↓ · F 결정 · Esc 닫기). 열려 있는 동안 이동·점프 입력은 말풍선이 가져간다.

## 마을 HUD와 이름표

- 오른쪽 위: 「안료 N」(물방울 모양, 골드 동전과 구분) + 일시정지. 가방·체력 없음. 전투 HUD의 골드 칩 자리와 같다.
- 건물 위 틀 없는 검은 이름표. 닫힌 작업대는 회색 이름 + 아래에 여는 조건(팀 문구 「N챕터 클리어 필요」, 예: 회수공방 「3챕터 클리어 필요」). 1챕터로 처음 출발하기 전에는 이름표를 달지 않는다(팀 규칙).
- 가장 가까운 대상만 포커스와 같은 색 테두리 + 위에 F 키. 포커스 색은 청록 `#3A8F8C`을 추천(아래).
- 이정표: 무기를 안 골랐으면 다가가기 전부터 이름 아래 「무기 2개 필요」, F 키에 빨간 자물쇠. F를 누르면 이정표 옆에 「← 출발 준비대에서 무기 2개」(누를 때마다 다시).
- 새로 열린 작업대: 이름표 위 검은 칩 「새로 열림」, 한 번 열어 보면 사라짐.

## 포커스 색

고른 칸·가까운 대상 테두리는 한 색으로 쓴다. 테두리는 배경 대비 3:1 이상이어야 한다. 창 안은 GPT 테마의 어두운 흑연 패널 `#22282F`, 마을 대상은 종이 배경 `#F4EFEA` 위에 놓이므로 두 배경 모두 본다.

| 후보 | 대비 | 판단 |
|---|---|---|
| 황토 `#D29D3B` | 2.1:1 | 미달. 골드 동전과 같은 노랑 계열이라 「돈」과 섞인다 |
| **청록 `#3A8F8C`** | 종이 3.4:1 · 어두운 패널 3.9:1 | 추천. GPT 테마 강조색 `#4D9E9B`(어두운 패널 4.7:1, 종이 2.8:1)를 조금 어둡게 해 두 배경 모두 3:1을 넘긴다. 주인공 청록 스카프와 같은 계열, 빨강(체력)·노랑(골드)과 겹치지 않는다 |
| 먹 굵은 테두리 `#242A30` | 12.7:1 | 테마와 가장 조용하지만 먹선 그림·버튼과 섞여 덜 띈다 |

최종 색은 GPT 쪽 테마 팔레트와 맞춰 정한다. 비교: 피그마 「포커스 색 비교 (종이 배경)」.

## 정한 것 (사용자 결정 2026-11-04)

| 항목 | 정한 것 | 팀 현재 구현 |
|---|---|---|
| 준비대 저장 | 선택하기로 확정, Esc는 저장 안 함 | 같음 |
| 화폐 위치 | 전투 HUD 오른쪽 위에 골드, 그 오른쪽에 안료(골드가 왼쪽으로 밀림). 마을은 골드가 없어 안료만 | 마을은 왼쪽 위 안료, 전투에는 안료 없음 |

| 가까운 대상 표시 | 흰색 대신 포커스 색 테두리 (색은 청록 추천, 확정 전) | 흰 2px 외곽선 |

## 열린 질문

- (정함, 사용자 2026-11-04) 시작 팔레트 리롤(염색공방 해금 「출발 리롤」)을 어디서 쓰는가. 리롤은 「출발 전에 무기 하나의 칸 색을 전부 다시 뽑기」인데, 준비대에서는 칸 색이 아직 「?」라 보고 고를 수 없다. 추천: 팀이 새로 넣은 「런 시작 때 출발 팔레트를 화면 가운데에 보여 주기」(`0d53d051`) 창에 「다시 뽑기 (남은 1회)」/「이대로 출발」을 붙인다. 리롤을 해금하지 않았으면 지금처럼 보여 주기만 한다.

## 테마 시안과 맞출 점 (GPT 쪽, 2026-11-04 보급소 시안 기준)

- 잘 맞음: 고른 줄 청록 테두리 + ▶ 표시, 아래 설명 줄, 「F 길게 해금」, 작은 크기에서 주인공·건물이 보인다(작은 크기 추천).
- 안료 위치: 시안은 마을 왼쪽 위. 결정은 오른쪽 위(전투에서는 골드 오른쪽).
- 잠긴 줄 문구: 시안 「Lv.2 이상에서 해금」 → 「2챕터 보스 뒤」, 가격은 그대로 보인다.
- 출발 지원금: 시안의 「200 → 300」, 「보유 안료가 증가」는 팀 규칙과 다르다. 골드 보너스 +50G → +100G(안료 아님).
- 「다음 런」 줄: 시안은 설명 문장. 이 설계는 실제 값 요약(골드 50G · 공격력 +0% · …).
- 버튼에 가격이 없어도 된다. 가격은 줄에 이미 있다(검토에서 가격 반복을 줄이자는 의견).
