# 마을 작업대 창 설계 (보급소 · 염색공방)

작성: 2026-11-04 · 팀 레포 기준: `d4786611` (2026-11-03) · 피그마: [탐색 · 마을 작업대 창](https://www.figma.com/design/qjL5PNYHPgTDQ0huZXBzLg/?node-id=80-75) v4 줄

마을 건물 앞에서 F를 누르면 뜨는 창이다. 마법안료로 영구 해금을 산다(런 중 정비소와 다름). 테마 없는 배치 기준이며, 테마는 GPT 쪽에서 입힌다.

## 창 공통 틀

| 위치 | 내용 |
|---|---|
| 자리 | 화면 오른쪽 위 고정(960×540 기준 폭 약 470). 주인공이 화면 오른쪽 절반에 있으면 왼쪽 위로 뒤집는다. 창을 연 건물 이름표를 포커스 색으로 칠해 연결한다 (3차 비교로 정함, [검토](../../work/reviews/2026-11-04-workbench-windows-review.md#3차-창-배치-대안-블라인드-비교-960540-테마-색)) |
| 머리 | 건물 이름 · 「다음 런: …」 한 줄 · 보유 안료 · 「지난 런 +N」 · `Esc 닫기` |
| 본문 | 건물마다 다름 (아래) |
| 아래 줄 | 왼쪽: 고른 항목 이름·설명·조건(✓/✕). 오른쪽: 해금 버튼 하나 (320 폭) |

- 고른 항목은 늘 하나다. 노란 테두리로 표시하고, 아래 줄과 버튼이 그 항목을 말한다. 마우스를 올리는 것도 「고르기」다.
- 가격은 항목 옆과 버튼 두 곳에만 쓴다.
- 글자는 1440 프레임에서 18px 이상, 960×540에서 12px 이상이다. 어두운 패널 위 보조 글자는 `#C3CACC` 이상 밝게.
- 길게 누르기는 약 0.4초, 버튼이 왼쪽부터 차오른다.

## 해금 버튼 상태

| 상태 | 버튼 | 항목 표시 |
|---|---|---|
| 살 수 있음 | 진한 버튼 `[F 길게] 해금 · 80 안료` | 가격(검정) |
| 안료 부족 | 회색 「안료 30 부족」 | 가격 빨강 「· 부족」 — 고르지 않아도 보인다 |
| 챕터 잠김 | 회색 「2챕터 보스를 깨면 열려요」 | 자물쇠 + 「2챕터 보스 뒤」 (보급소는 가격도 같이) |
| 다 올림 | 회색 「다 올렸어요」 | 「완료 ✓」 (진하게, 잠김과 구분) |
| 해금 직후 | 회색 「해금함」 | 칸이 채워지고 안료 옆 `−80`, 「다음 런」 줄 갱신 |

- 해금은 **F를 길게(약 0.4초)** 눌러야 한다. 버튼이 왼쪽→오른쪽으로 차오른다. 창을 연 F를 떼기 전에는 입력을 받지 않는다(여는 F가 바로 구매로 새지 않게).
- 조건 표시는 ✓/✕ 기호 + 글자 굵기로 구분하고 색은 보조로만 쓴다.

## 보급소

줄 4개(출발 지원금, 공격력, 최대 체력, 색상 잉크 보관함). 줄마다 이름 · 단계 칸 · 「지금 → 다음」 · 가격.

- ↑↓로 줄을 고른다.
- 챕터에 걸린 줄도 가격을 보여 주고, 이미 산 단계 칸은 진하게 둔다. 조건만 자물쇠와 덧붙인다.

## 염색공방

- 갈래를 탭 3개로 나눈다: 색 변경권 · 리롤 · 팔레트. 탭 옆에 진행도(0/5). 탭은 **Q / E**로만 바꾼다(탭 줄 양옆에 키 표시, 패드는 LB/RB).
- 탭마다 작은 트리만 보인다. 칸은 아이콘 + 이름 + (가격 또는 잠김 조건).
- 다른 탭에 걸친 앞 조건은 트리 맨 앞 「먼저 필요」 칩으로 보인다. 칩에는 포커스가 가지 않는다.
- 챕터에 걸린 칸: 회색 칸 + 자물쇠 + 「N챕터 보스 뒤」. 앞 칸만 안 산 칸(챕터 조건 없음): 흰 점선 칸, 자물쇠 없음.

### 방향키 이동 규칙 (트리)

- 칸은 열 격자에 놓는다.
- → : 첫 자식(위쪽 우선). ← : 부모. 첫 열에서 ←는 아무것도 안 한다.
- ↑↓ : 같은 열 안에서만. 같은 열에 칸이 없으면 오른쪽 열에서 가장 가까운 칸.
- 끝에서 반대편으로 넘어가지 않는다. →로 탭을 넘지 않는다.
- 창을 처음 열면 살 수 있는 첫 칸, 없으면 첫 칸. 탭마다 마지막으로 고른 칸을 기억한다.

### 설명 문구

- 「무기 N 첫 칸 무색」: 무색 칸은 다섯 색 중 원하는 색의 잉크를 끼울 수 있는 자유 칸이다(팀 `ink-blueprint-proposal.md` · `dcccf936`). 설명은 「첫 칸에 원하는 색 잉크」로 쓴다.

## 회수공방 (다음)

항목이 하나(파괴 +20G)라 탭·트리 없이 같은 틀의 작은 창으로 만든다.

## 열린 질문

- 창 폭 900은 검토자 1명이 크다고 했다(640 제안). 18px 글자를 지키면서 줄일 수 있는지 테마 단계에서 다시 본다.
- 두 건물이 같은 안료를 쓰는데 한 화면에서 비교할 수 없다는 의견이 있었다. 지금은 「지난 런 +N」만 둔다.
