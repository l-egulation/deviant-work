# 스토리 작업 인수인계

## 역할

이규재가 맡은 스토리 디자인. 지금은 보류 중이다. 다시 시작하면 팀 확정 이야기 위에서 빈 부분을 채운다.

## 다시 시작할 때 먼저 읽을 것 (팀 레포, 읽기 전용)

- `docs/design/story/opening.md` — 초반 스토리 확정본
- `docs/design/story/opening-playable.md` — 오프닝 ①~⑥ 연출·튜토리얼 (④~⑥ 미구현), 말풍선/상단 배너 규칙
- `docs/design/systems/village-palette-pieces.md` — 마을 팔레트 조각과 마을 장인 회차별 장면
- `docs/design/story/maintenance-introductions.md` — 정비소 상인(1챕터 마을 장인, 2챕터 수로 정비공)
- `data/story/opening_playable.json` — 오프닝 비트 원본

## 주의

- 팀은 화자 머리 위 **말풍선**(이야기)과 화면 상단 **배너**(조작 안내)를 섞지 않는다.
- 깃털펜은 기획에서 제외됐다.
- 회귀의 대가·세계 시간·지워짐의 원인은 팀 미정이다. 임의로 확정하지 않고 제안으로 쓴다.
- 보관한 콘셉트북(`archive/2026-10-concept-v7/storybook.html`)은 이미지가 들어 있는 단일 HTML이다.
