# Deviant

**Deviant**는 잉크를 이용해 무기와 전투 방식을 구성하는 2D 액션 로그라이트 게임 프로젝트입니다. Unity로 제작 중입니다. 현재는 전투 플레이테스트와 무기 제작 규칙을 다듬는 단계이며, 상세 세계관·스토리 라인과 전체 사용자 흐름은 확정 전입니다.

## 현재 게임 구성 초안

- 도면이 기본 무기 종류를 정합니다. 흰색 잉크는 무기 형태, 검정 잉크는 특수 공격을 정합니다.
- 별도 팔레트에는 정해진 색상 칸과 무색 칸이 있으며, 색상 잉크 파츠로 추가 효과를 구성합니다. 팔레트 없이 도면 무기를 사용하는 방향도 포함됩니다.
- 직접 강화하는 대상은 도면입니다. 파츠는 더 좋은 개체를 얻어 교체하는 방향입니다.
- 두 무기 장착, 무기 분류, 보상과 런 종료 구조는 최신 제작안과 함께 다시 확인해야 합니다. 수치·콘텐츠 수·경제 규칙은 아직 확정하지 않았습니다.

이 설명은 진행 중인 **설계안**의 요약입니다. Unity에 모두 구현됐다는 뜻은 아닙니다.

## 저장소 사용

이 저장소는 3D 모델링 파일을 복제하지 않고, Deviant의 UI 디자인과 영상·사운드 작업을 공유하기 위한 가벼운 작업 공간입니다.

| 경로 / 브랜치 | 용도 |
|---|---|
| `work/ui-design`의 `ui/` | UI 계획, 사용자 흐름, 시안과 검증 기록 |
| `video/` | 트레일러·홍보 영상의 기획, 대본, 편집 프로젝트 안내 |
| `audio/` | 음악·효과음의 기획, 큐시트, 작업 안내 |
| 기본 브랜치 `master` | 공통 안내와 가벼운 문서 |

게임 코드와 빌드는 별도 SSAFY 저장소에, 3D 캐릭터 모델링은 `deviant-modeling` 저장소에 있습니다. 이 저장소에 임시 빌드·모델 가중치·대용량 렌더 파일을 복사하지 않습니다.

## 파일 원칙

- 기획서, HTML, 코드, 작은 참고 이미지는 Git으로 관리합니다.
- Unity의 `Library/`, 캐시, 임시 렌더, 다운로드 파일과 인증 정보는 커밋하지 않습니다.
- 큰 영상·무손실 사운드·편집 원본을 올릴 때는 먼저 용량과 공유 방식을 정합니다. 필요하면 Git LFS 또는 별도 아티팩트 저장소를 설정합니다. 현재 LFS 설정은 없습니다.
- 사용한 외부 에셋은 출처와 사용 범위를 해당 작업 폴더에 기록합니다.

## 현재 UI 작업

[UI 브랜치](https://github.com/l-egulation/deviant-work/tree/work/ui-design/ui)에서 첫 화면부터 정비·전투·보상 흐름을 설계합니다. 기존 임시 HUD와 팔레트 제작소 시연은 참고 자료이며 최종 화면이 아닙니다.
